# 8 角色定义与行为规范

(gbt-48336-404-2026-clause-8-2)=
## 8.2 位置信息管理节点

:::{div}
:class: standard-paragraph

<p>位置信息管理节点可运行位置信息管理服务的服务端。位置信息锚点和位置信息标签运行位置信息管理服务的客户端，并通过 SSAP 与位置信息管理节点进行数据传输和交互。</p>

:::

:::{div}
:class: standard-paragraph

<p>位置信息管理节点对应的配置如下。</p>

:::

:::{div}
:class: standard-list-block

<ul class="standard-list">
<li><p>—— 设备类型指示应指示该设备为位置信息管理节点。</p>
</li>
<li><p>—— 固定合作设备集合标识的值根据固定合作设备集合密钥产生，其中合作设备集合密钥可以使用合作设备集合管理服务流程配置或离线预配置。属于相同合作设备集合的设备，可以基于合作设备集合密钥对设备集合标识进行解析，解析通过即为相同合作设备集合的设备。位置信息管理服务可以包含多个固定合作设备集合标识。</p>
</li>
<li><p>—— 动态合作设备集合标识的值根据动态合作设备集合密钥产生，其中合作设备集合密钥可以使用合作设备集合管理服务流程配置或离线预配置，可以通过高层应用动态配置。属于相同合作设备集合的设备，可以基于合作设备集合密钥对设备集合标识进行解析，解析通过即为相同合作设备集合的设备。位置信息管理服务可以包含多个动态合作设备集合标识。</p>
</li>
<li><p>—— SLB 解算能力指示和/或 SLE 解算能力指示中，需指示一种或多种解算方法，其中解算方法包括，基于角度测量信息和距离测量信息进行位置解算、基于多个锚点的距离测量信息进行位置解算、基于多个锚点的角度测量信息进行位置解算等。</p>
</li></ul>

:::

:::{div}
:class: standard-list-block

<ul class="standard-list">
<li><p>—— 当位置信息管理节点支持位置信息测量时，应通过 SLB 测量能力指示或 SLE 测量能力指示指示支持的测量方法；当位置信息管理节点不支持位置信息测量时，位置信息管理服务中不包含SLB 测量能力指示和 SLE 测量能力指示属性。</p>
</li>
<li><p>—— 当位置管理节点支持位置信息测量时，可通过距离信息指示与位置信息标签的距离信息。</p>
</li>
<li><p>—— 当位置信息管理节点同时为位置信息锚点时，应通过锚点相对位置信息以及锚点绝对位置信息两个属性中的至少一个指示该锚点的位置；当位置信息管理节点不为位置信息锚点时，位置信息管理服务中不包含锚点相对位置信息以及锚点绝对位置信息属性。</p>
</li></ul>

:::

:::{div}
:class: standard-paragraph

<p>位置信息管理节点运行的位置信息管理服务中，不包含标签相对位置信息以及标签绝对位置信息属性。</p>

:::

(gbt-48336-404-2026-clause-8-3)=
## 8.3 位置信息锚点

:::{div}
:class: standard-paragraph

<p>位置信息锚点可运行位置信息管理服务的服务端。位置信息管理节点运行位置信息管理服务的客户端，并通过 SSAP 与位置信息锚点进行位置信息管理服务的数据传输和交互。</p>

:::

:::{div}
:class: standard-paragraph

<p>位置信息锚点对应的配置如下。</p>

:::

:::{div}
:class: standard-list-block

<ul class="standard-list">
<li><p>—— 设备类型指示应指示该设备为位置信息锚点。</p>
</li>
<li><p>—— 固定合作设备集合标识的值根据固定合作设备集合密钥产生，其中合作设备集合密钥可以使用合作设备集合管理服务流程配置，或者离线预配置。属于相同合作设备集合的设备，可以基于合作设备集合密钥对设备集合标识进行解析，解析通过即为相同合作设备集合的设备。位置信息管理服务可以包含多个固定合作设备集合标识。</p>
</li>
<li><p>—— 动态合作设备集合标识的值根据动态合作设备集合密钥产生，其中合作设备集合密钥可以使用合作设备集合管理服务流程配置，可以离线预配置，可以通过高层应用动态配置。属于相同合作设备集合的设备，可以基于合作设备集合密钥对设备集合标识进行解析，解析通过即为相同合作设备集合的设备。位置信息管理服务可以包含多个动态合作设备集合标识。</p>
</li>
<li><p>—— SLB 测量能力指示和/或 SLE 测量能力指示指示支持的测量方法。</p>
</li>
<li><p>—— 锚点相对位置信息以及锚点绝对位置信息两个属性中的至少一个指示该锚点的位置。</p>
</li>
<li><p>—— 可选的，距离信息指示与位置信息标签的距离信息。</p>
</li>
<li><p>—— 当位置信息锚点同时为位置信息管理节点时，应通过 SLB 解算能力指示和/或 SLE 解算能力指示一种或多种解算方法，其中解算方法包括，基于角度测量信息和距离测量信息进行位置解算、基于多个锚点的距离测量信息进行位置解算、基于多个锚点的角度测量信息进行位置解算等。</p>
</li>
<li><p>—— 当位置信息锚点不为位置信息管理节点时，如果位置信息锚点支持位置信息解算，应通过 SLB解算能力指示和/或 SLE 解算能力指示一种或多种解算方法，其中解算方法包括，基于角度测量信息和距离测量信息进行位置解算、基于多个锚点的距离测量信息进行位置解算、基于多个锚点的角度测量信息进行位置解算等，如果位置信息锚点不支持位置信息解算，位置信息管理服务中不包含 SLB 解算能力指示和 SLE 解算能力指示属性。</p>
</li></ul>

:::

:::{div}
:class: standard-paragraph

<p>位置信息锚点运行的位置信息管理服务中，不包含标签相对位置信息以及标签绝对位置信息属性。</p>

:::

## 8.4 位置信息标签

:::{div}

<p>位置信息标签对应的配置如下。</p>

:::{div}
:class: standard-list-block

<li><p>—— 当位置信息标签配置有固定合作设备集合密钥时，固定合作设备集合标识的值根据固定合作设</p>
</li></ul>

:::

:::{div}
:class: standard-paragraph

<p>备集合密钥产生，其中合作设备集合密钥可以使用合作设备集合管理服务流程配置，或者离线预配置。属于相同合作设备集合的设备，可以基于合作设备集合密钥对设备集合标识进行解析，解析通过即为相同合作设备集合的设备。位置信息管理服务可以包含多个固定合作设备集合标识。</p>

:::

:::{div}
:class: standard-list-block

<ul class="standard-list">
<li><p>—— 当位置信息标签配置有动态合作设备集合密钥时，动态合作设备集合标识的值根据动态合作设备集合密钥产生，其中合作设备集合密钥可以使用合作设备集合管理服务流程配置，可以离线预配置，可以通过高层应用动态配置。属于相同合作设备集合的设备，可以基于合作设备集合密钥对设备集合标识进行解析，解析通过即为相同合作设备集合的设备。位置信息管理服务可以包含多个动态合作设备集合标识。</p>
</li>
<li><p>—— SLB 测量能力指示和/或 SLE 测量能力指示指示支持的测量方法。</p>
</li>
<li><p>—— 标签相对位置信息以及标签绝对位置信息两个属性中的至少一个指示该标签的位置。</p>
</li>
<li><p>—— 当位置信息标签支持位置信息解算时，应通过 SLB 解算能力指示和/或 SLE 解算能力指示一种或多种解算方法，其中解算方法包括基于角度测量信息和距离测量信息进行位置解算、基于多个锚点的距离测量信息进行位置解算、基于多个锚点的角度测量信息进行位置解算等，当位置信息标签不支持位置信息解算时，位置信息管理服务中不包含 SLB 解算能力指示和 SLE 解算能力指示属性。</p>
</li></ul>

:::

:::{div}
:class: standard-paragraph

<p>位置信息标签运行的位置信息管理服务中，不包含锚点相对位置信息和锚点绝对位置信息属性。</p>

## 8.5 复合设备

:::{div}
:class: standard-paragraph

<p>位置信息管理节点可以同时为位置信息锚点。同时为位置信息管理节点和位置信息锚点的设备，应符合 8.2 和 8.3 的要求。</p>

:::

:::{div}
:class: standard-paragraph

<p>位置信息管理节点可以同时为位置信息标签。同时为位置信息管理节点和位置信息标签的设备，应符合 8.2 和 8.4 的要求。</p>

:::

:::{div}
:class: standard-paragraph

<p>位置信息锚点和位置信息标签不可同时互为锚点和标签。</p>

:::

## 8.6 设备初始化

(gbt-48336-404-2026-clause-8-6-1)=
### 8.6.1 位置信息管理节点初始化

:::{div}
:class: standard-paragraph

<p>位置信息管理节点的设备类型指示、SLB 测量能力指示、SLE 测量能力指示、SLB 解算能力指示、SLE 解算能力指示属性值应进行配置，其中 SLB 测量能力指示、SLE 测量能力指示、SLB 解算能力指示、SLE 解算能力指示属性值应与接入层能力和应用能力匹配。</p>

:::

:::{div}
:class: standard-paragraph

<p>位置信息管理节点可配置固定合作设备集合密钥和/或动态合作设备集合密钥。位置信息管理节点根据合作设备集合密钥生成设备集合标识。</p>

:::

:::{div}
:class: standard-paragraph

<p>在一个位置信息管理合作设备集合中，需配置 1 个位置信息管理节点。</p>

:::

(gbt-48336-404-2026-clause-8-6-2)=
### 8.6.2 位置信息锚点初始化

:::{div}
:class: standard-paragraph

<p>位置信息锚点的设备类型指示、SLB 测量能力指示、SLE 测量能力指示、SLB 解算能力指示、SLE解算能力指示、锚点相对位置信息属性的值应进行配置，其中测量能力指示、解算能力指示属性的值应与接入层能力和应用能力匹配。</p>

:::

:::{div}
:class: standard-paragraph

<p>位置信息锚点可配置固定合作设备集合密钥和/或动态合作设备集合密钥。位置信息锚点根据合作设备集合密钥生成设备集合标识。</p>

:::

:::{div}
:class: standard-paragraph

<p>构建载体坐标系方案有以下几种。</p>

:::

:::{div}
:class: standard-list-block

<ul class="standard-list">
<li><p>—— 多锚点构建$xoy$平面：至少 3 个锚点的$z$坐标为 0，三个锚点构成笛卡尔坐标系的$xoy$平面。</p>
</li></ul>

:::

:::{div}
:class: standard-paragraph

<p>3 个锚点中，其中两个锚点的$y$坐标为 0，两个锚点的两个坐标的连线即为$x$坐标轴，并根据$x$坐标的从小到大的方向确定$x$坐标轴的方向，另外一个锚点的$x$坐标为 0，锚点与$x$坐标轴的垂线即为$y$坐标轴，并根据该锚点$y$坐标的正负值确定$y$坐标轴的方向。根据已经确定的$x$坐标轴和$y$坐标轴，通过右手坐标系确定$z$坐标轴及其方向，从而完成笛卡尔坐标系的构建。</p>

:::

:::{div}
:class: standard-list-block

<ul class="standard-list">
<li><p>—— 单锚点构建本地坐标系。</p>
</li>
<li><p>—— 位置信息管理节点为载体笛卡尔坐标系原点，$x$轴、$y$轴、$z$轴方向取决于应用实现。</p>
</li>
<li><p>—— 其他坐标系。</p>
</li></ul>

:::

(gbt-48336-404-2026-clause-8-7)=
## 8.7 设备接入

:::{div}
:class: standard-paragraph

<p>位置信息管理节点执行设备发现过程见第 7 章，其中公开信息应包含设备类型指示、SLB 解算能力指示和/或 SLE 解算能力指示等属性的数据。公开信息中可选包含固定合作设备集合标识和/或动态合作设备集合标识、SLB 测量能力指示、SLE 测量能力指示。当位置信息管理节点同时为位置信息锚点时，公开信息中可选包含锚点相对位置信息和锚点绝对位置信息等属性的数据。位置信息锚点或位置信息标签通过广播的公开信息识别位置信息管理节点后，位置信息锚点或位置信息标签应与位置信息管理节点执行空口接入流程。在接入流程中，位置信息锚点和位置信息标签是接入层 T 节点，位置信息管理节点是接入层 G 节点。</p>

:::

:::{div}
:class: standard-paragraph

<p>位置信息锚点执行设备发现过程见第 7 章，其中公开信息应包含设备类型指示、SLB 测量能力指示和/或 SLE 测量能力指示等属性的数据。公开信息中可选包含固定合作设备集合标识、SLB 解算能力指示、SLE 解算能力指示、锚点相对位置信息和锚点绝对位置信息等属性的数据。位置信息管理节点通过广播的公开信息识别位置信息锚点后，位置信息管理节点应与位置信息锚点执行空口接入流程。在接入流程中，位置信息锚点是接入层 T 节点，位置信息管理节点是接入层 G 节点。</p>

:::

:::{div}
:class: standard-paragraph

<p>位置信息标签执行设备发现过程见第 7 章，其中公开信息应包含设备类型指示、SLB 测量能力指示和/或 SLE 测量能力指示等属性的数据。公开信息中可选包含固定合作设备集合标识和/或动态合作设备集合标识、SLB 解算能力指示、SLE 解算能力指示、标签相对位置信息和标签绝对位置信息等属性的数据。位置信息管理节点通过广播的公开信息识别位置信息标签后，位置信息管理节点应与位置信息标签执行空口接入流程。在接入流程中，位置信息锚点是接入层 T 节点，位置信息管理节点是接入层 G节点。</p>

:::

:::{div}
:class: standard-paragraph

<p>位置信息管理节点同时为位置信息锚点时，该节点执行设备发现过程见第 7 章，其中公开信息应包含设备类型指示、SLB 解算能力指示和/或 SLE 解算能力指示、SLB 测量能力指示和/或 SLE 测量能力指示等属性的数据。公开信息中可选包含固定合作设备集合标识和/或动态合作设备集合标识、锚点相对位置信息和锚点绝对位置信息、距离信息等属性的数据。其他位置信息锚点或位置信息标签通过广播的公开信息识别该节点后，其他位置信息锚点或位置信息标签应与该节点执行空口接入流程。在接入流程中，该节点是接入层 G 节点，其他位置信息锚点和位置信息标签是接入层 T 节点。</p>

:::

:::{div}
:class: standard-paragraph

<p>位置信息管理节点同时为位置信息标签时，该节点执行设备发现过程见第 7 章，其中公开信息应包含设备类型指示、SLB 解算能力指示和/或 SLE 解算能力指示、SLB 测量能力指示和/或 SLE 测量能力指示等属性的数据。公开信息中可选包含固定合作设备集合标识和/或动态合作设备集合标识、标签相对位置信息和标签绝对位置信息等属性的数据。其他位置信息锚点或其他位置信息标签通过广播的公开信息识别该节点后，其他位置信息锚点或其他位置信息标签应与该节点执行空口接入流程。在接入流程中，该节点是接入层 G 节点，其他位置信息锚点或其他位置信息标签是接入层 T 节点。</p>
