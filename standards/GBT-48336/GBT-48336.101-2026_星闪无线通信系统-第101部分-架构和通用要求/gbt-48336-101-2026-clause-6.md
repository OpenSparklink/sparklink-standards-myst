# 6 架构

(gbt-48336-101-2026-clause-6-1)=
## 6.1 系统架构

:::{div}
:class: standard-paragraph

<p>星闪无线通信系统的整体系统架构见图 1。</p>

:::

:::{div}
:class: standard-list-block

<ul class="standard-list">
<li><p>—— 接入层包含 SLB、SLE 和 SLP。DLI 定义了基础服务层与接入层之间数据和信息交互的格式</p>
</li></ul>

:::

:::{div}
:class: standard-paragraph

<p>以及相应物理接口使用方式。SLB 和 SLE 由物理层和数据链路层构成，SLP 仅包含物理层。</p>

:::

:::{div}
:class: standard-paragraph

<p>SLB、SLE、SLP 和 DLI 的功能见 6.2.1。</p>

:::

:::{div}
:class: standard-list-block

<ul class="standard-list">
<li><p>—— 基础服务层可由一系列基础功能单元构成，各功能单元的具体功能见 6.2.2，其中：</p>
<ul class="standard-list">
<li><p>• 设备发现功能单元、服务管理功能单元、连接管理功能单元、测量管理功能单元、QoS 管理功能单元、安全管理功能单元构成了星闪无线通信系统的无线短距通用控制面；其中连接管理功能单元、测量管理功能及 QoS 管理单元为基础服务层提供基本管理服务，属于通用管理功能；</p>
</li>
<li><p>• 多域协调与管理功能单元和 5G 蜂窝网络融合功能单元为可选功能单元，属于星闪无线通信系统扩展控制面；</p>
</li>
<li><p>• 数据传输与适配功能单元负责数据封装等用户面功能，支持承载包括控制类数据、广播类数据、实时数据、可靠数据和透传数据在内的业务数据传输；</p>
</li>
<li><p>• 网络功能包括拓扑配置协议、无线邻居协议、多跳组网安全、无线网络协议、路由协议、网络服务发现与访问、网络错误与诊断、网络节能等内容，提供多跳组网能力；</p>
</li>
<li><p>• 传输功能支持点对点和多跳网络，提供面向连接或无连接的传输机制；</p>
</li>
<li><p>• 基础服务层也支持 TCP、UDP 和 IP 等传输协议。</p>
</li></ul>
</li>
<li><p>—— 基础应用层由原子能力协议以及应用协议构成，具体功能见 6.2.3。</p>
</li></ul>

:::

## 6.2 各协议层功能

(gbt-48336-101-2026-clause-6-2-1)=
### 6.2.1 接入层功能

(gbt-48336-101-2026-clause-6-2-1-1)=
#### 6.2.1.1 星闪同步低时延宽带（SLB）模式

:::{div}
:class: standard-paragraph

<p>SLB 的接入层包含物理层和数据链路层，其中 SLB 数据链路层包含媒体接入层和链路控制层。</p>

:::

:::{div}
:class: standard-paragraph

<p>SLB 物理层支持以下功能：</p>

:::

:::{div}
:class: standard-list-block

<ul class="standard-list">
<li><p>—— 传输信息的正确性校验并指示给数据链路层；</p>
</li>
<li><p>—— 传输信息的前向纠错编码/解码；</p>
</li>
<li><p>—— 混合自动重传请求软合并；</p>
</li>
<li><p>—— 传输信息到对应的物理资源的速率匹配；</p>
</li>
<li><p>—— 编码后的传输信息到对应的物理资源的映射；</p>
</li>
<li><p>—— 物理层控制信息和物理层数据信息的调制和解调；</p>
</li>
<li><p>—— 频率和时间的同步；</p>
</li>
<li><p>—— 无线特性测量并指示给数据链路层；</p>
</li>
<li><p>—— 多输入多输出天线处理；</p>
</li>
<li><p>—— 波束赋形；</p>
</li>
<li><p>—— 射频处理。</p>
</li></ul>

:::

:::{div}
:class: standard-paragraph

<p>SLB 的媒体接入层支持以下功能：</p>

:::

:::{div}
:class: standard-list-block

<ul class="standard-list">
<li><p>—— 对不同逻辑信道的数据进行复用，生成传输块，并递交到物理层；</p>
</li>
<li><p>—— 对链路控制层 PDU 数据进行级联；</p>
</li>
<li><p>—— 物理层传递的传输块进行解复用，并递交到不同的逻辑信道；</p>
</li>
<li><p>—— 随机接入过程；</p>
</li>
<li><p>—— 资源请求过程；</p>
</li>
<li><p>—— 混合自动重传请求；</p>
</li>
<li><p>—— 逻辑信道优先级机制；</p>
</li>
<li><p>—— 链路控制层数据量报告；</p>
</li>
<li><p>—— 非连续接收；</p>
</li>
<li><p>—— 数据透传。</p>
</li></ul>

:::

:::{div}
:class: standard-paragraph

<p>SLB 的链路控制层支持以下功能：</p>

:::

:::{div}
:class: standard-list-block

<ul class="standard-list">
<li><p>—— 传输基础服务层 PDU；</p>
</li>
<li><p>—— 对传输模式 1 类型的数据，进行自动重传请求状态报告；</p>
</li>
<li><p>—— 对链路控制层 SDU 进行切分和重组；</p>
</li>
<li><p>—— 对链路控制层 SDU 进行重分段；</p>
</li>
<li><p>—— 基础服务层 PDU 重复检测；</p>
</li>
<li><p>—— 基础服务层 PDU 重排序；</p>
</li>
<li><p>—— 链路管理功能；</p>
</li>
<li><p>—— 加解密；</p>
</li>
<li><p>—— 完整性保护；</p>
</li>
<li><p>—— 数据透传。</p>
</li></ul>

:::

:::{div}
:class: standard-paragraph

<p>SLB 接入层还支持 G 节点和 T 节点之间的以下控制管理功能：</p>

:::

:::{div}
:class: standard-list-block

<ul class="standard-list">
<li><p>—— 通信域系统消息广播；</p>
</li></ul>

:::

:::{div}
:class: standard-list-block

<ul class="standard-list">
<li><p>—— 连接建立、重配置、拒绝、释放；</p>
</li>
<li><p>—— 认证与安全机制更新；</p>
</li>
<li><p>—— 资源配置；</p>
</li>
<li><p>—— 状态管理；</p>
</li>
<li><p>—— 测量与上报；</p>
</li>
<li><p>—— T 节点能力上报；</p>
</li>
<li><p>—— 辅助信息上报。</p>
</li></ul>

:::

(gbt-48336-101-2026-clause-6-2-1-2)=
#### 6.2.1.2 星闪同步低功耗（SLE）模式

:::{div}
:class: standard-paragraph

<p>SLE 的物理层支持以下功能：</p>

:::

:::{div}
:class: standard-list-block

<ul class="standard-list">
<li><p>—— 非链接态同步广播数据传输（如视频流、音频流等）；</p>
</li>
<li><p>—— 非链接态异步广播数据传输（如节点业务信息、温度信息、湿度信息、传感器信息等）；</p>
</li>
<li><p>—— 非链接态的广播发现过程，通过广播流程获取节点信息（如节点业务信息等）；</p>
</li>
<li><p>—— 链接态同步广播数据传输（如视频流、音频流等）；</p>
</li>
<li><p>—— 采用 GFSK 波形的无线帧类型 1；</p>
</li>
<li><p>—— 使用在低时延传输、高频率交互场景中的无线帧类型 2；</p>
</li>
<li><p>—— 使用在常规覆盖场景下的无线帧类型 3；</p>
</li>
<li><p>—— 使用在扩展覆盖场景下的无线帧类型 4；</p>
</li>
<li><p>—— 单播；</p>
</li>
<li><p>—— 基于确认应答/否定应答反馈的可靠组播；</p>
</li>
<li><p>—— 传输信息的前向纠错编码/解码；</p>
</li>
<li><p>—— 重传合并；</p>
</li>
<li><p>—— 用于灵活配置物理层资源的系统管理帧；</p>
</li>
<li><p>—— 不同测量模式或阶段使用的四种测量帧类型。</p>
</li></ul>

:::

:::{div}
:class: standard-paragraph

<p>SLE 数据链路层数据面支持以下功能：</p>

:::

:::{div}
:class: standard-list-block

<ul class="standard-list">
<li><p>—— 非周期同步广播数据传输；</p>
</li>
<li><p>—— 周期同步广播数据传输；</p>
</li>
<li><p>—— 数据包的分段和重组；</p>
</li>
<li><p>—— 数据面信息与控制面信息的复用；</p>
</li>
<li><p>—— 加解密；</p>
</li>
<li><p>—— 完整性保护。</p>
</li></ul>

:::

:::{div}
:class: standard-paragraph

<p>SLE 数据链路层控制面支持以下功能：</p>

:::

:::{div}
:class: standard-list-block

<ul class="standard-list">
<li><p>—— 数据链路物理层参数交互和更新；</p>
</li>
<li><p>—— 节点特性交互；</p>
</li>
<li><p>—— 节点版本交互；</p>
</li>
<li><p>—— 信道质量上报；</p>
</li>
<li><p>—— 功率控制；</p>
</li>
<li><p>—— 休眠与唤醒；</p>
</li>
<li><p>—— 测量与上报。</p>
</li></ul>

:::

</li>

</li></ul>

:::

:::{div}
:class: standard-paragraph

<p>服务管理功能单元用于设备内部的服务管理及维护以及设备之间的服务发现，支持以下功能：</p>

:::

:::{div}
:class: standard-list-block

</li>
<li><p>—— 设备间的服务发现；</p>
</li>
<li><p>—— 设备间的属性读取；</p>
</li>
<li><p>—— 设备间的属性写入；</p>
</li>
<li><p>—— 设备间的交互信息错误处理；</p>
</li>
<li><p>—— 服务端的通知与指示；</p>
</li>
<li><p>—— 方法交互操作；</p>
</li>
<li><p>—— 事件上报操作。</p>
</li></ul>

:::

(gbt-48336-101-2026-clause-6-2-2-3)=
#### 6.2.2.3 连接管理功能单元

:::{div}
:class: standard-paragraph

<p>连接管理功能单元支持以下功能：</p>

:::

:::{div}
:class: standard-list-block

<ul class="standard-list">

</li>

</li>

</li>
<li><p>—— 与接入层接口信息交互的维护。</p>
</li></ul>

:::

(gbt-48336-101-2026-clause-6-2-2-4)=
#### 6.2.2.4 QoS 管理功能单元

:::{div}
:class: standard-paragraph

<p>QoS 管理功能单元可根据业务传输需求以及网络状况等因素确定星闪无线通信系统需要提供的服务质量，确保星闪无线通信系统的传输能力与业务需求相匹配。QoS 管理功能单元具备以下功能：</p>

:::

:::{div}
:class: standard-list-block

<ul class="standard-list">
<li><p>—— 传输通道的 QoS 参数配置；</p>
</li>
<li><p>—— 管理并维护业务流与传输通道的 QoS 映射规则；</p>
</li>
<li><p>—— 指示连接管理功能单元建立新的传输通道或更改传输通道映射关系；</p>
</li>
<li><p>—— 基于 QoS 流的流量监控。</p>
</li></ul>

:::

(gbt-48336-101-2026-clause-6-2-2-5)=
#### 6.2.2.5 测量管理功能单元

:::{div}
:class: standard-paragraph

<p>测量管理功能单元支持以下功能：</p>

:::

:::{div}
:class: standard-list-block

<ul class="standard-list">
<li><p>—— 触发接入层测量物理层信号质量；</p>

</li>
<li><p>—— 为其他基础服务层功能单元（如 QoS 管理功能单元、5G 融合功能单元等）或授权应用提供统一的测量服务接口。允许其向测量管理功能单元提供测量配置信息并对测量结果进行查询。</p>
</li></ul>

:::

(gbt-48336-101-2026-clause-6-2-2-8)=
#### 6.2.2.8 5G 蜂窝网络融合功能单元

:::{div}
:class: standard-paragraph

:::

:::{div}
:class: standard-list-block

<ul class="standard-list">
<li><p>—— 可信 G 节点的选择；</p>
</li>
<li><p>—— T 节点或者 G 节点的注册；</p>
</li>
<li><p>—— QoS 策略的下发；</p>
</li>
<li><p>—— 远程状态查询。</p>
</li></ul>

:::

(gbt-48336-101-2026-clause-6-2-2-9)=
#### 6.2.2.9 数据传输与适配功能单元

:::{div}
:class: standard-paragraph

<p>数据传输与适配功能单元负责执行基础服务层的用户面操作，支持以下功能：</p>

:::

:::{div}
:class: standard-list-block

<ul class="standard-list">
<li><p>—— 对发送端基础服务层 SDU 进行分包处理；</p>
</li>
<li><p>—— 发送端基础服务层 SDU 进行向下透传处理；</p>
</li></ul>

:::

:::{div}
:class: standard-list-block

<ul class="standard-list">
<li><p>—— 发送端基础服务层多个 SDU 进行聚合处理；</p>
</li>
<li><p>—— 数据重传；</p>

### 6.2.3 基础应用层功能

(gbt-48336-101-2026-clause-6-2-3-1)=
#### 6.2.3.1 应用协议

:::{div}
:class: standard-paragraph

<p>应用协议面向特定场景定义两个或多个设备的角色、每个角色的功能及设备之间的交互行为，也定义每个角色完成业务所需的基础服务层和接入层的能力和具体参数配置。根据服务的业务类型不同，应用包含音频、视频、控制、数传、定位和感知等。</p>

:::

(gbt-48336-101-2026-clause-6-2-3-2)=
#### 6.2.3.2 原子能力协议

:::{div}
:class: standard-paragraph

<p>原子能力协议定义应用所使用的基础与通用性的功能，以及完成这个功能涉及的控制信令与交互流程。原子能力协议具有通用性、独立性。一个原子能力协议可服务多个应用协议，一个应用协议也可调用多个原子能力协议。</p>

:::

(gbt-48336-101-2026-clause-6-3-2)=
### 6.3.2 业务流

:::{div}
:class: standard-paragraph

<p>业务流由基础应用层定义并维护，是用于承载业务数据传输的最小单位。业务流通过端口（Port）进行识别，一条业务流在本端和对端使用的端口可独立维护。一条业务流中的数据通过用户面服务接入节点递交给基础服务层。</p>

:::

(gbt-48336-101-2026-clause-6-3-3)=
### 6.3.3 传输通道

:::{div}
:class: standard-paragraph

<p>传输通道由基础服务层的数据传输与适配功能单元定义并维护，用于承载不同星闪设备之间基础应用层或者基础服务层功能单元的数据交互。</p>

:::

:::{div}
:class: standard-paragraph

<p>传输通道通过 TCID 进行识别。基础服务层会为与它连接的同一个星闪设备的每一条传输通道在本侧建立并维护唯一的 TCID。</p>

:::

:::{div}
:class: standard-paragraph

<p>传输通道根据维护方式的不同分为缺省方式和非缺省方式两种。</p>

:::

:::{div}
:class: standard-list-block

<ul class="standard-list">
<li><p>—— 缺省方式：传输通道使用预先定义好的固定 TCID，该传输通道具有默认的配置参数。数据传输与适配功能单元在接入层逻辑链路建立完成后可自动建立并使用该类传输通道，星闪设备之间可不进行配置信令协商。</p>
</li>
<li><p>—— 非缺省方式：传输通道使用的 TCID、传输通道的配置参数以及传输通道的建立与释放等操作，应基于连接管理功能单元之间的配置信令协商结果。</p>
</li></ul>

:::

:::{div}
:class: standard-paragraph

<p>为了适配不同业务的传输需求，星闪无线通信系统为传输通道定义了四种传输模式：基础模式、透传模式、流模式和可靠模式，每种传输模式的主要特性见表 1。从控制面角度，连接管理功能单元负责根据业务的 QoS 需求为业务数据配置匹配传输模式的传输通道；从数据传输角度，数据传输与适配功能单元负责基于被配置的传输模式及相关参数对传输通道内的业务数据执行具体的用户面操作。</p>

:::
