(gbt-48336-101-2026-clause-3)=
# 3 术语和定义

:::{div}
:class: standard-paragraph

<p>下列术语和定义适用于本文件。</p>

:::

(gbt-48336-101-2026-clause-3-1)=
## 3.1 星闪无线通信系统 SparkLink wireless communication system

:::{div}
:class: standard-paragraph

<p>支持极化码通信、定位、感知，能快速切换频率、精确同步的无线短距离通信系统。</p>

:::

(gbt-48336-101-2026-clause-3-2)=
## 3.2 管理节点 grant⁃node

:::{div}
:class: standard-paragraph

<p>G<strong> </strong><strong>节点</strong>星闪无线通信系统（3.1）发送资源管理信息的节点。</p>

:::

(gbt-48336-101-2026-clause-3-3)=
## 3.3 终端节点 terminal node

:::{div}
:class: standard-paragraph

<p>T<strong> </strong><strong>节点</strong>星闪无线通信系统（3.1）接收资源管理信息，根据资源管理信息发送数据的节点。</p>

:::

(gbt-48336-101-2026-clause-3-4)=
## 3.4 管理节点方向通信链路 communication link for transmission from grant node to terminal node

:::{div}
:class: standard-paragraph

<p>G<strong> </strong><strong>链路</strong>管理节点（3.2）到终端节点（3.3）的通信链路。</p>

:::

(gbt-48336-101-2026-clause-3-5)=
## 3.5 终端节点方向通信链路 communication link for transmission from terminal node to grant node

:::{div}
:class: standard-paragraph

<p>T<strong> </strong><strong>链路</strong>终端节点（3.3）到管理节点（3.2）的通信链路。</p>

:::

(gbt-48336-101-2026-clause-3-6)=
## 3.6 管理节点符号 symbol for transmission from grant node to terminal node

:::{div}
:class: standard-paragraph

<p>G<strong> </strong><strong>符号</strong>承载 G 链路（3.4）传输的循环前缀正交频分复用（CP⁃OFDM）符号。</p>

:::

(gbt-48336-101-2026-clause-3-7)=
## 3.7 终端节点符号 symbol for transmission from terminal node to grant node

:::{div}
:class: standard-paragraph

<p>T<strong> </strong><strong>符号</strong>承载终端 T 链路（3.5）传输的 CP⁃OFDM 符号。</p>

:::

(gbt-48336-101-2026-clause-3-8)=
## 3.8 通信域 communication domain

:::{div}
:class: standard-paragraph

<p>SLB 通信系统中单个 G 节点（3.2）管理的资源集合。</p>

:::

:::{admonition} 注
:class: note

<p>一个通信域由该通信域的 G 链路、T 链路和附链路资源组成。</p>

:::

(gbt-48336-101-2026-clause-3-9)=
## 3.9 超帧 super frame

:::{div}
:class: standard-paragraph

<p>SLB 通信系统中由 8 个无线帧组成的时间周期结构。</p>

:::

(gbt-48336-101-2026-clause-3-10)=
## 3.10 位置解算节点 position computing node

:::{div}
:class: standard-paragraph

<p>根据一个或多个距离/角度/位置信息，确定位置标签定位信息的节点。</p>

:::

(gbt-48336-101-2026-clause-3-11)=
## 3.11 感知请求节点 sensing request node

:::{div}
:class: standard-paragraph

<p>发起感知测量过程并期望获得感知结果的节点。</p>

:::

(gbt-48336-101-2026-clause-3-12)=
## 3.12 感知管理节点 sensing management node

:::{div}
:class: standard-paragraph

<p>为感知测量过程配置资源的节点。</p>

:::

(gbt-48336-101-2026-clause-3-13)=
## 3.13 默认承载 default bearer

:::{div}
:class: standard-paragraph

<p>具备默认的 QoS 参数配置，为基础服务层各功能单元的控制信令类数据传输提供服务的逻辑信道（3.14）。</p>

:::

(gbt-48336-101-2026-clause-3-14)=
## 3.14 逻辑信道 logical channel

:::{div}
:class: standard-paragraph

<p>星闪无线通信系统（3.1）接入层为基础服务层提供数据传输服务的数据通道。</p>

:::

(gbt-48336-101-2026-clause-3-15)=
## 3.15 信道占用时间 channel occupancy time

:::{div}
:class: standard-paragraph

<p>SLB 通信系统在非连续传输模式下，从竞争信道成功后的第一个无线帧开始，到所有基础载波都释放信道之前的最后一个无线帧（含）为止的全部整数个无线帧。</p>

:::

(gbt-48336-101-2026-clause-3-16)=
## 3.16 传输时间间隔 transmission time interval

:::{div}
:class: standard-paragraph

<p>SLB 通信系统传输块集的到达时间间隔。</p>

:::

(gbt-48336-101-2026-clause-3-17)=
## 3.17 基础信道 basic channel

:::{div}
:class: standard-paragraph

<p>SLB 通信系统工作频段划分最小频域资源单元。</p>

:::

(gbt-48336-101-2026-clause-3-18)=
## 3.18 信道 channel

:::{div}
:class: standard-paragraph

<p>星闪无线通信系统（3.1）工作所占用频率资源。</p>

:::

(gbt-48336-101-2026-clause-3-19)=
## 3.19 子载波 subcarrier

:::{div}
:class: standard-paragraph

<p>SLB 通信系统物理层最小频域资源单元。</p>

:::

(gbt-48336-101-2026-clause-3-20)=
## 3.20 载波 carrier

:::{div}
:class: standard-paragraph

<p>星闪无线通信系统（3.1）物理层用于承载信息的频域资源。</p>

:::

:::{admonition} 注
:class: note

<p>SLB 通信系统中，载波包含若干个基础载波。</p>

:::

(gbt-48336-101-2026-clause-3-21)=
## 3.21 基础载波 basic carrier

:::{div}
:class: standard-paragraph

<p>SLB 通信系统物理层中基础信道内所有子载波组成的频域资源。</p>

:::

(gbt-48336-101-2026-clause-3-22)=
## 3.22 有效子载波 valid subcarrier

:::{div}
:class: standard-paragraph

<p>SLB 通信系统物理层可用于映射数据或信号的子载波。</p>

:::

(gbt-48336-101-2026-clause-3-23)=
## 3.23 中心子载波 center subcarrier

:::{div}
:class: standard-paragraph

<p>SLB 通信系统物理层处于基础载波中心的子载波。</p>

:::

(gbt-48336-101-2026-clause-3-24)=
## 3.24 分隔子载波 isolation subcarrier

:::{div}
:class: standard-paragraph

<p>SLB 通信系统物理层中用于分隔相邻基础载波的子载波。</p>

:::

(gbt-48336-101-2026-clause-3-25)=
## 3.25 功能单元 functional unit

:::{div}
:class: standard-paragraph

<p>星闪无线通信系统（3.1）基础服务层定义的负责特定功能或操作的逻辑功能实体。</p>

:::

(gbt-48336-101-2026-clause-3-26)=
## 3.26 传输通道 transport channel

:::{div}
:class: standard-paragraph

<p>星闪无线通信系统（3.1）基础服务层为基础应用层提供数据传输服务的数据通道。</p>

:::

(gbt-48336-101-2026-clause-3-27)=
## 3.27 原子能力 atomic capability

:::{div}
:class: standard-paragraph

<p>抽象出来的基础与通用性的基础应用层功能。</p>

:::

(gbt-48336-101-2026-clause-3-28)=
## 3.28 发现方 discovery party

:::{div}
:class: standard-paragraph

<p>设备发现过程中，搜索其他设备及其公开信息的一方。</p>

:::

(gbt-48336-101-2026-clause-3-29)=
## 3.29 被发现方 discovered party

:::{div}
:class: standard-paragraph

<p>设备发现过程中，公开发现等级和设备信息的一方。</p>

:::

(gbt-48336-101-2026-clause-3-30)=
## 3.30 过滤条件 filter condition

:::{div}
:class: standard-paragraph

<p>针对设备公开信息提供的可过滤选项，通过逻辑“与”“或”“非”进行组合。</p>

:::

(gbt-48336-101-2026-clause-3-31)=
## 3.31 服务 service

:::{div}
:class: standard-paragraph

<p>服务端公开的一组能力信息或功能集合。</p>

:::

(gbt-48336-101-2026-clause-3-32)=
## 3.32 首要服务 primary service

:::{div}
:class: standard-paragraph

<p>服务端对外公开的能提供一组应用完整功能的服务集合。</p>

:::

(gbt-48336-101-2026-clause-3-33)=
## 3.33 次要服务 secondary service

:::{div}
:class: standard-paragraph

<p>不独立对外公开，为其他服务提供支撑性功能的服务。</p>

:::

(gbt-48336-101-2026-clause-3-34)=
## 3.34 高层信令 higher layer signaling

:::{div}
:class: standard-paragraph

<p>物理层之上的控制信息。</p>

:::
