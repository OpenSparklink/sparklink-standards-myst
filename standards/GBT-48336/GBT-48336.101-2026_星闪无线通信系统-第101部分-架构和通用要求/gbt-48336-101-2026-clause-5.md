# 5 概述

:::{div}
:class: standard-paragraph

<p>星闪无线通信系统由接入层、基础服务层及基础应用层三部分构成。</p>

:::

:::{div}
:class: standard-paragraph

<p>接入层实现业务数据在空口的传输交互。接入层根据实现功能的不同分为管理节点（G 节点）和终端节点（T 节点），其中 G 节点为其覆盖下的 T 节点提供连接管理、资源分配、信息安全等接入层服务。</p>

:::

:::{div}
:class: standard-paragraph

<p>基础服务层提供设备发现、服务管理、连接管理（建立、维护与释放）、QoS 管理、测量管理、信息安全、多跳组网、面向连接或无连接传输等功能，用于支撑从业务触发到业务结束的整个业务周期的连接交互需求。</p>

:::

:::{div}
:class: standard-paragraph

<p>基础应用层实现各类应用功能，其中，针对共性业务诉求，定义模块化的原子能力协议，供所有应用协议进行调用；基础应用层也面向具体场景定义应用协议，用于实现业务的端到端交互并且保证不同设备的互联互通。</p>

:::

:::{div}
:class: standard-paragraph

<p>星闪无线通信系统支持通信、定位和感知场景。</p>

:::

:::{div}
:class: standard-paragraph

<p>根据通信双方节点类型不同，星闪无线通信系统支持的通信场景分为：</p>

:::

:::{div}
:class: standard-list-block

<ul class="standard-list">
<li><p>—— 支持 G 节点和 T 节点之间的通信；</p>
</li>
<li><p>—— 支持不同通信域中 G 节点之间的通信；</p>
</li>
<li><p>—— 支持同一通信域内不同 T 节点之间通过 G 节点进行中继通信；</p>
</li>
<li><p>—— 支持同一通信域内不同 T 节点之间直接进行通信；</p>
</li>
<li><p>—— 支持任意两个节点之间进行直通通信；</p>
</li>
<li><p>—— 支持任意多个节点之间进行基于多跳网络拓扑的通信。</p>
</li></ul>

:::

:::{div}
:class: standard-paragraph

<p>星闪无线通信系统支持的定位场景分为：</p>

:::

:::{div}
:class: standard-list-block

<ul class="standard-list">
<li><p>—— 支持一个位置锚点与一个位置标签之间测量距离、到达角或离开角；</p>
</li>
<li><p>—— 支持至少一个位置锚点与多个位置标签之间并发测量距离、到达角或离开角，其中至少一个位置锚点与多个位置标签构成一个测量组；</p>
</li>
<li><p>—— 支持至少一个位置标签与多个位置锚点之间并发测量距离、到达角或离开角，其中至少一个位置标签与多个位置锚点构成一个测量组。</p>
</li></ul>

:::

:::{div}
:class: standard-paragraph

<p>G 节点或 T 节点可作为位置锚点、位置标签或者位置解算节点。G 节点配置各个位置锚点、位置标签和位置信息解算节点的定位参数。</p>

:::

:::{div}
:class: standard-paragraph

<p>星闪无线通信系统支持的感知场景分为：</p>

:::

:::{div}
:class: standard-list-block

<ul class="standard-list">
<li><p>—— 单站感知：支持节点自发自收进行感知测量；</p>
</li>
<li><p>—— 双站感知：支持两个节点之间进行感知测量；</p>
</li>
<li><p>—— 协作感知：支持 G 节点作为感知管理节点，配置多个节点进行感知测量并上报感知测量信息，完成多节点协作感知；</p>
</li>
<li><p>—— 代理感知：支持 T 节点作为感知请求节点，向 G 节点发送感知流程请求，并实现代理感知；</p>
</li>
<li><p>—— 公共资源感知：同步信号可用作信道状态信息估计，并进一步用作感知。</p>
</li></ul>

:::
