# 9 基础应用层要求

(gbt-48336-101-2026-clause-9-1)=
## 9.1 音频

:::{div}
:class: standard-paragraph

<p>对于音频类型业务，基础应用层可支持以下原子能力协议。</p>

:::

:::{div}
:class: standard-list-block

<ul class="standard-list">
<li><p>—— 音频流配置与传输管理：定义了单播、组播、广播等音频传输方式，码流格式；多音频通道音频流</p>
</li></ul>

:::

:::{div}
:class: standard-paragraph

<p>的分发和混音。</p>

:::

:::{div}
:class: standard-list-block

<ul class="standard-list">
<li><p>—— 合作设备集合管理：定义了合作设备集合的组建、发现、连接、移除的功能，可提供将多个功能与</p>
</li></ul>

:::

:::{div}
:class: standard-paragraph

<p>状态相同的设备视为一个合作设备集合进行管理的能力。</p>

:::

:::{div}
:class: standard-list-block

<ul class="standard-list">
<li><p>—— 媒体控制：定义了媒体播放、媒体浏览、音量调整等控制面功能。</p>
</li>
<li><p>—— 高清音频编解码：定义了 L2HC。</p>
</li></ul>

:::

## 9.3 控制

:::{div}
:class: standard-paragraph

<p>对于控制类型业务，基础应用层可支持以下应用协议：</p>

:::

:::{div}
:class: standard-list-block

<ul class="standard-list">
<li><p>—— USB HID 应用配置和管理：定义了对原子能力相关服务的配置和数据传输的要求；</p>
</li>
<li><p>—— 对于控制类型业务，基础应用层可支持以下原子能力协议：</p>
</li>
<li><p>—— 用于 USB HID 应用的数据交互管理服务：定义了星闪以无线方式模拟 USB HID 设备和主机，</p>
</li></ul>

:::

:::{div}
:class: standard-paragraph

<p>通过服务管理呈现功能及使用 SSAP 传输 USB HID 数据；</p>

:::

:::{div}
:class: standard-list-block

<ul class="standard-list">
<li><p>—— 电量信息管理服务：定义了电量信息；</p>
</li>
<li><p>—— 设备信息管理服务：定义了设备信息，包括设备的厂商、型号、版本、外观等信息。</p>
</li></ul>

:::

## 9.5 定位

:::{div}
:class: standard-paragraph

<p>对于定位类型业务，基础应用层可支持以下应用协议：</p>

:::

:::{div}
:class: standard-list-block

<ul class="standard-list">
<li><p>—— 数字车钥匙应用配置和管理，定义了对数字车钥匙场景下各角色与行为，原子能力相关服务的</p>
</li></ul>

:::

:::{div}
:class: standard-paragraph

<p>配置和数据传输的要求。</p>

:::

:::{div}
:class: standard-paragraph

<p>对于定位类型业务，基础应用层可支持以下原子能力协议：</p>

:::

:::{div}
:class: standard-list-block

<ul class="standard-list">
