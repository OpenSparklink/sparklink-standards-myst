# 4 符号和缩略语

(gbt-48336-101-2026-clause-4-1)=
## 4.1 符号

:::{div}
:class: standard-paragraph

<p>下列符号适用于本文件。</p>

:::

:::{div}
:class: standard-definitions

$f_{\mathrm{s}}$
: 基准采样频率。

:::

:::{div}
:class: standard-definitions

$f_{\mathrm{s}\_\mathrm{d}}$
: 派生的基带采样频率。

:::

:::{div}
:class: standard-definitions

$K$
: 同步符号的参数，单个符号中包含的码字序列的长度。

:::

:::{div}
:class: standard-definitions

$L$
: 占空比。

:::

:::{div}
:class: standard-definitions

$M\mathrm{seg}$
: 测量字段包含的测量子片段个数。

:::

:::{div}
:class: standard-definitions

$N\mathrm{cts}$
: 测量字段的测量符号总个数。

:::

:::{div}
:class: standard-definitions

$N\mathrm{seg}$
: 每个测量子片段包含的测量符号个数。

:::

:::{div}
:class: standard-definitions

$N\mathrm{sync}$
: 同步序列的长度。

:::

:::{div}
:class: standard-definitions

$S(i)$
: 第$i$ 个同步字段符号。

:::

:::{div}
:class: standard-definitions

$T\mathrm{gap}$
: 相邻的两个测量子片段之间的时间。

:::

:::{div}
:class: standard-definitions

$Tc$
: 脉冲持续时间。

:::

:::{div}
:class: standard-definitions

$Tp$
: 波形的带宽参数。

:::

:::{div}
:class: standard-definitions

$Ts$
: 基本时间单位。

:::

:::{div}
:class: standard-definitions

$Ts\_d$
: 派生的基本时间单位。

:::

:::{div}
:class: standard-definitions

$\alpha$
: 派生系数。

:::

:::{div}
:class: standard-definitions

$\beta$
: 决定波形形状的参数。

:::
