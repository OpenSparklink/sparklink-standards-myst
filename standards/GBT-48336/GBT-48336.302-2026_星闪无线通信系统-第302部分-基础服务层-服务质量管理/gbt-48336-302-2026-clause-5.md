# 5 概述

:::{div}
:class: standard-paragraph

<p>本文件定义了基础服务层 QoS管理相关的功能及流程,支持传输IP数据或非IP数据。</p>

:::

:::{div}
:class: standard-paragraph

<p>QoS管理功能单元是承接 QoS管理的基础服务层逻辑功能实体,负责接收基础应用层或基础服务层其他功能单元提交的服务传输请求,并与连接管理等功能单元交互,共同满足单播、组播和广播数据在基础服务层的通信要求。</p>

:::

:::{div}
:class: standard-paragraph

<p>QoS管理功能单元为基础应用层或基础服务层其他功能单元提供以下服务和接口原语:</p>

:::

:::{div}
:class: standard-list-block

<ul class="standard-list">
<li><p>——— 接收并满足服务传输请求;</p>
</li>
<li><p>——— 基于业务 QoS参数推导出星闪 QoS参数;</p>
</li>
<li><p>——— 执行动态 QoS控制;</p>
</li>
<li><p>——— 通知5G 融合功能单元无法满足业务流的 QoS要求等异常事件。</p>
</li></ul>

:::

:::{div}
:class: standard-paragraph

<p>QoS管理功能单元需要基础服务层其他功能单元分别提供以下服务和接口原语:</p>

:::

:::{div}
:class: standard-list-block

<ul class="standard-list">
<li><p>——— 连接管理功能单元:提供建立、重配置或释放传输通道,以及满足 QoS 需求的数据传输服</p>
</li></ul>

:::

:::{div}
:class: standard-paragraph

<p>务,其中传输通道及 QoS更新相关接口原语见 GB/T48336.301—2026中9.2.3;</p>

:::

:::{div}
:class: standard-list-block

<ul class="standard-list">
<li><p>——— 数据传输与适配功能单元:提供传输 QoS管理信令服务;</p>
</li>
<li><p>——— 测量管理功能单元:提供测量服务并反馈测量结果,其中测量服务接口原语见 GB/T48336.301—</p>
</li></ul>

:::

:::{div}
:class: standard-paragraph

<p>2026 中10.2;</p>

:::

:::{div}
:class: standard-list-block

<ul class="standard-list">
<li><p>——— 5G 融合功能单元:提供 QoS策略配置等服务。</p>
</li></ul>

:::
