(gbt-48336-302-2026-clause-3)=
# 3 术语和定义

:::{div}
:class: standard-reference

<p>GB/T48336.101—2026界定的以及下列术语和定义适用于本文件。</p>

:::

(gbt-48336-302-2026-clause-3-1)=
## 3.1 原语 primitive

:::{div}
:class: standard-paragraph

<p>星闪无线通信系统内各层或各功能单元间控制语义与信息交互的标准化抽象操作。</p>

:::

(gbt-48336-302-2026-clause-3-2)=
## 3.2 服务质量 quality of service; QoS

:::{div}
:class: standard-paragraph

<p>提供数据传输服务的水平。</p>

:::

(gbt-48336-302-2026-clause-3-3)=
## 3.3 QoS流 QoS flow

:::{div}
:class: standard-paragraph

<p>具有不同 QoS参数的数据流。</p>

:::

(gbt-48336-302-2026-clause-3-4)=
## 3.4 QoS规则 QoS rule

:::{div}
:class: standard-paragraph

<p>业务流映射到 QoS流的映射规则。</p>

:::

(gbt-48336-302-2026-clause-3-5)=
## 3.5 业务 QoS参数 service QoS parameter

:::{div}
:class: standard-paragraph

<p>应用层用于描述业务数据特征的 QoS参数。</p>

:::

(gbt-48336-302-2026-clause-3-6)=
## 3.6 星闪 QoS参数 sparklink QoS parameter

:::{div}
:class: standard-paragraph

<p>星闪无线通信系统用于描述 QoS流特征的 QoS参数。</p>

:::

(gbt-48336-302-2026-clause-3-7)=
## 3.7 动态 QoS控制 dynamic QoS control

:::{div}
:class: standard-paragraph

<p>可实时调整星闪 QoS参数和传输行为以满足 QoS需求的机制。</p>

:::

(gbt-48336-302-2026-clause-3-8)=
## 3.8 服务传输请求 service transmission request

:::{div}
:class: standard-paragraph

<p>基础应用层或基础服务层其他功能单元向 QoS管理功能单元提出建立业务流的请求原语。</p>

:::

(gbt-48336-302-2026-clause-3-9)=
## 3.9 差分服务代码点 differentiated services code point

:::{div}
:class: standard-paragraph

<p>用于表征IP分组转发行为的编码值。</p>

:::
