# 7 单跳星闪IP承载组网拓扑

:::{div}
:class: standard-paragraph

<p>如图 2 所示，星闪通信域内包括两类设备角色，即星闪 IP 承载终端节点（IPoSL 终端节点）和星闪IP 承载网关节点（IPoSL 网关节点）。IPoSL 终端节点与 IPoSL 网关节点直连建立单跳通信拓扑。</p>

:::

:::{div}
:class: standard-diagram

```{mermaid}
flowchart LR
  Net(["Internet"]) --- Gw
  subgraph Domain["星闪通信域"]
    Gw["IPoSL网关节点"] -.- A(["IPoSL终端节点"])
    Gw -.- B(["IPoSL终端节点"])
    Gw -.- C(["IPoSL终端节点"])
  end
```

:::

(gbt-48336-406-2026-figure-2)=
:::{div}
:class: standard-caption

<p>图 2　单跳星闪 IP 承载组网示意图</p>

:::

:::{div}
:class: standard-paragraph

<p>如图 3 所示，IPoSL 终端节点为 IP 数据报文的发送端或接收端。通常为传感器、执行器、智能手机、智能音响等设备。IPoSL 网关节点负责连接星闪通信域和 IP 网络的网关单元，实现星闪通信域内部IPoSL 终端节点与 Internet 网络 IP 终端的通信或星闪通信域内部 IPoSL 终端之间的 IP 报文转发。例如 IPoSL 网关节点可为家庭网关、家庭路由器等设备。特殊情况下，IPoSL 网关节点也可作为 IP 数据报文的发送端或接收端。</p>

:::

:::{div}
:class: standard-diagram

```{mermaid}
  B <-->|星闪域内单跳通信| C
  A <-->|IP应用端到端通信| C
```
