(gbt-48336-406-2026-clause-10)=
# 10 IP承载技术要求

(gbt-48336-406-2026-clause-10-1)=
## 10.1 IP 适配管理功能单元技术要求

:::{div}
:class: standard-paragraph

<p>建立和维护 IP 地址与星闪设备 L2ID 映射表，内容包括〈IPoSL 终端节点私网 IP 地址，IPoSL 终端节点 L2ID〉映射表项和〈公网 IP 地址，IPoSL 网关节点 L2ID〉映射表项。</p>

:::

:::{div}
:class: standard-paragraph

<p>建立和维护〈IP 地址与传输通道解析表〉，表项为〈目的（私网或公网）IP 地址，DSCP，目的 L2ID，TCID，传输模式（帧格式）〉。</p>

:::

(gbt-48336-406-2026-clause-10-2)=
## 10.2 QoS 管理功能单元技术要求

:::{div}
:class: standard-paragraph

<p>QoS 管理功能单元针对无特殊 QoS 要求的 IP 应用数据传输，应将 IP QoS 参数映射到星闪 IP 承载默认 QoS 参数。针对有明确 QoS 要求的 IP 应用数据传输，基础应用层应将业务关联的 QoS 参数（DSCP）等信息递交给 QoS 管理功能单元，本端 QoS 管理功能单元基于接收到的参数与对端 QoS 管理功能单元进行传输所需的 QoS 协商参数，从而确定对应的星闪 IP 承载 QoS 参数（包含 IP 应用 QoS 参数 DSCP 与 IP 承载 SLQI 的映射）。</p>

:::

:::{div}
:class: standard-paragraph

<p>具体的 IP 应用类别及其 DSCP 等级与星闪 IP 承载 SLQI 及其 QoS 参数间的映射关系应遵循</p>

:::

:::{div}
:class: standard-reference

<p>GB/T 48336.302—2026 中 7.4 定义的标准星闪 QoSindex 和 QoS 参数之间的映射表。</p>

:::

(gbt-48336-406-2026-clause-10-3)=
## 10.3 连接管理功能单元技术要求

:::{div}
:class: standard-paragraph

<p>连接管理功能单元建立传输通道，应根据 QoS 管理功能单元协商后的星闪承载 IP 的 QoS 参数，建立满足 IP 应用业务 QoS 要求的传输通道，包括建立表项〈目的 L2ID，TCID，SLQI，传输模式〉。具体传输通道流程应遵循 GB/T 48336.301—2026 中 9.4 定义的连接管理流程。</p>

:::

(gbt-48336-406-2026-clause-10-4)=
## 10.4 数据传输与适配单元技术要求

:::{div}
:class: standard-paragraph

<p>按照星闪 IP 承载需求，基础服务层帧结构中 PI（Protocol Identifier）字段取值应包括 1 或 2，分别指示上层协议类型为 IPv4 协议或 IPv6 协议。</p>

:::
