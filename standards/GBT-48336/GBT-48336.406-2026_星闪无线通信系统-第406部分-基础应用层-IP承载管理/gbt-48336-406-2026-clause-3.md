(gbt-48336-406-2026-clause-3)=
# 3 术语和定义

:::{div}
:class: standard-reference

<p>GB/T 48336.101—2026 界定的以及下列术语和定义适用于本文件。</p>

:::

(gbt-48336-406-2026-clause-3-1)=
## 3.1 星闪 IP 承载网关节点 iposl gateway node

:::{div}
:class: standard-paragraph

<p>连接星闪通信域和 IP 网络的网络单元，实现星闪通信域内部终端节点与 IP 网络终端节点间的 IP通信或星闪通信域内部终端节点之间的 IP 通信。</p>

:::

(gbt-48336-406-2026-clause-3-2)=
## 3.2 星闪 IP 承载终端节点 iposl terminal node

:::{div}
:class: standard-paragraph

<p>通过星闪传输通道发送或接收 IP 报文的节点。</p>

:::

(gbt-48336-406-2026-clause-3-3)=
## 3.3 协议标识 protocol identifier

:::{div}
:class: standard-paragraph

<p>定义为 1 字节长字段，封装在基础服务层帧结构中，指示基础服务层之上的协议类型。</p>

:::
