(gbt-48336-406-2026-clause-8)=
# 8 IPoSL节点角色

:::{div}
:class: standard-paragraph

<p>单跳星闪 IP 承载组网中包括两类设备角色，即 IPoSL 网关节点和 IPoSL 终端节点。两类设备应支持如下功能。</p>

:::

:::{div}
:class: standard-list-block

<ul class="standard-list">
<li><p>—— IPoSL 网关节点：</p>
<ul class="standard-list">
<li><p>• 支持作为 IPoSL 配置管理服务的客户端或服务端，并遵循 GB/T 48336.301—2026 中 6.6.2定义的设备发现配置流程对发现方和被发现方配置设备公开信息和扫描参数，以使得通过扫描发现 IPoSL 终端节点或通过发送广播消息被 IPoSL 终端节点发现；</p>
</li>
<li><p>• 支持公网私网网络地址转换/网络地址端口转换（NAT/NAPT）；</p>
</li>
<li><p>• 支持维护 IP 地址与星闪设备 L2ID 的映射表〈IP 地址，L2ID〉；</p>
</li>
<li><p>• 支持根据 IP 应用 QoS 需求与 IPoSL 终端节点间进行 QoS 协商；</p>
</li>
<li><p>• 支持与 IPoSL 终端节点间建立单播、组播或广播传输通道。</p>
</li></ul>
</li>
<li><p>—— IPoSL 终端节点：</p>
<ul class="standard-list">
<li><p>• 支持作为 IPoSL 配置管理服务的服务端或客户端，并遵循 GB/T 48336.301—2026 中 6.6.2定义的设备发现配置流程对发现方和被发现方配置设备公开信息和扫描参数，以使得通过扫描发现 IPoSL 网关节点或通过发送广播消息被 IPoSL 网关节点发现；</p>
</li>
<li><p>• 支持维护 IP 地址与星闪设备 L2ID 的映射表〈IP 地址，L2ID〉；</p>
</li>
<li><p>• 支持根据 IP 应用 QoS 需求与 IPoSL 网关节点间进行 QoS 协商；</p>
</li>
<li><p>• 支持与 IPoSL 网关节点间建立单播、组播或广播传输通道。</p>
</li></ul>
</li></ul>

:::
