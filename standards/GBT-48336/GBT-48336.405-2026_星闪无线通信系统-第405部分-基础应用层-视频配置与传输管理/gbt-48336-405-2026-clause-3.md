(gbt-48336-405-2026-clause-3)=
# 3 术语和定义

:::{div}
:class: standard-reference

<p>GB/T 48336.101 界定的以及下列术语和定义适用于本文件。</p>

:::

(gbt-48336-405-2026-clause-3-1)=
## 3.1 视频源 video source

:::{div}
:class: standard-paragraph

<p>产生视频数据的末端节点。</p>

:::

(gbt-48336-405-2026-clause-3-2)=
## 3.2 视频宿 video sink

:::{div}
:class: standard-paragraph

<p>使用（包括播放）视频数据的末端节点。</p>

:::

(gbt-48336-405-2026-clause-3-3)=
## 3.3 视频设备 video device

:::{div}
:class: standard-paragraph

<p>具有一个或多个视频源，具有一个或多个视频宿，或者既具有一个或多个视频源也具有一个或多个视频宿的设备。</p>

:::

(gbt-48336-405-2026-clause-3-4)=
## 3.4 视频发送端 video sender

:::{div}
:class: standard-paragraph

<p>发送视频流或音视频流的设备或装置。</p>

:::

(gbt-48336-405-2026-clause-3-5)=
## 3.5 视频接收端 video receiver

:::{div}
:class: standard-paragraph

<p>接收视频流或音视频流的设备或装置。</p>

:::

(gbt-48336-405-2026-clause-3-6)=
## 3.6 视频流 video stream

:::{div}
:class: standard-paragraph

<p>从视频源到视频宿的一系列数据，仅包含视频数据，又分为视频裸流和视频编码流。</p>

:::

(gbt-48336-405-2026-clause-3-7)=
## 3.7 音视频流 audio and video stream

:::{div}
:class: standard-paragraph

<p>从视频源到视频宿的一系列数据，包含视频流和音频流。</p>

:::

(gbt-48336-405-2026-clause-3-8)=
## 3.8 视频裸流 raw video stream

:::{div}
:class: standard-paragraph

<p>由模拟视频信号经过采样、量化、编码得到的未经压缩的视频流。</p>

:::

(gbt-48336-405-2026-clause-3-9)=
## 3.9 视频编码流 video encoding stream

:::{div}
:class: standard-paragraph

<p>对视频裸流进行视频编码后的数字视频数据。</p>

:::

(gbt-48336-405-2026-clause-3-10)=
## 3.10 组播源 multicast source

:::{div}
:class: standard-paragraph

<p>组播视频数据的发送者，用来生成和发送视频裸流数据或视频编码流数据。</p>

:::

(gbt-48336-405-2026-clause-3-11)=
## 3.11 组播宿 multicast sink

:::{div}
:class: standard-paragraph

<p>一个或多个期望接收特定组播组数据的设备。</p>

:::

(gbt-48336-405-2026-clause-3-12)=
## 3.12 组播组管理者 multicast group manager

:::{div}
:class: standard-paragraph

<p>具备生成和维护“组播组成员管理表项”功能的逻辑功能节点，通常为组播源。</p>

:::

(gbt-48336-405-2026-clause-3-13)=
## 3.13 组播组成员 multicast group member

:::{div}
:class: standard-paragraph

<p>由组播组管理者管理的一个或多个组播宿设备。</p>

:::

(gbt-48336-405-2026-clause-3-14)=
## 3.14 组播组 multicast group

:::{div}
:class: standard-paragraph

<p>由一个组播源和一个或多个组播组成员构成、使用唯一组标识（Group ID）的设备组。</p>

:::

(gbt-48336-405-2026-clause-3-15)=
## 3.15 视频数据通道 video transmission channel

:::{div}
:class: standard-paragraph

<p>用于在视频发送端和视频接收端之间传输视频数据的逻辑实体。</p>

:::

(gbt-48336-405-2026-clause-3-16)=
## 3.16 单播视频数据通道 unicast video data channel

:::{div}
:class: standard-paragraph

<p>一个确定的视频发送端与一个确定的视频接收端之间传输视频数据的通道。</p>

:::

(gbt-48336-405-2026-clause-3-17)=
## 3.17 组播视频数据通道 multicast video data channel

:::{div}
:class: standard-paragraph

<p>一个确定的视频发送端与多个确定的视频接收端之间传输视频数据、依赖于接入层可靠组播能力的通道。</p>

:::

(gbt-48336-405-2026-clause-3-18)=
## 3.18 广播视频数据通道 broadcast video data channel

:::{div}
:class: standard-paragraph

<p>用于进行视频数据广播传输、依赖于接入层广播能力的通道。</p>

:::
