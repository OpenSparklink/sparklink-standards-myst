# 8.4 广播视频配置与传输管理流程

(gbt-48336-405-2026-clause-8-4-1)=
## 8.4.1 概述

:::{div}
:class: standard-paragraph

<p>广播视频应用是指通过广播业务传输通道进行视频流传输的一类视频应用。广播业务传输通道依赖于接入层的广播能力，需要接入层提供支持业务广播的逻辑信道。广播业务传输通道不依赖于连接，其控制信息需要借助通用控制广播传输通道（Common Control Broadcast Transport Channel，CCBTC）进行传输。</p>

:::

:::{div}
:class: standard-paragraph

<p>针对广播视频应用场景，视频源作为广播业务的发送方，视频宿则作为广播业务的接收方。两者对应有不同的广播业务传输通道建立流程。</p>

:::

:::{div}
:class: standard-paragraph

<p>广播视频配置与传输管理总体流程包括：</p>

:::

:::{div}
:class: standard-list-block

<ol class="alpha-list" start="1">
<li><p>a） 广播视频应用参数配置与重配置；</p>
</li>
<li><p>b） 视频广播传输通道开启与视频流广播传输开始；</p>
</li>
<li><p>c） 广播视频流传输停止与应用释放。</p>
</li></ol>

:::

:::{div}
:class: standard-paragraph

<p>详见 8.4.3~8.4.5。该方式下，视频源和视频宿之间不建立连接，广播视频配置与传输管理流程中涉及的相关信令或信息通过通用控制广播传输通道发送。那么，视频源即可通过使用接入层的广播传输能力将一个或多个视频流通过广播通信方式发送，在该视频源设备可覆盖范围内的设备均可接收该广播视频流数据。</p>

:::

(gbt-48336-405-2026-clause-8-4-3)=
## 8.4.3 广播视频应用参数配置与重配置

:::{div}
:class: standard-paragraph

<p>广播视频应用配置是指视频源和视频宿间通过通用控制广播通道发送和接收视频应用相关的配置信息的过程。视频源应根据广播视频应用内容要求设置广播视频应用配置信息，广播视频应用配置信息携带在设备发现流程设备公开信息中。设备公开信息的数据结构设计详见 8.4.2。当视频宿接收到该配置信息，从而可决定需要接收的广播视频应用，并可根据配置信息中携带的编解码类型、QoS 要求等进行本地配置。</p>

:::

:::{div}
:class: standard-paragraph

<p>广播视频应用重配置是指广播视频源更新调整了应用配置信息，例如编解码类型与参数和广播视频应用 QoS 要求。视频宿通过通用控制广播通道接收广播视频应用重配置信息后，可按照配置信息内容进行本地配置更新。</p>

:::

:::{div}
:class: standard-paragraph

<p>针对上述广播视频应用参数配置与重配置，广播视频源向连接管理功能单元发送通用控制广播传输通道发送请求用于请求在通用控制广播传输通道上通过广播包携带并发送广播视频应用配置信息。随后，连接管理功能单元向广播视频应用视频源回复通用控制广播传输通道发送响应用于确认已发送广播视频应用配置信息。在广播视频宿端，广播视频应用视频宿向连接管理功能单元请求查询在通用控制广播传输通道上接收到的广播视频应用配置信息广播包。从而，广播视频应用视频宿可查询接收广播视频源发送的配置信息。</p>

:::

(gbt-48336-405-2026-clause-8-4-4)=
## 8.4.4 广播视频数据通道开启与视频流广播传输开始

:::{div}
:class: standard-paragraph

<p>广播视频应用数据应通过发送方和接收方分别建立的广播业务传输通道进行视频流数据的发送和接收。其中，广播视频源作为发送方首先决定执行广播业务，并向基础服务层 QoS 管理功能单元发送层间原语指示广播视频应用的 QoS 参数。从而 QoS 管理功能单元与连接管理功能单元间交互传输通道建立请求和传输通道建立响应消息完成发送方广播业务传输通道建立。</p>

:::

:::{div}
:class: standard-paragraph

<p>当视频源接收到 QoS 管理功能单元反馈广播通道结果后，视频源向连接管理功能单元发送通用控制广播传输通道发送请求，携带广播视频流配置信息。当视频源收到连接与管理的通用控制广播传输通道发送确认后，视频源开始通过广播业务传输通道发送广播视频应用数据。</p>

:::

:::{div}
:class: standard-paragraph

<p>对于广播视频宿端，当视频宿决定需要进行接收广播视频流数据时，视频宿应向连接管理功能单元发送通用控制广播传输通道接收查询，从而接收广播视频源发送的广播视频流配置信息。视频宿接收到连接管理发送的通用控制广播传输通道接收上报消息后，视频宿进行广播视频应用业务选择，随后视频宿指示 QoS 管理功能单元执行广播业务传输通道建立。当广播业务传输通道建立完成后，QoS 管理功能单元应反馈广播通道结果，视频宿从广播业务传输通道上接收广播视频应用数据。</p>

:::

:::{div}
:class: standard-paragraph

<p>广播业务通道的建立过程应符合 GB/T 48336.301—2026 中 9.4 的要求。其中，视频源作为广播传输通道的发送方，视频宿作为广播传输通道的接收方。</p>

:::

(gbt-48336-405-2026-clause-8-4-5)=
## 8.4.5 广播视频流传输停止与应用释放

:::{div}
:class: standard-paragraph

<p>当广播视频源不再发送广播数据时，应发送通用控制广播传输通道停止发送请求，停止发送广播视频流配置信息。当视频源收到通用控制广播传输通道停止发送响应后，应向 QoS 管理功能单元指示停止广播业务，释放广播业务传输通道。</p>

:::

:::{div}
:class: standard-paragraph

<p>当视频宿不再接收广播数据时，应向 QoS 管理功能单元指示停止广播业务，释放广播业务传输通道。广播业务传输通道的释放具体流程应符合 GB/T 48336.301—2026 中 9.4 的要求。</p>

:::
