### 8.1.2 接入侧会话建立请求消息

:::{div}
:class: standard-paragraph

<p>融合系统类型一的会话建立流程中，TNGF 基于 AsSessionContextSetupRequest 消息向 T 节点转发 NAS 消息、TNGF 隧道信息和 QoS 参数信息。其中，PDUSessionEstablishmenAccept 封装在nasContainer 中，PDUSessionEstablishmenAccept 消息的定义应符合 3GPP TS 24.501 v16.3.0（2019⁃12）中 8.3.2 定义的 PDU 会话建立接受消息，其中包含 MDF 或 PMF 信息。</p>

:::

:::{div}
:class: standard-paragraph

<p>接入侧会话建立请求消息的具体结构定义见图 50。各字段含义如下所示。</p>

:::

:::{div}
:class: standard-list-block

<ol class="alpha-list" start="1">
<li><p>a） transactionID：1 字节，信令交互标识。</p>
</li>
<li><p>b） pduSession：1 字节，取值范围 0~255，PDU 会话标识。</p>
</li>
<li><p>c） tngfTunnelInfo：变长，指示隧道信息，其结构定义见图 73。</p>
</li>
<li><p>d） nasContainer：变长，承载 PDUSessionEstablishmenAccept 消息，其结构定义见图 79。</p>
</li>
<li><p>e） optionBitmap：1 字节，指示后续可选字段是否存在，某比特位置 1 表示存在对应字段，置 0 表示不存在对应字段。指示信息如下：</p>
<ol class="decimal-list" start="1">
<li><p>1） bit0：指示是否存在 dscp⁃MappingList 字段；</p>
</li>
<li><p>2） 其他：预留。</p>
</li></ol>
</li>
<li><p>f） dscp⁃MappingList：变长，可选字段，指示若干个 DSCP 与 XQI 或 SLQI 的映射关系，其结构定义见图 75。</p>
</li></ol>

:::

</li>
<li><p>b） pduSession：1 字节，取值范围 0~255，PDU 会话标识。</p>
</li>
<li><p>c） optionBitmap：1 字节，指示后续可选字段是否存在，某比特位置 1 表示存在对应字段，置 0 表示不存在对应字段。指示信息如下：</p>

### 8.1.8 PDU 会话关联请求消息

:::{div}
:class: standard-paragraph

<p>融合系统类型二的 PDU 会话建立或修改流程中，T 节点基于 PduSessionAssociationRequest 消息向G 节点请求建立或修改 PDU 会话。请求消息中包含终端类型、星闪无线通信系统 QoS 参数和 DNN 信息，其中 DNN 信息的定义应符合 3GPP TS 24.501 v16.3.0（2019⁃12）中 9.11.2.1B 的规定。</p>

:::

:::{div}
:class: standard-paragraph

<p>PDU 会话关联请求消息的具体结构定义见图 58。各字段含义如下所示。</p>

:::

:::{div}
:class: standard-list-block

<ol class="alpha-list" start="1">
<li><p>a） transactionID：1 字节，信令交互标识。</p>
</li>
<li><p>b） terminalType：2 比特，指示节点类型，可选字段。指示信息如下：</p>
<ol class="decimal-list" start="1">
<li><p>1） 0：sl⁃5G⁃terminaltype 类型，指示 5G 融合会话信息，用于请求 SMF 在下发的 QoS 策略中携带 5QI；</p>
</li>
<li><p>2） 1：其他通用类型，默认值；</p>
</li>
<li><p>3） 其他：预留。</p>
</li></ol>
</li>
<li><p>c） X：1 比特，指示是否存在 xqiInfoList，1 表示存在，0 表示不存在。</p>
</li>
<li><p>d） S：1 比特，指示是否存在 slqiInfoList，1 表示存在，0 表示不存在。</p>
</li>
<li><p>e） A：1 比特，指示是否存在 applicationInfoList，1 表示存在，0 表示不存在。</p>
</li>
<li><p>f） dnn：变长，指示 DNN 信息，表示申请 PDU 会话的类型，其结构参考图 59。</p>
</li>
<li><p>g） xqiInfoList：变长，可选字段，指示若干个 XQI，其结构见图 77。</p>
</li>
<li><p>h） slqiInfoList：变长，可选字段，指示若干个 SLQI，其结构见图 78。</p>
</li>

</li></ol>

:::{div}
:class: standard-paragraph

<p>融合系统类型二的 PDU 会话建立或修改流程中，G 节点基于 PduSessionAssociationRe⁃sponse 消息向 T 节点发送 PDU 会话及其关联的星闪无线通信系统的 QoS 控制策略。</p>

:::

:::{div}
:class: standard-paragraph

<p>PDU 会话关联响应消息的具体结构定义见图 60。各字段含义如下所示。</p>

:::

:::{div}
:class: standard-list-block

<ol class="alpha-list" start="1">
<li><p>a） transactionID：1 字节，信令交互标识，与 PDU 会话关联请求消息的 transactionID 相同。</p>
</li>
<li><p>b） pduSession：1 字节，取值范围 0~255，PDU 会话标识。</p>
</li>
<li><p>c） cellular⁃5G⁃InactiveTimer：4 比特，指示 5G 非活跃计时器超时时间，取值如下：</p>
<ol class="decimal-list" start="1">
<li><p>1） 0：0 ms；</p>
</li>
<li><p>2） 1：10 ms；</p>
</li>
