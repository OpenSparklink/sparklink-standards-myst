# 7 星闪5G融合链路管控

(gbt-48336-304-2026-clause-7-1)=
## 7.1 QoS 策略管理

(gbt-48336-304-2026-clause-7-1-1)=
### 7.1.1 概述

:::{div}
:class: standard-paragraph

<p>基于注册流程以及 PDU 会话建立或修改流程中的 QoS 策略配置和更新，T 节点获得融合系统的QoS 控制策略。</p>

:::

:::{div}
:class: standard-paragraph

<p>针对融合系统类型一，QoS 控制策略由 TNGF 发送给 T 节点。</p>

:::

:::{div}
:class: standard-paragraph

<p>针对融合系统类型二，QoS 控制策略由 G 节点发送给 T 节点。G 节点根据 QoS 控制策略为其覆盖下的 T 节点进行空口资源分配和调度。</p>

:::

(gbt-48336-304-2026-clause-7-1-2)=
### 7.1.2 融合系统类型一

(gbt-48336-304-2026-clause-7-1-2-1)=
#### 7.1.2.1 远端业务的 QoS 控制

:::{div}
:class: standard-paragraph

<p>融合系统类型一下的远端业务 QoS 策略配置流程见图 34，基于 6.2.2 注册流程中的步骤 9a、9b 和9d，或 6.4.2 和 6.5.1 中 PDU 会话建立或修改流程中的 QoS 策略配置和更新，T 节点获得融合系统的QoS 控制策略，包括 QFI 与 DSCP 的映射、DSCP 与 XQI（和/或 SLQI）的映射，以及 XQI（和/或 SLQI）与星闪无线通信系统 QoS 参数的对应关系。通过基础服务层的管理实体维护 QoS 表，该 QoS 表可包括多个服务质量 QoS 参数配置。QoS 参数应符合附录 C 的规定。</p>

</li>
<li><p>2） TNGF 基于步骤 9b 的 EAP 请求/5G 通知消息将星闪无线通信系统的 QoS 控制策略发送给 T 节点，包括 DSCP 与 XQI（和/或 SLQI）的映射，以及 XQI（和/或 SLQI）与星闪无线通信系统 QoS 参数的映射关系；</p>
</li>
<li><p>3） TNGF 基于步骤 9d 的 AAA 消息将星闪无线通信系统的 QoS 控制策略发送给 G 节点，包括DSCP 与 XQI（和/或 SLQI）的映射，以及 XQI（和/或 SLQI）与星闪无线通信系统 QoS 参数的映射关系。</p>
</li></ol>
</li>
<li><p>b） 基于 PDU 会话建立流程配置 QoS 策略如下：</p>
<ol class="decimal-list" start="1">
<li><p>1） AMF 基于 N2 PDU 会话请求消息将 SMF 生成的 5QI 与 QFI 的映射关系发送给 TNGF；</p>
</li>
<li><p>2） TNGF 合并注册过程和会话过程的端到端 QoS 映射关系，并基于接入侧会话建立请求消息（格式见 8.1.2）将 QFI 与 DSCP 的映射、DSCP 与 XQI（和/或 SLQI）的映射关系发送给 T节点；</p>
</li>
<li><p>3） 5G 核心网 PDU 会话网元接收 G 节点发送的测量指标，将短距 QoS 测量指标以及 5G 核心网 5QI 测量指标读取到 5G 核心网 PDU 会话网元的 QoS 管理实体；</p>
</li></ol>
</li></ol>

:::

:::{div}
:class: standard-list-block

<ol class="decimal-list" start="4">
<li><p>4） 5G 核心网 PDU 会话网元根据测量指标判断当前数据流传输的可靠性，并基于判定结果确定是否调整 QoS 参数配置；</p>
<ol class="decimal-list" start="5">
<li><p>5） 5G 核心网 PDU 会话网元或 G 节点根据 QoS 映射策略动态切换 QoS 表中对应的 QoS 参数配置；</p>
</li>
<li><p>6） T 节点、G 节点或 5G 核心网 PDU 会话网元根据 QoS 映射策略，从 QoS 表中选择 QoS 参数配置，并将 QoS 参数配置通知给 5G 核心网 PDU 会话网元。其中，QoS 参数配置用于 T 节点、G 节点与 5G 核心网 PDU 会话网元之间传输特定 QoS 的数据流。</p>
</li></ol>
</li>
<li><p>c） 基于 PDU 会话修改流程更新 QoS 策略如下：</p>
<ol class="decimal-list" start="1">
<li><p>1） AMF 基于 N2 PDU 会话请求消息将 SMF 更新的 5QI 与 QFI 的映射关系发送给 TNGF；</p>
</li>
<li><p>2） TNGF 基于 PDU 会话修改请求消息（格式见 8.1.4）将更新的融合系统的 QoS 控制策略发送给 T 节点，包括 QFI 与 DSCP 的映射、DSCP 与 XQI（和/或 SLQI）的映射，以及 XQI（和/或 SLQI）与星闪无线通信系统 QoS 参数的映射关系；</p>
</li>
<li><p>3） T 节点或 G 节点的管理实体根据测量指标判断当前数据流传输的可靠性，并基于判定结果确定是否调整 QoS 参数配置；</p>
</li>
<li><p>4） T 节点或 G 节点的管理实体判断测量指标是否超过阈值，若测量指标超过阈值，则根据QoS 映射策略动态切换 QoS 表中对应的 QoS 参数配置；</p>
</li>
<li><p>5） G 节点根据 QoS 策略将目标业务数据发送至 5G 核心网 PDU 会话网元，包括将目标业务数据映射至与目标 QoS 策略对应的 QoS 流逻辑接口，并通过目标 QoS 流逻辑接口将目标业务数据发送至 5G 核心网 PDU 会话网元。</p>
</li></ol>
</li></ol>

<p>融合系统类型一远端策略配置方法二（可选）将数据流的 IP 包头信息（DSCP；或 DSCP 和 IPv6 流标签）和 XQI（和/或 SLQI）以及星闪无线通信系统 QoS 参数的映射关系限制在星闪通信域内部，5G 核心网不感知，以下为策略配置具体流程。</p>

:::{div}

<ol class="decimal-list" start="1">

</li>
<li><p>2） TNGF 确定 QFI，DSCP（或 DSCP 和 IPv6 流标签），XQI（和/或 SLQI）以及与星闪无线通信系统 QoS 参数的映射关系，TNGF 基于接入侧会话建立请求消息（格式见 8.1.2）将 QFI与 DSCP（或 DSCP 和 IPv6 流标签）的映射、DSCP（或 DSCP 和 IPv6 流标签）与 XQI（和/或SLQI）的映射，以及 XQI（和/或 SLQI）和星闪无线通信系统 QoS 参数的映射关系发送给 T节点；</p>
</li>
<li><p>3） TNGF 将 T 节点的本地 IP 地址、DSCP（或 DSCP 和 IPv6 流标签）和 XQI（和/或 SLQI）（或星闪无线通信系统 QoS 参数）发送给 G 节点。G 节点确定 DSCP（或 DSCP 和 IPv6 流标签）或 XQI（和/或 SLQI）与 TCID 的映射并发送给 T 节点。</p>
</li></ol>
</li>
<li><p>b） 基于 PDU 会话修改流程更新 QoS 策略如下：</p>
<ol class="decimal-list" start="1">
<li><p>1） AMF 基于 N2 PDU 会话修改消息将 SMF 更新的 5QI 与 QFI 的映射关系发送给 TNGF；</p>
</li>
<li><p>2） TNGF 更新 QFI，DSCP（或 DSCP 和 IPv6 流标签），XQI（和/或 SLQI）以及与星闪无线通信系统 QoS 参数的映射关系，TNGF 基于接入侧会话建立请求消息（格式见 8.1.2）将更新后的 QFI 与 DSCP（或 DSCP 和 IPv6 流标签）的映射、DSCP（或 DSCP 和 IPv6 流标签）与XQI（和/或 SLQI）的映射，以及 XQI（和/或 SLQI）和星闪无线通信系统 QoS 参数的映射关系发送给 T 节点；</p>
</li>
<li><p>3） TNGF 将更新后的 T 节点的本地 IP 地址、DSCP（或 DSCP 和 IPv6 流标签）和 XQI（和/或SLQI）（或星闪无线通信系统 QoS 参数）发送给 G 节点。G 节点将更新后的 DSCP（或DSCP 和 IPv6 流标签）或 XQI（和/或 SLQI）与 TCID 的映射并发送给 T 节点。</p>
</li></ol>
</li></ol>

### 7.1.3 融合系统类型二

(gbt-48336-304-2026-clause-7-1-3-1)=
#### 7.1.3.1 远端业务流 QoS 控制

:::{div}
:class: standard-paragraph

<p>融合系统类型二可支持远端业务 QoS 策略配置流程，具体见图 38，基于 6.2.3 注册流程中的注册接受，或 6.4.3.2、6.5.2.2 中 PDU 会话建立或修改流程的 QoS 策略配置，G 节点获得融合系统的 QoS 控制策略，并基于步骤 5 的 PDU 会话关联响应消息将星闪无线通信系统的 QoS 控制策略发送给 T 节点。</p>

:::

:::{div}
:class: standard-paragraph

<p>其中，图 38 中的 PDU 会话关联请求消息和 PDU 会话关联响应消息的格式分别见 8.1.8 和 8.1.9。</p>

:::

:::{div}
:class: standard-paragraph

<p>远端业务流 QoS 控制策略配置涉及以下具体流程。</p>

:::

:::{div}
:class: standard-list-block

<ol class="alpha-list" start="1">
<li><p>a） 5G 核心网给 G 节点配置 QoS 信息流程如下：</p>
<ol class="decimal-list" start="1">
<li><p>1） SMF 可基于 5G 融合会话指示信息确定在融合系统的 QoS 控制策略，将 5QI 通过 NAS 消息发送给 G 节点；5G 融合会话指示信息可由 G 节点在注册流程或 PDU 会话建立流程中发送给 5G 核心网相关网元，用于请求 SMF 在该 QoS 策略中携带 5QI 信息；</p>
</li>
<li><p>2） AMF 可基于注册接受消息将融合系统的 QoS 控制策略发送给 G 节点，包括 5QI 与 XQI（和/或 SLQI）的映射、XQI 与星闪无线通信系统 QoS 参数的映射关系；</p>
</li></ol>
</li></ol>

:::

:::{div}
:class: standard-list-block

<ol class="decimal-list" start="3">
<li><p>3） SMF 基于 PDU 会话建立接受消息将融合系统的 QoS 控制策略发送给 G 节点，包括 QFI 与5QI 的映射关系。</p>
</li>
<li><p>b） G 节点给 T 节点配置 QoS 信息：G 节点通过 PDU 会话关联响应消息（格式见 8.1.9）将星闪无</p>
</li></ol>

:::

:::{div}
:class: standard-paragraph

<p>线通信系统的 QoS 控制策略发送给 T 节点，可包括 PDU 会话标识、短距流描述（IP 五元组、优先级等）与 DSCP 的映射、DSCP 与 XQI（和/或 SLQI）的映射，以及 XQI（和/或 SLQI）与星闪无线通信系统 QoS 参数的映射关系。当 T 节点与 G 节点之间基于非 IP 传输时，短距流描述由星闪高层定义的 AID 和/或端口组成，AID 和端口定义应符合 GB/T 48336.301 的规定。</p>

## 7.2 节点和链路状态管理

(gbt-48336-304-2026-clause-7-2-1)=
### 7.2.1 概述

:::{div}
:class: standard-paragraph

<p>在融合系统中，为实现 5G 核心网对星闪短距通信域链路状态的管理和监测，T 节点的基础服务层中的 5G 融合功能单元将 5G 核心网配置的链路状态监测策略指示给测量管理模块，测量管理模块启动链路测量，并把测量量上报给 5G 融合功能单元，由 5G 融合功能单元上报给 5G 核心网。</p>

:::

:::{div}
:class: standard-paragraph

<p>5G 核心网根据 T 节点上报的链路状态测量指示 T 节点进行对应链路的 QoS 调整，T 节点的 5G融合功能单元接收并将该 QoS 调整信息传递给基础服务层的 QoS 管理功能单元，由 QoS 管理功能单元执行相应的操作。</p>

:::

:::{admonition} 注
:class: note

<p>节点和链路状态管理仅涉及融合系统类型一。</p>

:::

(gbt-48336-304-2026-clause-7-2-5-3)=
#### 7.2.5.3 基于随流监测的节点和链路状态管理

:::{div}
:class: standard-paragraph

<p>融合系统中，将随流检测方法用于短距域内的管理节点或终端节点，以根据实时业务流的情况对短距域业务节点的网络状态进行测量。</p>

:::

:::{div}
:class: standard-paragraph

<p>短距域内的 G 节点或 T 节点对 5G 网络下发的短距通信域传输通道质量的检测请求消息进行响应后，可对目标业务流的传输路径进行标识，生成随流检测消息，用于 G 节点或 T 节点测量目标业务流的传输通道质量。其中，标识目标业务流的传输路径包括对目标业务流对应的业务 IP 报文地址进行解析和读取，并将获取到的业务 IP 报文地址的标识映射到所述检测消息的路径标签位的节点地址位。</p>

:::

:::{div}
:class: standard-paragraph

<p>G 节点或 T 节点将目标业务流传输通道质量测量结果上报到 5G 网络，接收 5G 网络下发的服务质量 QoS 策略，并将此 QoS 策略分发到短距域内业务节点，用于业务节点之间进行 QoS 协商，并基于QoS 参数实时调整传输通道，更好地进行消息传递和数据同步。</p>

:::
