# 6.4 会话建立

(gbt-48336-304-2026-clause-6-4-1)=
## 6.4.1 概述

:::{div}
:class: standard-paragraph

<p>融合系统类型一和类型二中的 PDU 会话建立、修改和释放流程仅用于远端通信场景。</p>

:::

(gbt-48336-304-2026-clause-6-4-2)=
## 6.4.2 融合系统类型一

:::{div}
:class: standard-paragraph

<p>融合系统类型一中的 PDU 会话建立流程见图 22，具体流程及信令应符合 3GPP TS 23.502 v18.3.0（2023⁃09）中 4.12.5 的规定。其中，T 节点等同于 3GPP TS 23.502 v18.3.0（2023⁃09）中流程图 4.12.5⁃1的 UE，可信 G 节点等同于 3GPP TS 23.502 v18.3.0（2023⁃09）中流程图 4.12.5⁃1 的非可信非 3GPP 接入，TNGF 等同于 3GPP TS 23.502 v18.3.0（2023⁃09）中流程图 4.12.5⁃1 的 N3IWF。按照 3GPP TS 23.502 v18.3.0（2023⁃09）的相关要求，融合系统类型一会话建立流程如下。</p>

<ol class="decimal-list" start="1">
<li><p>1） TNGF 分配此 PDU 会话对应的用户面 GTP⁃U 隧道信息（即 F⁃TEID，包括 TNGF 的 IP 地址与 TNGF TEID）。上述 TNGF IP 地址与注册流程中步骤 9b 发送的 TNGF IP 地址相同；TNGF TEID 是 PDU 会话粒度，即不同的 PDU 会话分配不同的 TNGF TEID。TNGF将上述 TNGF F⁃TEID 与此 PDU 会话的会话标识（即 PDU session ID）通过步骤 3 发送给T 节点。</p>
</li>
<li><p>2） T 节点分配此 PDU 会话对应的 T 节点隧道信息（即 F⁃TEID，包括 T 节点的 IP 地址与 T 节点 TEID）。上述 T 节点 IP 地址为注册流程中步骤 11 获取的 T 节点 IP 地址。T 节点 TEID可是 PDU 会话粒度，也可是 T 节点粒度。即 T 节点可为不同的 PDU 会话分配不同的TNGF TEID，或者与 T 节点控制面 GTP⁃U 隧道对应的 T 节点 TEID 相同（即注册流程 9c步骤，T 节点分配的传输 NAS 或 PLAP 消息需要的 T 节点的 TEID 信息）。</p>
</li></ol>
</li></ol>

:::

:::{div}
:class: standard-list-block

<ol class="alpha-list" start="5">
<li><p>e） 步骤 6：N2 PDU 会话请求。</p>
</li>
<li><p>f） 步骤 7：对于非漫游和 LBO 场景，采用 3GPP TS 23.502 v18.3.0（2023⁃09）中流程图 4.3.2.2.1⁃1步骤 14 之后的所有步骤；对于基于归属地漫游场景，采用 3GPP TS 23.502 v18.3.0（2023⁃09）中流程图 4.3.2.2.2⁃1 步骤 18 之后的所有步骤。</p>
</li>
<li><p>g） 步骤 8：基于 F⁃TEID 隧道进行映射。</p>
</li>
<li><p>h） 步骤 9：基于 GTP⁃U 的 QoS 流传输。</p>
</li></ol>

:::
