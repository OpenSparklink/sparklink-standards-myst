# 附录D（资料性） 融合系统信道映射

(gbt-48336-304-2026-clause-d-1)=
## D.1 融合系统类型一控制面信道映射

:::{div}
:class: standard-paragraph

<p>融合系统类型一控制面信道映射架构如图 D.1 所示，5G 蜂窝网融合功能单元提供的控制面服务包括 5G 融合服务发现、注册、鉴权、QoS 管理以及链路状态监测等，包括如下说明：</p>

:::

:::{div}
:class: standard-list-block

<ol class="alpha-list" start="1">
<li><p>a） 5G 融合服务发现与星闪无线通信系统通用服务管理共用一个服务管理传输通道；</p>
</li>
<li><p>b） 融合系统中承载在 EAP⁃5G 协议或 IP 传输协议的 NAS（或 PLAP）消息共用一个 5G 融合传输通道；</p>
</li>
<li><p>c） 融合系统中的 5G 融合控制面信令数据默认通过默认空口承载 LCID 传输，该默认空口承载可在接入层连接建立完成时激活。</p>
</li></ol>

:::

## D.3 融合系统类型一远端用户面信道映射

:::{div}
:class: standard-paragraph

<p>融合系统类型一远端用户面信道映射架构如图 D.3 所示，数据流在节点内部具有以下处理流程。</p>

:::

:::{div}
:class: standard-list-block

<ol class="alpha-list" start="1">
<li><p>a） 来自基础应用层或 APP 的数据包在 PDU 层封装成 IP 数据包，该 IP 地址为 T 节点在请求建立PDU 会话的时候由 5G 核心网分配。PDU 层的数据包根据 QoS 规则包过滤策略生成 QoS 流，并基于 GTP⁃U 隧道协议传输。</p>
</li>
<li><p>b） T 节点基于注册流程中通过 DHCP 获取的 IP 地址，与 G 节点之间数据传输基于本地 IP 寻址，星闪无线通信域之间的 IP 传输基于 DSCP（或 DSCP 与 IPv6 流标签）进行 QoS 控制。</p>
</li>
<li><p>c） 上行（T 节点→G 节点）：基于 DSCP（或 DSCP 和 IPv6 流标签）与 TCID 的映射关系，在基础服务层执行 IP 数据包与对应传输通道 TCID 的映射，下行则相反。</p>
</li>
<li><p>d） 上行（T 节点→G 节点）：基于 TCID 与 LCID 的映射关系，接入层将来自传输通道 TCID 上的数据映射到对应的 LCID 上，下行则相反。</p>
</li></ol>

:::

:::{div}
:class: standard-paragraph

<p>其中，DSCP（或 DSCP 和 IPv6 流标签）与 TCID 的映射关系，以及 TCID 与 LCID 的映射关系均由基础服务层维护。G 节点的基础服务层基于 IP 流与传输通道映射配置消息（格式见 8.1.14）为 T 节点配置短距通信相关的 QoS 策略。</p>

:::

<p>融合系统类型二远端用户面信道映射架构如图 D.4 所示，数据流在节点内部的处理流程如下：</p>

:::

:::{div}
:class: standard-list-block

<ol class="alpha-list" start="1">
<li><p>a） 来自基础应用层或 APP 的数据包在 PDU 层封装成 IP 数据包，T 节点与 G 节点间的数据传输基</p>
</li></ol>

:::

:::{div}
:class: standard-paragraph

<p>于 DSCP（或 DSCP 和 IPv6 流标签）和 XQI（和/或 SLQI）进行 QoS 控制；</p>

:::

:::{div}
:class: standard-list-block

<ol class="alpha-list" start="2">
<li><p>b） 传输通道 TCID 中封装的数据包与 PDU 会话解耦，即参考星闪无线通信系统 QoS 参数建立传输通道（TCID 和 LCID），不同 PDU 会话上的数据可在相同的 TCID 上传输；</p>
</li>
<li><p>c） 上行（T 节点→G 节点）：基于 DSCP（或 DSCP 和 IPv6 流标签）与 TCID 的映射关系，在基础服务层执行 IP 数据包与对应传输通道 TCID 的映射，下行则相反；</p>
</li>
<li><p>d） 上行（T 节点→G 节点）：基于 TCID 与 LCID 的映射关系，接入层将来自传输通道 TCID 上的数据映射到对应的 LCID 上，下行则相反。</p>
</li></ol>

:::

:::{div}
:class: standard-paragraph

<p>其中，DSCP（或 DSCP 和 IPv6 流标签）与 TCID 的映射关系，以及 TCID 与 LCID 的映射关系均由基础服务层维护。G 节点的基础服务层基于 IP 流与传输通道映射配置消息（格式见 8.1.14）为 T 节点配置短距通信相关的 QoS 策略。</p>
