# 5 概述

(gbt-48336-304-2026-clause-5-1)=
## 5.1 星闪 5G 融合系统架构

:::{div}
:class: standard-paragraph

<p>本文件定义了星闪无线通信系统的通信设备和 5G 蜂窝网络节点之间进行通信的融合通信架构，实现了网络的分级连接管理、统一配置维护。</p>

:::

:::{div}
:class: standard-paragraph

<p>星闪 5G 蜂窝网络融合（简称“星闪 5G 融合”或“5G 融合”）系统架构见图 1，在 5G 通信域的核心网网元和星闪短距域通信 G 节点、T 节点中的基础服务层引入管理实体进行协议适配。T 节点与 G 节点之间通过星闪短距通信网络进行通信，G 节点与 5G 核心网会话网元之间通过 5G 蜂窝网络进行通信，T 节点与 5G 核心网会话网元之间通过星闪短距通信网络和 5G 蜂窝网络进行协同通信。</p>

:::

:::{div}
:class: standard-paragraph

<p>在本文件中，星闪短距通信网络称为非 3GPP 通信，5G 通信网络对应的通信称为 3GPP 通信。如无特殊指明，星闪无线通信系统和 5G 蜂窝网络构成的整体网络系统和相应的网络架构分别定义为星闪5G 融合系统（简称“5G 融合系统”或“融合系统”）与星闪 5G 融合架构。</p>

:::

(gbt-48336-304-2026-clause-5-2-1-2)=
#### 5.2.1.2 网元功能

:::{div}
:class: standard-paragraph

<p>融合系统类型一涉及以下主要网元类型及功能。</p>

:::

:::{div}
:class: standard-list-block

<ol class="alpha-list" start="1">
<li><p>a） T 节点：融合系统的终端节点（简称“终端”），其基础服务层具备 5G 融合功能单元且 5G 融合功能单元支持 NAS 功能。T 节点的主要功能如下：</p>
<ol class="decimal-list" start="1">
<li><p>1） 通过可信星闪接入网接入 5G 核心网；</p>
</li></ol>
</li></ol>

:::

:::{div}
:class: standard-list-block

<ol class="decimal-list" start="2">
<li><p>2） 根据 5G 核心网的配置对星闪无线通信系统进行状态测量并上报；</p>
</li>
<li><p>3） 根据 5G 核心网的 QoS 策略配置进行业务交互；</p>
</li>
<li><p>4） 通过星闪短距通信网络向 G 节点发送接纳控制请求消息，使可信 G 节点确定 5G 蜂窝网络的接入网关功能。</p>
</li>
<li><p>b） G 节点：融合系统的可信汇聚管理节点（简称“汇聚节点”），可为可信任非 3GPP 接入的通信交换点。当 G 节点接收终端通过星闪短距通信网络发送的接纳控制请求消息，确定出 5G 网络的接入网关功能后，建立 G 节点与接入网关功能的会话连接。其中，接纳控制请求消息用于指示数据流传输策略或进行数据流分流策略协商。G 节点的基础服务层具备 5G 融合功能单元，其主要功能如下：</p>
<ol class="decimal-list" start="1">
<li><p>1） 提供 5G 融合服务，可使 T 节点进行服务发现并访问；</p>
</li>
<li><p>2） 对支持 5G 融合功能的 T 节点进行身份鉴权；</p>
</li>
<li><p>3） 根据 5G 核心网的 QoS 策略配置对其覆盖下的 T 节点进行空口资源分配和调度；</p>
</li>
<li><p>4） 为 T 节点提供空口数据传输服务，可用于 T 节点与 TNGF、T 节点与 5G 核心网的控制面及用户面交互；</p>
</li>
<li><p>5） 为 T 节点分配 IP 地址，用于控制面和用户面数据传输；</p>
</li>
<li><p>6） 接收 T 节点通过星闪短距通信网络发送的接纳控制请求消息，根据该消息进行公共陆地移动网络 PLMN 检索，确定 5G 网络的接入网关功能；</p>
</li>
<li><p>7） 建立 G 节点与接入网关功能的会话连接，会话连接用于 T 节点通过 G 节点和接入网关功能与 T 节点请求的运营商部署的 5G 核心网进行数据传输；</p>
</li>
<li><p>8） 获取与目标业务数据对应的目标 QoS 策略。</p>
</li></ol>
</li>
<li><p>c） TNGF：类型一下部署在运营商 5G 蜂窝网络中的可信非 3GPP 网关节点，主要功能如下：</p>
<ol class="decimal-list" start="1">
<li><p>1） 具备可信非 3GPP 网络接入网关功能；</p>
</li>
<li><p>2） 中转 T 节点与 5G 核心网之间的 NAS 消息；</p>
</li>
<li><p>3） 与 T 节点交互控制面和用户面传输的 GTP⁃U 隧道信息；</p>
</li>
<li><p>4） 向 T 节点转发 5G 核心网的 QoS 策略配置，并提供 QoS 信息更新；</p>
</li>
<li><p>5） 向 G 节点提供星闪无线通信的 QoS 策略配置；</p>
</li>
<li><p>6） 建立 T 节点与运营商 5G 蜂窝网络接入网关功能的会话连接；</p>
</li>
<li><p>7） 在与 G 节点建立会话连接的情况下，接收 5G 核心网发送的 SMC 请求消息，包括 5G 核心网配置的 QoS 策略信息等；</p>
</li>
<li><p>8） 接收 T 节点发送的 SMC 完成消息（如 QoS 参数等），并发送至 5G 核心网；</p>
</li>
<li><p>9） 向 G 节点发送 QoS 管理事件的反馈信息；</p>
</li>
<li><p>10） 根据接纳控制请求消息检索 G 节点支持的运营商 PLMN 列表；</p>
</li>
<li><p>11） 向 T 节点转发完整性保护算法，用于 T 节点与 TNGF 之间的控制面和用户面数据的完整性保护；</p>
</li>
<li><p>12） 基于 TNGF 密钥生成星闪无线通信接入层密钥，并提供给 G 节点，用于建立 T 节点与 G节点之间的安全连接。</p>
</li></ol>
</li></ol>

:::

:::{div}
:class: standard-paragraph

<p>类型一中涉及的其他 5G 核心网网元功能应符合 3GPP TS 23.501 v17.7.0（2022⁃12）中 4.2 定义的各类网元功能规定。</p>

:::

<li><p>c） Ta：可信 G 节点与 TNGF 之间的接口，支持 AAA 协议，承载 EAP⁃5G 业务，该信息结构应遵循A.1 和 A.2 的定义。</p>

</li>
<li><p>6） 可为 T 节点分配 IP 地址，用于 T 节点与 G 节点间的控制面和用户面数据传输；</p>

## 5.3 星闪设备协议架构

(gbt-48336-304-2026-clause-5-3-1)=
### 5.3.1 概述

:::{div}
:class: standard-paragraph

<p>根据 GB/T 48336.101 的规定，星闪设备内部从基础应用层到接入层的协议架构见图 4。</p>

:::

:::{div}
:class: standard-paragraph

<p>在融合系统中，5G 核心网可为其覆盖下的一个或多个星闪无线通信系统提供统一的网络管理服务，其中每个星闪无线通信系统包含至少一个可信 G 节点和若干 T 节点。融合系统在星闪设备的基础服务层定义了 5G 融合功能单元，负责所属星闪设备与融合系统中的其他网元进行信令交互，并根据 5G 核心网配置与所属星闪设备内的其他功能单元进行信令或数据交互。5G 融合单元涉及的服务及功能见 5.3.2。</p>

(gbt-48336-304-2026-clause-5-3-2)=
### 5.3.2 5G 融合功能单元服务及功能

:::{div}
:class: standard-paragraph

<p>5G 融合功能单元是基础服务层的一个逻辑上的功能实体，可提供如下服务：</p>

:::

:::{div}
:class: standard-list-block

<ol class="alpha-list" start="1">
<li><p>a） 为上层提供 5G 核心网配置的 QoS 策略；</p>
</li>
<li><p>b） 为融合系统提供传输状态监控；</p>
</li>
<li><p>c） 指示数据流传输策略。</p>
</li></ol>

:::

:::{div}
:class: standard-paragraph

<p>根据图 4 所示架构，为实现 5G 蜂窝网对星闪无线通信系统的统一网络管理，星闪无线通信系统的5G 融合功能单元需调用星闪设备内部中的其他功能单元以完成以下特定操作。</p>

:::

:::{div}
:class: standard-list-block

<ol class="alpha-list" start="1">
<li><p>a） 需要服务管理功能单元提供的服务：</p>
<ol class="decimal-list" start="1">
<li><p>1） 5G 融合服务发现；</p>
</li>
<li><p>2） 进行数据流分流策略协商。</p>
</li></ol>
</li>
<li><p>b） 需要连接管理功能单元提供建立、维护并释放 5G 融合专用的传输通道的服务。其中，传输通道承载的 T 节点与网关（如 TNGF）之间的数据基于 GTP⁃U 隧道协议，该信息结构应遵循 A.3的定义。</p>
</li></ol>

:::

:::{admonition} 注
:class: note

<p>其他非 GTP⁃U 协议参照上述步骤执行。</p>

:::

:::{div}
:class: standard-list-block

<ol class="alpha-list" start="3">
<li><p>c） 需要 QoS 管理功能单元提供的服务：</p>
<ol class="decimal-list" start="1">
<li><p>1） 接收 5G 融合功能单元提供的 QoS 策略并用于星闪通道的建立；</p>
</li>
<li><p>2） 在星闪通道的 QoS 无法满足要求时，向 5G 融合功能单元反馈。</p>
</li></ol>
</li>
<li><p>d） 需要测量管理功能单元提供的服务：</p>
<ol class="decimal-list" start="1">
<li><p>1） 接收 5G 融合功能单元的测量请求，并执行测量；</p>
</li>
<li><p>2） 向 5G 融合功能单元反馈测量结果。</p>
</li></ol>
</li>
<li><p>e） 需要数据传输与适配功能单元提供 5G 融合相关的数据传输与接收服务。</p>
</li></ol>

:::

:::{div}
:class: standard-paragraph

<p>为实现星闪设备与 5G 核心网的交互，T 节点的 5G 融合功能单元支持的功能包括：</p>

:::

:::{div}
:class: standard-list-block

<ol class="alpha-list" start="1">
<li><p>a） 可信 G 节点的选择；</p>
</li>
<li><p>b） 针对融合类型一，支持 T 节点注册；</p>
</li>
<li><p>c） 针对融合类型一，支持与 5G 核心网建立会话；</p>
</li>
<li><p>d） 针对融合类型二，支持接收 5G 核心网的 QoS 策略；</p>
</li>
<li><p>e） 根据 5G 核心网的配置触发对星闪无线通信系统的状态测量并将测量结果上报。</p>
</li></ol>

:::

:::{div}
:class: standard-paragraph

<p>为实现星闪设备与 5G 核心网的交互，G 节点的 5G 融合功能单元支持的功能包括：</p>

:::

:::{div}
:class: standard-list-block

<ol class="alpha-list" start="1">
<li><p>a） 调用服务管理功能单元发布 5G 融合服务，可使 T 节点进行服务发现并访问；</p>
</li>
<li><p>b） 对支持 5G 融合功能的 T 节点进行身份鉴权；可支持 T 节点白名单机制；</p>
</li>
<li><p>c） 根据 5G 核心网的 QoS 策略配置对其覆盖下的 T 节点进行空口资源分配和调度；</p>
</li>
<li><p>d） 可为 T 节点分配 IP 地址，用于控制面和用户面数据传输。</p>
</li></ol>

:::

### 5.3.3 控制面协议栈架构

(gbt-48336-304-2026-clause-5-3-3-1)=
#### 5.3.3.1 概述

:::{div}
:class: standard-paragraph

<p>根据信令交互涉及的网元类型不同，融合系统的控制面协议栈架构分为星闪设备之间的控制面协议架构（简称“融合系统短距控制面架构”）以及星闪设备与融合系统内其他网元之间的控制面协议架构（简称“融合系统远端控制面架构”）。其中，融合系统远端控制面架构可进一步分为融合系统类型一远端控制面架构（见 5.3.3.3）和融合系统类型二远端控制面架构（见 5.3.3.4）。对于融合系统的任意一种类型，其在 T 节点和 G 节点之间的直接信令交互均使用 5.3.3.2 定义的融合系统短距控制面架构。</p>

:::

:::{admonition} 注 1
:class: note

<p>本文件中，星闪设备之间的控制面协议架构仅指 T 节点和 G 节点之间的融合系统短距控制面架构。</p>
