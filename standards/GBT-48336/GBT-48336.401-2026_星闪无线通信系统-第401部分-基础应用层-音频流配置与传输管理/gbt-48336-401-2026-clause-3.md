(gbt-48336-401-2026-clause-3)=
# 3 术语和定义

:::{div}
:class: standard-reference

<p>GB/T 48336.101 界定的以及下列术语和定义适用于本文件。</p>

:::

(gbt-48336-401-2026-clause-3-1)=
## 3.1 音源 audio source

:::{div}
:class: standard-paragraph

<p>音频数据的产生和发送方。</p>

:::

(gbt-48336-401-2026-clause-3-2)=
## 3.2 音宿 audio sink

:::{div}
:class: standard-paragraph

<p>音频数据接收和消费方。</p>

:::

(gbt-48336-401-2026-clause-3-3)=
## 3.3 服务端 server

:::{div}
:class: standard-paragraph

<p>提供至少一种具体服务的星闪设备。</p>

:::

:::{div}
:class: standard-paragraph

<p>[来源：GB/T 48336.301—2026，3.2]</p>

:::

(gbt-48336-401-2026-clause-3-4)=
## 3.4 音频流 audio stream

:::{div}
:class: standard-paragraph

<p>音源和音宿之间传输的连续音频数据。</p>

:::

(gbt-48336-401-2026-clause-3-5)=
## 3.5 混音 audio mixing

:::{div}
:class: standard-paragraph

<p>将来自多个音源的音频流混合成一个音频流的操作或将 1 个音源的音频流并发到多个音频流的操作。</p>

:::

(gbt-48336-401-2026-clause-3-6)=
## 3.6 客户端 client

:::{div}
:class: standard-paragraph

<p>访问服务端并接受至少一种具体服务的星闪设备。</p>

:::

:::{div}
:class: standard-paragraph

<p>[来源：GB/T 48336.301—2026，3.3]</p>

:::

(gbt-48336-401-2026-clause-3-7)=
## 3.7 音频服务端 audio server

:::{div}
:class: standard-paragraph

<p>提供音频服务的服务端。</p>

:::

(gbt-48336-401-2026-clause-3-8)=
## 3.8 音频客户端 audio client

:::{div}
:class: standard-paragraph

<p>访问音频服务端的客户端。</p>

:::

(gbt-48336-401-2026-clause-3-9)=
## 3.9 配置代理 configuration agent

:::{div}
:class: standard-paragraph

<p>在音频广播通信方式中，具有发现音源，替代音源对音宿进行配置功能的实体。</p>

:::

(gbt-48336-401-2026-clause-3-10)=
## 3.10 管理代理 management agent

:::{div}
:class: standard-paragraph

<p>在音频广播通信方式中，具有接收配置代理的配置，并将该配置传递给音宿的功能的实体。</p>

:::
