# 6.1 音频流管理服务

(gbt-48336-401-2026-clause-6-1-1)=
## 6.1.1 服务概述

:::{div}
:class: standard-paragraph

<p>音频流管理服务用于配置音频流和音频流数据通道的参数、控制音频流数据通道的创建和释放、控制音频流的传输和停止。</p>

:::

:::{div}
:class: standard-paragraph

<p>音频流管理服务见表 1。</p>

:::

:::{div}
:class: standard-paragraph

<p>音源访问点：一个音源访问点表示设备有产生和发送一路音频流的能力。音频流管理服务中可含有多个音源访问点属性，表示设备有产生和发送多路音频流的能力。每个音源访问点均需在其关联的音源属性组的范围下进行配置，音源访问点属性是可读的，反映了音频访问点代表的音频流的属性和配置信息。当音频服务端为音源时，音频流管理服务中应定义至少含有一个音源访问点属性。</p>

:::

:::{div}
:class: standard-paragraph

<p>音宿访问点：一个音宿访问点表示设备有接收和处理一路音频流的能力。音频流管理服务中可含有多个音宿访问点属性，表示设备有接收和处理多路音频流的能力。每个音宿访问点均需在其关联的音宿属性组的范围下进行配置，音宿访问点属性是可读的，反映了音宿访问点代表的音频流的属性和配置信息。当音频服务端为音宿时，音频流管理服务中应定义至少含有一个音宿访问点属性。</p>

:::

:::{div}
:class: standard-paragraph

<p>音频控制点：音频客户端可通过音频控制点对音频流进行配置，配置会触发音频流对应的音源访问点、音宿访问点属性值发生变更。</p>

:::

:::{div}
:class: standard-paragraph

<p>音频流状态变更：当音频服务端需要改变音频流状态时，音频服务端可通过事件将该状态变化通知音频客户端。</p>

:::

:::{div}
:class: standard-paragraph

<p>音源访问点和音宿访问点统称为音频访问点。</p>

:::

:::{div}
:class: standard-paragraph

<p>音频流管理服务应对不同的客户端创建不同实例，不同客户端之间的配置是独立的。</p>

:::
