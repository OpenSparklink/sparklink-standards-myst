# 7.5.3.135 连接释放原因指示信息

:::{div}
:class: figure-code

```asn1
-- ASN1START
XRCReleaseReason ::= UINT3
```

:::

```asn1
-- ASN1STOP
```

:::{div}
:class: standard-paragraph

<p>XRCReleaseReason指示 XRC连接释放原因,取值如下:</p>

:::

:::{div}
:class: standard-list-block

<ul class="standard-list">
<li><p>——— 0:表示接入限制,比如资源有限等;</p>
</li>
<li><p>——— 1:表示 T节点主动申请释放;</p>
</li>
<li><p>——— 2:表示 G节点高层主动释放;</p>
</li>
<li><p>——— 3:表示重要配置失败,比如安全密钥更新失败等;</p>
</li>
<li><p>——— 4:表示未知异常;</p>
</li>
<li><p>——— 5:表示节能并要求保留安全上下文;</p>
</li>
<li><p>——— 其他:预留。</p>
</li></ul>

:::
