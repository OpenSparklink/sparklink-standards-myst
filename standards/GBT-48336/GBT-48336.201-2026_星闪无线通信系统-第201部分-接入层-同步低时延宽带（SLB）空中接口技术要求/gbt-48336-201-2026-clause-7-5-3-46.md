# 7.5.3.46 第二类数据信息传输物理资源配置信息

:::{div}
:class: figure-code

```asn1
-- ASN1START
DataResourceConfType2 ::= SEQUENCE {
    dmrs-PortInfo   ENUMERATED {port1, port2, port4, port8} OPTIONAL,
    dmrs-CombInfo   CombInfo    OPTIONAL,
    codingModulationTable   CodingModulationTable,
    codingModulationInfo    CodingModulationInfo,
    frameSymbolInfo DedicatedTimeResource,
    numOfSubCarrierGroup    NumOfSubCarrierGroup    OPTIONAL,
    ttiPeriod   TTiPeriod,
    ttiOffset   TTiOffset,
    phyIDforRSsequence  PhyIDforRSsequence  OPTIONAL,
    phyIDforScrambling  PhyIDforScrambling  OPTIONAL,
    ...
}
-- ASN1STOP
```

:::

:::{div}
:class: standard-paragraph

<p>第二类数据信息传输解调参考信号支持连续子载波发送,或者梳齿状子载波发送。当采用梳齿状子载波发送时,偶数端口使用偶数子载波发送,奇数端口使用奇数子载波发送。</p>

:::

:::{div}
:class: standard-paragraph

<p>第二类数据信息传输解调参考信号所用的符号是被调度资源中相应子载波可用的前$N$ 个符号,其中$N=N_{\mathrm{port}}/N_{\mathrm{comb}}$,$N_{\mathrm{port}}$是端口总数量$,N_{\mathrm{comb}}$取1或者2,当采用连续子载波发送方式时$,N_{\mathrm{comb}}$为1,当采用梳齿方式发送时$,N_{\mathrm{comb}}$为 2。$N$ 个符号中,第$M$ 个符号传输的端口号包括$[M\times N_{\mathrm{comb}},M\times$$N_{\mathrm{comb}}+N_{\mathrm{comb}}),$其中$M=[0,N-1]\text{。}$</p>

:::

:::{div}
:class: standard-paragraph

<p>当前 TTI满足 mod((当前 TTI顺序号-GCI所在 TTI顺序号$),\mathrm{TTiPeriod})=\mathrm{TTiOffset}$时,或当TTiPeriod等于0且当前 TTI满足(当前 TTI顺序号-GCI所在 TTI顺序号$)=\mathrm{TTiOffset}$时,使用 Da-taResourceConfType2配置的资源传输数据信号,DedicatedTimeResource指示 TTI中的符号资源。该周期信息为第二类数据的期望周期,尤其在非连续传输模式下,G节点基于此周期尽可能抢占信道并安排具体资源位置。</p>

:::

:::{div}
:class: standard-paragraph

<p>dmrs-PortInfo为解调参考信号端口数量信息。</p>

:::

:::{div}
:class: standard-paragraph

<p>numOfSubCarrierGroup用于指示第二类数据物理资源的频域信息,表明所需要使用的工作子载波组数量,为可选,具体工作子载波组使用情况由预配置调度激活去激活信息中动态指示。</p>

:::

:::{div}
:class: standard-paragraph

<p>phyIDforRSsequence用于配置SPS资源 G链路或 T 链路参考信号序列生成的物理层标识,可选信元。</p>

:::

:::{div}
:class: standard-paragraph

<p>phyIDforScrambling用于对第二类数据的 G 链路或 T 链路半静态调度数据进行比特加扰,可在xrcReconfiguration消息中携带并配置。</p>

:::
