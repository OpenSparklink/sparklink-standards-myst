# 7.5.3.122 物理层标识配置信息

```asn1
-- ASN1START
```

:::{div}
:class: figure-code

```asn1
IDConfig ::= SEQUENCE {
    newphy-IDforUnicast PhyID   OPTIONAL,
    newphy-IDforGroupcast   PhyIDList   OPTIONAL,
    newphy-IDforNextAccess  PhyID   OPTIONAL,
    newSecurityContextID    SecurityContextID   OPTIONAL,
    newphy-IDforPreConfig   PreConfigPhysID OPTIONAL,
    ...
```

:::

```asn1
-- ASN1STOP
```

:::{div}
:class: standard-paragraph

<p>G节点应为 T 节点配置一个用于单播通信的物理层标识newphy-IDforUnicast,可为 T 节点配置一个或者多个用于组播或者广播通信的物理层标识newphy-IdforGroupcast。在连续传输模式下,用于单播通信和组播通信的物理层标识不应在[contentionPhysID-starting,contentionPhysID-ending]内;</p>

:::

:::{div}
:class: standard-paragraph

<p>G 节点应为T节点配置下次随机接入的物理层标识newphy-IDforNextAccess;G节点应为T节点配置安全上下文关联标识newSecurityContextID,T节点在有安全上下文的关联请求信息中使用该ID作为索引指示安全上下文。</p>

:::

:::{div}
:class: standard-paragraph

<p>newphy-IDforPreConfig用于预配置调度激活去激活信息掩码,当至少配置一类预配置信息时(比如SPS/CSI-RS/SRS/CQI等),需要配置该参数。</p>

:::
