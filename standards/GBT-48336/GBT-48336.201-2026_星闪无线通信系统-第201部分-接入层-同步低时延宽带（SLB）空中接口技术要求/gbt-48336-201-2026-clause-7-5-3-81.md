# 7.5.3.81 高阶调制功率回退信息

:::{div}
:class: figure-code

```asn1
-- ASN1START
TxPowerLimitation ::= SEQUENCE {
    qam16MaxLimitation  UINT3,
    qam16MinLimitation  UINT3,
    qam64MaxLimitation  UINT3,
    qam64MinLimitation  UINT3,
    qam256MaxLimitation UINT3,
    qam256MinLimitation UINT3,
    qam1024MaxLimitation    UINT3,
    qam1024MinLimitation    UINT3,
    qam4096MaxLimitation    UINT3,
    qam4096MinLimitation    UINT3,
    ...
}
-- ASN1STOP
```

:::

:::{div}
:class: standard-paragraph

<p>上述各字段中,MaxLimitation的值代表相应调制模式下最大发送功率的回退值,MinLimitation的值代表相应调制模式下最小发送功率的提升值。</p>

:::
