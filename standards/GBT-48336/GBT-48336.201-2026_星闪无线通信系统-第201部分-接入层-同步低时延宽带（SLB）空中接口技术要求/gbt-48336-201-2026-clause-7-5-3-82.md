# 7.5.3.82 DRX参数配置信息

:::{div}
:class: figure-code

```asn1
-- ASN1START
DRX-Config ::= SEQUENCE {
    drxCfgAddList   DrxCfgList  OPTIONAL,
    drxCfgDelList   DrxCfgList  OPTIONAL,
    drxCfgEnableList    DrxCfgList  OPTIONAL,
    drxCfgDisableList   DrxCfgList  OPTIONAL,
    lateNonCriticalExtension    OCTET STRING    OPTIONAL,
    nonCriticalExtension    SEQUENCE {} OPTIONAL
}
DrxCfgList ::= SEQUENCE (SIZE(1..32)) OF OneDrxCfg
OneDrxCfg ::= SEQUENCE {
    drxIndex    UINT5,
    drxCfgParam SEQUENCE {
    carrierChannelListConf  CarrierChannelListConf,
    startSuperframeIdx  SuperframeIndex,
    frameOffset FrameOffset,
    drxPeriod   UINT16,
    onPeriod    INTEGER (1..65535),
    timeGranularity INTEGER (1..32),
    wakeupIndication    BIT STRING (SIZE (58))  OPTIONAL, --Need OR
    wakeupMask  BIT24   OPTIONAL, --Need OR
    ...
    } OPTIONAL,
    ...
}
-- ASN1STOP
```

:::

:::{div}
:class: standard-paragraph

<p>DRX非连续接收参数配置信元,属于T节点专有配置。该信元可承载在xrcReconfigurationRequest或xrcReconfiguration消息中。</p>

:::

:::{div}
:class: standard-paragraph

<p>drxIndex为 DRX配置项索引,在同一个 T 节点内唯一 ,每个 T 节点最多可支持最大32个配置项。</p>

:::

:::{div}
:class: standard-paragraph

<p>DRX配置包括“添加”“删除”“使能”和“去使能”等操作。其中使能和去使能操作不会添加或删除指定的 DRX配置项,需确保对应的配置项存在。当同时包含添加和删除操作时,T 节点宜先进行删除操作,再进行添加操作。</p>

:::

:::{div}
:class: standard-paragraph

<p>drxCfgParam 包含 DRX具体的配置参数,“添加”操作应包含该项,其他三个操作无需包含。其中,carrierChannelListConf包含 T节点某一个工作频段上的工作信道列表。DRX的起始时间由startSuperframeIdx和frameOffset共同指定。startSuperframeIdx指示该 DRX 配置项生效时刻对应的超帧号。frameOffset指示生效时刻所在超帧内的无线帧偏移量,因此,DRX配置的最小时间颗粒度为无线帧 时 长。timeGranularity 指示 drxPeriod 和 onPeriod 的时间单位———整 数 个 无线 帧 时 长。</p>

:::

:::{div}
:class: standard-paragraph

<p>drxPeriod指示 DRX的周期,为整数个timeGranularity。onPeriod指示 T 节点唤醒后的持续接收时间,为整数个timeGranularity。</p>

:::

:::{div}
:class: standard-paragraph

<p>wakeupMask和 wakeupIndication为可选配置,参考6.2.4.6.3,用于 G 节点动态指示特定 T 节点的休眠和唤醒信息,由 G节点主动对 T 节点进行相关参数配置。wakeupMask为24比特的循环冗余校验掩码,可用于指示当前 DRX配置。wakeupIndication使用58个比特中的某一比特并置“1”指示当前 T节点,其余比特均为0。</p>

:::

:::{div}
:class: standard-paragraph

<p>当 DRX配置中使用 wakeupMask和 wakeupIndication时,T节点在 DRX的每一个onPeriod时间内监测 GCI“休眠与唤醒指示信息”,当定位并发现其24比特的“休眠与唤醒指示信息掩码”与自己某个DRX配置中的 wakeupMask相同时,则认为 G节点针对该 DRX配置对当前 T节点进行动态的休眠与唤醒指示。此时,T节点需要进一步使用 wakeupIndication和 GCI“休眠与唤醒指示信息”中的58比特进行“与”操作,当结果为非零时,表明该 T节点在当前onPeriod剩余时间需要继续唤醒并监测 GCI休眠与唤醒指示信息;当结果为0时,表明 T节点在当前onPeriod剩余时间无需唤醒(即可睡眠),但仍然需要在下一个onPeriod起始时刻再次唤醒。</p>

:::

:::{div}
:class: standard-paragraph

<p>当 DRX配置中不包含 wakeupIndication和 wakeupMask时,T 节点无需监测 GCI休眠与唤醒指示信息。</p>

:::
