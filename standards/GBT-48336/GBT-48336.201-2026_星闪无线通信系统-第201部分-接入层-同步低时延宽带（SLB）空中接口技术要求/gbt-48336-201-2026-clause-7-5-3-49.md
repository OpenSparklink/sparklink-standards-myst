# 7.5.3.49 信道状态信息配置信息

```{image} ../../../assets/structured/GBT-48336.201-2026/regions/p0218-figure-03-509.png
:alt: 协议代码：7.5.3.49 信道状态信息配置信息
:class: source-code
:width: 1029px
```

:::{div}
:class: standard-paragraph

<p>当 GCI指示“信道状态信息配置信息 CSI-RS”时,该 CSI-RS信息所在 TTI计算如下。</p>

:::

:::{div}
:class: standard-paragraph

<p>当前 TTI满足 mod((当前 TTI顺序号-GCI所在 TTI顺序号$),\mathrm{TTiPeriod})=\mathrm{TTiOffset}$时,或当TTiPeriod等于0且当前 TTI满足(当前 TTI顺序号-GCI所在 TTI顺序号$)=\mathrm{TTiOffset}$时,G节点使用 CSI-RS-Conf配置的资源发送信道状态信息参考信号。当ttiPeriod不配置时,默认取值为0;当ttiOffset不配置时,默认取值为0。DedicatedTimeResource指示 TTI中的符号资源,其中 CSI-RS资源的起始符号信息symbolStarting可不配置或配置为0,具体起始符号数值由其他信元计算得出并覆盖该配置项,见6.2.3.3。csi-rs-Identity为当前CSI-RS配置标识,可被物理层预配置调度激活去激活信息指示和调度。当csi-rs-Identity与cqi-Identity相同时,物理层预配置调度激活去激活信息可同时进行激活去激活。csi-rs-DedicatedACK 用于对 CSI-RS信号的反馈资源配置。</p>

:::

:::{div}
:class: standard-paragraph

<p>当删除 CSI-RS相关配置时,只需要提供 DSI-RS配置标识csi-rs-Identity即可。</p>

:::

:::{div}
:class: standard-paragraph

<p>针对信道状态信息梳齿偏移序号信息csi-rs-CombOffset和信道状态信息梳齿集合信息csi-rs-CombInfo,当子载波编号满足$\mathrm{mod}(\#\mathrm{subcarrier},\mathrm{csi}-\mathrm{rs}-\mathrm{CombInfo})=\mathrm{mod}(\mathrm{csi}-\mathrm{rs}-\mathrm{CombOffset},\mathrm{csi}-\mathrm{rs}-$CombInfo)时,该子载波发送信道状态信息参考信号。</p>

:::

:::{div}
:class: standard-paragraph

<p>若未配置newphy-IDforPreConfig,则需要配置。</p>

:::

:::{div}
:class: standard-paragraph

<p>phyIDforRSsequence用于配置 CSI-RS参考信号序列生成的物理层标识,可选信元。</p>

:::

:::{div}
:class: standard-paragraph

<p>locationInd指示 CSI-RS符号位置指示,为可选项,默认值为pcib,即为 G-PCIB之后的第一个符号,sab指示为SAB之后的第一个符号。</p>

:::
