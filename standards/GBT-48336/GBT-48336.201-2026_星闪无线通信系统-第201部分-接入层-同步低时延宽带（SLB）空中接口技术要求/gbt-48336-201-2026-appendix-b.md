# 附录 B（资料性）典型应用场景下安全配置示例

:::{div}
:class: standard-paragraph

<p>典型<strong>应用</strong>场景<strong>下的安全配置示</strong>例</p>

:::

:::{div}
:class: standard-paragraph

<p><strong>B</strong>.1 降噪</p>

:::

:::{div}
:class: standard-paragraph

<p>降噪场景下的安全配置举例如下。</p>

:::

:::{div}
:class: standard-list-block

<ul class="standard-list">
<li><p>——— 认证凭证配置:配置密钥方法。</p>
</li>
<li><p>——— 传输安全保护:关闭用户面完整性保护。开启用户面加密保护,建议密钥流提前生成,以加快加解密速度。</p>
</li>
<li><p>——— 安全隔离:禁止同步低时延宽带通信系统的流量进入车内网。</p>
</li></ul>

:::

:::{div}
:class: standard-paragraph

<p><strong>B</strong>.2 <strong>语</strong>音</p>

:::

:::{div}
:class: standard-paragraph

<p>语音场景下的安全配置举例如下。</p>

:::

:::{div}
:class: standard-list-block

<ul class="standard-list">
<li><p>——— 认证凭证配置:配置口令方法。</p>
</li>
<li><p>——— 传输安全保护:开启用户面完整性保护和加密保护。用户面完整性保护的 MIC长度选择根据完整性保护算法支持的 MIC长度和预配置的 MIC长度优选策略进行选择。</p>
</li>
<li><p>——— 安全隔离:禁止同步低时延宽带通信系统的流量进入车内网。</p>
</li></ul>

:::

:::{div}
:class: standard-paragraph

<p><strong>B</strong>.3 投屏</p>

:::

:::{div}
:class: standard-paragraph

<p>投屏场景下的安全配置举例如下:</p>

:::

:::{div}
:class: standard-list-block

<ul class="standard-list">
<li><p>——— 认证凭证配置。</p>
</li>
<li><p>——— 手机-CDC:配置口令方法。</p>
</li>
<li><p>——— CDC-其他屏幕:配置密钥方法。</p>
</li>
<li><p>——— 传输安全保护:开启用户面完整性保护和加密保护。用户面完整性保护的 MIC长度的选择根据完整性保护算法支持的 MIC长度和预配置的 MIC长度优选策略进行选择。投屏场景下的MIC长度优先级为128比特&gt;64比特&gt;32比特。</p>
</li>
<li><p>——— 安全隔离:禁止同步低时延宽带通信系统的流量进入车内网。</p>
</li></ul>

:::

:::{div}
:class: standard-paragraph

<p><strong>B</strong>.4 电<strong>子</strong>钥匙</p>

:::

:::{div}
:class: standard-paragraph

<p>电子钥匙场景下的安全配置建议如下。</p>

:::

:::{div}
:class: standard-list-block

<ul class="standard-list">
<li><p>——— 认证凭证配置:配置密钥方法。</p>
</li>
<li><p>——— 传输安全保护:开启用户面机密性和完整性保护。用户面完整性保护的 MIC长度选择根据完整性保护算法支持的 MIC长度和预配置的 MIC长度优选策略进行选择。电子钥匙场景下的MIC长度优先级为128比特&gt;64比特&gt;32比特。</p>
</li>
<li><p>——— 安全隔离:允许同步低时延宽带通信系统的流量进入车内网。</p>
</li></ul>

:::
