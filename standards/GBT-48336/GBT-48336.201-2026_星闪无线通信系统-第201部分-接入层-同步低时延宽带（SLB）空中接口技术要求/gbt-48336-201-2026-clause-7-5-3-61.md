# 7.5.3.61 G 节点特定载波切换指示信息

:::{div}
:class: figure-code

```asn1
-- ASN1START
CarrierSwitch-GSpecific ::= SEQUENCE {
    channelNumberList   SEQUENCE (SIZE (1..16)) OF ChannelNumber,
    carrierSwitchTime   SuperframeIndex,
    ...
}
-- ASN1STOP
```

:::

:::{div}
:class: standard-paragraph

<p>channelNumberList指示 G节点发生载波配置变化时,一个或多个目标通信域载波的信道号;car-rierSwitchTime指示 G节点发送该系统消息所在的超帧之后载波配置变化生效的目标超帧的编号,在该超帧之前,G节点仍旧使用未切换的载波进行数据传输。</p>

:::
