# 7.5.3.89 DMRS-D资源配置信息

:::{div}
:class: figure-code

```asn1
-- ASN1START
DMRS-D-SetConf ::= SEQUENCE {
    dmrs-D-GlinkToAddModList    DMRS-D-GlinkList    OPTIONAL,
    dmrs-D-GlinkToDelModList    DMRS-D-GlinkList    OPTIONAL,
    dmrs-D-TlinkToAddModList    DMRS-D-TlinkList    OPTIONAL,
    dmrs-D-TlinkToDelModList    DMRS-D-TlinkList    OPTIONAL,
    ...
}
DMRS-D-GlinkList ::= SEQUENCE (SIZE(1..8)) OF DMRS-D-Conf
DMRS-D-TlinkList ::= SEQUENCE (SIZE(1..4)) OF DMRS-D-Conf
-- ASN1STOP
```

:::

:::{div}
:class: standard-paragraph

<p>当 G链路或 T链路 DMRS-D 资源配置中同时包含添加和删除操作时,T 节点宜先进行删除操作,再进行添加操作。</p>

:::
