# 7.5.3.50 信道状态信息集合配置信息

:::{div}
:class: figure-code

```asn1
-- ASN1START
CSI-RS-Set-Conf ::= SEQUENCE {
    csi-rs-confAddList  CSI-RS-confList OPTIONAL,
    csi-rs-confDelList  CSI-RS-confList OPTIONAL,
    ...
}
CSI-RS-confList ::= SEQUENCE (SIZE (1..16)) OF CSI-RS-Conf
-- ASN1STOP
```

:::

:::{div}
:class: standard-paragraph

<p>信道状态信息集合配置信息 CSI-RS包括添加、删除等操作。当同时包含添加和删除操作时,T 节点宜先进行删除操作,再进行添加操作。</p>

:::
