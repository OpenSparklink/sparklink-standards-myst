### 8.4.1.2 最小输出功率

:::{div}
:class: standard-paragraph

<p>SLB设备在每个发射通道天线连接处的最小输出功率应不高于$P_{\mathrm{max}}-32\mathrm{dB}$ 和-15dBm 的最大值。</p>

:::{div}
:class: standard-paragraph

(gbt-48336-201-2026-clause-8-4-1-4)=
### 8.4.1.4 输出功率模板

:::{div}
:class: standard-paragraph

<p>SLB发射机从最大输出功率到最小输出功率的转换时间小于或等于1 s。对于相邻符号间1 s$\mu \mu$的转换时间,前1符号占0.5 s,后1符号占0.5 s。</p>

:::

:::{div}
:class: standard-paragraph

<p>$\mu \mu$SLB发射机在不同输出功率之间转换时间小于或等于1 s。对于相邻符号间1 s的转换时间,前$\mu \mu$1符号占0.5 s,后1符号占0.5 s。</p>

:::

:::{div}
:class: standard-paragraph

<p>$\mu \mu$</p>

:::

(gbt-48336-201-2026-clause-8-4-2)=
## 8.4.2 调制精度

(gbt-48336-201-2026-clause-8-4-2-1)=
### 8.4.2.1 频率误差

:::{div}
:class: standard-paragraph

<p>频率误差、载波泄漏、误差矢量幅度和频谱平坦度等指标常用来进行调制精度度量。调制精度用于衡量SLB设备的输出有用信号的调制质量。如无特殊说明,发射机调制精度均在每个发射通道的每个信道上规定。</p>

:::

:::{div}
:class: standard-paragraph

<p>SLB设备工作在1GHz以上的频段时,发射信道中心频点的相对频率误差应在$\pm 5\times 10^{-6}$以内。</p>

:::

:::{div}
:class: standard-paragraph

<p>SLB设备工作在sub1GHz频段时,发射信道中心频点的相对频率误差应在$\pm 20\times 10^{-6}$以内。发射信道中心频点和符号时钟频率应来源于同一个晶振。</p>

:::

:::{div}
:class: standard-paragraph

<p>SLB设备 G节点做频偏校正后,G节点发射信道中心频点与接收到的同步源信道中心频点的相对频率误差应在$\pm 0.1\times 10^{-6}$以内。</p>

:::

:::{div}
:class: standard-paragraph

<p>SLB设备 T节点做频偏校正后,T节点发射信道中心频点与接收到的 G节点信道中心频点的相对频率误差应在$\pm 0.1\times 10^{-6}$以内。</p>

:::

(gbt-48336-201-2026-clause-8-4-2-2)=
### 8.4.2.2 载波泄漏和带内杂散

:::{div}
:class: standard-paragraph

<p>SLB设备 G节点工作在 1GHz以上的频段时,发射信道中心频点的载波泄漏功率应不高于$P-40\mathrm{dB}$和-20dBm 的最大值,工作在sub1GHz频段时,发射信道中心频点的载波泄漏功率应不高于$P-40\mathrm{dB}$,带内杂散泄漏功率应不高于$P-40\mathrm{dB}$,$P$ 为设备在天线连接处的实际的输出功率,以dBm 为单位。载波泄漏的测量带宽应为以载波中心频点(与信道中心频率对应)为中心的一个子载波内,载波泄漏值在信道估计阶段计算。</p>

:::

:::{div}
:class: standard-paragraph

<p>SLB设备 T节点发射信道中心频点的载波泄漏功率,在发射功率为$-40\mathrm{dBm}\sim -30\mathrm{dBm}$ 之间时应不高于$P-10\mathrm{dB}$和-20dBm 的最大值,在发射功率为$-30\mathrm{dBm}\sim 0\mathrm{dBm}$ 之间时应不高于$P-$20dBm 和-20dBm 的最大值,在发射功率为0dB以上时应不高于$P-25\mathrm{dBm}$ 和-20dBm 的最大值,带内杂散泄漏功率应不高于$P-40\mathrm{dB}$,P为设备在天线连接处的实际的输出功率,以dBm 为单位。</p>

:::

:::{div}
:class: standard-paragraph

<p>载波泄漏的测量带宽应为以载波中心频点(与信道中心频率对应)为中心的一个子载波内,载波泄漏值在信道估计阶段计算。</p>

:::

:::{div}
:class: standard-paragraph

<p>当SLB设备工作在由多个基础信道组成的工作信道时,载波泄漏可能在多个信道所覆盖的最低到最高频率范围中间的某个子载波上,需要满足的要求不变。</p>

:::

:::{div}

<p>误差矢量幅度的测量应先完成无线帧定时、初/精频偏估计、信道响应系数估计等。对于数据符号,将接收到的信号做相应的定时、频偏补偿后,经FFT 后得到每个子载波上的信号,子载波上的信号与估计的信道响应系数做均衡得到均衡后的信号,以均衡后的信号为基础,在星座图中找到一个距离均衡后信号欧式距离最小的星座点,EVM 计算方式如公式(51)所示。</p>

:::

(gbt-48336-201-2026-equation-51)=
```{math}
\mathrm{EVM}=\sqrt{\frac{\sum_{t\in T}\sum_{f\in F(t)}|Z'(t,f)-I(t,f)|^2}{\sum_{t\in T}\sum_{f\in F(t)}|I(t,f)|^2}}\tag{51}
```

:::{div}
:class: standard-paragraph

<p>式中:</p>

:::

:::{div}
:class: standard-definitions

$T$
: 观察时间内总的 OFDM 的符号数;

:::

:::{div}
:class: standard-definitions

$F(t)$
: 某个 OFDM 符号所包含的子载波数;

:::

:::{div}
:class: standard-definitions

I(t,f)
: 重建的理想调制符号;

:::

:::{div}
:class: standard-definitions

Z'(t,f)
: 接收的经过定时、频偏补偿后的调制符号,如公式(52)所示。

:::

(gbt-48336-201-2026-equation-52)=
```{math}
Z'(t,f)=\frac{\operatorname{FFT}\{z(v-\Delta\widetilde t)\cdot\exp(-j2\pi\Delta\widetilde f\cdot v)\}\cdot\exp(j2\pi f\Delta\widetilde t)}{\widetilde a(f)\cdot\exp(j\varphi(f))}\tag{52}
```

:::{div}
:class: standard-paragraph

<p>式中:</p>

:::

:::{div}
:class: standard-definitions

z(v)
: 时域接收的信号;

:::

:::{div}
:class: standard-paragraph

<p>$\sim$</p>

:::

:::{div}
:class: standard-definitions

$\Delta t$
: FFT处理窗与理想定时之间的时间差;

:::

:::{div}
:class: standard-paragraph

<p>$\sim$</p>

:::

:::{div}
:class: standard-definitions

$\Delta f$
: 频偏;

:::

:::{div}
:class: standard-definitions

a~(f)
: 信道幅度相应;

:::

:::{div}
:class: standard-definitions

(f)
: 相位响应。

:::

:::{div}
:class: standard-paragraph

:::

(gbt-48336-201-2026-clause-8-4-2-4)=
### 8.4.2.4 频谱平坦度

:::{div}
:class: standard-paragraph

<p>SLB设备工作信道带宽的至少中间62%信道带宽包含的子载波上,SLB设备每个子载波上信号的功率不应超过中间62%信道带宽内所有子载波平均功率的$\pm 2\mathrm{dB}$,信道带宽内的其余子载波上信号的功率不应超过中间62%信道带宽内所有子载波平均功率的+4dB/-6dB。中心子载波和保护带内的子载波无需满足频谱平坦度要求,如果某个子载波只有一部分在中间62%信道带宽内,则这个子载波被视为在中间62%信道带宽内。频谱平坦度的测量信号为参考信号。</p>

:::

:::{div}
:class: standard-paragraph

<p>频谱平坦度的测量应先完成无线帧定时、初/精频偏估计等。对于数据符号,将接收到的信号做相应的定时、频偏补偿后,经FFT后得到每个子载波上的信号,估计每个子载波的信号功率。然后计算每个子载波的信号功率与中间62%信道带宽内所有子载波平均功率的差异,判断是否满足频谱平坦度的要求。频谱平坦度的测量时间为20个超帧,每个超帧单独计算子载波功率,然后平均得到相应的子载波功率。</p>

:::

(gbt-48336-201-2026-clause-8-4-2-5)=
### 8.4.2.5 时延一致性要求

:::{div}
:class: standard-paragraph

<p>时延一致性规定了任意两个发射通道天线连接器处之间的平均帧定时差。对于支持 MIMO 的SLB设备,任意两个发射通道的平均帧定时差应不大于8ns。</p>

:::

## 8.4.3 无用发射

(gbt-48336-201-2026-clause-8-4-3-1)=
### 8.4.3.1 频谱模板

:::{div}
:class: standard-paragraph

<p>SLB设备的发射频谱模板和发射杂散指标通常由无用发射规定。如无特殊说明,无用发射定义在发射的总带宽上,对于单个信道发射,总带宽即单个信道带宽,对于多个信道发射,总带宽即所有信道的带宽之和。无用发射应符合所在国家和地区的法规要求。</p>

:::

:::{div}
:class: standard-paragraph

<p>SLB设备灵活带宽基础模式每个发射通道的单个信道的发射频谱模板如图 42 和表 62 所示。</p>

:::

:::{div}
:class: standard-paragraph

<p>SLB设备每个发射通道上每个频点的带外发射应满足频谱模板规定的限值和-53dBm/MHz中的最大值。其中,单个信道为单个基础信道,或者由$N$ 个连续基础信道构成的工作信道。在工作信道中,发射机以相同的功率谱密度在每个基础信道上进行发射。</p>

:::

:::{div}
:class: standard-paragraph

<p>模板中的Fc为信道的中心频点,带宽BW 为信道的总带宽。$\mathrm{Fc}=(F1+F2)/2$,其中F1和F2分别为信道所覆盖频率范围的最低频率和最高频率。相应的频谱模板指标要求应符合表62的要求。</p>

:::

:::{div}
:class: standard-paragraph

<p>SLB设备的第一邻道功率泄漏比例应大于或等于35dB,第二邻道功率泄漏比例应大于或等于40dB。</p>

:::

:::{div}
:class: standard-paragraph

<p>其中,邻道功率泄漏比定义为工作信道内平均功率与工作信道外相邻频率范围内平均功率的比例值。</p>

:::

:::{div}
:class: standard-paragraph

<p>第一邻道定义为工作信道以Fc-BW 或Fc+BW 为中心频率,以工作信道为带宽的频率范围。第二邻道定义为以Fc-2BW 或Fc+2BW 为中心,以工作信道为带宽的频率范围。工作信道带宽见8.2。</p>

### 8.4.3.2 发射杂散

:::{div}
:class: standard-paragraph

<p>发射杂散包括谐波辐射、寄生辐射、互调产物和变频产物。</p>

:::

:::{div}
:class: standard-paragraph

<p>在SLB设备的第二邻道以外,带外杂散泄漏比例应大于或等于45dB。带外杂散泄漏比定义为工作信道内的平均发射功率与第二邻道以外以 BW 为带宽的频率范围的平均发射功率的比例。第二邻道定义以Fc-2BW 或Fc+2BW 为中心,以BW 为带宽的频率范围。第二邻道外定义为距离工作信道中心频率2.5BW 以外频谱范围。发射杂散应符合国家频谱法规规定的杂散要求。</p>

:::

(gbt-48336-201-2026-clause-8-4-3-3)=
### 8.4.3.3 部分发射的频谱模板

:::{div}
:class: standard-paragraph

<p>SLB设备的工作信道由多个基础载波构成,但在其中部分基础载波上,SLB设备不发射信号。这种情况下,SLB设备每个发射通道的发射频率模板为每个基础信道符合如图42所示的发射频率模板的线性加和。</p>

:::

:::{div}
:class: standard-paragraph

<p>SLB设备的工作信道外第一邻道功率泄漏比例应大于或等于35dB,工作信道外第二邻道功率泄漏比例应大于或等于40dB。其中,邻道功率泄漏比定义为工作信道内平均功率与工作信道外相邻频率范围内平均功率的比例值。第一邻道定义为工作信道以Fc-BW 或 Fc+BW 为中心频率,以工作信道为带宽的频率范围。第二邻道定义为以Fc-2BW 或Fc+2BW 为中心,以工作信道为带宽的频率范围。SLB设备两个发射基础载波之间的非发射基础载波上,或者在工作信道边缘的非发射基础载波上,邻道功率泄漏比应大于或等于32dB。</p>

:::
