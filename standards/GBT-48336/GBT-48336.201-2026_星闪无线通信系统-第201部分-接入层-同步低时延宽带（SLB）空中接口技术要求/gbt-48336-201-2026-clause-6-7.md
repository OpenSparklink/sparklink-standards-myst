# 6.7 感知测量流程

(gbt-48336-201-2026-clause-6-7-1)=
## 6.7.1 概述

:::{div}
:class: standard-paragraph

<p>G节点作为感知管理节点,可通过 XRC消息向 T 节点发送感知能力请求,T 节点通过 XRC消息向 G节点发送其传输测量帧的能力,以及其通过测量帧进行感知测量的能力。基于 T 节点的能力,G节点通过 XRC消息配置 T节点传输测量帧。</p>

:::

:::{div}
:class: standard-list-block

<ul class="standard-list">
<li><p>——— 单站、双站感知测量:支持 G节点和 T 节点之间传输测量帧,支持两个 T 节点之间传输测量帧,也支持单个节点发送并接收测量帧进行感知测量。基于 G 节点的配置,两个节点传输测量帧,支持如下情况。</p>
</li></ul>

:::

:::{div}
:class: standard-list-block

<ul class="standard-list">
<li><p>· $\cdot$单向测量:一个节点发送测量帧,另外一个节点接收测量帧并根据测量帧进行感知测量。</p>
</li></ul>

:::

:::{div}
:class: standard-paragraph

<p>此时,一个节点发送测量帧称为一个感知事件。节点间可传输多个感知事件进行多次感知或者进行更准确的感知。</p>

:::

:::{div}
:class: standard-list-block

<ul class="standard-list">
<li><p>· $\cdot$双向测量:第一节点发送第一测量帧,第二节点发送第二测量帧,同时第二节点向第一节</p>
</li></ul>

:::

:::{div}
:class: standard-paragraph

<p>点反馈第一测量帧的测量信息(信道状态信息),此时第一节点根据双向测量帧获得的复合信道进行感知。此时,两个节点先后共发送两个测量帧称为一个感知事件。节点间可传输多个感知事件进行多次感知或者进行更准确的感知;G 节点可配置 T 节点在感知事件中先发送测量帧还是后发送测量帧。</p>

:::

:::{div}
:class: standard-paragraph

<p>节点可对对端节点发送的测量帧进行感知测量,并上报感知测量信息,感知测量信息包括:出发角信息 AoD,到达角信息 AoA,基于频率域I路和 Q 路信息的信道状态信息,基于时间域信道冲击响应的信道状态信息,距离多普勒信息,感知目标信息等。</p>

:::

:::{div}
:class: standard-list-block

<ul class="standard-list">
<li><p>——— 多站感知测量:基于上述 G节点配置的一个节点发送测量帧,另外一个节点接收测量帧进行</p>
</li></ul>

:::

:::{div}
:class: standard-paragraph

<p>单向感知测量的情况,G节点可配置多个节点传输测量帧,支持如下情况:</p>

:::

:::{div}
:class: standard-list-block

<ul class="standard-list">
<li><p>· $\cdot$一个节点发送测量帧,多个节点接收该一个节点发送的测量帧,该多个节点根据 G 节点</p>
</li></ul>

:::

:::{div}
:class: standard-paragraph

<p>的配置对接收到的测量帧进行感知并上报感知信息;</p>

:::

:::{div}
:class: standard-list-block

<ul class="standard-list">
<li><p>· $\cdot$多个节点发送测量帧,一个节点接收该多个节点发送的多个测量帧。</p>
</li></ul>

:::

:::{div}
:class: standard-paragraph

<p>基于上述 G节点配置的两个节点间传输测量帧进行双向感知测量的情况,G 节点可配置多个节点传输测量帧,支持如下情况:</p>

:::

:::{div}
:class: standard-list-block

<ul class="standard-list">
<li><p>· $\cdot$一个节点与多个节点传输测量帧,该多个节点中的每个节点都可接收到该一个节点发送</p>
</li></ul>

:::

:::{div}
:class: standard-paragraph

<p>的测量帧,该一个节点也可接收到该多个节点中的每个节点发送的测量帧,该一个节点与该多个节点根据 G节点的配置对接收到的测量帧进行感知并上报感知信息。</p>

:::

:::{div}
:class: standard-list-block

<ul class="standard-list">
<li><p>——— 多种协作感知测量:G节点可作为感知管理节点,配置多个节点发送和接收测量帧,进行感知</p>
</li></ul>

:::

:::{div}
:class: standard-paragraph

<p>测量并上报感知测量信息,完成对环境的多节点协作感知,支持如下情况:</p>

:::

:::{div}
:class: standard-list-block

<ul class="standard-list">
<li><p>· $\cdot$多对节点发送并接收测量帧,进行双向测量并上报感知测量信息,完成多节点协作感知;</p>
</li>
<li><p>· $\cdot$多对节点发送或接收测量帧,进行单向测量并上报感知测量信息,完成多节点协作感知;</p>
</li>
<li><p>· $\cdot$多个节点发送并接收测量帧进行感知测量并上报感知测量信息,完成多节点协作感知;</p>
</li>
<li><p>· $\cdot$以上多种模式组合的多节点协作感知。</p>
</li></ul>

:::

:::{div}
:class: standard-paragraph

<p>在多节点协作感知中,感知管理节点可为多个节点分配不同的时间、频率资源,在多节点协作感知中避免干扰。</p>

:::

:::{div}
:class: standard-list-block

<ul class="standard-list">
<li><p>——— 代理感知、T节点发起感知测量:基于上述 G节点配置进行感知测量的情况,T 节点可作为感</p>
</li></ul>

:::

:::{div}
:class: standard-paragraph

<p>知请求节点,向 G节点发送请求,支持如下情况:</p>

:::

:::{div}
:class: standard-list-block

<ul class="standard-list">
<li><p>· $\cdot$代理感知,也即 T节点向 G节点发送代理感知请求,G 节点向 T 节点发送代理感知反馈</p>
</li></ul>

:::

:::{div}
:class: standard-paragraph

<p>并配置进行代理感知。G节点通过感知测量上报消息将代理感知结果发送给 T节点;</p>

:::

:::{div}
:class: standard-paragraph

<p>$\cdot T$节点发起的感知,也即 T 节点向 G 节点发送感知流程请求,G 节点向 T 节点发送感知</p>

:::

:::{div}
:class: standard-paragraph

<p>流程反馈并配置进行感知。</p>

:::

:::{div}
:class: standard-list-block

<ul class="standard-list">
<li><p>——— 公共资源感知、非链接感知测量:同步信号可用作信道状态信息的估计,并进一步用作感知。</p>
</li>
<li><p>——— 感知资源预留:G节点可给 T节点配置资源预留,当该资源预留指示的时间资源与 T 节点已</p>
</li></ul>

:::

:::{div}
:class: standard-paragraph

<p>经被配置数据传输重叠时,T节点不在该资源预留指示的时间资源上发送和接收数据。</p>

:::

:::{div}
:class: standard-list-block

<ul class="standard-list">
<li><p>——— 支持设备状态上报:在感知测量中,感知设备可通过感知设备状态上报,表示当前设备稳定性</p>
</li></ul>

:::

:::{div}
:class: standard-paragraph

<p>状态。在感知测量中,支持位置测量指示,以及配置位置测量量上报周期,以动态获取感知设备相对位置。</p>

:::

:::{div}
:class: standard-list-block

<ul class="standard-list">
<li><p>——— 支持感知模式切换:在感知测量中,感知设备如果存在切换感知模式的需求,通过发送感知行</p>
</li></ul>

:::

:::{div}
:class: standard-paragraph

<p>为指示,并进行超宽带脉冲感知配置,实现常规波形感知到超宽带脉冲感知的切换。当感知行</p>

:::

:::{div}
:class: standard-paragraph

<p>为指示配置为感知终止,释放感知信号配置,并进行超宽带脉冲感知配置,常规波形感知切换至超宽带脉冲感知;当感知行为指示配置为感知停止,不释放感知信号配置,并进行超宽带脉冲感知配置,常规波形感知切换至超宽带脉冲感知,并支持切换为常规波形感知原有信号配置;当感知行为指示配置为从启动测量生效时间重新开始执行感知,原有时间资源配置失效,并进行超宽带脉冲感知配置,常规波形感知可与超宽带脉冲感知同时进行。</p>

:::
