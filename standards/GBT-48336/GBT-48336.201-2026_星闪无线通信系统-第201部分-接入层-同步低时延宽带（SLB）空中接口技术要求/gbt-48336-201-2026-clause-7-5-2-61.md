# 7.5.2.61 超宽带脉冲感知配置反馈消息

:::{div}
:class: figure-code

```asn1
-- ASN1START
SLPSensingConfigurationFeedback ::= SEQUENCE {
    xrc-Identifier  XRC-Identifier,
    sLPSensingConfigIndex   UINT8,
    sLPSensingConfigState   UINT8,
    lateNonCriticalExtension    OCTET STRING    OPTIONAL,
    nonCriticalExtension    SEQUENCE {} OPTIONAL
}
-- ASN1STOP
```

:::

:::{div}
:class: standard-paragraph

<p>SLPSensingConfigurationFeedback由 T节点发送给 G节点,用于向 G节点进行超宽带脉冲感知配置反馈。sLPSensingConfigIndex用于指示感知信号配置索引;sLPSensingConfigState用于指示感知信号配置状态,标识节点是否接受该请求。0:接受感知信号配置;1:拒绝感知信号配置;其他数值预留。</p>

:::
