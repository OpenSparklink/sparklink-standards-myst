## 6.4.1 超宽带脉冲波形和调制

:::{div}
:class: standard-paragraph

<p>超宽带脉冲信号的参考脉冲波形为凯撒 Kaiser波形,其表达方式如公式(21)所示。</p>

:::

(gbt-48336-201-2026-equation-21)=
```{math}
r(t)=\begin{cases}\frac1L\frac{I_0\!\left[\beta\sqrt{1-\left(\frac{2t}{L}\right)^2}\right]}{I_0[\beta]},&|t|\leq\frac L2\\0,&|t|>\frac L2\end{cases}\tag{21}
```

:::{div}
:class: standard-paragraph

<p>式中:</p>

:::

:::{div}
:class: standard-definitions

$I_{0}$
: 第一类零阶修正贝塞尔函数;

:::

:::{div}
:class: standard-list-block

<ul class="standard-list">
<li><p>——— 决定波形形状的参数$,=10$;</p>
</li></ul>

:::

:::{div}
:class: standard-paragraph

<p>$\beta \beta$</p>

:::

:::{div}
:class: standard-definitions

$T_{p}$
: 波形的带宽参数;

:::

:::{div}
:class: standard-definitions

$L$
: 对于凯撒脉冲波形$,L$ 为脉冲持续时间,该值为$3\cdot T_{p}$。

:::

:::{div}
:class: standard-paragraph

<p>针对不同带宽的信号,带宽参数$T_{p}$和归一化互相关函数参数$T_{w}$如表15所示。</p>

:::

<p>超宽带脉冲发射波形$p(t)$与参考脉冲波形$r(t)$的归一化互相关函数如公式(22)所示。</p>

:::

(gbt-48336-201-2026-equation-22)=
```{math}
\phi(\tau)=\frac1{\sqrt{E_r}\sqrt{E_p}}\operatorname{Re}\left[\int_{-\infty}^{\infty}r(t)\,p^*(t+\tau)\,\mathrm dt\right]\tag{22}
```

:::{div}
:class: standard-paragraph

<p>式中:</p>

:::

:::{div}
:class: standard-definitions

$E_{r}$
: $r(t)$的能量;

:::

:::{div}
:class: standard-definitions

$E_{p}$
: $p(t)$的能量;

:::

:::{div}
:class: standard-definitions

p\* (t)
: p(t)的复共轭;

:::

:::{div}
:class: standard-definitions

$\mathrm{Re}[\cdot ]$
: 表示实部。

:::

:::{div}
:class: standard-paragraph

<p>令 $|\phi(\tau)|$ 表示 $\phi(\tau)$ 的强度，则 $|\phi(\tau)|$ 需要满足在至少 $T_w$ 的持续时间里主瓣强度大于或等于 0.92，旁瓣强度不大于 0.1。具体而言，令 $\tau_i(i=1,2,\cdots)$ 为公式（23）定义的临界点的集合。</p>

:::

(gbt-48336-201-2026-equation-23)=
```{math}
\left.\frac{\mathrm d}{\mathrm d\tau}|\phi(\tau)|\right|_{\tau=\tau_i}=0\tag{23}
```

:::{div}
:class: standard-paragraph

<p>归一化互相关函数的强度最大值出现在 $\tau_{\mathrm{max}}$，对于所有的 $\tau$ 都有 $|\phi(\tau_{\mathrm{max}})|\geq|\phi(\tau)|$。对于包含 $\tau_{\mathrm{max}}$ 且持续时间大于或等于 $T_w$ 的连续集合，要求 $|\phi(\tau)|\geq0.92$。同时对所有 $\tau_i$，旁瓣需满足 $|\phi(\tau_i)|\leq0.1$。</p>

:::

:::{div}
:class: standard-paragraph

<p>对于一个超宽带脉冲测量信号的一个码片$c(n),c(n)\in \{-1,0,+1\}$,该码片的载波调制信号为$,c(n)\cdot r(t-n\cdot T_{c})\cdot \mathrm{cos}[2\pi \cdot f_{c}\cdot (t-n\cdot T_{c})]$,其中$f_{c}$为载波中心频率$,T_{c}=1/$最大脉冲重复频率,为每个码片的持续时间,其中,最大脉冲重复频率为499.2MHz。</p>

<p>图 6　超宽带脉冲测量帧同步字段格式</p>

<p>其中$,S(i)$为同步字段符号序列,每个符号是一个长度为$K$ 的码字序列,码字序列经过占空比为$L$的插零时域扩展后形成同步信号,符号长度为$T_{\mathrm{bsym}}=K\times L\times T_{c}$。同步字段中包含的符号个数$N_{\mathrm{sync}}$由高层信令配置,个数0代表不发送同步字段。同步字段共包含$N_{\mathrm{sync}}\times K\times L$ 个码片,时间长度为$T_{\mathrm{sync}}=N_{\mathrm{sync}}\times T_{\mathrm{bsym}}=N_{\mathrm{sync}}\times K\times L\times T_{c}$,$T_{c}$为一个码片的时长。同步字段重复发送$N_{\mathrm{sync}}$个相同的符号。</p>

:::

:::{div}
:class: standard-paragraph

<p>同步符号的参数$K$ 和$L$,同步符号索引,以及同步序列的长度$N_{\mathrm{sync}}$由高层信令配置。</p>

```{image} ../../../assets/structured/GBT-48336.201-2026/diagrams/figure-7-structured.svg
:class: standard-vector-figure
```

(gbt-48336-201-2026-figure-7)=
:::{div}
:class: standard-caption

<p>图 7　测量字段格式</p>

:::

:::{div}
:class: standard-paragraph

<p>测量字段包含$M_{\mathrm{seg}}$个测量子片段,每个测量子片段由$N_{\mathrm{seg}}$个测量符号CTS(信道训练序列,Channel TrainingSequence)组成$,M_{\mathrm{seg}}$和$N_{\mathrm{seg}}$由高层信令配置。测量字段的测量符号 CTS 总个数为$N_{\mathrm{cts}}=$$N_{\mathrm{seg}}\times M_{\mathrm{seg}}$,0代表不发送测距字段。相邻的两个测量子片段之间的时间为$T_{\mathrm{gap}}$。</p>

:::

:::{div}
:class: standard-paragraph

<p>对于普通测量模式内容如下。</p>

:::

:::{div}
:class: standard-list-block

<ul class="standard-list">
<li><p>——— 测量子片段之间的时间间隔由高层信令配置$,T_{\mathrm{gap}}=T_{\mathrm{base}}=N_{\mathrm{gap}}\times T_{\mathrm{bsym}}$,其中$N_{\mathrm{gap}}$由高层信令指示。</p>
</li>
<li><p>——— 加扰$SC$ 序列的长度与$N_{\mathrm{cts}}$相同,为固定全为1的序列。</p>
</li>
<li><p>——— 测量符号 CTS与同步符号相同,同步符号由高层信令配置。</p>
</li>
<li><p>——— 测量信号即为由测量符号进行插零时域扩展后生成的基础超宽带脉冲测量信号。</p>
</li></ul>

:::

:::{div}
:class: standard-paragraph

<p>对于安全测量模式内容如下。</p>

:::

:::{div}
:class: standard-list-block

<ul class="standard-list">
<li><p>——— 测量子片段之间的时间间隔由高层信令配置和安全算法确定的偏移量确定$,T_{\mathrm{gap}}=T_{\mathrm{base}}-$$T_{\mathrm{offset}}=N_{\mathrm{gap}}\times T_{\mathrm{bsym}}-N_{\mathrm{offset}}\times T_{c}$,其中$,N_{\mathrm{gap}}$由高层信令指示$,N_{\mathrm{offset}}$由安全算法确定。</p>
</li>
<li><p>——— 加扰$SC$ 序列的长度与$N_{\mathrm{cts}}$相同,由安全算法生成(+1,-1)二元伪随机序列。</p>
</li>
<li><p>——— 测量符号由安全算法确定符号索引。</p>
</li>
<li><p>——— 测量符号进行插零时域扩展后生成的基础超宽带脉冲测量信号,乘以对应的加扰符号,并增加循环前缀和补零后缀,产生安全测量信号。</p>
</li></ul>

:::

:::{div}
:class: standard-paragraph

<p>对于一个码片长度为$K\times L$ 的基础超宽带脉冲测量信号,将该测量信号的最后$L_{\mathrm{CP}}$个码片放置在该基础超宽带脉冲测量信号前面,并在该基础超宽带脉冲测量信号后增加$L_{\mathrm{zero}}$个零码片,构成安全测量信号,其中$,L_{\mathrm{CP}}$和$L_{\mathrm{zero}}$由高层信令配置。安全测量信号共包含$K\times L+L_{\mathrm{CP}}+L_{\mathrm{zero}}$个码片,如图8所示。</p>

:::

:class: table-scroll figure-table-scroll

<tr><td>码片序列</td><td>$C(0)\times SC,0,0,\ldots,0$，$C(1)\times SC,0,0,\ldots,0$，……，$C(K-1)\times SC,0,0,\ldots,0$</td></tr>

## 6.4.4 多天线情况的超宽带脉冲测量信号

:::{div}
:class: standard-paragraph

<p>多天线情况是指:发送测量信号的设备具有$m$ 个天线,接收测量信号的设备具有$n$ 个天线,其中$m$、$n$ 为正整数,且其中至少一个大于1。发送测量信号的设备使用$m$ 个天线中的1个天线和接收测量信号的设备使用$n$ 个天线中个1个天线作为一个天线对,则上述多天线情况具有$(m\times n)$个不同的天线对。</p>

:::

:::{div}
:class: standard-paragraph

<p>超宽带脉冲测量帧由一个或多个测量子片段组成。当超宽带脉冲测量帧由多个测量子片段组成时,任意相邻的两个测量子片段之间是子片段间隔。当相邻的两个测量子片段发生发送天线切换时,该相邻的两个测量子片段之间的子片段间隔需大于发送天线切换的时间,当相邻的两个测量子片段发生接收天线切换时,该相邻的两个测量子片段之间的子片段间隔需大于接收天线切换的时间。</p>

:::

:::{div}
:class: standard-paragraph

<p>对于每个测量子片段,在该测量子片段对应的时间中,发送测量信号的设备使用$m$ 个天线中的1个天线发送测量信号,接收测量信号的设备使用$n$ 个天线中个1个天线接收测量信号。发送测量信号的设备使用$m$ 个天线中的该1个天线和接收测量信号的设备使用$n$ 个天线中个该1个天线组成的天线对,称为该测量子片段对应的天线对。</p>

:::

:::{div}
:class: standard-paragraph

<p>若测量子片段对应天线对的次序类型配置为发送优先顺序,测量子片段对应天线对的次序按照优先变更发送节点的天线确定。例如,发送节点有3个天线,分别记为I1、I2、I3,接收节点有2个天线,分别记为 R1、R2,则发生天线切换的前6个测量子片段对于天线对的顺序为:(I1,R1)、(I2,R1)、(I3,R1)、(I1,R2)、(I2,R2)、(I3,R2),后续测量子片段与天线对的对应关系以此类推。这种方式构成的有序集合称为发送优先顺序天线对集合(集合中天线对的索引从0开始)。</p>

:::

:::{div}
:class: standard-paragraph

<p>若测量子片段对应天线对的次序类型配置为接收优先顺序,测量子片段对应天线对的次序按照优先变更接收节点的天线确定。例如,发送节点有3个天线,分别记为I1、I2、I3,接收节点有2个天线,分别记为 R1、R2,则发生天线切换的前6个测量子片段信号对于天线对的顺序为:(I1,R1)、(I1,R2)、(I2,R1)、(I2,R2)、(I3,R1)、(I3,R2),后续测量子片段与天线对的对应关系以此类推。这种方式构成的有序集合称为接收优先顺序天线对集合(集合中天线对的索引从0开始)。</p>

:::

:::{div}
:class: standard-paragraph

<p>若测量子片段对应天线对的次序类型配置为随机,则测量子片段对应天线对的次序由发送优先顺序天线对集合确定,其中随机天线对集合为发送优先顺序天线对集合经过随机置乱获得的有序集合,随机天线对集合的具体方法如下。</p>

:::

:::{div}
:class: standard-paragraph

<p>步骤1,初始化:</p>

:::

:::{div}
:class: standard-list-block

<ul class="standard-list">
<li><p>——— 候选天线对集合$=$发送优先顺序天线对集合;</p>
</li>
<li><p>——— 天线对数量$L0=m\times n$;</p>
</li>
<li><p>——— 使用配置的安全随机种子、当前测量帧的起始时刻对应的超宽带脉冲配置时间粒度值,通过安全随机函数生成长度为256比特的第四安全序列;</p>
</li>
<li><p>——— 根据 G节点配置确定随机数位宽$K$,其中配置值$K$ 应满足$L0\lt 2^{K}$ 且$K\leq [256/L0]($这里[]表示向下取整)。</p>
</li></ul>

:::

:::{div}
:class: standard-paragraph

<p>步骤2,$L=0$,重复如下步骤,直到$L=L0$:</p>

:::

:::{div}
:class: standard-list-block

<ul class="standard-list">
<li><p>——— 第四安全序列中索引为$(L\times K)$至$(L\times K+K-1)$的比特对应的十进制数整除以$(L0-L)$取余数的结果为第一索引;</p>
</li>
<li><p>——— 随机天线对集合中索引为$L$ 的天线对$=$候选天线对集合中索引为第一索引的天线对;</p>
</li>
<li><p>——— 从候选天线对集合中删除索引为第一索引的天线对;</p>
</li>
<li><p>——— $L=L+1$。</p>
</li></ul>

:::

:::{div}
:class: standard-paragraph

<p>步骤3,输出随机天线对集合。</p>

:::
