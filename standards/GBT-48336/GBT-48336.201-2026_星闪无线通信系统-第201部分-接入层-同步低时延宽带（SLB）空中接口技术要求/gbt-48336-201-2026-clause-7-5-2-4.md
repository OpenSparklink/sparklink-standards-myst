# 7.5.2.4 T链路信道反馈消息

:::{div}
:class: figure-code

```asn1
-- ASN1START
TlinkChannelStatusFeedback ::= SEQUENCE {
    xrc-Identifier  XRC-Identifier,
    srs-PortInfo    PortInfo-1,
    tlinkCommonChnStatusFeedback    CommonChannelStatusFeedback,
    channelStatusType   ENUMERATED {layer, cw}  OPTIONAL,
    lateNonCriticalExtension    OCTET STRING    OPTIONAL,
    nonCriticalExtension    SEQUENCE {} OPTIONAL
}
-- ASN1STOP
```

:::

:::{div}
:class: standard-paragraph

<p>TlinkChannelStatusFeedback由 G节点发送给 T节点,用于向 T节点反馈 T链路信道状态信息。</p>

:::

:::{div}
:class: standard-paragraph

<p>该消息包括 SRS 端口信息 srs-PortInfo,通用链路状态信息tlinkCommonChnStatusFeedback。</p>

:::

:::{div}
:class: standard-paragraph

<p>channelStatusType指示tlinkCommonChnStatusFeedback包含的 T链路状态信息所对应的类型,多流或者码字。</p>

:::
