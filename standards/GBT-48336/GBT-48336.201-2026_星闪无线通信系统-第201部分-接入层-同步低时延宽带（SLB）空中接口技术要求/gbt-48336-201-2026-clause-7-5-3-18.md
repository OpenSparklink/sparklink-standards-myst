# 7.5.3.18 同步通信域集合拓扑信息

:::{div}
:class: figure-code

```asn1
-- ASN1START
MultiDomainSyncTopoInfo ::= SEQUENCE {
    syncDomainIDList    SEQUENCE (SIZE (1..32)) OF SyncDomainIDInfo,
    syncRandomValue UINT16,
    ...
```

:::

```asn1
-- ASN1STOP
```

:::{div}
:class: standard-paragraph

<p>MultiDomainSyncTopoInfo指示同步通信域集合的拓扑信息,其中syncDomainIDList用于指示同步通信域的拓扑关系;syncRandomValue用于指示同步通信域集合的仲裁随机变量,该值由同步通信域集合的同步根节点产生,当两个同步通信域集合的通信域数量相同时,该值小的集合同步优先级更高。在同步通信域集合中,具有直接同步关系的上一级通信域的 G节点与下一级通信域的 G节点时间同步误差小于$\pm 2\mathrm{Ts}$、载波中心频点同步误差的相对值小于$0.1\times 10^{-6}$。</p>

:::
