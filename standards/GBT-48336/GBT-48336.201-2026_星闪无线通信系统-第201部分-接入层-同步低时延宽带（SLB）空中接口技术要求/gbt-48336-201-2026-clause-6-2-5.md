# 6.2.5 物理层数据信息

(gbt-48336-201-2026-clause-6-2-5-1)=
## 6.2.5.1 概述

:::{div}
:class: standard-paragraph

<p>同步低时延宽带通信系统的预配置调度方式传输数据支持一个传输块在一个 TTI中传输。</p>

:::

:::{div}
:class: standard-paragraph

<p>同步低时延宽带通信系统的预配置调度方式传输数据支持以一个或多个 TTI为周期传输,其中每个周期在一个TTI中传输一个传输块,每个周期传输的传输块采用TTI中相同的资源配置和相同的调制编码方式。</p>

:::

:::{div}
:class: standard-paragraph

<p>同步低时延宽带通信系统的预配置调度方式传输数据支持以一个 TTI为周期传输第一类数据信息,其中每个周期在一个 TTI中传输多个传输块,每个周期传输的传输块数量相同,每个传输块采用相同的调制编码方式,TTI中传输该多个传输块的资源配置相同。</p>

:::

:::{div}
:class: standard-paragraph

<p>同步低时延宽带通信系统支持动态调度传输,动态调度的数据支持一个传输块在一个 TTI中传输。该一个传输块在该一个TTI中的时频资源由动态调度数据控制信息指示。在同一个TTI中,支持由多个动态调度数据控制信息各调度一个传输块,以实现多个传输块在一个 TTI中传输。</p>

:::

(gbt-48336-201-2026-clause-6-2-5-2-2)=
### 6.2.5.2.2 信息比特和调制编码方式

:::{div}
:class: standard-paragraph

<p>第一类数据信息调度信息通过高层信令 DataResourceConfPackage发送,指示第一类数据信息的封装个数信息$N$、采样位宽信息$K$、传输流数$v$、调制符号 重 复 次 数$N_{\mathrm{dup}}$,调制方 式 信息 (QPSK、16QAM、64QAM、256QAM、1024QAM、4096QAM),以及传输整个封装使用的物理资源,其中$N\geq$1,$K\in \{8,16,24,32,40,48,56,64,72,80,88,96,104,112,120,128\}\text{。}$一个传输块的信息比特数目为$K\cdot N$,信息比特序列表示为$a_{0}$,$a_{1}$,$a_{2}$,$a_{3},\ldots ,a_{K\cdot N-1}$,高层配置采用的循环冗余校验比特的长度$L$,其中$L=24$,16,8,相应的循环冗余校验生成多项式为$g_{\mathrm{CRC}24\mathrm{A}}(D)$、$g_{\mathrm{CRC}16}(D)$或$g_{\mathrm{CRC}8}(D)$。</p>

:::

:::{div}
:class: standard-paragraph

<p>计算信道比特序列数 $E_{\mathrm{tot}}$：如果流数 $v=1$，$E_{\mathrm{tot}}=\left[\frac{N_{\mathrm{RE}}}{N_{\mathrm{dup}}}\right]\cdot Q_m$；如果流数 $v=2$，$E_{\mathrm{tot}}=N_{\mathrm{RE}}\cdot Q_m+\left[\frac{N_{\mathrm{RE}}}{N_{\mathrm{dup}}}\right]\cdot Q_m$；如果流数 $v\geq3$，$E_{\mathrm{tot}}=N_{\mathrm{RE}}\cdot Q_m\cdot v$。其中 $N_{\mathrm{RE}}$ 是调度的子载波数，$Q_m$ 是调制方式，$N_{\mathrm{dup}}$ 是调制符号重复次数；$[\cdot]$ 表示向上取整；$v$ 是传输流数。$R=(K\cdot N+L)/E_{\mathrm{tot}}$，需满足 $R\leq15/16$。</p>

:::

:::{div}
:class: standard-paragraph

<p>计算分段数 $C$：如果 $R\geq5/32$，$C=\left[\frac{E_{\mathrm{tot}}}{N_{\mathrm{max}}}\right]$，其中，$N_{\mathrm{max}}$ 的值为 4096 或者 1024。如果 $\operatorname{mod}(E_{\mathrm{tot}},N_{\mathrm{max}})\ne0$ 且 $\left(R>\frac7{16}\parallel C<9\right)$ 且 $(E_{\mathrm{tot}}-C\cdot N_{\mathrm{max}})\cdot R>T$，则 $C=C+1$，否则 $C=\max(1,C)$；其中 $R=(K\cdot N+L)/E_{\mathrm{tot}}$，$T$ 根据 $R$ 以及 $N_{\mathrm{max}}$ 确定，如果 $R>2/3$，$T=192\times N_{\mathrm{max}}/4096$，否则 $T=384\times N_{\mathrm{max}}/4096$；如果 $R<5/32$，$C=\left[\frac{3\times(K\cdot N+L)}{N_{\mathrm{max}}}\right]$。</p>

:::

:::{div}
:class: standard-paragraph

<p>如 $v>1$ 或调制方式非 QPSK，$C1=\left[\frac{E_{\mathrm{tot}}}{E_{\mathrm{int}}}\right]$，$C=\max(C1,C)$，其中 $E_{\mathrm{int}}$ 表示信道交织器最大支持的输入长度。</p>

:::

:::{div}
:class: standard-paragraph

<p>计算信息比特数 $A$：$A=8\cdot C\cdot\left[\frac{K\cdot N+L}{8\cdot C}\right]-L$，如 $A>K\cdot N$，则将比特序列 $a_0,a_1,a_2,a_3,\cdots,a_{K\cdot N-1}$ 扩展为 $a_{k\_E}$，其中 $a_{k\_E}=a_k$，$k=0,\cdots,K\cdot N-1$，$k=K\cdot N,\cdots,A-1$ 时，$a_{k\_E}=0$。计算序列 $a_{k\_E}$ 的循环冗余校验比特 $p_0,p_1,p_2,p_3,\cdots,p_{L-1}$，并生成循环冗余校验后的输出比特序列 $b_0,b_1,b_2,b_3,\cdots,b_{A+L-1}$。</p>

:::

:::{div}
:class: standard-paragraph

<p>信道比特序列长度$E_{\mathrm{tot}}$,以及每个编码块分段对应的信道比特序列长度$E_{r}$ 的计算方法如下,其中$0\leq r\lt C$,$C$ 是编码块分段的数量:</p>

:::

:::{div}
:class: standard-list-block

<ul class="standard-list">
<li><p>——— 当$C=1$时$,E_{0}=E_{\mathrm{tot}}$。</p>
</li>
<li><p>——— 当$C\gt 1$时,每个编码块分段对应的信道比特序列长度$E_{r}$ 为$:E_{r}=E_{0}=[E_{\mathrm{tot}}/C]$,其中$0\leq$$r\lt C$。</p>
</li></ul>

:::

:::{div}
:class: standard-paragraph

<p>第一类数据信息传输使用6.2.6规定的信道编码参数,进行 6.2.6.1.1、6.2.6.1.2、6.2.6.1.3 和6.2.6.1.4的极化编码,产生比特序列$g_{k}$,其中$k=0,\ldots ,[E_{\mathrm{tot}}/C]\cdot C-1$。比特序列$g_{k}$扩展为$g_{k\_E}$,其中$g_{k\_E}=g_{k}$,$k=0,\ldots ,[E_{\mathrm{tot}}/C]\cdot C-1$,$k=[E_{\mathrm{tot}}/C]\cdot C,\ldots ,E_{\mathrm{tot}}$时$g_{k\_E}=0$。将$g_{k\_E}$根据 6.5.7的方法产生比特加扰后的比特序列$\widetilde{g}_{k}$,根据6.5.6的方法将比特序列$\widetilde{g}_{k}$映射为调制符号序列$d_{i}$。</p>

:::

(gbt-48336-201-2026-clause-6-2-5-2-3)=
### 6.2.5.2.3 资源映射

:::{div}
:class: standard-paragraph

<p>调制符号序列$d_{i}$ 在被配置的时频上按照符号索引的先后顺序,以及每个符号中子载波索引从小到大的顺序映射到各符号的子载波上。</p>

:::

:::{div}
:class: standard-paragraph

<p>对于 G链路和 T链路,在被调度的时频资源中,除了映射 DMRS-D 的时频资源,其他时频资源都用于映射第一类数据信息。</p>

:::

:::{div}
:class: standard-paragraph

<p>对于附链路,映射第一类数据信息的资源见6.2.5.4。</p>

:::
