<p>图 61　密钥更新流程</p>

:::{div}
:class: standard-paragraph

<p>当密钥更新时,G节点和 T节点记录新密钥启用的 GFN 值。</p>

:::

:::{div}
:class: standard-paragraph

<p>G节点记录的新密钥启用的 GFN 值如下:</p>

:::

:::{div}
:class: standard-list-block

<ul class="standard-list">
<li><p>——— 信令面 G链路:G节点收到密钥更新响应后的第一条 G链路消息的 GFN 值;</p>
</li>
<li><p>——— 信令面 T链路:G节点收到的密钥更新响应的 GFN 值;</p>
</li>
<li><p>——— 用户面 G链路 T链路:激活时间中的 G链路 T链路 GFN 值。</p>
</li></ul>

:::

:::{div}
:class: standard-paragraph

<p>T节点记录的新密钥启用的 GFN 值如下:</p>

:::

:::{div}
:class: standard-list-block

<ul class="standard-list">
<li><p>——— 信令面 T链路:T节点发送的密钥更新响应的 GFN 值;</p>
</li>
<li><p>——— 信令面 G链路:发送密钥更新响应后,收到的第一条 G节点 G链路消息的 GFN 值;</p>
</li>
<li><p>——— 用户面 G链路 T链路:激活时间中的 G链路 T链路 GFN 值。</p>
</li></ul>

:::

:::{div}
:class: standard-paragraph

<p>在信令面 T 链路 GFN.su、信令面 G 链路 GFN.sd、用户面 T 链路 GFN.uu、或用户面 G 链路GFN.ud到达上一次密钥更新时记录的 GFN 值之前,G节点应触发密钥更新流程。</p>

:::

:::{div}
:class: standard-paragraph

<p>若之前没有密钥更新,则在信令面 T链路 GFN.su、信令面 G链路 GFN.sd、用户面 T链路 GFN.uu、或用户面 G链路 GFN.ud到达缺省值(如全1)前,G节点应触发密钥更新流程。</p>

:::

:::{div}
:class: standard-paragraph

<p>派生密钥有效期到期时,G节点应触发密钥更新流程。如果 T节点的信令面 T链路 GFN.su、信令面 G链路 GFN.sd、用户面 T 链路 GFN.uu、或用户面 G 链路 GFN.ud和上一次密钥更新时记录的GFN 值重复时,G节点还没有发起密钥更新流程,则 T 节点断开连接、删除安全上下文并重新发起认证和安全上下文协商流程(见9.3.2.1)。</p>

:::

:::{div}
:class: standard-paragraph

<p>如果 G节点的信令面 T链路 GFN.su、信令面 G 链路 GFN.sd、用户面 T 链路 GFN.uu、或用户面G链路 GFN.ud和上一次密钥更新时记录的 GFN 值重复时,G 节点还未成功完成密钥更新流程,则G节点根据7.4.2.2.3的连接释放过程断开连接、删除安全上下文。</p>

:::

:::{div}
:class: standard-paragraph

<p>密钥更新流程描述如下。</p>

:::

:::{div}
:class: standard-list-block

<ol class="alpha-list" start="1">
<li><p>a) G节点向 T节点发送密钥更新请求。携带 G 节点的counter值,携带用户面密钥的 G 链路T链路启动时间activation(activationg表示 G 链路激活时间,activationt表示 T 链路激活时间)。G节点使用信令面的认证加密算法和更新前的认证加密密钥 Ks.ac对密钥更新请求消息做保护,或者 G节点使用信令面的完整性保护算法和更新前的完整性保护密钥 Ks.int对密钥更新请求消息做完整性保护,使用信令面的加密算法和更新前的加密密钥 Ks.enc对密钥更新请求消息做加密保护。G 节点根据该counter值和 Kgt生成新的密钥 Kmid,进而根据Kmid生成新的信令面的加密密钥和完整性保护密钥。</p>
</li>
<li><p>b) 如果密钥更新请求消息进行了加密,则 T节点解密密钥更新请求消息。T节点检查密钥更新请求消息的完整性。如果完整性验证不通过,则 T 节点丢弃该消息。如果完整性验证通过,则 T 节点保存该counter值,并根据counter值和 Kgt生成新的密钥 Kmid,进而根据Kmid生成信令面的认证加密密钥或信令面的加密密钥和完整性保护密钥,用户面的认证加密密钥或用户面的加密密钥和完整性保护密钥。</p>
</li>
<li><p>c) T节点向 G节点发送密钥更新响应。T 节点使用信令面的认证加密算法和更新后的认证加密密钥 Ks.ac对密钥更新响应做保护,或者 T节点使用信令面的完整性保护算法和更新后的完整性保护密钥 Ks.int对密钥更新响应消息做完整性保护,使用信令面的加密算法和更新后的加密密钥 Ks.enc对密钥更新响应消息做加密保护。</p>
</li>
<li><p>d) 如果密钥更新响应消息进行了加密,则 G节点解密密钥更新响应消息。G 节点检查密钥更新响应消息的完整性。如果完整性验证不通过,则 G 节点丢弃该消息并重新发起密钥更新请求。如果完整性验证通过,则 G节点根据 Kmid生成新的用户面的认证加密密钥或用户面的加密密钥和完整性保护密钥。</p>
</li>
<li><p>e) 启动时间activation以 GFN 值表示,当 GFN 达到启动时间时,用户面使用新的用户面密钥对用户面进行安全保护。启动时间应小于或等于上一次启动时间。若第一次密钥更新,启动时间应小于缺省值(如全1)。</p>
</li></ol>

:::

(gbt-48336-201-2026-clause-9-3-6-2)=
## 9.3.6.2 Kgt更新机制

:::{div}
:class: standard-paragraph

<p>在counter或 COUNTERg 值 超 过 翻转 之 前的 某 阈 值 时 (阈 值缺 省 值 为 011111111111 1111<sub>2</sub>),G节点和 T节点在连接断开后删除安全上下文。在counter或 COUNTERg值到达翻转点时,G节点和 T节点应断开连接,并删除安全上下文。在 Kgt有效期到达到期之前的某阈值时,G 节点和 T节点在连接断开后删除安全上下文。在 Kgt有效期到期时,G 节点和 T 节点应断开连接,删除安全上下文。生成安全上下文后,counter值初始化为0。</p>

:::

(gbt-48336-201-2026-figure-62)=
:::{div}
:class: standard-caption

<p>图 62　组密钥更新流程</p>

:::

:::{div}
:class: standard-paragraph

<p>当满足以下条件之一时,G节点需要发起更新组密钥流程:</p>

:::

:::{div}
:class: standard-list-block

<ol class="alpha-list" start="1">
<li><p>a) G节点的 GGFN 和上一次密钥更新时记录的 GGFN 即将重复时;</p>
</li>
<li><p>b) GK 有效期到期;</p>
</li>
<li><p>c) 组内成员发生变动时可由基础服务层触发。</p>
</li></ol>

:::

:::{div}
:class: standard-paragraph

<p>在信令面 G链路 GGFN.sd或用户面 G链路 GGFN.ud到达上一次组密钥更新时记录的 GGFN 值之前,G节点发起组密钥更新流程。</p>

:::

:::{div}
:class: standard-paragraph

<p>在 GK 有效期到期时,G 节点和 T 节点应断开组播连接并删除组密钥,G 节点发起组密钥更新流程。</p>

:::

:::{div}
:class: standard-paragraph

<p>如果 T节点的信令面 G链路 GGFN.sd或用户面 G链路的 GGFN.ud和上一次组密钥更新时记录的 GGFN 值重复时,G节点还没有发起组密钥更新流程,则 T节点断开组播连接(停止接收组播消息)、删除组密钥并向 G节点发送组密钥请求。</p>

:::

:::{div}
:class: standard-paragraph

<p>如果 G节点的信令面 G链路 GGFN.sd或用户面 G链路的 GGFN.ud和上一次组密钥更新时记录的 GGFN 值重复时,G节点还未成功完成密钥更新流程,则 G节点断开组播连接(停止接收组播消息)、删除组密钥并重新发起组密钥更新流程。</p>

:::

:::{div}
:class: standard-paragraph

<p>组密钥更新流程描述如下。</p>

:::

:::{div}
:class: standard-list-block

<ol class="alpha-list" start="1">
<li><p>a) (可选)T 节点向 G 节点发送组密钥请求消息,携带 T 节点的 newSecurityContextID,指示T节点请求组密钥。T节点使用信令面的认证加密算法和认证加密密钥 Ks.ac对组密钥请求消息做保护,或者 T节点使用信令面的完整性保护算法和完整性保护密钥 Ks.int对组密钥请求消息做完整性保护,使用信令面的加密算法和加密密钥 Ks.enc对组密钥请求消息做加密保护。</p>
</li>
<li><p>b) G 节点 产 生随 机数 RAND,并根 据 RAND 和 组 ID 生 成 新 的 组密 钥 GK,$\mathrm{GK}=\mathrm{KDF}$(RAND,组ID),其中 KDF是 G节点支持的优先级最高的密钥派生函数。</p>
</li>
<li><p>c) 当信令面的加密保护未开启时,G节点根据共享密钥 Kgt和 COUNTERg,使用选择的密钥派生函数计算 出 保护组密 钥 GK 机 密 性的 密 钥 Kg:Kg=KDF (Kgt,COUNTERg,&quot;group key&quot;)。G节点把 GK 和 Kg进行异或得到$:\mathrm{GKc}=\mathrm{GK}\oplus Kg$。每推演一次 Kg,COUNTERg加一。</p>
</li>
<li><p>d) G节点向 T节点发送组密钥更新消息。当信令面的加密保护未开启时,组密钥更新消息携带GKc,COUNTERg和用户面密钥的 G链路启动时间 Gactivation。当信令面的加密保护开启时,组密钥更新消息携带 GK 和用户面密钥的 G链路启动时间 Gactivation。</p>
</li>
<li><p>e) G节点使用信令面的认证加密算法和认证加密密钥 Ks.ac对组密钥更新消息做保护,或者G节点使用信令面的完整性保护算法和完整性保护密钥 Ks.int对组密钥更新消息做完整性保护,使用信令面的加密算法和加密密钥 Ks.enc对组密钥更新消息做加密保护。</p>
</li>
<li><p>f) 如果组密钥更新消息进行了加密,则 T节点解密组密钥更新消息。T 节点检查密钥更新消息</p>
</li></ol>

:::

:::{div}
:class: standard-paragraph

<p>的完整性。如果完整性验证不通过,则 T 节点丢弃该消息。如果完整性验证通过,当信令面的加密保护未开启时,T节点比较收到的 COUNTERg值是否比自己保存的 COUNTERg值大。如果 T节点收到的COUNTERg值比自己保存的COUNTERg值大,则 T节点根据共享密钥 Kgt和 COUNTERg,使用选择的密钥派生函数计算出保护组密钥 GK 机密性的密钥</p>

:::

:::{div}
:class: standard-definitions

Kg
: Kg=KDF (Kgt,COUNTERg,&quot;groupkey&quot;),并 把 GKc和 Kg 进行异或得到$:\mathrm{GK}=$GKc⊕ Kg。T节点保存新的组密钥 GK。T 节点根据 GK 生成组播信令面的安全密钥和组播用户面的安全密钥(见9.3.3.2)。如果 T 节点收到的 COUNTERg值小于或等于自己保存的 COUNTERg值,则 T节点丢弃该消息。

:::

:::{div}
:class: standard-list-block

<ol class="alpha-list" start="7">
<li><p>g) T节点向 G节点发送组密钥更新确认消息。T 节点使用信令面的认证加密算法和认证加密密钥 Ks.ac对组密钥更新确认消息做保护,或者 T 节点使用信令面的完整性保护算法和完整性保护密钥 Ks.int对组密钥更新确认消息做完整性保护,使用信令面的加密算法和加密密钥Ks.enc对组密钥更新确认消息做加密保护。</p>
</li>
<li><p>h) 如果组密钥更新确认消息进行了加密,则 G节点解密组密钥更新确认消息。G 节点检查组密钥更新确认消息的完整性。如果完整性验证不通过,则 G 节点丢弃该消息并重新发起组密钥更新消息。如果完整性验证通过,则 G 节点保存新的组密钥 GK。G 节点根据 GK 生成组播信令面的安全密钥和组播用户面的安全密钥(见9.3.3.2)。</p>
</li></ol>

:::

:::{div}
:class: standard-paragraph

<p>当 G节点收到所有 T节点的组密钥更新确认消息后,即启动新的信令面组密钥对信令面组播进行安全保护。</p>

:::

:::{div}
:class: standard-paragraph

<p>用户面启动时间 Gactivation以组播 GGFN 值表示,当 GGFN 达到启动时间时,G节点应使用新的用户面组密钥对用户面进行安全保护。启动时间应小于或等于上一次启动时间。若第一次密钥更新,启动时间应小于缺省值(如全1)。</p>

:::
