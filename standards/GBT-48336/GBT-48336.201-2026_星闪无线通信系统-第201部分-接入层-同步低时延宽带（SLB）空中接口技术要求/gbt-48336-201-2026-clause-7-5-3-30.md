# 7.5.3.30 竞争接入资源池信息

:::{div}
:class: figure-code

```asn1
-- ASN1START
ContentionAccessResource ::= SEQUENCE {
    superframePeriod    SuperframePeriod,
    superframeOffset    SuperframeOffset,
    frameOffset FrameOffset,
    contentionAccessDuration    INTEGER (0..8),
    contentionAccessResourceSYS DedicatedTimeResource,
    contentionAccessResourceGroup   ENUMERATED { one, two },
    waitingWindow   UINT10,
    backoffWindow   UINT10,
    contentionPhysID-starting   PhyID   OPTIONAL,
    contentionPhysID-ending PhyID   OPTIONAL,
    ...
}
-- ASN1STOP
```

:::

:::{div}
:class: standard-paragraph

<p>在非连续传输模式下,基于6.2.4.5使用接入资源;在连续传输模式下,可使用基于contentionAccessResource配置的接入资源。</p>

:::

:::{div}
:class: standard-paragraph

<p>当超帧号满足 mod(超帧号$,\mathrm{su}p\mathrm{erframePeriod})=\mathrm{su}p\mathrm{erframeOffset}$时,从该超帧内第frameOffset个无线帧开始,共contentionAccessDuration个无线帧包含竞争接入资源池。</p>

:::

:::{div}
:class: standard-paragraph

<p>contentionAccessResourceSYS指示一个无线帧内发送竞争接入信息的符号资源,包括$N$ 个符号。</p>

:::

:::{div}
:class: standard-paragraph

<p>contentionAccessResourceGroup指示由contentionAccessResourceSYS确定的发送竞争接入信息资源中包括的接入信道的个数 M。当$M$ 取1时,接入信道使用所有$N$ 个符号。</p>

:::

:::{div}
:class: standard-paragraph

<p>当$N\lt 12$时$,M$ 仅取1;</p>

:::

:::{div}
:class: standard-paragraph

<p>当$N=12$时$,M$ 的值可为1或2,当$M$ 取2时,第一个接入信道使用前6个符号,第二个接入信道使用后6个符号;</p>

:::

:::{div}
:class: standard-paragraph

<p>当$N=13$时$,M$ 的值可为1或2,当$M$ 取2时,第一个接入信道使用前6个符号,第二个接入信道使用后7个符号;</p>

:::

:::{div}
:class: standard-paragraph

<p>当$N=14$时$,M$ 的值可为1或2,当$M$ 取2时,第一个接入信道使用前7个符号,第二个接入信道使用后7个符号。</p>

:::

:::{div}
:class: standard-paragraph

<p>在一个配置周期内共有$\mathrm{numY}=\mathrm{contentionAccessDuration}\times M$ 个接入信道,按照时间顺序接入信道编号为$\#0$到$\#(\mathrm{numY}-1)\text{。}$</p>

:::

:::{div}
:class: standard-paragraph

<p>T节点在这些资源中随机选择一个资源发送接入信息。waitingWindow 为随机接入的等待时间窗口大小,单位为 TTI。backoffWindow 为竞争接入的随机退避时间窗上边界,单位为 TTI。</p>

:::
