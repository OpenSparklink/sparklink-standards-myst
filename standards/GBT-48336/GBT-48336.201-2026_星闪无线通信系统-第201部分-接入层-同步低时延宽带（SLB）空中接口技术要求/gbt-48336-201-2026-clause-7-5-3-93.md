# 7.5.3.93 SPS业务特征信息

:::{div}
:class: figure-code

```asn1
-- ASN1START
SPSTrafficPatternInfo ::= SEQUENCE{
    trafficPeriodicity  SPSTrafficPatternEnum,
    trafficOnDuration   SPSTrafficPatternEnum,
    trafficOffset   SPSTrafficPatternEnum,
    messageSize BIT STRING (SIZE (6))
}
SPSTrafficPatternEnum ::= ENUMERATED {
    f3, f6, f12, f24, f48, sf5, sf10, sf20,
    sf50, sf100, sf200, sf300, sf400, sf500, sf600, sf700,
    sf800, sf900, sf1000
}
-- ASN1STOP
```

:::

:::{div}
:class: standard-paragraph

<p>SPS业务特征信息,包括SPS业务周期trafficPeriodicity、持续时间trafficOnDuration、时间偏移量trafficOffset和包大小 messageSize。其中业务周期单位为无线帧或者超帧;包大小单位为字节。</p>

:::
