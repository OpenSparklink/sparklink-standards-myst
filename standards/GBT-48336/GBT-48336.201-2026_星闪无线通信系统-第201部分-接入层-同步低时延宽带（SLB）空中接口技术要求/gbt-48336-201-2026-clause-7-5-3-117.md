# 7.5.3.117 多频段配置信息

:::{div}
:class: figure-code

```asn1
-- ASN1START
MultiBandConfig ::= SEQUENCE {
    oneBandConfigList   SEQUENCE (SIZE (1..16)) OF OneBandConfig
}
OneBandConfig ::= SEQUENCE {
    bandIdx BandIndex,
    maxBandwidthConfig  MaxBandwidthCap,
    carrierChannelListConf  CarrierChannelListConf,
    maxMeasureBandwidthConfig   MaxBandwidthCap OPTIONAL,
    p0-NominalConfig    P0-NominalConfig    OPTIONAL,
    ...
}
-- ASN1STOP
```

:::

:::{div}
:class: standard-paragraph

<p>MultiBandConfig用于配置多频段参数,其中,oneBandConfigList用于指示一到多个频段的配置信息。在其中,bandIdx指示当前配置的频段索引号;maxBandwidthConfig用于指示当前频段上配置的最大工作带宽,即最大传输带宽;carrierChannelListConf用于指示当前频段上配置的一到多个信道的信道号集合;maxMeasureBandwidthConfig用于指示当前频段上配置的最大测量带宽,即最大测量带宽。所有配置的信道的带宽之和不应超过节点在当前频段的最大带宽能力 MaxBandwidthCap。p0-NominalConfig用于指示当前频段上的功率配置信息。</p>

:::
