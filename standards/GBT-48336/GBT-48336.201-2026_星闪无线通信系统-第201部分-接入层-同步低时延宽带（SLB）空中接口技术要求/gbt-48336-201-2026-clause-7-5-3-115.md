# 7.5.3.115 没有安全上下文的关联请求信息

:::{div}
:class: figure-code

```asn1
-- ASN1START
AssociationRequestNonSec ::= SEQUENCE {
    indication  BIT STRING (SIZE (2)),
    psk-id  UINT24 OPTIONAL, -- Need OR
    ke-alg-trad BIT4    OPTIONAL, -- Need OR
    ke-alg-reserve  BIT4 OPTIONAL, -- Need OR
    rtx BIT256 OPTIONAL, -- Need OR
    rty BIT256 OPTIONAL, -- Need OR
    ketx    BIT256 OPTIONAL, -- Need OR
    kety    BIT256 OPTIONAL, -- Need OR
    sec-capabilities    BIT32,
    noncet  BIT256,
    reserve1    BIT STRING (SIZE (2))   OPTIONAL, -- Need OR
    reserve2    BIT STRING (SIZE (1..6400)) OPTIONAL, -- Need OR
    ...
}
-- ASN1STOP
```

:::

:::{div}
:class: standard-paragraph

<p>AssociationRequestNonSec用于在没有安全上下文的条件下由 T 节点向 G 节点发送的关联(认证)请求,具体包含的信息元素见9.3。sec-capabilities的指示信息参考9.3.7。</p>

:::
