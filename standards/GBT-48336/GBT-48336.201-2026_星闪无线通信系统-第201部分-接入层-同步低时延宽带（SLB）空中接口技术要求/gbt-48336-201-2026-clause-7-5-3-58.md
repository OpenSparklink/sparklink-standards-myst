# 7.5.3.58 链路数据时延能力指示信息

:::{div}
:class: figure-code

```asn1
-- ASN1START
MinDataDelay ::= SEQUENCE {
    minGlinkDataDelay   INTEGER(-300..16384),
    minTlinkDataDelay   INTEGER(1..1000),
    ...
}
-- ASN1STOP
```

:::

:::{div}
:class: standard-paragraph

<p>包含 T节点在 Glink和 Tlink两个方向上处理数据时延能力,单位为微秒。minGlinkDataDelay指示 T节点从解析 GCI到能够成功处理第一个 G 链路数据的时延,T 节点可支持 G 链路数据与相应GCI位于不同基础载波的情况,在时间维度上,该情况下的 G链路数据资源块可位于相应 GCI之前,此时 minGlinkDataDelay取值为负数;minTlinkDataDelay指示 T 节点从解析 GCI到能够成功发送第一个 T链路数据的时延。</p>

:::

:::{div}
:class: standard-paragraph

<p>G节点根据该时间信息并结合系统使用的符号类型、符号长度,可计算对应的符号个数。以 minGlinkDataDelay为例,符号个数$N=[\mathrm{minGlinkDataDela}y/sy\mathrm{mbol}\_\mathrm{len}],$不能整除时向上取整。符号时长参考1。</p>

:::

:::{div}
:class: standard-paragraph

<p>G节点根据计算所得的符号个数$N$,合理安排符合该 T 节点处理能力的 Glink和 Tlink数据资源位置。</p>

:::
