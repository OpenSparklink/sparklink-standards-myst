# 附录 N（规范性）ASN.1 可选信元说明标记

:::{div}
:class: standard-paragraph

<p><strong>ASN•</strong>1<strong>可</strong>选<strong>信元</strong>说明<strong>标</strong>记</p>

:::

:::{div}
:class: standard-paragraph

<p>本附录规定了本文件使用 ASN.1的 OPTIONAL关键字时可附加的说明标记及其含义。</p>

:::

:::{div}
:class: standard-list-block

<ul class="standard-list">
<li><p>——— NEEDOR:当对应可选信元不存在时,其旧值删除(若有)。</p>
</li>
<li><p>——— 无说明标记:当对应可选信元不存在时,其旧值预留(若有)。</p>
</li></ul>

:::

:::{div}
:class: standard-paragraph

<p>标记有 OPTIONAL关键字的信元可使用以上任意一种方式。若有特殊处理方式,通过文字描述进行说明(比如默认值等),并以该文字描述的含义为准。</p>

:::
