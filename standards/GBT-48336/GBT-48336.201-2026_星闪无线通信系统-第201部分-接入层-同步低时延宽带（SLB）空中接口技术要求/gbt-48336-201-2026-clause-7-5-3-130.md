# 7.5.3.130 节点定位坐标信息

:::{div}
:class: figure-code

```asn1
-- ASN1START
NodePositioningCoordinates ::= SEQUENCE {
    xCoordinate PositioningRelativeCoordinate,
    yCoordinate PositioningRelativeCoordinate,
    zCoordinate PositioningRelativeCoordinate,
    longitudeCoordinate LongitudeCoordinate OPTIONAL,
    latitudeCoordinate LatitudeCoordinate OPTIONAL,
    altitudeCoordinate AltitudeCoordinate OPTIONAL,
    ...
}
PositioningRelativeCoordinate ::= UINT32
LongitudeCoordinate ::= UINT32
LatitudeCoordinate ::= UINT32
AltitudeCoordinate ::= UINT32
-- ASN1STOP
```

:::

:::{div}
:class: standard-paragraph

<p>xCoordinate用于配置相对位置坐标的$x$ 轴坐标;yCoordinate用于配置相对位置坐标的$y$ 轴坐标;zCoordinate用于配置相对位置坐标的$z$ 轴坐标;PositioningRelativeCoordinate使用二补数指示坐标数值,坐标值为PositioningRelativeCoordinate二补数表示的数值$\times 2^{-10}$,单位为米;当xCoordinate、yCoordinate和zCoordinate配置的值均为0xFFFFFFFF时,相对位置坐标无效。</p>

:::

:::{div}
:class: standard-paragraph

<p>longitudeCoordinate、latitudeCoordinate和altitudeCoordinate用于指示北斗坐标系中坐标点的位置,其中longitudeCoordinate指示经度信息,latitudeCoordinate指示维度信息,altitudeCoordinate指示海拔高度信息。坐标点的经度坐标值为$[180\times \mathrm{LO}/2^{32}],$单位为度,其中 LO 为LongitudeCoordinate二补数表示的数值,正值为东经,负值为西经;坐标点的维度坐标值为$[90\times \mathrm{LA}/2^{32}]$单位为度,其中LA 为LatitudeCoordinate二补数表示的数值,正值为北纬,负值为南纬;坐标点的海拔高度坐标值为$\mathrm{AL}\times$$2^{-1}$,单位为米,其中 AL为 AltitudeCoordinate二补数表示的数值,正值为高于参考平面,负值为低于参考平面;当longitudeCoordinate、latitudeCoordinate和altitudeCoordinate配置的值均为0xFFFFFFFF时,绝对位置坐标无效。</p>

:::
