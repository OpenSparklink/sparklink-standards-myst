# 附录 K（资料性）被测设备数据包参数双向复合信道计算方法

:::{div}
:class: standard-paragraph

<p>被<strong>测设</strong>备<strong>数据包参数双向</strong>复<strong>合信道的计</strong>算<strong>方法</strong></p>

:::

:::{div}
:class: standard-paragraph

<p>I节点和 R节点做信道估计,得到第$k$ 个子载波 CSI:</p>

:::

```{math}
h_k^{\mathrm R}(t_1)=h_{k,0}e^{-j[2\pi(f_k^{\mathrm R}-f_k^{\mathrm I})t_1+\varphi_{\mathrm{I,init}}-\varphi_{\mathrm{R,init}}]}
```

```{math}
h_k^{\mathrm I}(t_2)=h_{k,0}e^{-j[2\pi(f_k^{\mathrm I}-f_k^{\mathrm R})t_2+\varphi_{\mathrm{R,init}}-\varphi_{\mathrm{I,init}}]}
```

:::{div}
:class: standard-paragraph

<p>假设$\Delta _{t}$是I节点和 R节点之间的clockoffset,$\theta _{\mathrm{IR}}$是双方 LO 之间的phaseoffset,则 R和I节点的第$k$ 个载波的相位分别为:</p>

:::

```{math}
\varphi_{\mathrm R}(f_k,r)=-2\pi(f_k^{\mathrm R}-f_k^{\mathrm I})\left(\frac r{c_0}+\Delta_t\right)-\theta_{\mathrm{IR}}\pmod{2\pi}
```

```{math}
\varphi_{\mathrm I}(f_k,r)=-2\pi(f_k^{\mathrm I}-f_k^{\mathrm R})\left(\frac r{c_0}-\Delta_t\right)+\theta_{\mathrm{IR}}\pmod{2\pi}
```

:::{div}
:class: standard-paragraph

<p>对应IQ 值相乘$h_{k}^{\mathrm{R}}(t)h_{k}^{\mathrm{I}}(t),$相位可消去$\Delta _{t}$和$\theta _{\mathrm{IR}}$:</p>

:::

```{math}
\varphi_{2W}(f_k,r)=\varphi_{\mathrm R}(f_k,r)+\varphi_{\mathrm I}(f_k,r)=-4\pi(f_k^{\mathrm R}-f_k^{\mathrm I})r/c_0
```

:::{div}
:class: standard-paragraph

<p>消去时钟偏移$\Delta _{t}$ ,LO 相差$\theta _{\mathrm{IR}}$ 后,不同$f_{k}$ 的测量结果$\varphi _{2W}(f_{k},r)$仅与目标距离$r$相关,可合并处理。$f^{\mathrm{R}}_{k}-f_{k}^{\mathrm{I}}$ 宜精确补偿,包括载波频偏(CFO)和采样时钟偏差(SCO)补偿。</p>

:::
