# 7.5.3.104 同步域测量信息

:::{div}
:class: figure-code

```asn1
-- ASN1START
SyncDomainInfo ::= SEQUENCE {
    domainID DomainID OPTIONAL,
    domainSysInfoTimeResource   DomainSysInfoTimeResource   OPTIONAL,
    timeSync    TimeDomainSync-Value    OPTIONAL,
    frequencySync   FrequencySync-Value OPTIONAL,
    cpConfig    CPConfig    OPTIONAL,
    ftsIndication   ENUMERATED { high, normal } OPTIONAL,
    stsIndication   INTEGER (1..20) OPTIONAL,
    rsrp    RSRP-Value  OPTIONAL,
    sinr    SINR-Value  OPTIONAL,
    ...
}
-- ASN1STOP
```

:::

:::{div}
:class: standard-paragraph

<p>SyncDomainInfo用 于 指示一 个 同步通信域集合中一 个目 标通信域的同步测量信息,其 中domainID用于指示该通信域 G节点的物理层标识;domainSysInfoTimeResource用于指示该通信域系统消息的时间资源;timeSync用于指示以服务通信域 G节点为基准,目标通信域的时间调整量,其中提前为负值,延迟为正值;frequencySync用于指示以服务通信域 G 节点为基准,目标通信域的频率调整量,其中目标通信域中心频率小于服务通信域中心频率时,该值为负值,目标通信域中心频率大于服务通信域中心频率时,该 值 为 正值;cpConfig 指示 目 标通信域的 循环 前 缀 配置;ftsIndication 和stsIndication指示目标通信域的同步信号;rsrp指示目标通信域的 RSRP测量值;sinr指示目标通信域的SINR测量值。</p>

:::
