# 7.5.3.84 其他配置信息

:::{div}
:class: figure-code

```asn1
-- ASN1START
OtherConfig ::= SEQUENCE {
    drx-config  DRX-Config  OPTIONAL,
    lcsr-config LCSR-Config OPTIONAL,
    rlf-config  RLF-Config  OPTIONAL,
    domainSysInfo   DomainSysInfo   OPTIONAL,
    carrierSwitchMASK   BIT24   OPTIONAL,
    domainWallClockTime DomainWallClockTime OPTIONAL,
    lowEnergyConfig LowEnergyConfig OPTIONAL,
    ...
}
-- ASN1STOP
```

:::

:::{div}
:class: standard-paragraph

<p>OtherConfig可包含非连续接收 DRX 相关配置drx-config、链路控制层数据量上报相关配置lcsr-config、载波快速切换的 CRC掩码carrierSwitchMASK、通信域时间信息、链路失败相关参数配置rlf-config和深度节能配置信息。</p>

:::
