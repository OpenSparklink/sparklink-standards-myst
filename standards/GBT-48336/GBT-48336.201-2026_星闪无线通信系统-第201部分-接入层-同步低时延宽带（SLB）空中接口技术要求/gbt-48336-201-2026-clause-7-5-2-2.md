# 7.5.2.2 G 链路信道查询消息

:::{div}
:class: figure-code

```asn1
-- ASN1START
GlinkChannelStatusRequest ::= SEQUENCE {
    xrc-Identifier  XRC-Identifier,
    requestType ENUMERATED {layer, cw},
    lateNonCriticalExtension    OCTET STRING    OPTIONAL,
    nonCriticalExtensions   SEQUENCE {} OPTIONAL
}
-- ASN1STOP
```

:::

:::{div}
:class: standard-paragraph

<p>GlinkChannelStatusRequest由 G节点发送给 T节点,用于查询 G链路信道状态信息。</p>

:::

:::{div}
:class: standard-paragraph

<p>其中,requestType指示 G链路信道状态反馈类型,layer为多流反馈,cw 为码字反馈。</p>

:::
