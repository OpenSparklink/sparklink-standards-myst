# 7.5.2.19 安全上下文请求消息

:::{div}
:class: figure-code

```asn1
-- ASN1START
SecurityContextRequest ::= SEQUENCE {
    xrc-Identifier  XRC-Identifier,
    kegx    BIT256,
    kegy    BIT256,
    rgx BIT256  OPTIONAL, -- Need OR
    rgy BIT256  OPTIONAL, -- Need OR
    nonceg  BIT256,
    algorithm   BIT24,
    mic-length  BIT16,
    authg   BIT128,
    reserve BIT STRING (SIZE (1..6400)) OPTIONAL, -- Need OR
    lateNonCriticalExtension    OCTET STRING    OPTIONAL,
    nonCriticalExtension    SEQUENCE {} OPTIONAL
}
-- ASN1STOP
```

:::

:::{div}
:class: standard-paragraph

<p>SecurityContextRequest由 G节点向 T节点发送,用于在无安全上下文时,向 T 节点请求安全上下文。具体包含的信元描述见9.3。mic-length的低8比特表示信令面 MIC长度的字节数,高8比特表示用户面 MIC长度的字节数。</p>

:::
