# 7.5.2.63 超宽带脉冲感知行为指示消息

:::{div}
:class: figure-code

```asn1
-- ASN1START
SLPSensingBehavioralIndicator ::= SEQUENCE {
    xrc-Identifier  XRC-Identifier,
    sLPSensingConfigIndex   UINT8,
    activeSignalingFrameNumber  UINT30,
    sLPSensingBehavioralConfiguration   UINT8,
    lateNonCriticalExtension    OCTET STRING    OPTIONAL,
    nonCriticalExtension    SEQUENCE {} OPTIONAL
}
-- ASN1STOP
```

:::

:::{div}
:class: standard-paragraph

<p>SLPSensingBehavioralIndicator由 G节点发送给 T 节点,用于指示超宽带脉冲感知行为。sLP-SensingConfigIndex用于指示感知信号配置索引;activeSignalingFrameNumber指示启动测量生效时间,以无线帧表达;sLPSensingBehavioralConfiguration用于指示超宽带脉冲感知行为指示配置,其中,0:从启动测量生效时间重新开始执行超宽带脉冲感知测量,原有时间资源配置失效。当该启动测量生效时间指示的时间是过去时间时,被配置节点应根据该组信令计算后续的测量事件组的起始时间,并执行后续测量事件组的测量;1:超宽带脉冲感知测量终止,释放超宽带脉冲感知信号配置;2:超宽带脉冲感知测量停止,不释放超宽带脉冲感知测量信号配置。</p>

:::
