# 7.5.3.99 上报事件配置信息

:::{div}
:class: figure-code

```asn1
-- ASN1START
EventTriggerConfig ::= SEQUENCE {
    eventId CHOICE {
    eventA1 SEQUENCE {
    a1-Threshold    MeasTriggerQuantity,
    timeToTrigger   TimeToTrigger
    },
    eventA2 SEQUENCE {
    a2-Threshold    MeasTriggerQuantity,
    timeToTrigger   TimeToTrigger
    }
    },
    ...
}
-- ASN1STOP
```

:::

:::{div}
:class: standard-paragraph

<p>用于配置事件触发上报相关配置,包含 A1事件和 A2事件,其中 A1配置门限a1-Threshold,当测量量大于或等于该门限时,触发上报;其中 A2事件,配置门限a2-Threshold,当测量量小于或等于该门限时,触发上报。</p>

:::
