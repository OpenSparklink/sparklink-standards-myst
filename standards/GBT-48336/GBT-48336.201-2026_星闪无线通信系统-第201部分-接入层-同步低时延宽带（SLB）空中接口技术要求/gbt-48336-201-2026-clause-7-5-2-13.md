# 7.5.2.13 XRC释放请求消息

:::{div}
:class: figure-code

```asn1
-- ASN1START
XRCReleaseRequest ::= SEQUENCE {
    xrc-Identifier  XRC-Identifier,
    causeRelease    XRCReleaseReason    OPTIONAL,
    lateNonCriticalExtension    OCTET STRING    OPTIONAL,
    nonCriticalExtension    SEQUENCE{}  OPTIONAL
}
-- ASN1STOP
```

:::

:::{div}
:class: standard-paragraph

<p>xrcReleaseRequest用于 T 节点向 G 节点主动申请 XRC连接的释放。其中causeRelease取值为1,即 T节点主动申请释放。</p>

:::
