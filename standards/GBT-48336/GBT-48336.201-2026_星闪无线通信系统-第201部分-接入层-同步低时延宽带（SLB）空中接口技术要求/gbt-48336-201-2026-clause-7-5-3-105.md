# 7.5.3.105 同步组测量信息

:::{div}
:class: figure-code

```asn1
-- ASN1START
SyncDomainGroupInfo ::= SEQUENCE {
    multiDomainSyncMode ENUMERATED {mode1, mode2, mode3, spare1},
    multiDomainSyncTopoInfo MultiDomainSyncTopoInfo OPTIONAL,
    syncDomainInfoList  SEQUENCE (SIZE(1..8)) OF SyncDomainInfo OPTIONAL,
    ...
}
-- ASN1STOP
```

:::

:::{div}
:class: standard-paragraph

<p>SyncDomainGroupInfo用于指示 T节点在目标信道上测量的同步通信域集合的信息,其中 multiDomainSyncMode用于指示同步模式,multiDomainSyncTopoInfo用于指示同步通信域集合的拓扑关系,syncDomainInfoList用于指示在该同步通信域集合中,T节点在目标信道上检测到的一个或多个通信域的同步测量的信息。</p>

:::
