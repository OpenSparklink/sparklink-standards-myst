# 7.5.3.98 测量配置信息

:::{div}
:class: figure-code

```asn1
-- ASN1START
MeasConfig-TSpecific ::= SEQUENCE {
    measureObjectList   SEQUENCE (SIZE(1..8)) OF MeasureObject,
    measurementchannel  ChannelNumber   OPTIONAL,
    measurementPeriod   UINT16  OPTIONAL,
    measurementOnDuration   INTEGER (1..65535)  OPTIONAL,
    measurementOffset   UINT16  OPTIONAL,
    measurementStarting UINT16  OPTIONAL,
    measurementCount    UINT5   OPTIONAL,
    nOffset UINT3   OPTIONAL,
    ftsIndication   ENUMERATED { high, normal } OPTIONAL,
    stsIndication   INTEGER (1..20) OPTIONAL,
    ...
}
MeasureObject ::= UINT4
```

:::

```asn1
-- ASN1STOP
```

:::{div}
:class: standard-paragraph

<p>测量配置信息包含若干个测量目标 measureobject,测量目标用来指示具体的测量量,其中0、1、2、3、4、5、6、7分别对应rsrp、rsrq、sinr、同步通信域集合测量、时间调整测量、频率调整测量、信道忙占比和 RSSI,其他比特预留;measurementchannel用于指示测量对应的信道,默认为 T 节点当前工作信道;measurementPeriod用来配置测量资源的周期、measurementOnDuration用来配置测量资源周期内的资源持续时间,measurementOffset用来配置测量资源周期内的偏移量,measurementStarting用于指示测量开始的超帧编号,measurementCount用于指示测量资源的数量,当该值为0时,不限定测量资源的 具 体数量,单位 均 为 超 帧;nOffset 指示 目 标通信域的 广 播 信息 偏 移 值;ftsIndication 和stsIndication指示目标通信域的同步信号。当测量配置指示为同步通信域集合测量时,T 节点需在目标信道中监测一个或多个 G节点,并接收 G节点通过广播信息发送的同步通信域集合信息。当测量配置指示为时间调整测量时,T节点在目标信道上按照nOffset、ftsIndication和stsIndication参数的指示进行时间调整信息的测量,当测量配置指示为频率调整测量时,T 节点在目标信道上按照 nOffset、ftsIndication和stsIndication参数的指示进行频率调整信息的测量。</p>

:::
