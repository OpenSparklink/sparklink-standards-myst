# 7.5.3.100 测量门限信息

:::{div}
:class: figure-code

```asn1
-- ASN1START
MeasTriggerQuantity ::= CHOICE {
    rsrp    RSRP-Value,
    rsrq    RSRQ-Value,
    sinr    SINR-Value,
    timeSync    TimeDomainSync-Value,
    frequencySync   FrequencySync-Value,
    domainSync  UINT5,
    channelBusyRatio    ChannelBusyRatioMeasure,
    ...
}
-- ASN1STOP
```

:::

:::{div}
:class: standard-paragraph

<p>其中domainSync用于指示同步通信域集合中包含的通信域的个数。</p>

:::
