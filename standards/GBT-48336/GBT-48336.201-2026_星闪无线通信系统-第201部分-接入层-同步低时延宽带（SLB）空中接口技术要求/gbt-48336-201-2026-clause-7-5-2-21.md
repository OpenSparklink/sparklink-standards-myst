# 7.5.2.21 有安全上下文的关联建立消息

:::{div}
:class: figure-code

```asn1
-- ASN1START
AssociationSetupWithSec ::= SEQUENCE {
    xrc-Identifier  XRC-Identifier,
    causeReject SecurityFailureReason   OPTIONAL, -- Need OR
    identityConfig  IDConfig    OPTIONAL,
    lateNonCriticalExtension    OCTET STRING    OPTIONAL,
    nonCriticalExtension    SEQUENCE {} OPTIONAL
}
-- ASN1STOP
```

:::

:::{div}
:class: standard-paragraph

<p>AssociationSetupWithSec用于在有安全上下文的条件下由 G 节点发送给 T 节点的关联(认证)消息,具体包含的信息元素见9.3。causeReject中包含拒绝的具体原因。</p>

:::

:::{div}
:class: standard-paragraph

<p>identityConfig应包含下次接入时在接入请求信息中使用的newphy-IDforNextAccess和在关联请求信息中使用的安全上下文关联标识newSecurityContextID。identityConfig可包含newphy-IdforU-nicast、newphy-IDforGroupcast和newphy-IDforPreConfig。</p>

:::
