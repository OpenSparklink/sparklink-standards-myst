# 7.5.2.25 厂商自定义消息

:::{div}
:class: figure-code

```asn1
-- ASN1START
VendorDefinedInfo ::= SEQUENCE {
    xrc-Identifier XRC-Identifier,
    companyID BIT16,
    vendorDefCompanyID SEQUENCE(SIZE (1..255)) OF BIT8,
    lateNonCriticalExtension OCTET STRING OPTIONAL,
    nonCriticalExtension SEQUENCE {} OPTIONAL
}
-- ASN1STOP
```

:::

:::{div}
:class: standard-paragraph

<p>VendorDefinedInfo由 G节点发送给 T节点,或者由 T 节点发送给 G 节点,用于发送厂商自定义消息,其中,companyID是由联盟分配的厂商唯一标识。</p>

:::
