# 7.5.2.33 位置测量信号测量反馈消息

:::{div}
:class: figure-code

```asn1
-- ASN1START
PositioningMeasurementReport ::= SEQUENCE {
    xrc-Identifier  XRC-Identifier,
    positioningMeasuretItemList SEQUENCE (SIZE(1..256)) OF PositioningMeasureItem
OPTIONAL, -- Need OR
    positioningMeasureNonConItemList SEQUENCE (SIZE(1..256)) OF PositioningMeasureNonConItem
OPTIONAL, -- Need OR
    nodePositioningCoordinates  NodePositioningCoordinates  OPTIONAL, -- Need OR
    lateNonCriticalExtension    OCTET STRING    OPTIONAL,
    nonCriticalExtension    SEQUENCE {} OPTIONAL
}
PositioningMeasureItem ::= SEQUENCE {
    positionningResourceIndex   UINT8,
    measRound   UINT16,
    m1ResouceMeasurement    PositioningSignalMeasurement    OPTIONAL,
    m2ResouceMeasurement    PositioningSignalMeasurement    OPTIONAL,
    m3ResouceMeasurement    PositioningSignalMeasurement    OPTIONAL,
    doubleSideThreeMessageRTTMeasure    SEQUENCE (SIZE(2)) OF BIT32 OPTIONAL,
    doubleSideTwoMessageRTTMeasure  BIT32   OPTIONAL,
    ...
}
PositioningMeasureNonConItem ::= SEQUENCE {
    positionningResourceIndex   UINT8,
    positioningEventIndex   UINT12,
    m1ResouceMeasurement    PositioningSignalMeasurement    OPTIONAL,
    m2ResouceMeasurement    PositioningSignalMeasurement    OPTIONAL,
    m3ResouceMeasurement    PositioningSignalMeasurement    OPTIONAL,
    doubleSideThreeMessageRTTMeasure    SEQUENCE (SIZE(2)) OF BIT32 OPTIONAL,
    doubleSideTwoMessageRTTMeasure  BIT32   OPTIONAL,
    ...
}
PositioningSignalMeasurement ::= SEQUENCE {
    rxTimingMeasure BIT32   OPTIONAL, -- Need OR
    rxAoAVerticalMeasure    INTEGER (0..1800)   OPTIONAL, -- Need OR
    rxAoAHorizontalMeasure  INTEGER (0..3599)   OPTIONAL, -- Need OR
    txAoDMeasure    UINT9   OPTIONAL, -- Need OR
    rxPortCSIMeasure    SEQUENCE (SIZE(1..255)) OF PerPortCSIMeasure    OPTIONAL, -- Need OR
    rxBeamCSIMeasure    SEQUENCE (SIZE(1..511)) OF PerBeamCSIMeasure    OPTIONAL, -- Need OR
    ...
}
PerPortCSIMeasure ::= SEQUENCE (SIZE(1..255)) OF PerBandCSIMeasure
PerBeamCSIMeasure ::= SEQUENCE (SIZE(1..255)) OF PerBandCSIMeasure
PerBandCSIMeasure ::= SEQUENCE {
    frequencyComb   CombInfo-3,
    quantizationBitWidth    INTEGER (1..16),
    rplCSIMeasuerNumber UINT16,
    iCSIMeasuerNumber   SEQUENCE (SIZE(1..39)) OF UINT16,
    qCSIMeasuerNumber   SEQUENCE (SIZE(1..39)) OF UINT16,
    sinrCSIMeasuerNumber    SEQUENCE (SIZE(1..39)) OF UINT8,
    carrierFrequencyOffset  UINT16,
    ...
}
-- ASN1STOP
```

:::{div}
:class: standard-paragraph

<p>positioningMeasuretItemList包括 T 节点在连续发送信道中的位置测量信息;positioningMea-sureNonConItemList包括T节点在非连续发送信道中的位置测量信息;positionningResourceIndex指示测量信号的配置索引;posMeasRound指示位置测量信号测量反馈消息对应的测量轮序号;position-ingEventIndex指示测量信号所在的测量事件;doubleSideThreeMessageRTTMeasure指示双边三信号RTT测量的时间差;rxTimingMeasure指示位置测量信号的到达时间,以本地 CP-OFDM 符号的初始时间为基准;rxAoAVerticalMeasure指示位置测量信号的到达角度的垂直方向角,以垂直于椭球面的正上方为$z$ 轴0°,以0.1°为单位;rxAoAVerticalMeasure指示位置测量信号的到达角度的水平方向角,以正南方向为$x$ 轴,以正东方向为$y$ 轴,正南方向为0°,以0.1°为单位;txAoDMeasure指示发送波束的索引,进而指示位置测量信号的出发角度;rxPortCSIMeasure基于端口的位置测量信号按照时间顺序反馈的信道状态信息;rxBeamCSIMeasure基于波束的位置测量信号按照时间顺序反馈的信道状态信息;PerPortCSIMeasuer对于一个基于端口的位置测量信号按照频率资源(子载波号)从小到大的顺序反馈的信道状态信息;PerBeamCSIMeasuer对于一个基于波束的位置测量信号按照频率资源从小到大的顺序反馈的信道状态信息;PerBandCSIMeasure一个载波的位置测量信号的信道状态信息;sin-rCSIMeasuerNumber该字段为1字节无符号数,(该字段的数值/2-5)为子载波的 SINR 信息;carrier-FrequencyOffset指示位置测量信号接收设备相对与发送设备相对频率偏移量(CFO),为两字节有符号整数,单位是$0.01\times 10^{-6}$。</p>
