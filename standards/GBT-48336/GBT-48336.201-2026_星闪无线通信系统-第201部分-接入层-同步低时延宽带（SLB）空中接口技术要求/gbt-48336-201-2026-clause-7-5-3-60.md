# 7.5.3.60 T节点特定载波切换指示信息

:::{div}
:class: figure-code

```asn1
-- ASN1START
CarrierSwitch-TSpecific ::= SEQUENCE {
    channelNumber   ChannelNumber,
    carrierSwitchTime   SuperframeIndex,
    tPhyID  PhyID   OPTIONAL,   -- Need OR
    domainSysInfo   DomainSysInfo   OPTIONAL,   -- Need OR
    ...
}
-- ASN1STOP
```

:::

:::{div}
:class: standard-paragraph

<p>channelNumber指示 T节点载波切换的目标载波信道号;carrierSwitchTime指示 G 节点发送该XRC消息所在的超帧之后 T节点进行载波切换的超帧的编号,在该超帧之前,T 节点仍旧使用未切换的载波与 G节点进行数据传输。DomainSysInfo是channelNumber指定的载波上通信域的系统消息;</p>

:::

:::{div}
:class: standard-paragraph

<p>当信息包含tPhyID时,T节点在channelNumber指定的载波上按照 DomainSysInfo配置的信息使用tPhyID做随机接入。</p>

:::
