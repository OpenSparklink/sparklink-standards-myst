# 7.5.3.16 通信域时间信息

:::{div}
:class: figure-code

```asn1
-- ASN1START
DomainWallClockTime ::= SEQUENCE {
    timeReferenceFrame  FrameIndex,
    ntp128bit   BIT128  OPTIONAL,   -- Need OR
    ntp64bit    BIT64   OPTIONAL,   -- Need OR
    ntp32bit    BIT32   OPTIONAL,   -- Need OR
    ...
}
-- ASN1STOP
```

:::

:::{div}
:class: standard-paragraph

<p>通信域时间信息提供与timeReferenceFrame指示某无线帧起始时刻以及该时刻所对应的 NTP时间信息。时间信息支持使用三种格式表达,其中ntp128bit使用128比特 NTP时间戳格式,ntp64bit使用64比特 NTP时间戳格式,ntp32bit使用32比特 NTP时间戳格式。</p>

:::
