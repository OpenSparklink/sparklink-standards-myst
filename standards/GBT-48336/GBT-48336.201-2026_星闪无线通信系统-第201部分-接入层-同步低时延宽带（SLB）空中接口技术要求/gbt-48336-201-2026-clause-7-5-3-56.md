# 7.5.3.56 信道质量指示配置信息

:::{div}
:class: figure-code

```asn1
-- ASN1START
CQI-Conf ::= SEQUENCE {
    cqi-Identity    UINT16,
    newphy-IDforPreConfig   PreConfigPhysID OPTIONAL,
    cqi-FeedbackMode    ENUMERATED {carrier, sub-carrier, spare2, spare1}   OPTIONAL,
    cqi-CombInfo    CombInfo-1  OPTIONAL,
    cqi-CombOffset  CombOffset-1    OPTIONAL,
    cqi-TimeResource    DedicatedTimeResource   OPTIONAL,
    ttiPeriod   TTiPeriod   OPTIONAL,
    ttiOffset   TTiOffset   OPTIONAL,
    phyIDforRSsequence  PhyIDforRSsequence  OPTIONAL,
    phyIDforScrambling  PhyIDforScrambling  OPTIONAL,
    powerOffset PowerOffset OPTIONAL,
    ...
}
-- ASN1STOP
```

:::

:::{div}
:class: standard-paragraph

<p>当预配置调度激活去激活信息 GCI指示 CQI标识时,CQI信息所在 TTI按如下方式计算。</p>

:::

:::{div}
:class: standard-paragraph

<p>当前 TTI满足 mod((当前 TTI顺序号-GCI所在 TTI顺序号$),\mathrm{TTiPeriod})=\mathrm{TTiOffset}$时,或当TTiPeriod等于0且当前 TTI满足(当前 TTI顺序号-GCI所在 TTI顺序号$)=\mathrm{TTiOffset}$时,T节点使用 CQI-Conf配置的资源发送信道质量指示信息,当ttiPeriod不配置时,默认取值为0;当ttiOffset不配置时,默认取值为0。DedicatedTimeResource指示 TTI中的符号资源。cqi-Identity为当前 CQI配置标识,可被物理层预配置调度激活去激活信息指示和调度。当cqi-Identity与csi-rs-Identity相同时,物理层预配置调度激活去激活信息可同时进行激活去激活。</p>

:::


:::{div}
:class: standard-paragraph

<p>当删除 CQI相关配置时,只需要提供 CQI配置标识信息cqi-Identity即可。</p>

:::

:::{div}
:class: standard-paragraph

<p>cqi-FeedbackMode指示基于基础载波的反馈方式或基于子载波组的反馈方式。</p>

:::

:::{div}
:class: standard-paragraph

<p>针对信道质量指示 梳齿 集合信息 cqi-CombInfo 和信道质量指示 梳齿 偏 移 序号信息 cqi-CombOffset,当 子载波 编 号 满足$\mathrm{mod}(\#\mathrm{subcarrier},cqi-\mathrm{CombInfo})=\mathrm{mod}(cqi-\mathrm{CombOffset},cqi-$CombInfo)时,该子载波发送信道质量指示信息。</p>

:::

:::{div}
:class: standard-paragraph

<p>若未配置newphy-IDforPreConfig,则需要配置。</p>

:::

:::{div}
:class: standard-paragraph

<p>phyIDforRSsequence用于配置 CQI反馈信息的参考信号序列生成的物理层标识,可选信元。</p>

:::

:::{div}
:class: standard-paragraph

<p>phyIDforScrambling用于配置 CQI反馈信息比特加扰的物理层标识,可选信元。</p>

:::

:::{div}
:class: standard-paragraph

<p>powerOffset用于配置 CQI反馈信息的功率偏置值,默认值为0。</p>

:::
