# 7.5.3.112 MAC层逻辑信道配置信息

:::{div}
:class: figure-code

```asn1
-- ASN1START
MAC-Config ::= SEQUENCE {
    priority    INTEGER (1..8),
    prioritisedBitSize  ENUMERATED {
    s0, s8, s16, s32, s64, s128, s256, s512,
    s1024, s2048, s4096, s8192, s16384, s32768, s65536, invalid
    } OPTIONAL,
    ...
}
-- ASN1STOP
```

:::

:::{div}
:class: standard-paragraph

<p>MAC层配置信息包括逻辑信道优先级priority,其中1为优先级最高。prioritisedBitSize指示逻辑信道首次数据封装的最大数据量,单位为字节,默认值为invalid。当配置为invalid时,数据封装量无限制。</p>

:::
