# 7.5.3.1 节点能力版本信息

:::{div}
:class: figure-code

```asn1
-- ASN1START
CapabilityVersion ::= SEQUENCE {
    majorVersion    UINT4,
    minorVersion    UINT4
}
-- ASN1STOP
```

:::

:::{div}
:class: standard-paragraph

<p>指示节点能力的版本信息,本文件定义 majorVersion取值为2,minorVersion取值为1。</p>

:::
