:::{div}
:class: standard-paragraph

<p>ACK 资源配置dedicatedACK-ResourceSetConf。</p>

:::

:::{div}
:class: standard-paragraph

<p>glinkmcsTableIndication用于指示 G链路采用的 MCS表格,默认值为table1。</p>

:::

:::{div}
:class: standard-paragraph

<p>tlinkmcsTableIndication用于指示 T链路采用的 MCS表格,默认值为table1。</p>

:::

:::{div}
:class: standard-paragraph

<p>schedMode用于指示数据调度模式。tb表示基于 TB的调度模式,为默认值;cbg1表示基于单级动态调度数据控制信息的调度模式;cbg2表示基于两级动态调度数据控制信息的调度模式。</p>

:::

:::{div}
:class: standard-paragraph

<p>dmrs-D-SetConf用于对 G 链路和/或 T 链路数据在不同端口数量情况下的 DMRS-D 梳齿配置信息。</p>

:::

:::{div}
:class: standard-paragraph

<p>harqFeedbackMode、singleStageCBGNumber、firstStageBits和secondStageBits四个参数用于配置HARQ 反馈模式。harqFeedbackMode指示 HARQ 反馈模式。tb表示基于 TB反馈模式,cbg1表示基于单级 CBG反馈模式,cbg2表示基于两级 CBG反馈模式。</p>

:::

:::{div}
:class: standard-paragraph

<p>当harqFeedbackMode值为tb时,配置为 TB反馈模式,其他参数无效。该参数不配置时,tb为默认值。</p>

:::

:::{div}
:class: standard-paragraph

<p>当harqFeedbackMode值为 cbg1 时,配置 为 单级 HARQCBG 反馈模式,并 且 singleStageCB-GNumber用于配置在单级 HARQCBG 反馈模式下反馈的比特数,其他参数无效。singleStageCB-GNumber取值为c2时,表示 TB包含的 CBG的最大个数为2,对应的 A/N 反馈的个数为2;当取值为c4时,表示 TB包含的 CBG的最大个数为4,对应的 A/N 反馈的个数为4;当取值为c8时,表示 TB包含的 CBG的最大个数为8,对应的 A/N 反馈的个数为8。</p>

:::

:::{div}
:class: standard-paragraph

<p>当harqFeedbackMode值为 cbg2 时,配置 为 两 级 HARQCBG 反馈模式,并 且 singleStageCB-GNumber用于配置在两级 HARQCBG反馈模式下使用单级 CBG 反馈时的比特数;同时配置在两级HARQCBG反馈模式下使用两级 HARQCBG反馈时,firstStageBits表示第一级CBG反馈的CBG比特数,secondStageBits表示第二级 CBG反馈的 CBG比特数。</p>

:::

:::{div}
:class: standard-paragraph

<p>glinkselfTTI-Scheduling用于指示 G 链路是否采用本 TTI调度,当该值为true时,GCI指示本TTI内的调度,当该值为false时,GCI指示下一 TTI内的调度。不配置时,默认为false。</p>

:::

:::{div}
:class: standard-paragraph

<p>tlinkselfTTI-Scheduling用于指示 T 链路是否采用本 TTI调度,当该值为true时,GCI指示本TTI内的调度,当该值为false时,GCI指示下一 TTI内的调度。不配置时,默认为false。</p>

:::

:::{div}
:class: standard-paragraph

<p>glinkselfTTI-HARQFeedback用于指示 G链路传输是否采用本 TTI内的 HARQ 反馈,当该值为true时,G链路传输的在本 TTI内进行 HARQ 反馈,当该值为false时,G链路传输的在下一 TTI内进行 HARQ 反馈。不配置时,默认为false。</p>

:::

:::{div}
:class: standard-paragraph

<p>srConfig指示 T节点调度请求信息资源相关配置。</p>

:::

:::{div}
:class: standard-paragraph

<p>cqi-Set-Conf指示信道质量信息资源相关配置。</p>

:::

:::{div}
:class: standard-paragraph

<p>harqTxMode指示单级 HARQ 反馈使用的传输模式配置。m0指示采用基于序列方式传输,m1指示基于数据传输方式传输,其他预留。</p>

:::

:::{div}
:class: standard-paragraph

<p>maxMotherCodeLength指示最大母码长度,n1指示4096,为默认值;n2指示1024,其他预留。</p>

:::

:::{div}
:class: standard-paragraph

<p>enablePAS指示开启或关闭传输物理层数据信息相位调整信号,默认为false,即关闭。当取值为true时,pasMCSIndex 进 一步指示 开启 传输的 条 件,即 基 于 当 前 MCS 表格 的 MCS 索 引 阈 值,当MCS大于或等于该 MCS索引阈值时,开启传输物理层数据信息相位调整信号,否则不开启传输。</p>

:::

:::{div}
:class: standard-paragraph

<p>phyIDforRSsequence用于配置PAS参考信号序列生成的物理层标识,可选信元。在开启传输物理层数据信息相位调整信号时,若未配置时,则可配置。</p>

:::

:::{div}
:class: standard-paragraph

<p>phyIDforScramblingGlinkData和phyIDforScramblingTlinkData分别用于对 G 链路和 T 链路动态调度数据进行比特加扰,可在xrcReconfiguration消息中携带并配置。</p>

:::
