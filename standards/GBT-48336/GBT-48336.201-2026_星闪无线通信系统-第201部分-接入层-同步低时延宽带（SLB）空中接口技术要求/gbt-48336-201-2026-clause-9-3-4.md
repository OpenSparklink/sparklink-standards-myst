# 9.3.4 密钥派生函数

(gbt-48336-201-2026-clause-9-3-4-1)=
## 9.3.4.1 单播密钥派生函数

:::{div}
:class: standard-paragraph

<p>密钥派生函数 KDF的输入包含密钥和其他输入参数。派生的密钥如公式(58)、公式(59)所示。</p>

:::

:::{div}
:class: standard-paragraph

<p>当使用 HMAC-SHA256作为密钥派生函数时,</p>

:::

(gbt-48336-201-2026-equation-58)=
```{math}
\begin{aligned}\text{派生的密钥}&=\operatorname{KDF}(\mathrm{Key},\text{参数 1},\text{参数 2},\cdots,\text{参数 }n)\\&=\operatorname{HMAC-SHA256}(\mathrm{Key},\text{参数 1}\mathbin{\Vert}\text{参数 2}\mathbin{\Vert}\cdots\mathbin{\Vert}\text{参数 }n)\end{aligned}\tag{58}
```

:::{div}
:class: standard-paragraph

<p>当使用 HMAC-SM3作为密钥派生函数时,</p>

:::

(gbt-48336-201-2026-equation-59)=
```{math}
\begin{aligned}\text{派生的密钥}&=\operatorname{KDF}(\mathrm{Key},\text{参数 1},\text{参数 2},\cdots,\text{参数 }n)\\&=\operatorname{HMAC-SM3}(\mathrm{Key},\text{参数 1}\mathbin{\Vert}\text{参数 2}\mathbin{\Vert}\cdots\mathbin{\Vert}\text{参数 }n)\end{aligned}\tag{59}
```

:::{div}
:class: standard-paragraph

<p>式中:</p>

:::

:::{div}
:class: standard-definitions

||
: 串联。

:::

:::{div}
:class: standard-paragraph

<p>根据密钥派生函数,从 Kgt推演出一个中间密钥 Kmid,如公式(60)所示。</p>

:::

(gbt-48336-201-2026-equation-60)=
```{math}
\mathrm{Kmid}=\operatorname{KDF}(\mathrm{Kgt},\mathrm{counter})\tag{60}
```

:::{div}
:class: standard-paragraph

<p>同步低时延宽带通信系统信令面的认证加密密钥,用户面的认证加密密钥,信令面的加密密钥和完整性保护密钥,用户面的加密密钥和完整性保护密钥根据密钥派生函数从 Kmid推演。如果需要的密钥长度为128比特,则对 KDF的输出截取高128比特作为密钥。其中信令面、用户面和控制面认证加密保护密钥如公式(61)、公式(62)、公式(63)所示。信令面机密性保护密钥、信令面完整性保护密钥如公式(64)、公式(65)所示。用户面机密性保护密钥、用户面完整性保护密钥、控制面完整性保护密钥如公式(66)、公式(67)、公式(68)所示。</p>

:::

:::{div}
:class: standard-paragraph

(gbt-48336-201-2026-clause-9-3-4-2)=
## 9.3.4.2 组播密钥派生函数

:::{div}
:class: standard-paragraph

<p>组播密钥派生函数使用 HMAC-SHA256或 HMAC-SM3(输出长度:256比特)。</p>

:::

:::{div}
:class: standard-paragraph

<p>根据密钥派生函数,从 RAND和组ID推演出一个组密钥 GK,如公式(69)所示。</p>

:::

(gbt-48336-201-2026-equation-69)=
```{math}
\mathrm{GK}=\operatorname{KDF}(\mathrm{RAND},\text{组 ID})\tag{69}
```

:::{div}
:class: standard-paragraph

<p>同步低时延宽带通信系统对应组ID的组播信令面的认证加密密钥,用户面的认证加密密钥,信令面的加密密钥和完整性保护密钥,用户面的加密密钥和完整性保护密钥根据密钥派生函数从 GK 推演。</p>

:::

:::{div}
:class: standard-paragraph

<p>如果需要的密钥长度为128比特,则对 KDF的输出截取高128比特作为密钥。组播信令面认证加密保护密钥、组播用户面认证加密保护密钥如公式(70)、公式(71)所示。组播信令面机密性保护密钥、组播信令面完整性保护密钥如公式(72)、公式(73)所示。组播用户面机密性保护密钥、组播用户面完整性保护密钥如公式(74)、公式(75)所示。</p>

:class: standard-paragraph

(gbt-48336-201-2026-clause-9-3-4-3)=
## 9.3.4.3 广播信息随机校验值

:::{div}
:class: standard-paragraph

<p>G 节点通过securityConfig信元或消息向 T节点配置 mibVerificationKeyVar、DHFN、通信域密钥派生函数 DomainKDF。G节点计算256比特哈希值$=\mathrm{DomainKDF}(\mathrm{mibVerificationKe}y\mathrm{Var},\mathrm{DGFN}$ 高27比特)。当广播信息在某无线帧发送时,G节点使用该无线帧的无线帧索引号按表68获得对应的6比特随机校验值,并设置该广播信息中的6比特随机校验值字段。</p>

:::

:::{div}
:class: standard-paragraph

<p>在初始接入流程中,G 节点需要向 T 节点配置 mibVerificationKey、DHFN、通信域密钥派生函数DomainKDF等参数,mibverificationKey配置后立即生效。在 DGFN 翻转之前,G 节点需要通过securityConfig消息向 T 节点配置 nextMibVerificationKey。nextMibVerificationKey生效时刻为 DGFN翻转时刻。</p>

:::

:::{div}
:class: standard-paragraph

<p>在 T节点收到 G 节点配置的 mibVerificationKeyVar、DHFN、通信域密钥派生函数 DomainKDF等参数后,T节点对 G节点广播信息进行校验。T节点计算256比特哈希值$=\mathrm{DomainKDF}(\mathrm{mibVeri}-$ficationKeyVar,DGFN 高27比特)。T节点使用 G节点广播信息中的无线帧索引号按表获得对应的6比特随机校验值,T节点比较本地获得的6比特随机校验值和 G 节点广播信息中的6比特随机校验值是否一致,一致则 T节点校验 G节点广播信息成功,不一致则 T节点校验 G节点广播信息失败。</p>

:::
