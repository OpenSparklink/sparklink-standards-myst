# 6.8 超宽带脉冲测量流程

(gbt-48336-201-2026-clause-6-8-1)=
## 6.8.1 超宽带脉冲位置测量概述

:::{div}
:class: standard-paragraph

<p>T节点通过 XRC消息交互通知其传输超宽带脉冲测量帧的能力。</p>

:::

:::{div}
:class: standard-paragraph

<p>基于 T节点的能力,G 节点通过 XRC 消息配置 T 节点传输超宽带脉冲测量帧,支持 G 节点和T节点之间传输超宽带脉冲测量帧,支持两个 T节点之间传输超宽带脉冲测量帧。</p>

:::

:::{div}
:class: standard-paragraph

<p>基于 G节点的配置,两个节点传输超宽带脉冲测量帧,支持如下情况:</p>

:::

:::{div}
:class: standard-list-block

<ul class="standard-list">
<li><p>——— 一个节点发送超宽带脉冲测量帧,另外一个节点根据超宽带脉冲测量帧进行测量;</p>
</li>
<li><p>——— 双边两消息,也即两个节点中一个节点先发送第一超宽带脉冲测量帧,另外一个节点后发送第二超宽带脉冲测量帧,此时两个节点分别根据对方节点发送的超宽带脉冲测量帧进行测量;对于双边两消息,两个节点先后共发送两个超宽带脉冲测量帧称为一个超宽带脉冲测量事件,两个节点可传输多个超宽带脉冲测量事件进行多次测量或者进行更准确的测量;</p>
</li>
<li><p>——— 双边三消息测量,也即两个节点中第一个节点先发送第一超宽带脉冲测量帧,然后第二个节点后发送第二超宽带脉冲测量帧,最后第一个节点发送第三超宽带脉冲测量帧,此时两个节点分别根据对方节点发送的超宽带脉冲测量帧进行测量;对于双边三消息,两个节点先后共发送三个超宽带脉冲测量帧称为一个超宽带脉冲测量事件,两个节点可传输多个超宽带脉冲测量事件进行多次测量或者进行更准确的测量。</p>
</li></ul>

:::

:::{div}
:class: standard-paragraph

<p>G节点可配置 T节点在超宽带脉冲测量事件中先发送超宽带脉冲测量帧还是后发送超宽带脉冲测量帧,或者在连续的超宽带脉冲测量事件中交替先发送超宽带脉冲测量帧或者后发送超宽带脉冲测量帧。</p>

:::

:::{div}
:class: standard-paragraph

<p>节点可传输不同带宽的超宽带脉冲。</p>

:::

:::{div}
:class: standard-paragraph

<p>节点可在不同信道传输超宽带脉冲测量帧,用于接收节点对多个信道进行拼接。</p>

:::

:::{div}
:class: standard-paragraph

<p>节点可使用多天线发送超宽带脉冲测量帧,节点可使用多天线接收超宽带脉冲测量帧。</p>

:::

:::{div}
:class: standard-paragraph

<p>当发送节点和接收节点支持多天线传输超宽带脉冲测量帧时,G 节点可配置发送节点先切换天线或者接收节点先切换天线。</p>

:::

:::{div}
:class: standard-paragraph

<p>当发送节点和接收节点支持多天线传输超宽带脉冲测量帧时,G 节点可配置进行天线切换的起始测量子片段,在该测量子片段之前,发送节点和接收节点不进行天线切换,从该测量子片段开始进行天线切换。</p>

:::

:::{div}
:class: standard-paragraph

<p>当发送节点和接收节点在不同信道上使用多天线传输超宽带脉冲测量帧时,发送节点和接收节点需根据 G 节点配置的天线对顺序,针对每一个天线对使用配置的信道顺序传输超宽带脉冲测量帧,也即先进行信道跳频然后进行天线切换。</p>

:::

:::{div}
:class: standard-paragraph

<p>节点可对多个信道的超宽带脉冲测量帧进行测量,并将测量量进行处理将多个信道的测量信息拼接为一个更大带宽的信道的测量信息。</p>

:::

:::{div}
:class: standard-paragraph

<p>节点可对对端节点发送的超宽带脉冲测量帧进行测量,并上报测量信息,测量量包括出发角信息AoD、到达角信息 AoA、双边两消息的时间测量信息、双边三消息的时间测量信息、基于频率域I路和 Q路信息的信道状态信息、基于时间域信道冲击响应的信道状态信息、距离多普勒信息、感知目标信息等。</p>

:::

:::{div}
:class: standard-paragraph

<p>根据 G节点的配置,当节点使用多天线传输超宽带脉冲测量帧时,节点可对一个特定的发送天线和接收天线对进行测量并上报测量信息,也可对所有发送天线和接收天线对进行测量并上报测量信息。</p>

:::

:::{div}
:class: standard-paragraph

<p>基于上述 G节点配置的两个节点间传输超宽带脉冲测量帧的情况,G 节点可配置1个节点与多个节点传输超宽带脉冲测量帧,此时该多个节点中的每个节点都可接收到该1个节点发送的超宽带脉冲测量帧,该一个节点也可接收到该多个节点中的每个节点发送的超宽带脉冲测量帧。该一个节点与该多个节点根据 G节点的配置对接收到的超宽带脉冲测量帧进行测量并上报测量信息。</p>

:::

:::{div}
:class: standard-paragraph

<p>基于上述 G节点配置的一个节点发送超宽带脉冲测量帧,另外一个节点接收超宽带脉冲测量帧的情况,G节点可配置1个节点发送超宽带脉冲测量帧并配置多个节点接收该1个节点发送的超宽带脉冲测量帧,该多个节点根据 G 节点的配置对接收到的超宽带脉冲测量帧进行测量并上报测量信息。</p>

:::

:::{div}
:class: standard-paragraph

<p>G节点还可配置多个节点发送超宽带脉冲测量帧并配置一个节点接收该多个节点发送的多个超宽带脉冲测量帧。</p>

:::

:::{div}
:class: standard-paragraph

<p>G节点可给 T节点配置资源预留,当该资源预留指示的时间资源与 T节点已经被配置数据链路重叠时,T节点不在该资源预留指示的时间资源上发送和接收数据。</p>

:::

:::{div}
:class: standard-paragraph

<p>G节点配置超宽带脉冲信号的时间资 源 时,信 令 指示的单位 为 超宽带脉冲配置时间 粒 度$=$$256\times \mathrm{Tc}$。</p>

:::

(gbt-48336-201-2026-clause-6-8-3)=
## 6.8.3 超宽带脉冲测量的参数和配置

:::{div}
:class: standard-paragraph

<p>G节点向 T节点发送超宽带脉冲测量能力请求,T 节点向 G 节点反馈超宽带脉冲测量能力响应,G节点根据该 T节点的超宽带脉冲测量能力配置该 T节点对超宽带脉冲测量帧的传输和测量。</p>

:::

:::{div}
:class: standard-paragraph

<p>当节点支持重叠方式信道拼接时,该节点可对频率存在重叠的多个分别传输的信道进行测量,并对该多个信道的多个测量量进行处理,形成一个等效于该多个信道覆盖的更大带宽的测量量。当节点支持连续方式信道拼接时,该节点可对频率连续的多个分别传输的信道进行测量,并对该多个信道的多个测量量进行处理,形成一个等效于该多个信道覆盖的更大带宽的测量量。当节点支持非连续方式信道拼接时,该节点可以频率非连续的多个分别传输的信道进行测量,并对该多个信道的多个测量量进行处理,形成一个等效于该多个信道覆盖的更大带宽的测量量。当节点被配置进行信道拼接的测量时,该节点应上报信道拼接后的测量量。</p>

:::

:::{div}
:class: standard-paragraph

<p>G节点配置超宽带脉冲测量帧的时间资源时,应确保测量事件内间隔、测量事件间间隔、测量事件组间间隔的时长大于该节点的能力。当该节点支持多天线传输时,上述三个时间间隔也应大于天线的切换间隔。</p>

:::

:::{div}
:class: standard-paragraph

<p>对于超宽带脉冲测量时间,G 节点可配置 T 节点作为先发节点或者后发节点。基于 G 节点的配置,可支持 G节点先发 T节点后发的测量,T节点先发 G 节点后发的测量,以及一个 T 节点先发一个T节点后发的测量。</p>

:::

:::{div}
:class: standard-paragraph

<p>对于支持多天线传输的节点,G节点配置超宽带脉冲测量帧时,应确保测量子片段间的间隔大于天线的切换间隔。</p>

:::

:::{div}
:class: standard-paragraph

<p>对于支持多天线传输的节点,对于一个超宽带脉冲测量帧,G 节点可配置发送节点天线切换优先、接收节点天线切换优先或者随机天线切换。G节点应确保测量子片段间的间隔大于发送天线的切换间隔和接收天线的切换间隔。</p>

:::

:::{div}
:class: standard-paragraph

:::{div}
:class: standard-paragraph

:::{div}

## 6.8.4 超宽带脉冲感知的参数和配置

:::{div}
:class: standard-paragraph

<p>G节点向 T节点发送超宽带脉冲感知能力请求,T 节点向 G 节点反馈超宽带脉冲感知能力响应,G节点根据该 T节点的超宽带脉冲感知能力配置该 T节点对超宽带脉冲测量帧的传输和测量。</p>

:::

:::{div}
:class: standard-paragraph

<p>当节点支持重叠方式信道拼接时,该节点可对频率存在重叠的多个分别传输的信道进行测量,并对该多个信道的多个测量量进行处理,形成一个等效于该多个信道覆盖的更大带宽的测量量。当节点支持连续方式信道拼接时,该节点可对频率连续的多个分别传输的信道进行测量,并对该多个信道的多个测量量进行处理,形成一个等效于该多个信道覆盖的更大带宽的测量量。当节点支持非连续方式信道拼接时,该节点可对频率非连续的多个分别传输的信道进行测量,并对该多个信道的多个测量量进行处理,形成一个等效于该多个信道覆盖的更大带宽的测量量。当节点被配置进行信道拼接的测量时,该节点应上报信道拼接后的测量量。</p>

:::

:::{div}
:class: standard-paragraph

<p>G节点配置超宽带脉冲测量帧的时间资源时,应确保测量事件间间隔、测量事件组间间隔的时长大于该节点的能力。当该节点支持多天线传输时,上述三个时间间隔也应大于天线的切换间隔。</p>

:class: standard-paragraph

:::{div}
:class: standard-paragraph

:class: standard-paragraph
