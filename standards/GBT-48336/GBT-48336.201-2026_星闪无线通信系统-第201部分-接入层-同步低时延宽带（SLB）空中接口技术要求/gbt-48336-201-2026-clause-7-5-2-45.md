# 7.5.2.45 感知设备状态上报消息

:::{div}
:class: figure-code

```asn1
-- ASN1START
SensingDeviceState ::= SEQUENCE {
    xrc-Identifier  XRC-Identifier,
    sensingConfigIndex  UINT8,
    stabilityIndicator  BoolType,
    lateNonCriticalExtension    OCTET STRING    OPTIONAL,
    nonCriticalExtension    SEQUENCE {} OPTIONAL
}
-- ASN1STOP
```

:::

:::{div}
:class: standard-paragraph

<p>SensingDeviceState由 T节点发送给 G节点,用于上报设备状态信息。sensingConfigIndex用于指示感知信号配置索引;stabilityIndicator用于标识感知上报的感知设备当前状态是否稳定,0代表感知设备状态稳定,1代表感知设备状态不稳定。</p>

:::
