# 7.5.2.52 超宽带脉冲测量信息上报消息

:::{div}
:class: figure-code

```asn1
-- ASN1START
SLPMeasurementReport ::= SEQUENCE {
    xrc-Identifier  XRC-Identifier,
    sLPMeasurementReport SEQUENCE (SIZE(1..256))OF SLPMeasurementReportItem OPTIONAL,--NeedOR
    lateNonCriticalExtension    OCTET STRING    OPTIONAL,
    nonCriticalExtension    SEQUENCE {} OPTIONAL
}
SLPMeasurementReportItem ::= SEQUENCE {
    sLPConfigIndex  UINT8,
    sLPMeasEventGroupIndex  UINT16,
    sLPMeasEventIndex   UINT8,
    sLPMeasReportType   BIT16,
    aoAReport   AoAReport OPTIONAL, -- Need OR
    aoDReport   AoDReport OPTIONAL, -- Need OR
    cSIReport   CSIReport OPTIONAL, -- Need OR
    cIRReport-FirstPath CIRReportInfo OPTIONAL, -- Need OR
    cIRReport-StrongestPath CIRReportInfo OPTIONAL, -- Need OR
    cIRReport-TxTime    CIRReportInfo OPTIONAL, -- Need OR
    ss-TWRorDs-TWRReport    Ss-TWRorDs-TWRReport OPTIONAL, -- Need OR
    rxAntennaPhaseDiffReport    RxAntennaPhaseDiffReport OPTIONAL, -- Need OR
    txAntennaPhaseDiffReport    TxAntennaPhaseDiffReport OPTIONAL, -- Need OR
    rangeDopplerReport-FirstPath    RangeDopplerReportInfo OPTIONAL, -- Need OR
    rangeDopplerReport-StrongestPath    RangeDopplerReportInfo OPTIONAL, -- Need OR
    rangeDopplerReport-TxTime   RangeDopplerReportInfo OPTIONAL, -- Need OR
    sensingTargetReport SensingTargetReport OPTIONAL, -- Need OR
    vendorSpecificReport    VendorSpecificReport OPTIONAL, -- Need OR
    ...
}
Ss-TWRorDs-TWRReport ::= SEQUENCE {
    ss-TWR-firstNodeTimeDiff    UINT24,
    ss-TWR-secondNodeTimeDiff   UINT24,
    sLPFrequencyDeviation   UINT24,
    ds-TWRfirstNodeFirstTimeDiff    UINT24,
    ds-TWRfirstNodeSecondTimeDiff   UINT24,
    ds-TWRsecondNodeFirstTimeDiff   UINT24,
    ds-TWRsecondNodeSecondTimeDiff  UINT24
}
-- ASN1STOP
```

:::

:::{div}
:class: standard-paragraph

<p>SLPMeasurementReport由 T 节点发送给 G 节点,用于进行超宽带脉冲测量信息上报。sLPConfigIndex指示位置测量信号配置索引;sLPMeasEventGroupIndex指示超宽带脉冲测量事件组序号;</p>

:::

:::{div}
:class: standard-paragraph

<p>sLPMeasEventIndex指示超宽带脉冲测量事件序号;sLPMeasReportType使用位图指示位置测量信息上报消息中包含的位置测量信息,其中比特0指示位置测量信号 AoA 信息;比特1指示位置测量信号AoD信息;比特2指示载波I路 Q 路信息表达的测量信号信道状态信息;比特3指示信道冲击响应表达的测量信号信道状态信息—以第一径为初始参考;比特4指示信道冲击响应表达的测量信号信道状态信息—以最强径为初始参考;比特5指示信道冲击响应表达的测量信号信道状态信息—以信号发送时间为初始参考;比特6指示双边两消息/双边三消息时间信息;比特7指示接收天线相位差信息;比特8指示发送天线相位差信息;比特9指示I路 Q 路信息表达测量信号处理得到的距离多普勒信息—以第一径为初始参考;比特10指示I路 Q 路信息表达测量信号处理得到的距离多普勒信息—以最强径为初始参考;比特11指示I路 Q 路信息表达测量信号处理得到的距离多普勒信息—以信号发送时间为初始参考;比特12指示感知目标信息,该信息表达信号处理后感知目标的特性信息;比特15指示厂商自定义数据信息;其他比特位预留。</p>

:::

:::{div}
:class: standard-paragraph

<p>Ss-TWRorDs-TWRReport用于指示双边两消息/双边三消息时间信息。其中,ss-TWR-firstNodeTimeDiff指示双边两消息先发节点测量时间差;ss-TWR-secondNodeTimeDiff指示双边两消息后发节点测量时间差;sLPFrequencyDeviation指示超宽带频率偏差量;ds-TWRfirstNodeFirstTimeDiff指示双边三消息先发节点测量第一时间差;ds-TWRfirstNodeSecondTimeDiff指示双边三消息先发节点测量第二时间差;ds-TWRsecondNodeFirstTimeDiff指示双边三消息后发节点测量第一时间差;ds-TWRsecondNodeSecondTimeDiff指示双边三消息后发节点测量第二时间差。</p>

:::
