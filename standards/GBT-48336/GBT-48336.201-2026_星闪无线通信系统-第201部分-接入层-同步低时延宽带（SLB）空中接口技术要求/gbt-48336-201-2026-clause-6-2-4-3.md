# 6.2.4.3 广播信息

(gbt-48336-201-2026-clause-6-2-4-3-1)=
## 6.2.4.3.1 信息比特

:::{div}
:class: standard-paragraph

<p>广播信息中,有效比特42比特,预留比特6比特,CRC24比特,共72比特,承载物理层配置参数,从最低位比特到最高位比特,具体包含如下信息。</p>

:::

:::{div}
:class: standard-list-block

<ul class="standard-list">
<li><p>——— 3比特:符号类型指示。0:类型一 A,1:类型一 B,2:类型二,3:类型三,4:类型四,其他取值预留。</p>
</li>
<li><p>——— 1比特:发送广播信息的基础信道是否允许直通链路使用。0:不允许,1:允许。</p>
</li>
<li><p>——— 13比特:无线帧索引号低13位。本字段指示发送该广播信息的第一个符号所在无线帧的无线帧索引号的低13位。无线帧索引号共19位,其中高16位为无线帧所在超帧的超帧编号,无线帧索引号的低3位为该无线帧的无线帧编号。</p>
</li>
<li><p>——— 6比特:随机校验值。随机校验值的生成方法见9.3.4.3。</p>
</li>
<li><p>——— 3比特:TTI长度指示,0:1无线帧,1:2无线帧,2:4无线帧,3:8无线帧,4:16无线帧,5:32无线帧,6:64无线帧,7:预留。</p>
</li>
<li><p>——— 3比特:通信域第一组系统消息DomainSysInfo-Group0的发送周期,0指示可能发送系统消息的无线帧的起始编号为64的倍数,1指示可能发送系统消息的无线帧的起始编号为128的倍数,2指示可能发送系统消息的无线帧的起始编号为256的倍数,3指示可能发送系统消息的无线帧的起始编号为512的倍数;4指示可能发送系统消息的无线帧的起始编号为1024的倍数,5指示可能发送系统消息的无线帧的起始编号为2048的倍数,6指示可能发送系统消息的无线帧的起始编号为4096的倍数,7指示可能发送系统消息的无线帧的起始编号为8192的倍数。</p>
</li>
<li><p>——— 2比特:指示通信域第一组系统消息 DomainSysInfo-Group0在一个发送周期内可能使用的连续的 TTI长度的个数,该字段指示的连续的 TTI中的公共 GCI资源中发送 DomainSysInfo-Group0的调度信息,0指示从起始超帧编号开始最多在8个连续的 TTI长度内发送系统消息,1指示从起始超帧编号开始最多在16个连续的 TTI长度内发送系统消息,2指示从起始超帧编号开始最多在32个连续的 TTI长度内发送系统消息,3指示从起始超帧编号开始最多在64个连续的 TTI长度内发送系统消息。</p>
</li>
<li><p>——— 3比特:G 链路物理层控制信息 块 G-PCIB 符号 个 数信息 NSymb-G-PCIB,0:NSymb-G-$\mathrm{PCIB}=1$,1:$\mathrm{NS}y\mathrm{mb}-G-\mathrm{PCIB}=2$,2:$\mathrm{NS}y\mathrm{mb}-G-\mathrm{PCIB}=3$,3:$\mathrm{NS}y\mathrm{mb}-G-\mathrm{PCIB}=4$,4:NSymb-G-$\mathrm{PCIB}=6$,5:$\mathrm{NS}y\mathrm{mb}-G-\mathrm{PCIB}=8$,6:$\mathrm{NS}y\mathrm{mb}-G-\mathrm{PCIB}=10$,7:$\mathrm{NS}y\mathrm{mb}-G-\mathrm{PCIB}=12$。在包含同步信息块SAB的 TTI中,G-PCIB为从$\#8$符号开始的连续 NSymb-G-PCIB个符号;在其他TTI中,G-PCIB为从$\#1$符号开始的连续 NSymb-G-PCIB个符号。</p>
</li>
<li><p>——— 1比特:广播信息或系统消息变更指示信息,0指示广播信息和系统消息在下一个变更周期的内容与当前变更周期的内容相同,1指示广播信息或系统消息在下一个变更周期的内容与当前变更周期的内容不同,新的配置参数在该下一个变更周期的起始时刻生效。本字段在一个变更周期内保持不变,本字段取值不受上一个变更周期传输的广播信息中本字段取值的限制。</p>
</li></ul>

:::

:::{div}
:class: standard-paragraph

<p>当本字段取值为“1”,且广播信息中的参数在下一个变更周期变更时:$\cdot G$节点应在该下一个变更周期的第一个SAB周期中发送广播信息;</p>

:::

:::{div}
:class: standard-paragraph

<p>$\cdot G$节点应保证不存在跨越本变更周期和该下一个变更周期的同步信息块周期。</p>

:::

:::{div}
:class: standard-list-block

<ul class="standard-list">
<li><p>——— 2比特:广播信息或系统消息的变更周期,0指示512无线帧,1指示1024无线帧,2指示2048无线帧,3指示4096无线帧。</p>
</li></ul>

:::

:::{div}
:class: standard-list-block

<ul class="standard-list">
<li><p>——— 5比特:目标接收功率谱密度。本 G节点希望接收 T节点信号的功率谱密度$=$目标接收功率谱密度基准值-目标接收功率谱密度步长$\times$对应数值。8.4.1.3无特殊说明的工作频段,目标接收功率谱密度基准值默认等于-15dBm/基础载波,目标接收功率谱密度步长默认等于3dB。</p>
</li>
<li><p>——— 6比特:预留比特,当前版本全部为0。</p>
</li>
<li><p>——— 24比特:根据6.5.1的处理方法,使用循环冗余校验生成多项式$g_{\mathrm{CRC}24\mathrm{B}}(D)$计算循环冗余校验序列。</p>
</li></ul>

:::

(gbt-48336-201-2026-clause-6-2-4-3-2)=
## 6.2.4.3.2 信道编码和调制

:::{div}
:class: standard-paragraph

<p>广播信息使用6.2.6规定的信道编码参数,以$C=1$进行6.2.6.1.2、6.2.6.1.3和6.2.6.1.4的极化编码,产生比特序列$g_{k}$,其中$k=0,\ldots ,G-1$,并根据6.5.6的方法使用 QPSK 调制将比特序列$g_{k}$ 映射为调制符号序列$d_{i}$。</p>

:::

(gbt-48336-201-2026-clause-6-2-4-3-3)=
## 6.2.4.3.3 资源映射

:::{div}
:class: standard-paragraph

<p>在连续传输模式下,G节点从$\#0$无线帧开始,以8ms为周期发送广播信息。</p>

:::

:::{div}
:class: standard-paragraph

<p>在非连续传输模式下,G节点在每一个 COT 的第一个 TTI中,包含同步信息块SAB的基础载波上发送广播信息;G 节点在其他包含同步信息块 SAB 的 TTI中,包含同步信息块 SAB 的基础载波上,都可发送广播信息。</p>

:::

:::{div}
:class: standard-paragraph

<p>G节点仅在包含同步信息块SAB和广播信息的同步信息块传输周期中,包含同步信息块SAB和广播信息的基础载波上发送用于调度通信域系统消息的 GCI。</p>

:::

:::{div}
:class: standard-paragraph

<p>当 TTI中传输广播信息时,广播信息编码调制后的符号序列$d_{i}$ 在该 TTI第一个无线帧的$\#5$符号和$\#7$符号共两个符号中按照符号的时间顺序,在每个符号中按照先低频率子载波再高频率子载波的顺序进行映射。</p>

:::
