# 7.5.3.35 T节点特定控制信息资源池信息

:::{div}
:class: figure-code

```asn1
-- ASN1START
ControlResource ::= SEQUENCE {
    controlTimeResource DedicatedTimeResource,
    ttiPeriod   TTiPeriod,
    ttiOffset   TTiOffset,
    dedicatedACK-ResourceSetConf    DedicatedACK-ResourceSetConf,
    modSymDupInfo   SEQUENCE (SIZE (1..8)) OF INTEGER (1..1024) OPTIONAL,
    ...
}
-- ASN1STOP
```

:::

:::{div}
:class: standard-paragraph

<p>当 GCI指示“T节点特定控制信息资源池信息”时,该信息所在 TTI按如下方式计算。</p>

:::

:::{div}
:class: standard-paragraph

<p>当前 TTI满足 mod(当前 TTI顺序号$,\mathrm{TTiPeriod})=\mathrm{TTiOffset}$时,或当 TTiPeriod等于0且当前TTI满足当前 TTI顺序号$=\mathrm{TTiOffset}$时,T节点特定控制信息资源池信息指示在该 TTI内的1组用来盲检测控制信息的资源,以及与该控制信息资源池配对的 ACK 资源池。</p>

:::

:::{div}
:class: standard-paragraph

<p>当 T节点没有被配置特定控制信息资源池时,T节点使用通信域公共控制信息资源池检测控制信息,并根据通信域公共控制信息的资源确定 ACK 资源池集合中的一个 ACK 资源池反馈 ACK 信息。</p>

:::

:::{div}
:class: standard-paragraph

<p>在 XRC重配置消息xrcReconfiguration时,modSymDupInfo可用于指示调制符号重复信息,可配置最多8组调制符号重复次数指示,并由6.2.4.6.1中描述的3比特“调制符号重复指示”进行引用。</p>

:::
