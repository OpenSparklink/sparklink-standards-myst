# 6.5 物理层通用功能

(gbt-48336-201-2026-clause-6-5-1)=
## 6.5.1 循环冗余校验

:::{div}
:class: standard-paragraph

<p>进行循环冗余校验运算的输入信息比特序列记为$a_{0}$,$a_{1}$,$a_{2}$,$a_{3},\ldots ,a_{A-1}$,生成的校验比特序列记为$p_{0}$,$p_{1}$,$p_{2}$,$p_{3},\ldots ,p_{L-1}$,其中$A$ 是输入比特的数量$,L$ 是校验比特的数量。校验比特通过如下循环冗余校验生成多项式进行计算:</p>

:::

:::{div}
:class: standard-paragraph

<p>$g_{\mathrm{CRC}24\mathrm{A}}(D)=[D^{24}+D^{23}+D^{18}+D^{17}+D^{14}+D^{11}+D^{10}+D^{7}+D^{6}+D^{5}+D^{4}+D^{3}+D+1]$循环冗余校验长度$L=24$;</p>

:::

:::{div}
:class: standard-paragraph

<p>$g_{\mathrm{CRC}24\mathrm{B}}(D)=[D^{24}+D^{23}+D^{21}+D^{20}+D^{17}+D^{15}+D^{13}+D^{12}+D^{8}+D^{4}+D^{2}+D+1],$循环冗余校验长度$L=24$;</p>

:::

:::{div}
:class: standard-paragraph

<p>$g_{\mathrm{CRC}16}(D)=[D^{16}+D^{12}+D^{5}+1],$循环冗余校验长度$L=16$;</p>

:::

:::{div}
:class: standard-paragraph

<p>$g_{\mathrm{CRC}8}(D)=[D^{8}+D^{6}+D^{5}+D^{3}+1],$循环冗余校验长度$L=8$;</p>

:::

:::{div}
:class: standard-paragraph

<p>$g_{\mathrm{CRC}6}(D)=[D^{6}+D^{5}+1],$循环冗余校验长度$L=6$。</p>

:::

:::{div}
:class: standard-paragraph

<p>循环冗余校验采用系统码的方式,也即在 GF(2)域中,多项式:$a_{0}D^{A+L-1}+a_{1}D^{A+L-2}+\ldots +a_{A-1}D^{L}+p_{0}D^{L-1}+p_{1}D^{L-2}+\ldots +p_{L-2}D^{1}+p_{L-1}$可被相应的循环冗余校验生成多项式整除。</p>

:::

:::{div}
:class: standard-paragraph

<p>当使用循环冗余校验生成多项式$g_{\mathrm{CRC}24\mathrm{A}}(D)\text{、}g_{\mathrm{CRC}24\mathrm{B}}(D)\text{、}g_{\mathrm{CRC}8}(D)$和$g_{\mathrm{CRC}6}(D)$时,经过循环冗余校验后的输出比特序列表示为$b_{0}$,$b_{1}$,$b_{2}$,$b_{3},\ldots ,b_{B-1}$,其中$B=A+L$。输入信息比特、校验比特、输出比特的关系为:</p>

:::

:::{div}
:class: standard-paragraph

<p>$b_{k}=a_{k}$,其中$k=0$,1,$2,\ldots ,A-1$;</p>

:::

:::{div}
:class: standard-paragraph

<p>$b_{k}=p_{k-A}$,其中$k=A$,$A+1$,$A+2,\ldots ,A+L-1$。</p>

:::

:::{div}
:class: standard-paragraph

<p>当需要对循环冗余校验输出比特序列增加掩码时,经过循环冗余校验后的输出比特序列表示为$b_{0}$,$b_{1}$,$b_{2}$,$b_{3},\ldots \ldots b_{B-1}$,其中$B=A+L$。输入信息比特、校验比特、输出比特的关系为:</p>

:::

:::{div}
:class: standard-paragraph

<p>$b_{k}=a_{k}$,其中$k=0$,1,$2,\ldots ,A-1$;</p>

:::

:::{div}
:class: standard-paragraph

<p>$b_{k}=(p_{k-A}+x_{\mathrm{MASK},k-A})\mathrm{mod}2$,其中$k=A$,$A+1$,$A+2,\ldots ,A+L-1$;</p>

:::

:::{div}
:class: standard-paragraph

<p>其中$L=24$,$x_{\mathrm{MASK},0}$,$x_{\mathrm{MASK},1}$,$x_{\mathrm{MASK},2},\ldots ,x_{\mathrm{MASK},23}$是掩码序列。</p>

:::

<p>通信域使用 CP-OFDM 符号为类型一 A 或类型一B的场景$l=0$,1,…,13,通信域使用CP-OFDM符号为类型二的场景$l=0$,1,…,12,通信域使用 CP-OFDM 符号为类型三的场景$l=0$,1,…,11,通信域使用 CP-OFDM 符号为类型四的场景$l=0$,1,…,9;$N_{\mathrm{ID}}$为高层phyIDforRSsequence配置的对应物理层信号的24比特标识的低8位,对应物理层信号未配置该参数或配置中不包含该参数时,默认为24比特 G节点物理层标识的低8位$;N_{\mathrm{CP}}=0$,1,2,3,表示通信域使用的循环前缀类型,通信域使用CP-OFDM符号为类型一 A 或类型一 B的场景$N_{\mathrm{CP}}=3$,通信域使用 CP-OFDM 符号为类型二的场景$N_{\mathrm{CP}}=2$,通信域使用 CP-OFDM 符号为类型三的场景$N_{\mathrm{CP}}=1$,通信域使用 CP-OFDM 符号为类型四的场景$N_{\mathrm{CP}}=0$;$N_{\mathrm{PID}}$为高层phyIDforRSsequence配置的对应物理层信号的24比特标识,对应物理层信号未配置该参数或配置中不包含该参数时,默认为24比特 G节点物理层标识。</p>

(gbt-48336-201-2026-clause-6-5-4)=
## 6.5.4 功率控制

:::{div}
:class: standard-paragraph

<p>T节点在使用 T 符号发送信道探测信号、解调参考信号、相位调整信号、接入信息、ACK 反馈信息、第一类数据信息、第二类数据信息时,T 节点在该 T 符号相应子载波上发送的初始总功率通过公式(30)确定:</p>

:::

(gbt-48336-201-2026-equation-30)=
```{math}
P=10\lg(M)+P_o+PL\tag{30}
```

:::{div}
:class: standard-paragraph

<p>式中:</p>

:::

:::{div}
:class: standard-definitions

$M$
: 发送信号或者信息使用的子载波的个数;

:::

:::{div}
:class: standard-definitions

$P_{\mathrm{o}}$
: 发送信号或者信息对应的目标接收功率;

:::

:::{div}
:class: standard-definitions

$PL$
: T节点测量的 G节点到 T节点的路径损耗$,PL=g\mathrm{LinkReferenceSi}g\mathrm{nalPower}-\mathrm{RSRP}$。

:::

:::{div}
:class: standard-paragraph

<p>对于信道探测信号$,P_{\mathrm{o}}$通过系统消息或 XRC重配置消息中的srs-P0-NominalConfig配置。</p>

:::

:::{div}
:class: standard-paragraph

<p>对于接入信息、接入信息解调参考信号、接入信息相位调整信号$,P_{\mathrm{o}}$通过系统消息或 XRC重配置消息中的rach-P0-NominalConfig配置。</p>

:::

:::{div}
:class: standard-paragraph

<p>对于 ACK 反馈信息以及 ACK 反馈信息解调参考信号$,P_{\mathrm{o}}$通过系统消息或 XRC重配置消息中的ack-P0-NominalConfig配置。</p>

:::

:::{div}
:class: standard-paragraph

<p>对于第一类数据信息、第一类数据信息解调参考信号、第一类数据信息相位调整信号$,P_{\mathrm{o}}$通过系统消息或 XRC重配置消息中的data-Class1-P0-NominalConfig配置。</p>

:::

:::{div}
:class: standard-paragraph

<p>对于第二类数据信息、第二类数据信息解调参考信号、第二类数据信息相位调整信号$,P_{o}$通过系统消息或 XRC重配置消息中的data-Class2-P0-NominalConfig配置。</p>

:::

:::{div}
:class: standard-paragraph

<p>当 T节点在 T符号上发送 N 个信号或者信息时,T 节点在该 T 符号发送的总功率通过公式(31)确定。</p>

:::

(gbt-48336-201-2026-equation-31)=
```{math}
\hat P=\min\left\{\hat P_{\mathrm{MAX}},\sum_{i=0}^{N-1}\hat P_i\right\}\tag{31}
```

:::{div}
:class: standard-paragraph

<p>式中:</p>

:::

:::{div}
:class: standard-definitions

$P_{\mathrm{MAX}}$
: T节点对应的功率等级允许的最大发送功率绝对值;

:::

:::{div}
:class: standard-definitions

$P_{i}$
: $N$ 个信号或者信息中某一个信号或者信息的初始总功率绝对值;

:::

:::{div}
:class: standard-paragraph

<p>$N-1$</p>

:::

:::{div}
:class: standard-definitions

$\sum _{i=0}P_{i}$
: $N$ 个信号或者信息的初始总功率绝对值的和。

:::

:::{div}
:class: standard-paragraph

<p>$N-1$当$\sum _{i=0}P_{i}\gt P_{\mathrm{MAX}}$ 时,T 节点在该符号上的发送功率为$P_{\mathrm{MAX}}$,在该符号上发送信号或者信息的所有子载波中每个子载波上发送的功率绝对值为$P_{k}=P_{\mathrm{MAX}}/K$,其中$K$ 是 T节点在该符号上发送信号或者信息使用的子载波的个数。</p>

:::

(gbt-48336-201-2026-clause-6-5-5)=
## 6.5.5 测量量

(gbt-48336-201-2026-clause-6-5-5-1)=
### 6.5.5.1 同步参考信号接收功率(RSRP)

:::{div}
:class: standard-paragraph

<p>同步参考信号接收功率是指 T 节点在第一训练信号所在的符号上第一训练信号的接收功率(单位:W)对每个有效子载波的线性平均值,假如 T 节点具有多个接收天线,则上报的 RSRP值不低于任何一个接收天线的值。</p>

:::

(gbt-48336-201-2026-clause-6-5-5-2)=
### 6.5.5.2 接收信号能量指示(RSSI)

:::{div}
:class: standard-paragraph

<p>接收信号能量指示是指 T节点在一个 CP-OFDM 符号时间长度内接收到的 OFDM 符号时间长度的总接收功率(单位:W)对每个有效子载波的线性平均值,其中总接收功率包括有用信号的接收功率、同信道干扰接收功率、临信道干扰接收功率、热噪声接收功率等所有的接收功率。假如 UE侧具有多个接收天线,则上报的 RSSI值不低于任何一个接收天线的值。</p>

:::

(gbt-48336-201-2026-clause-6-5-5-3)=
### 6.5.5.3 同步参考信号接收质量(RSRQ)

:::{div}
:class: standard-paragraph

<p>同步信号参考信号接收质量是指 RSRP和 RSSI的比值,即 RSRP/RSSI,其中 RSRP和 RSSI的测量符号相同。假如 T节点具有多个接收天线,则上报的 RSRQ 值不低于任何一个接收天线的值。</p>

:::

(gbt-48336-201-2026-clause-6-5-5-4)=
### 6.5.5.4 同步信号信干扰比(SINR)

:::{div}
:class: standard-paragraph

<p>同步信号信 干扰比 SINR 是指 RSRP 与 (RSSI-RSRP)的 比 值,即 RSRP/(RSSI-RSRP),其 中RSRP和 RSSI的测量符号相同。假如 UE侧具有多个接收天线,则上报的SINR值不低于任何一个接收天线的值。</p>

:::

(gbt-48336-201-2026-clause-6-5-5-5)=
### 6.5.5.5 信道忙占比(CBRA)

:::{div}
:class: standard-paragraph

<p>信道忙占比 CBRA 是指在测量时间内,信号接收功率超过门限的总时间与测量时间的比值,其中信号接收功率超过门限包含两种情况,当测量节点检测到超帧不连续传输的前导信息时,当超帧不连续传输的前导信息中的第一组同步序列部分中符号接收功率的线性平均值超过-87dBm 时,信道为忙,同时需要解析出超帧不连续传输的数据帧的长度,超帧不连续传输的前导信息以及数据帧的长度内,都认为系统为忙;当测量节点未检测到超帧不连续传输的前导信息时,当在一个 CP-OFDM 符号时间长度内接收到的 OFDM 符号时间长度的总接收功率(单位:W)的线性平均值超过-62dBm 时,该CP-OFDM 符号时间长度内信道为忙。</p>

:::

(gbt-48336-201-2026-clause-6-5-5-6)=
### 6.5.5.6 位置测量信号信道状态信息

:::{div}
:class: standard-paragraph

<p>对于一 个 载波中 除 DC 子载波 之外 的一 个 有 效 子载波$k$,发 送 的测距符号 矢 量 为$\mathbf{x}_{k}=$$[x_{1},x_{2},\ldots ,x_{N_{\mathrm{TX}}}]^{\mathrm{T}}$,接收矢量为$\mathbf{y}_{k}=[y_{1},y_{2},\ldots ,y_{N_{\mathrm{RX}}}]^{\mathrm{T}}$,可用公式(32)表示。</p>

:::

(gbt-48336-201-2026-equation-32)=
```{math}
\boldsymbol y_k=\boldsymbol H_k\boldsymbol x_k+\boldsymbol n\tag{32}
```

:::{div}
:class: standard-paragraph

<p>式中:</p>

:::

:::{div}
:class: standard-definitions

$\mathbf{H}_{k}$
: $N_{\mathrm{RX}}\times N_{\mathrm{TX}}$维度的信道矩阵,其阵元称为信道系数;

:::

:::{div}
:class: standard-definitions

$\mathbf{n}$
: 白高斯噪声。

:::

:::{div}
:class: standard-paragraph

<p>位置测量信号信道状态信息是指测距中根据测距符号到达接收天线连接器时获取的信道系数的估计值。对于SISO,$\mathbf{H}_{k}$仅含有一个信道系数,该信道系数为对应子载波$k$ 的一个复数值(IQ 值)。</p>

:::

:::{div}
:class: standard-paragraph

<p>位置测量信号信道状态信息有2种测量方式。</p>

:::

:::{div}
:class: standard-list-block

<ul class="standard-list">
<li><p>——— 测量模式1:所有位置测量符号取算术平均方式:接收的全部测距帧内,所有测距符号的CSI估计值取平均作为结果。</p>
</li>
<li><p>——— 测量模式2:特定测距符号方式:在所有跳频信道上,G 节点或 T 节点按第$n$ 个测距符号的CSI进行反馈。</p>
</li></ul>

:::

:::{div}
:class: standard-paragraph

<p>CSI每个IQ 值的表达形式如公式(33)所示。</p>

:::

(gbt-48336-201-2026-equation-33)=
```{math}
\mathrm{IQ}[\mathrm{dBm}]=20\lg\left(\operatorname{abs}\left(\frac{\mathrm{IQ}[\mathrm{linear}]}{1024}\right)\right)+\mathrm{RPL}[\mathrm{dBm}]\tag{33}
```

:::{div}
:class: standard-paragraph

<p>式中:</p>

:::

:::{div}
:class: standard-definitions

IQ\[linear\]
: CSI反馈值,是一个相对线性值(无单位),为12比特有符号整型数;

:::

:::{div}
:class: standard-definitions

RPL\[dBm\]
: IQ[linear]所采用的相对参考值,为 12 比特有 符号 整 型数,单位 为 分 贝 毫瓦(dBm);

:::

:::{div}
:class: standard-definitions

IQ\[dBm\]
: 采样点的实际测量功率值,按照公式(33)由IQ[linear]和 RPL[dBm]进行联合编码后计算得到,单位为分贝毫瓦(dBm)。

:::

### 6.5.5.8 位置测量信号到达角度信息

:::{div}
:class: standard-paragraph

<p>位置测量信号到达角度(AoA)为位置测量信号到达方向在参考坐标系中的水平角和垂直角,其中参考坐标系的$Z$ 轴为所在地椭球面法线方向$,X$ 轴正方向为所在地正南方向$,Y$ 轴正方向为所在地正东方向。在参考坐标系统中,估计的水平角相对于$X$ 轴进行测量,且以逆时针方向为正;估计的垂直角相对于$Z$ 轴进行测量,且以$X-Y$ 平面方向为正。AoA 由设备根据位置测量信号在天线处确定。AoA水平角的取值范围为[0,360),AoA 垂直角的取值范围为[0,180]。</p>

## 6.5.8 SC-FDMA波形生成

:::{div}
:class: standard-paragraph

<p>复数符号$x(0),\ldots ,x(M_{\mathrm{symb}}-1)$被分成$M_{\mathrm{symb}}/M^{\mathrm{Total}}_{\mathrm{sc}}$ 集合,每个集合对应一个SC-FDMA 符号。变换预编码过程如公式(42)所示。</p>

:::

(gbt-48336-201-2026-equation-42)=
```{math}
\begin{gathered}
y(l\times M_{\mathrm{SC}}^{\mathrm{Total}}+k)=\frac1{\sqrt{M_{\mathrm{SC}}^{\mathrm{Total}}}}\sum_{i=0}^{M_{\mathrm{SC}}^{\mathrm{Total}}-1}x(l\times M_{\mathrm{SC}}^{\mathrm{Total}}+i)e^{-j\frac{2\pi ik}{M_{\mathrm{SC}}^{\mathrm{Total}}}}\\
k=0,\cdots,M_{\mathrm{SC}}^{\mathrm{Total}}-1\\
l=0,\cdots,\frac{M_{\mathrm{symb}}}{M_{\mathrm{SC}}^{\mathrm{Total}}}-1
\end{gathered}\tag{42}
```

:::{div}
:class: standard-paragraph

<p>经过上述过程得到复值符号$y(0),\ldots ,y(M_{\mathrm{symb}}-1)\text{。}M^{\mathrm{Total}}_{\mathrm{sc}}=M_{\mathrm{SCG},1}N_{\mathrm{SCG},1}$其中$M_{\mathrm{SCG},1}$表示占用的第一颗粒度子载波组的个数,且满足$M_{\mathrm{SCG},1}=2^{\alpha _{2}}\cdot 3^{\alpha _{3}}\cdot 5^{\alpha _{5}}$。其中$,\alpha _{2}$,$\alpha _{3}$,$\alpha _{5}$为非负整数值。</p>

:::

(gbt-48336-201-2026-clause-6-5-9)=
## 6.5.9 Zadoff-Chu序列

:::{div}
:class: standard-paragraph

<p>Zadoff-Chu 序列 $r_{u,v}^{(\alpha,\delta)}(n)$ 是在基序列 $\overline r_{u,v}(n)$ 基础上，增加循环移位 $\alpha$ 确定的：</p>

:::

```{math}
r_{u,v}^{(\alpha,\delta)}(n)=e^{j\alpha n}\overline r_{u,v}(n),\quad0\leq n<M_{\mathrm{SC}}^{\mathrm{RS}}
```

:::{div}
:class: standard-paragraph

<p>其中$,M^{\mathrm{RS}}_{\mathrm{SC}}=mN_{\mathrm{SCG},1}$是参考信号的长度$,1\leq m\leq (N^{\mathrm{Total}}_{\mathrm{sc}}/N_{\mathrm{SCG},3}),N_{\mathrm{SCG},1}$是第一颗粒度子载波组中包含的子载波个数。</p>

:::

:::{div}
:class: standard-paragraph

<p>不同的参考信号是根据不同的循环移位值$\alpha$ 确定的。</p>

:::

:::{div}
:class: standard-paragraph

<p>基序列 $\overline r_{u,v}(n)$ 分成不同的组，组编号 $u\in\{0,1\cdots,29\}$。每个组内的基序列编号由 $v$ 表示。每组中包含 1 个序列长度为 $M_{\mathrm{SC}}^{\mathrm{RS}}=mN_{\mathrm{SCG},1}$，$1\leq m\leq5$ 的基序列 $(v=0)$ 和 2 个序列长度为 $M_{\mathrm{SC}}^{\mathrm{RS}}=mN_{\mathrm{SCG},1}$，$6\leq m\leq(N_{\mathrm{sc}}^{\mathrm{Total}}/N_{\mathrm{SCG},1})$ 的基序列 $(v=0,1)$。</p>

:::

:::

(gbt-48336-201-2026-equation-43)=
```{math}
u=(f_{\mathrm{gh}}(n_S)+f_{\mathrm{SS}})\bmod30\tag{43}
```

:::{div}
:class: standard-paragraph

<p>式中：$f_{\mathrm{gh}}(n_S)=\left(\sum_{i=0}^{7}c(8n_s+i)\cdot2^i\right)\bmod30$，$f_{\mathrm{SS}}=[ n_{\mathrm{ID}}^X/16]\bmod30$。</p>

:::

:class: standard-paragraph

<p>伪随机序列 $c(i)$ 由 6.5.2 确定，序列生成器 $c_{\mathrm{init}}=\left[\frac{n_{\mathrm{ID}}^X}{30}\right]$。</p>
