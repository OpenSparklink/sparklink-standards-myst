# 7.5.2.7 T节点辅助信息上报消息

:::{div}
:class: figure-code

```asn1
-- ASN1START
TNode-AssistantInformationReport ::= SEQUENCE {
    xrc-Identifier XRC-Identifier,
    tNode-AssistantInformationReportList SEQUENCE (SIZE(1..16)) OF
        TNode-AssistantInformationReport-IEs,
    lateNonCriticalExtension    OCTET STRING    OPTIONAL,
    nonCriticalExtension    SEQUENCE {} OPTIONAL
}
TNode-AssistantInformationReport-IEs ::= SEQUENCE {
    sps-TrafficpatternInformation   SPSTrafficPatternInfo   OPTIONAL,
    seviceCharcteristic SEQUENCE{
    samplinglength  SamplingLength,
    samplingrate    SamplingRate
    }   OPTIONAL,
    application-Info    AID OPTIONAL,
    qos-Info    XQI OPTIONAL,
    vendor-specific BIT128  OPTIONAL,
    servicePeriod   INTEGER (1..1023)   OPTIONAL,
    addressTypeRequest  AddressTypeInfo OPTIONAL,
    ...
```

:::

```asn1
-- ASN1STOP
```

:::{div}
:class: standard-paragraph

<p>TNode-AssistantInformationReport由 T节点发送给 G节点,用于进行辅助信息上报。对于 T 节点存在的多路业务,T 节点可上 报对 应的业务 对 应的应用层信息 application-Info 和 QoS 信息QoS-Info。</p>

:::

:::{div}
:class: standard-paragraph

<p>对于半静态业务,可上报SPS业务特征信息sps-TrafficpatternInformation。对于第一类业务,可上报第一类业务采样率samplingrate和量化位宽samplinglength。对于有明确周期的第二类业务,ser-vicePeriod指示业务周期,单位为毫秒,对于无周期的第二类业务,无需该配置。</p>

:::

:::{div}
:class: standard-paragraph

<p>addressTypeRequest指示 T节点申请指定地址类型的数据传输功能。其中,addressTypeBitmap某比特位置1时,指示 T节点申请对应地址类型的数据报文传输功能。当 T 节点申请 MAC地址数据传输功能时,可通过 macAddress上报 T节点已分配的 MAC地址。</p>

:::
