# 7.5.2.35 测量组参数配置消息

:::{div}
:class: figure-code

```asn1
-- ASN1START
MeasurementGroupConfiguration ::= SEQUENCE {
    xrc-Identifier  XRC-Identifier,
    measureGroupResourceConfigItemList SEQUENCE (SIZE(1..256)) OF
PositioningGroupResourceConfigItem,
    nodePositioningCoordinates  NodePositioningCoordinates  OPTIONAL,   -- Need OR
    lateNonCriticalExtension    OCTET STRING    OPTIONAL,
    nonCriticalExtension    SEQUENCE {} OPTIONAL
}
PositioningGroupResourceConfigItem ::= SEQUENCE {
    groupcastPhyID  UINT24,
    measGroupID UINT8,
    measureMode ENUMERATED {dl-flag, sul-flag, aul-flag, m2m-flag},
    measureSignalMode   ENUMERATED {m1, m2, m3, spare1},
    signalGenMethod ENUMERATED {csi, srs, pms, spare1},
    anchorSymbolNumber  INTEGER (2..255),
    firstSymbolIndexfirstAnchor UINT10,
    idleSymbolAnchor    INTEGER (0..16),
    tagSymbolNumber INTEGER (2..255),
    idleSymbolTag   INTEGER (0..16),
    idleSymbolInAchorTag    INTEGER (0..16),
    measReportDirection ENUMERATED {d1, d2, d3, d4, d5, d6, spare2, spare1},
    positionningResourceIndex   UINT8,
    posChannelIndication    ChannelNumber,
    posResourcePeriod   UINT16,
    posResourceOnduration   INTEGER (1..65535),
    posResourceOffset   UINT16,
    measReportResourceOffset    UINT9,
    measReportResourceDuration  UINT8,
    measReportMCS   INTEGER (1..31),
    posCpConfig CPConfig    OPTIONAL,
    signalSecurityMode  ENUMERATED {mode1, mode2}   OPTIONAL,
    signalGenPMSParam   INTEGER (3..20) OPTIONAL,
    dlFlagEnable    BoolType    OPTIONAL,
    calculationNodePhyID    UINT24  OPTIONAL,
    dlFlagPeriodInSulFlag   UINT16  OPTIONAL,
    ...
}
-- ASN1STOP
```

:::

:::{div}
:class: standard-paragraph

<p>groupcastPhyID指示测量组所有成员节点对应的组播地址 PhyId;measGroupID 为测量组的标识,用于区分不同位置锚点/位置标签构成的测量组;measureMode指示测量模式为 DL-FLAG,SUL-FLAG,AUL-FLAG或者 M2M-FLAG。measureSignalMode取值1时指示双向两信号,取值2时指示或双向三信号测量模式,取值3时指示循环双向三信号测量模式;signalGenMethod指示测量信号基于PMS或CSI-RS/SRS测量信号生成,pms1和pms2分别指示PMS模式一和模式二;firstSymbolIndex-firstAnchor指示第一个发送测量信号的节点(锚点/标签)发送的第一测量信号的第一个测量符号的位置,从 TTI的开端开始计数;anchorSymbolNumber指示每个锚点采用连续 CP-OFDM 测量符号作为测量信号的数量,取值至少为2;idleSymbolAnchor指示每个锚点测量信号中最后一个测量符号后面空闲的符号个数,即时间相邻的两个测量信号之间的间隔符号个数;tagSymbolNumber指示每个标签采用连续 CP-OFDM 测量符号作为测量信号的数量,取值至少为2;idleSymbolTag指示每个标签测量信号中最后一个测量符号后面空闲的符号个数,即时间相邻的两个测量信号之间的间隔符号个数;meas-ReportDirection指示测量时间差的传输方向,取值1时指示所有锚点和标签将测量时间差报告消息依次发送至 G 节点,取值2时指示所有锚点将测量时间差报告消息依次发送至标签,取值3时指示先发锚点将测量时间差报告消息组播发送给多个后发锚点和标签,取值4时指示由后发锚点依次向先发锚点发送测量时间差报告消息,取值5时指示所有锚点都依次组播发送测量时间差报告消息,取值6时指示所有锚点都依次向位置解算节点发送测量时间差报告消息。groupcastPhyID 指示 G 节点位置测量信号控制信息的 CRC掩码;measReportMCS指示测量时间差报告消息的传输所采用的 MCS的索引;</p>

:::

:::{div}
:class: standard-paragraph

<p>positionningResourceIndex指示测量信号的配置索引;posChannelIndication指示测量信号的信道号;</p>

:::

:::{div}
:class: standard-paragraph

<p>posResourcePeriod、posResourceOnduration、posResourceOffset分别指示测量组完成一轮双向测量(双向两信号/双向三信号/循环双向三信号)所需的周期(以 TTI为单位)、每个测量周期内含有有效测量信号的一个测量块的持续时长(以无线帧为单位)、每个测量块起始测量资源在第一个测量 TTI内的时间偏移量(以符号为单位);measReportResourceOffset指示测量组最后一个测量成员发送完毕测量信号的时刻,到测量组第一个锚点或第一个标签发送测量时间差报告消息所需的资源开端之间的时间间隔,以 TTI为单位;measReportResourceDuration指示测量组的所有锚点/所有标签通过直传链路发送测量时间差报告消息所需的资源时长,以 TTI为单位;posCpConfig指示测量符号所采用的 CP长度。从测量完成的 TTI的下一个 TTI开始(计数为1),经过 measReportResourceOffset个 TTI之后,连续 measReportResourceDuration个 TTI资源,用于多个锚点按照测量组建立消息中指示的顺序,依次发送 测量时间 差报告消 息;dlFlagEnable指示 在 SUL-FLAG 测量 模式 下,是 否 使能 DL-FLAG用于锚点间的同步。calculationNodePhyID指示位置解算节点的 PhyID;dlFlagPeriodInSulFlag指示SUL-FLAG中包含的 DL-FLAG周期,单位为 TTI。signalSecurityMode指示采用的安全信号模式一或模式二;signalGenPMSParam 指示PMS测量符号所采用的生成序列的$u$ 值。</p>

:::
