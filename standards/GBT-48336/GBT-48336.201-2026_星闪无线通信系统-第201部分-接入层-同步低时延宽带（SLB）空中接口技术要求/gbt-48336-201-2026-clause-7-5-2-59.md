# 7.5.2.59 超宽带脉冲感知能力响应消息

:::{div}
:class: figure-code

```asn1
-- ASN1START
SLPSensingCapabilityResponse ::= SEQUENCE {
    xrc-Identifier  XRC-Identifier,
    sLPSensingCapabilityResponseVar SLPSensingCapabilityResponse-IEs,
    lateNonCriticalExtension    OCTET STRING    OPTIONAL,
    nonCriticalExtension    SEQUENCE {} OPTIONAL
}
-- ASN1STOP
```

:::

:::{div}
:class: figure-code

```asn1
-- ASN1START
SLPSensingCapabilityResponse-IEs ::= SEQUENCE {
    sensingSessionSupport UINT8,
    measSignalCapability    BIT64,
    SenSingReportCapability BIT32,
    txMultipleAntenna   UINT8,
    txMultipleAntenna-Gap   UINT8,
    rxMultipleAntenna   UINT8,
    rxMultipleAntenna-Gap   UINT8,
    txMultipleAntenna-SwitchingOrder    BIT4,
    rxMultipleAntenna-SwitchingOrder    BIT4,
    sLPMeasEvent-Gap    UINT24,
    sLPMeasInnerEvent-Gap   UINT24,
    sLPMeasEventGroup-Gap   UINT24,
    sLPChannelCapability    BIT128,
    locationCapability  BoolType,
    ...
}
-- ASN1STOP
```

:::

:::{div}
:class: standard-paragraph

<p>SLPSensingCapabilityResponse由 T节点发送给 G节点,用于进行 T节点超宽带脉冲感知能力响应。其中sensingSessionSupport用于指示支持的感知连接数量;measSignalCapability使用位图的方式指示测量信号的能力,当比特位为0时,不支持对应的能力,当比特位为1时,支持对应的能力,其中比特$0\sim$比特28预留,比特29:安全测量序列;比特30:长度31的测量码字,占空比16;比特31:长度63的测量码字,占空比8;比特32:长度91的测量码字,占空比4;比特33:长度91的测量码字,占空比8;比特34:长度127的测量码字,占空比4;比特35:长度133的测量码字,占空比4;比特36:长度133的测量码字,占空比8;比特37:非等长测量码字集合;比特38:测量子片段符号的可选数量;比特39:测量子片段的可选数量;比特40:测量符号循环前缀的可选长度;比特41:测量符号补零的可选长度;比特42:测量码字循环移位;比特43:-10dB带宽大于或等于500MHz;比特44:-10dB带宽大于1GHz;</p>

:::

:::{div}
:class: standard-paragraph

<p>比特45:感知符号可选数量;其他比特预留。sensingReportCapability使用位图的方式指示测量上报的能力,当比特位为0时,不支持对应的能力,当比特位为1时,支持对应的能力,其中比特0:AoA 测量;</p>

:::

:::{div}
:class: standard-paragraph

<p>比特1:AoD测量;比特2:信道状态信息测量上报(载波IQ 信息上报);比特3:信道状态信息测量上报(CIR上报)-以第一径为初始参考;比特4:信道状态信息测量上报 (CIR 上报)-以最强径为初始参考;</p>

:::

:::{div}
:class: standard-paragraph

<p>比特5:信道状态信息测量上报 (CIR上报)-以信号发送时间为初始参考;比特6:预留;比特7:接收天线相位差信息上报;比特8:发送天线相位差信息上报;比特9:距离多普勒信息上报-以第一径为初始参考;比特10:距离多普勒信息上报-以最强径为初始参考;比特11:距离多普勒信息上报-以信号发送时间为初始参考;比特12:目标信息上报;比特13:重叠方式信道拼接;比特14:连续方式信道拼接;比特15:不连续方式信道拼接;其他比特预留。txMultipleAntenna用于指示发送多天线能力;txMulti-pleAntenna-Gap用于指示发送多天线切换间隔,单位为微秒;rxMultipleAntenna用于指示接收多天线能力;rxMultipleAntenna-Gap 用 于 指示接收多 天 线 切换 间隔,单位 为微 秒。txMultipleAntenna-SwitchingOrder使用位图的方式指示发送多天线切换次序的能力,当比特位为0时,不支持对应的能力,当比特位为1时,支持对应的能力,其中比特0:顺序切换;比特1:随机切换;其他比特预留,当发送多天线的数量为1时,该字段所有比特置为0。rxMultipleAntenna-SwitchingOrder使用位图的方式指示接收多天线切换次序的能力,当比特位为0时,不支持对应的能力,当比特位为1时,支持对应的能力,其中比特0:顺序切换;比特1:随机切换;其他比特预留,当接收多天线的数量为1时,该字段所有比特置为0。sLPMeasEvent-Gap用于指示超宽带脉冲感知事件间间隔,单位为纳秒;sLPMeasInnerEvent-Gap用于指示超宽带脉冲感知事件内间隔,单位为纳秒;sLPMeasEventGroup-Gap用于指示超宽带脉冲感知事件组间间隔,单位为纳秒;sLPChannelCapability使用位图的方式指示超宽带脉冲信道能力,128个比特中,最低位比特(第0位比特)对应物理信道号0,次低位比特(第1位比特)对应物理信道号1,按照此顺序,第79位比特对应物理信道号79;第125位比特对应物理信道号125,中心频点为7542.6;第126位比特对应物理信道号 126,中心频点为 8041.8;第 127 位比特对应物理信道号 127,中心频点为8541.0;第80位比特到第124位比特预留。locationCapability用于指示位置信息能力。</p>
