# 7.5.2.60 超宽带脉冲感知配置消息

:::{div}
:class: figure-code

```asn1
-- ASN1START
SLPSensingConfiguration ::= SEQUENCE {
    xrc-Identifier  XRC-Identifier,
    sLPSensingConfiguration SEQUENCE (SIZE(1..256)) OF SLPSensingResourceConfigItem

    lateNonCriticalExtension    OCTET STRING    OPTIONAL,
    nonCriticalExtension    SEQUENCE {} OPTIONAL
```

:::

:::{div}
:class: standard-paragraph

<p>SLPSensingConfiguration由 G 节点发送给 T 节点,用于进行超宽带脉冲感知配置。sLPSensing-ConfigIndex用于指示感知信号配置索引;sensReport使用位图的方式指示感知信息的上报,当比特位为0时,不进行相应感知信息的上报,当比特位为1时,进行相应感知信息的上报,其中比特0:AoA 测量上报;比特1:AoD测量上报;比特2:信道状态信息测量上报(载波IQ 信息上报);比特3:信道状态信息测量上报(CIR上报)-以第一径为初始参考;比特4:信道状态信息测量上报(CIR 上报)-以最强径为初始参考;比特5:信道状态信息测量上报(CIR 上报)-以信号发送时间为初始参考;比特6:预留;比特</p>

:::

:::{div}
:class: standard-definitions

7
: 接收天线相位差信息上报;比特8:发送天线相位差信息上报;比特9:距离多普勒信息上报-以第一径为初始参考;比特10:距离多普勒信息上报-以最强径为初始参考;比特11:距离多普勒信息上报-以信号发送时间为初始参考;比特12:目标信息上报;比特$13\sim$比特15预留;比特16:不进行感知上报;其他比特预留。对于仅发送超宽带脉冲测量信号的节点,需使用比特16指示不进行感知上报。对于自发自收超宽带脉冲测量信号的节点,需配置单向信号发送并配置测量信息上报。

:::

:::{div}
:class: standard-paragraph

<p>cIR-ReportLength指示 CIR上报时长,单位为纳秒;activeSignalingFrameNumber指示信令生效时间,以无线帧表达。sendingNodeInstruction指示先发后发,其中,在一次事件中,先发送信号的节点称为先发节点,后发送信号的节点称为后发节点;指示超宽带脉冲感知事件中先发送信号还是后发送信号,当超宽带脉冲感知事件组仅支持单向发送时,配置为先发的节点发送测量帧,配置为后发的节点接收测量帧。firstNode-TxMultiAntennaOrder指示先发节点发送测量帧多天线次序配置;secondNode-TxMultiAntennaOrder指示后发节点发送测量帧多天线次序配置;firstNode-TxAntennaNumber指示先发节点发送天线数量;firstNode-RxAntennaNumber指示先发节点接收天线数量;secondNode-Tx-AntennaNumber指示后发节点发送天线数量;secondNode-RxAntennaNumber指示后发节点接收天线数量;firstNode-TxMultiAntSwitchRes指示先发节点发送测量帧多天线切换资源配置;secondNode-TxMultiAntSwitchRes指示后发节点发送测量帧多天线切换资源配置;multiAntennaRandomOrder-Bitwidth指示多天线随机次序位宽;txAntennaNumber指示发送天线数量;rxAntennaNumber指示接收天线数量;measReportTxAntenna指示测量量发送天线配置;measReportRxAntenna指示测量量接收天线配置;sLPFirstMeasFrameStartTime为超宽带脉冲第一测量帧起始时刻,指示信令生效时刻与超宽带脉冲第一测量帧起始参考时刻的差值,以超宽带脉冲配置时间粒度为单位;sLPSecondMeas-FrameStartTime为超宽带脉冲第二测量帧起始时刻,指示超宽带脉冲第一测量帧起始时刻与超宽带脉冲第二测量帧起始时刻的差值,以超宽带脉冲配置时间粒度为单位。当该值为0时,不传输超宽带脉冲第二测量帧;sLPMeasEventCycle指示超宽带脉冲测量事件周期;sLPMeasEventGroupCycle指示超宽带脉冲测量事件组周期;sLPMeasEventNumberInGroup 指示超宽带脉冲测量事件组内事件总数;</p>

:::

:::{div}
:class: standard-paragraph

<p>sLPMeasEventGroupNumber指示超宽带脉冲测量事件组总数;sLPMeasEventNumber指示超宽带脉冲测量事件统计数量,表示从每个超宽带脉冲测量事件组中的第一个超宽带脉冲测量事件开始,一个测量信息上报对 应的超宽带脉冲测量 事 件的 个 数;sLPSignalBandwidth 指示超宽带脉冲信号带宽;</p>

:::

:::{div}
:class: standard-paragraph

<p>sLPChannel指示超宽带脉冲信道;channelOverlappingMode指示信道重叠模式;channelOrderMode指示信道使用顺序模式;frequencyStitchingNumber指示信道拼接数量;frequencyStitchingMeasFragStep指示信道拼接测量子片段步进;sensSymbolCodeLengthDutyCycle指示感知符号码字长度和占空因子;</p>

:::

:::{div}
:class: standard-paragraph

<p>sensSynchronousSymbolNumber指示感知同步符号个数;sensSymbolCodeIndex指示感知符号码字的索引;sensSymbolCodeCyclicShift指示感知符号码字循环移位;sensFragSymbolNumber指示感知子片段符号数;sensFragNumber指示感知子片段数;sensFragGap 指示感知子片段间隔粒度;sensSym-bolCPLength指示感知符号循环前缀长度;sensSymbolZeroPaddingLength指示感知符号补零长度。</p>

:::

:::{div}
:class: standard-paragraph

<p>sensingDeviceStateReport指示是否允许节点进行感知设备上报,0:优先级低,不允许进行感知设备状态上报;1:优先级高,允许进行感知设备状态上报。sLPposMeasIndication指示在超宽带脉冲感知测量中是否进行超宽带脉冲位置测量。sLPMeasReportPeriod指示超宽带脉冲位置测量量上报周期,以微秒为单位;当取值为0时,超宽带脉冲位置测量量为非周期上报;当值为0xFFFFFFFF时,该值无效,在超宽带脉冲感知中不进行位置测量量上报。</p>

:::
