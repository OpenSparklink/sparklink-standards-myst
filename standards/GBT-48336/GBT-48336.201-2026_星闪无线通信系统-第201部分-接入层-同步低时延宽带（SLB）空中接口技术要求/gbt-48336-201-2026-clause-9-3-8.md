# 9.3.8 口令要求

:::{div}
:class: standard-paragraph

<p>使用配置口令方式进行认证凭证配置时,应满足如下要求。</p>

:::

:::{div}
:class: standard-list-block

<ul class="standard-list">
<li><p>——— 用户设置口令时,应检测口令复杂度。口令至少满足如下要求。对于高安全要求的场景,口令</p>
</li></ul>

:::

:::{div}
:class: standard-paragraph

<p>要求可更加严格。</p>

:::

:::{div}
:class: standard-list-block

<ul class="standard-list">
<li><p>· $\cdot$口令长度至少8个字符。</p>
</li>
<li><p>· $\cdot$口令应包含如下至少两种字符的组合:小写字母、大写字母、数字、特殊字符。</p>
</li></ul>

:::

:::{admonition} 注
:class: note

<p>特殊字符指:\~ ! @#$%ˆ&amp;*()-_=+∖|[{}];:′&quot;,&lt;.&gt;/? 和空格。</p>

:::

:::{div}
:class: standard-list-block

<ul class="standard-list">
<li><p>· $\cdot$口令不能和账号一样。</p>
</li></ul>

:::

:::{div}
:class: standard-paragraph

<p>若设置的口令不符合上述规则,应进行告警。</p>

:::

:::{div}
:class: standard-list-block

<ul class="standard-list">
<li><p>——— 用户可修改口令。修改口令时应验证旧口令。</p>
</li>
<li><p>——— 口令文件应设置访问控制。</p>
</li>
<li><p>——— 操作界面中的口令不应明文显示。键入的口令缺省不应在图形界面上明文显示。对于命令行</p>
</li></ul>

:::

:::{div}
:class: standard-paragraph

<p>场景,登录口令也不应明文回显。</p>

:::

:::{div}
:class: standard-list-block

<ul class="standard-list">
<li><p>——— 口令输入框内容禁止拷贝。口令输入框不支持拷出功能。</p>
</li></ul>

:::
