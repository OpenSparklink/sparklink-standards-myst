# 7.5.2.39 代理感知请求消息

:::{div}
:class: figure-code

```asn1
-- ASN1START
SensingByProxyRequest ::= SEQUENCE {
    xrc-Identifier  XRC-Identifier,
    sensingByProxyRequest   SEQUENCE (SIZE(1..256)) OF SensingByProxyRequestItem    OPTIONAL,
-- Need OR
    lateNonCriticalExtension    OCTET STRING    OPTIONAL,
    nonCriticalExtension    SEQUENCE {} OPTIONAL
}
SensingByProxyRequestItem ::= SEQUENCE {
    sensingByProxyIndex UINT8,
    sensingProcedureIndex   UINT8,
    sensingByProxyReport    BIT32,
    sensingByProxyReportTimeUnit    UINT2,
    sensingByProxyReportPeriod  UINT16,
    sensingByProxyBandwidth UINT8,
    ...
}
-- ASN1STOP
```

:::

:::{div}
:class: standard-paragraph

<p>SensingByProxyRequest用于请求 G节点进行代理感知。其中,sensingByProxyIndex用于指示代理感知流程索引。sensingProcedureIndex用于指示接收代理感知请求消息的节点正在进行的感知流程,当该字段取值为0xFF时,指示此字段无效;当此字段为代理感知反馈中感知流程索引之一时,获取感知流程索引对应的感知测量量。sensingByProxyReport使用位图的方式指示请求代理感知测量量,当比特位为0时,不请求相应的代理感知测量量,当比特位为1时,请求相应的代理感知测量量。</p>

:::

:::{div}
:class: standard-paragraph

<p>sensingByProxyReportTimeUnit用于指示感知测量量上报周期的时间单位,0代表以超帧为单位,1代表以秒为单位,2代表以分为单位,3代表以小时为单位;sensingByProxyReportPeriod用于指示感知测量量上报周期的时间单位个数,感知测量量上报周期为上报周期的时间单位$\times$时间单位个数;sensingByProxyBandwidth用于指示代理感知带宽。</p>

:::
