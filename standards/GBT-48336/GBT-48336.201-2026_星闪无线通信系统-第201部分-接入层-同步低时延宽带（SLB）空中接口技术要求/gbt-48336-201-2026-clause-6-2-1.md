# 6.2.1 一般描述

:::{div}
:class: standard-paragraph

<p>120kHz基础子载波间隔系统中,物理层信号包括:</p>

:::

:::{div}
:class: standard-list-block

<ul class="standard-list">
<li><p>——— 同步信号;</p>
</li>
<li><p>——— G链路公共解调参考信号;</p>
</li>
<li><p>——— T链路控制信息解调参考信号;</p>
</li>
<li><p>——— 数据信息解调参考信号;</p>
</li>
<li><p>——— 数据信息相位调整信号;</p>
</li>
<li><p>——— 信道探测信号;</p>
</li>
<li><p>——— 信道状态信息参考信号;</p>
</li>
<li><p>——— 位置测量信号。</p>
</li></ul>

:::

:::{div}
:class: standard-paragraph

<p>物理层控制信息包括:</p>

:::

:::{div}
:class: standard-list-block

<ul class="standard-list">
<li><p>——— 同步信息;</p>
</li>
<li><p>——— 广播信息;</p>
</li>
<li><p>——— 接入信息;</p>
</li>
<li><p>——— 动态调度数据控制信息;</p>
</li>
<li><p>——— 预配置调度激活去激活信息;</p>
</li>
<li><p>——— 休眠与唤醒指示信息;</p>
</li>
<li><p>——— 快速载波切换指示信息;</p>
</li>
<li><p>——— 初始接入载波指示信息;</p>
</li>
<li><p>——— G链路位置测量信号或感知测量信号资源指示信息;</p>
</li>
<li><p>——— T链路位置测量信号资源指示信息;</p>
</li>
<li><p>——— 直通链路动态调度数据控制信息;</p>
</li>
<li><p>——— 单级 HARQ 反馈信息;</p>
</li>
<li><p>——— 两级 HARQ 反馈信息;</p>
</li>
<li><p>——— CQI反馈信息;</p>
</li>
<li><p>——— 调度请求信息。</p>
</li></ul>

:::

:::{div}
:class: standard-paragraph

<p>物理层数据信息包括:</p>

:::

:::{div}
:class: standard-list-block

<ul class="standard-list">
<li><p>——— 第一类物理层数据信息;</p>
</li>
<li><p>——— 第二类物理层数据信息。</p>
</li></ul>

:::

:::{div}
:class: standard-paragraph

<p>用于实现特定功能,映射多种物理层信号、物理层控制信息、物理层数据信息组合的一系列资源元素的集合称为物理层信息块。</p>

:::

:::{div}
:class: standard-paragraph

<p>通信域物理层信息块包括同步信息块SAB、接入信息块 RAB、G 链路物理层控制信息块 G-PCIB、附链路物理层数据信息块 A-PDIB。</p>

:::

:::{div}
:class: standard-paragraph

<p>此外,通信域上还包括映射物理层广播信息、G链路公共解调参考信号 G-DMRS-C、T 链路控制信息、数据信息解调参考信号 DMRS-D、物理层数据信息、信道探测信号、信道状态信息参考信号、位置测量信号和物理层数据信息相位调整信号的资源,以及未分配或未调度的空闲资源。</p>

:::

:::{div}
:class: standard-paragraph

<p>直通链路物理层信息块包括同步信息块SAB、直通链路物理层控制信息块P-PCIB。</p>

:::

:::{div}
:class: standard-paragraph

<p>此外,直通链路上还包括映射直通链路公共解调参考信号 P-DMRS-C、数据信息解调参考信号DMRS-D、物理层数据信息的资源,以及未分配或未调度的空闲资源。</p>

:::
