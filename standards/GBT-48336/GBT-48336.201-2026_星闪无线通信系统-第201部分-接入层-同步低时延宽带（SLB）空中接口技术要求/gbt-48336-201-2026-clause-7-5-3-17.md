# 7.5.3.17 同步通信域拓扑信息

:::{div}
:class: figure-code

```asn1
-- ASN1START
SyncDomainIDInfo ::= SEQUENCE {
    channelIndication   BIT64,
    domainID    DomainID,
    upLevelDomainIndication UINT5,
    ...
}
-- ASN1STOP
```

:::

:::{div}
:class: standard-paragraph

<p>指示在同步通信域集合中的一个通信域的信息,其中,channelIndication通过比特位图的方式指示该通信域 G 节点的工作信道,最高比特位指示工作频段中最高频率信道,次高比特位指示频段中次高频率信道,以此类推;domainID指示该通信域 G 节点的物理层标识;upLevelDomainIndication指示该通信域 G节点的上一级同步 G节点在同步通信域集合syncDomainIDList中的索引。</p>

:::
