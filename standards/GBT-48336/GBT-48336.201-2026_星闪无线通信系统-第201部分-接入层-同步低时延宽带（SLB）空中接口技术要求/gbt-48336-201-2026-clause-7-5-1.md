# 7.5.1 管理配置消息架构

(gbt-48336-201-2026-clause-7-5-1-1)=
## 7.5.1.1 G 链路系统消息

:::{div}
:class: figure-code

```asn1
-- ASN1START
GT-XRC-Definitions DEFINITIONS AUTOMATIC TAGS ::=

BEGIN

Glink-SystemInfo-Message ::= SEQUENCE {
    domainSysInfo DomainSysInfo,
    messageClassExtension SEQUENCE {}
}
-- ASN1STOP
```

:::

:::{div}
:class: standard-paragraph

<p>G链路系统消息主要用来承载通信域系统消息domainSysInfo。</p>

:::

(gbt-48336-201-2026-clause-7-5-1-2)=
## 7.5.1.2 G 链路公共控制消息

:::{div}
:class: figure-code

```asn1
-- ASN1START
Glink-CommonControl-Message ::= CHOICE {
    c1 CHOICE {
        xrcReject XRCReject,
        xrcSetup XRCSetup,
        spare6 NULL,
        spare5 NULL,
        spare4 NULL,
        spare3 NULL,
        spare2 NULL,
        spare1 NULL
    },
    messageClassExtension SEQUENCE {}
}
-- ASN1STOP
```

:::

:::{div}
:class: standard-paragraph

<p>G链路公共控制消息包含xrcReject或xrcSetup。其中xrcSetup消息由 G 节点向 T 节点发送,为T节点xrc连接进行必要配置;xrcReject消息由 G 节点向 T 节点发送,用于拒绝 T 节点的 XRC连接建立请求。</p>

:::

:::{div}
:class: standard-paragraph

<p>G链路公共控制消息在链路控制层采用传输模式3,不进行封装、重传、分包或组包。</p>

:::

(gbt-48336-201-2026-clause-7-5-1-3)=
## 7.5.1.3 G 链路专用控制消息

:::{div}
:class: figure-code

```asn1
-- ASN1START
Glink-DedicatedControl-Message ::= CHOICE {
    c1  CHOICE {
    xrcReconfiguration  XRCReconfiguration,
    xrcRelease  XRCRelease,
    securityContextRequest SecurityContextRequest,
    securityConfig  SecurityConfig,
    tNodeCapabilityRequest  TNodeCapabilityRequest,
    associationSetupWithSec AssociationSetupWithSec,
    associationSetupNonSec  AssociationSetupNonSec,
    glinkChannelStatusRequest   GlinkChannelStatusRequest,
    tlinkChannelStatusFeedback  TlinkChannelStatusFeedback,
    connectionKeyConfirmationRequest    ConnectionKeyConfirmationRequest,
    accessAuthenticationResponse    AccessAuthenticationResponse,
    vendorDefinedInfo   VendorDefinedInfo,
    testModeParameterRequest    TestModeParameterRequest,
    testModeResponse    TestModeResponse,
    tNodePositioningCapabilityRequest   TNodePositioningCapabilityRequest,
    positioningConfiguration    PositioningConfiguration,
    measurementGroupEstablishment   MeasurementGroupEstablishment,
measurementGroupConfiguration   MeasurementGroupConfiguration,
positioningMeasureTimeDifferenceReport PositioningMeasureTimeDifferenceReport,
tNodePosSensingCapRequest   TNodePosSensingCapRequest,
        sensingProcedureFeedback SensingProcedureFeedback,
        sensingByProxyFeedback SensingByProxyFeedback,
        sensingCapabilityRequest SensingCapabilityRequest,
        sensingConfiguration SensingConfiguration,
        sensingBehavioralIndicator SensingBehavioralIndicator,
        sLPCapabilityRequest SLPCapabilityRequest,
        sLPConfiguration SLPConfiguration,
        sLPMeasBehavioralIndicator SLPMeasBehavioralIndicator,
        sLPSensingCapabilityRequest SLPSensingCapabilityRequest,
        sLPSensingConfiguration SLPSensingConfiguration,
        sLPSensingBehavioralIndicator SLPSensingBehavioralIndicator,
        sLPseningReport SLPSensingReport,
        sLPSensingByProxyFeedback SLPSensingByProxyFeedback,
        slpsensingProcedureFeedback SlpsensingProcedureFeedback,
        ...
    },
    messageClassExtension SEQUENCE {}
}
-- ASN1STOP
```

:::

:::{div}
:class: standard-paragraph

<p>G链路专用控制消息在链路控制层缺省使用传输模式1-1,组播或广播可使用传输模式2-1,由媒体接入层子头 LCID字段指示(见表18)。</p>

:::

:::{div}
:class: standard-paragraph

<p>部分 G链路专用控制消息介绍如下:</p>

:::

:::{div}
:class: standard-list-block

<ul class="standard-list">
<li><p>——— xrcReconfiguration消息由 G节点向 T节点发送,用于对 XRC连接相关重配置;</p>
</li>
<li><p>——— xrcRelease消息用于进行 XRC连接释放;</p>
</li>
<li><p>——— securityContextRequest消息用于进行安全上下文请求;securityConfig消息用于进行安全相关配置;</p>
</li>
<li><p>——— tNodeCapabilityRequest消息用于查询 T节点能力;</p>
</li>
<li><p>——— associationSetupWithSec消息和associationSetupNonSec消息分别用于有安全上下文场景和无安全上下文场景的关联请求响应;</p>
</li>
<li><p>——— glinkChannelStatusRequest消息用于请求 G链路信道状态信息;</p>
</li>
<li><p>——— linkChannelStatusFeedback消息用于向 T节点发送 T链路信道状态信息。</p>
</li></ul>

:::

(gbt-48336-201-2026-clause-7-5-1-5)=
## 7.5.1.5 T链路专用控制消息

:::{div}
:class: figure-code

```asn1
-- ASN1START
Tlink-DedicatedControl-Message ::= CHOICE {
    c1  CHOICE {
    measurementReport   MeasurementReport,
    xrcReconfigurationComplete  XRCReconfigurationComplete,
    xrcSetupComplete    XRCSetupComplete,
    securityContextRespond SecurityContextRespond,
    securityConfigComplete  SecurityConfigComplete,
    associationComplete AssociationComplete,
    securityConfigGroupRequest  SecurityConfigGroupRequest,
    tNodeCapabilityFeedback TNodeCapabilityFeedback,
    glinkChannelStatusFeedback  GlinkChannelStatusFeedback,
    tNode-AssistantInformationReport    TNode-AssistantInformationReport,
    xrcReconfigurationRequest   XRCReconfigurationRequest,
    xrcReleaseRequest   XRCReleaseRequest,
    connectionKeyConfirmationResponse   ConnectionKeyConfirmationResponse,
    accessAuthenticationRequest AccessAuthenticationRequest,
    accessAuthenticationComplete    AccessAuthenticationComplete,
    vendorDefinedInfo   VendorDefinedInfo,
    testModeRequest TestModeRequest,
    testModeParameterResponse TestModeParameterResponse,
    tNodePositioningCapabilityFeedback TNodePositioningCapabilityFeedback,
    positioningMeasurementReport PositioningMeasurementReport,
    positioningMeasureTimeDifferenceReport PositioningMeasureTimeDifferenceReport,
    sensingDeviceState  SensingDeviceState,
    tNodePosSensingCapResponse  TNodePosSensingCapResponse,
    sensingMeasurementReport    SensingMeasurementReport,
    sensingProcedureRequest SensingProcedureRequest,
    sensingByProxyRequest   SensingByProxyRequest,
    sensingCapabilityResponse   SensingCapabilityResponse,
    sensingConfigurationFeedback    SensingConfigurationFeedback,
    sLPSensingProcedureRequest  SLPSensingProcedureRequest,
    sLPCapabilityResponse   SLPCapabilityResponse,
    sLPConfigurationFeedback    SLPConfigurationFeedback,
    sLPMeasurementReport    SLPMeasurementReport,
    sLPSensingCapabilityResponse    SLPSensingCapabilityResponse,
    sLPSensingConfigurationFeedback SLPSensingConfigurationFeedback,
    sLPSensingReport    SLPSensingReport,
    ...
    },
    messageClassExtension   SEQUENCE {}
}
-- ASN1STOP
```

:::

:::{div}
:class: standard-paragraph

<p>T链路专用控制消息在链路控制层采用传输模式1-1,支持封装、重传、分包和组包。部分 T 链路专用控制消息介绍如下:</p>

:::

:::{div}
:class: standard-list-block

<ul class="standard-list">
<li><p>——— measurementReport消息用于向 G节点进行测量上报;</p>
</li>
<li><p>——— xrcReconfigurationComplete消息用于向 G节点指示 XRC重配置完成;</p>
</li>
<li><p>——— xrcSetupComplete消息用于向 G节点指示 XRC非安全连接建立完成;</p>
</li>
<li><p>——— associationRequestWithSec消息用于存在安全上下文场景下的关联(认证)请求;securityCon-textRespond消息用于响应 G节点发送的安全上下文请求消息;</p>
</li>
<li><p>——— securityConfigComplete消息用于向 G节点指示安全配置完成;</p>
</li>
<li><p>——— associationComplete消息用于向 G节点发送关联完成消息;</p>
</li>
<li><p>——— tNodeCapabilityFeedback消息用于向 G节点进行 T节点能力上报;</p>
</li>
<li><p>——— glinkChannelStatusFeedback消息用于向 G节点报告 G链路信道状态信息;</p>
</li>
<li><p>——— tNode-AssistantInformationReport消息用于向 G节点进行辅助信息上报;</p>
</li>
<li><p>——— tNodePositioningCapabilityFeedback消息用于 T节点反馈位置信息的能力;</p>
</li>
<li><p>——— xrcReconfigurationRequest消息用于T节点根据新的 QoS要求向G节点请求发起XRC链接重配置;</p>
</li>
<li><p>——— xrcReleaseRequest消息用于 T节点主动请求释放 XRC连接。</p>
</li></ul>

:::
