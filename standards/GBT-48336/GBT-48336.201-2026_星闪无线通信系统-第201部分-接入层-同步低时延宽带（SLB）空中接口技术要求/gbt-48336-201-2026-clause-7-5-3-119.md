# 7.5.3.119 最大连续基础载波数信息

:::{div}
:class: figure-code

```asn1
-- ASN1START
MaxBandwidthCap ::= ENUMERATED { n1, n2, n3, n4, n5, n6, n8, n10,
    n12, n15, n16, n20, n24, n32, n40, n80,
    spare16, spare15, spare14, spare13, spare12, spare11, spare10, spare9,
    spare8, spare7, spare6, spare5, spare4, spare3, spare2, spare1 }
-- ASN1STOP
```

:::

:::{div}
:class: standard-paragraph

<p>MaxBandwidthCap用于指示最大连续基础信道数量或最大连续基础载波数量,以一个基础信道或基础载波的带宽为单位,取值范围可为1/2/3/4/5/6/8/10/12/15/16/20/24/32/40/80个,其中1和2只用于低成本的 T节点。基础信道或基础载波的实际带宽取决于当前所在频段。</p>

:::
