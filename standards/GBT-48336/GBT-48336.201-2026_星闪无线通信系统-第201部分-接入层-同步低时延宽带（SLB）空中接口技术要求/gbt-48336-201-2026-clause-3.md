(gbt-48336-201-2026-clause-3)=
# 3 术语和定义

:::{div}
:class: standard-reference

<p>GB/T48336.101—2026界定的以及下列术语和定义适用于本文件。</p>

:::

(gbt-48336-201-2026-clause-3-1)=
## 3.1 无线帧 radio frame

:::{div}
:class: standard-paragraph

<p>同步低时延宽带通信系统中每3840个基础时间单位组成的资源。</p>

:::

(gbt-48336-201-2026-clause-3-2)=
## 3.2 第一训练信号 first training signal; FTS

:::{div}
:class: standard-paragraph

<p>同步低时延宽带通信系统中用作时间和频率同步的主要信号。</p>

:::

(gbt-48336-201-2026-clause-3-3)=
## 3.3 第二训练信号 secondary training signal; STS

:::{div}
:class: standard-paragraph

<p>同步低时延宽带通信系统中用作时间和频率同步的辅助信号。</p>

:::

(gbt-48336-201-2026-clause-3-4)=
## 3.4 相位调整信号 phase adjustment signal; PAS

:::{div}
:class: standard-paragraph

<p>同步低时延宽带通信系统中用作相位调整的信号。</p>

:::

(gbt-48336-201-2026-clause-3-5)=
## 3.5 物理层标识 physical layer identity; PID

:::{div}
:class: standard-paragraph

<p>用于物理层寻址的标识。</p>

:::

(gbt-48336-201-2026-clause-3-6)=
## 3.6 位置锚点 positioning anchor

:::{div}
:class: standard-paragraph

<p>参与测距、测角或定位的节点中作为测距、测角或定位基准位置的节点。</p>

:::

(gbt-48336-201-2026-clause-3-7)=
## 3.7 位置标签 positioning tag

:::{div}
:class: standard-paragraph

<p>参与测距、测角或定位的节点中,通过测距、测角或定位过程,被确定相对于基准位置的距离、角度或位置的节点。</p>

:::

(gbt-48336-201-2026-clause-3-8)=
## 3.8 位置测量信号 positioning signal

:::{div}
:class: standard-paragraph

<p>位置锚点和位置标签之间发送的,用于测量位置信息(包括距离信息和/或方向信息)的测量信号。</p>

:::

:::{admonition} 注
:class: note

<p>在本文件中,用于测量距离信息的位置测量信号又称“测距信号”,用于测量角度信息的位置测量信号又可称为测角信号。</p>

:::

(gbt-48336-201-2026-clause-3-9)=
## 3.9 位置测量符号 positioning symbol

:::{div}
:class: standard-paragraph

<p>用于承载位置测量信号的一个 CP-OFDM 符号。</p>

:::

(gbt-48336-201-2026-clause-3-10)=
## 3.10 测距符号 ranging symbol

:::{div}
:class: standard-paragraph

<p>用于承载测量距离信息的位置测量信号的符号。</p>

:::

(gbt-48336-201-2026-clause-3-11)=
## 3.11 位置测量帧 positioning frame

:::{div}
:class: standard-paragraph

<p>位置测量符号所在的无线帧。</p>

:::

(gbt-48336-201-2026-clause-3-12)=
## 3.12 测距帧 ranging frame

:::{div}
:class: standard-paragraph

<p>测距符号所在的无线帧。</p>

:::

(gbt-48336-201-2026-clause-3-13)=
## 3.13 单向定位 single side positioning

:::{div}
:class: standard-paragraph

<p>位置锚点和位置标签之间,由位置锚点向位置标签发送位置测量信号,位置标签测量位置信息的过程;或者由位置标签向位置锚点发送位置测量信号,位置锚点测量位置信息的过程。</p>

:::

(gbt-48336-201-2026-clause-3-14)=
## 3.14 双向定位 double sides positioning

:::{div}
:class: standard-paragraph

<p>位置锚点和位置标签之间,位置锚点向位置标签发送位置测量信号,位置标签测量获取第一位置信息,位置标签向位置锚点发送位置测量信号,位置锚点测量获取第二位置信息,位置解算节点根据第一位置信息和第二位置信息进行确定位置标签位置信息的过程。</p>

:::

(gbt-48336-201-2026-clause-3-15)=
## 3.15 第一位置测量信号 first positioning signal

:::{div}
:class: standard-paragraph

<p>双向位置测量过程中,在时间上首先发送的位置测量信号。</p>

:::

(gbt-48336-201-2026-clause-3-16)=
## 3.16 第二位置测量信号 second positioning signal

:::{div}
:class: standard-paragraph

<p>双向位置测量过程中,第一位置测量信号的接收节点,在接收到第一位置测量信号之后发送的位置测量信号。</p>

:::

(gbt-48336-201-2026-clause-3-17)=
## 3.17 第三位置测量信号 third positioning signal

:::{div}
:class: standard-paragraph

<p>双向位置测量过程中,第一位置测量信号的发送节点,在接收到第二位置测量信号之后发送的位置测量信号。</p>

:::

(gbt-48336-201-2026-clause-3-18)=
## 3.18 第一位置节点 first positioning node

:::{div}
:class: standard-paragraph

<p>双向位置测量过程中,发送第一位置测量信号的节点。</p>

:::

:::{admonition} 注
:class: note

<p>第一位置节点也是第二位置测量信号的接收节点。当存在第三位置测量信号时,第一位置节点也是第三位置测量信号的发送节点。第一位置节点可能为 G节点或 T节点。</p>

:::

(gbt-48336-201-2026-clause-3-19)=
## 3.19 第二位置节点 second positioning node

:::{div}
:class: standard-paragraph

<p>双向位置测量过程中,接收第一位置测量信号的节点。</p>

:::

:::{admonition} 注
:class: note

<p>第二位置节点也是第二位置测量信号的发送节点。当存在第三位置测量信号时,第二位置节点也是第三位置测量信号的接收节点。第二位置节点可能为 G节点或 T节点。</p>

:::

(gbt-48336-201-2026-clause-3-20)=
## 3.20 位置测量信号离开时间 time of departure of positioning signal

:::{div}
:class: standard-paragraph

<p>一个用于测距的无线帧内发送的第一个 G链路或 T链路测距符号的开端,离开本地天线连接器的时刻。</p>

:::

(gbt-48336-201-2026-clause-3-21)=
## 3.21 位置测量信号到达时间 time of arrival of positioning signal

:::{div}
:class: standard-paragraph

<p>一个用于测距的无线帧内接收的第一个 G链路或 T链路测距符号的开端,到达本地天线连接器的时刻。</p>

:::

(gbt-48336-201-2026-clause-3-22)=
## 3.22 位置测量信号离开角度 angle of departure of positioning signal

:::{div}
:class: standard-paragraph

<p>位置测量信号发送节点发出信号的角度信息。</p>

:::

(gbt-48336-201-2026-clause-3-23)=
## 3.23 位置测量信号到达角度 angle of arrival of positioning signal

:::{div}
:class: standard-paragraph

<p>位置测量信号接收节点接收信号的角度信息。</p>

:::

(gbt-48336-201-2026-clause-3-24)=
## 3.24 超宽带脉冲测量事件 synchronous link positioning measurement event

:::{div}
:class: standard-paragraph

<p>用于使用超宽带脉冲进行测量的事件。</p>

:::

:::{admonition} 注1
:class: note

<p>当进行信道冲击响应测量、距离多普勒测量、感知测量、角度信息测量时,一个超宽带脉冲测量事件包括超宽带脉冲第一测量帧。</p>

:::

:::{admonition} 注2
:class: note

<p>当进行双边两消息时间信息测量时,一个超宽带脉冲测量事件包括超宽带脉冲第一测量帧和超宽带脉冲第二测量帧。</p>

:::

:::{admonition} 注3
:class: note

<p>当进行双边三消息时间信息测量时,一个超宽带脉冲测量事件包括超宽带脉冲第一测量帧、超宽带脉冲第二测量帧和超宽带脉冲第三测量帧。</p>

:::
