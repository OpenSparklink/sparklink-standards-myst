# 7.5.2.31 T节点定位能力反馈消息

:::{div}
:class: figure-code

```asn1
-- ASN1START
TNodePositioningCapabilityFeedback ::= SEQUENCE {
    xrc-Identifier  XRC-Identifier,
    tNodePositioningCapabilityFeedbackVar   TNodePositioningCapabilityFeedback-IEs,
    lateNonCriticalExtension    OCTET STRING    OPTIONAL,
    nonCriticalExtension    SEQUENCE {} OPTIONAL
}
TNodePositioningCapabilityFeedback-IEs ::= SEQUENCE {
    ofdmwaveRTTPositioning  BoolType,
    ofdmwaveM2MFlagPositioning  BoolType    OPTIONAL,
    ofdmwaveDlFlagPositioning   BoolType    OPTIONAL,
    ofdmwaveSullFlagPositioning BoolType    OPTIONAL,
    ofdmwaveAulFlagPositioning  BoolType    OPTIONAL,
    ofdmwaveStitchingPositioning    BoolType    OPTIONAL,
    txPosSignalBandwidth    UINT7,
    txPosSignalCSI  BoolType,
    txPosSignalSRS  BoolType,
    txPosSignalSecurity BoolType,
    txPosSignalPMS  BoolType,
    rxPosSignalBandwidth    UINT7,
    rxPosSignalCSI  BoolType,
    rxPosSignalSRS  BoolType,
    rxPosSignalSecurity BoolType,
    rxPosSignalPMS  BoolType,
    portBasedTxSignal   BoolType,
    portNumber  UINT7,
    beamBasedTxSignal   BoolType,
    beamNumber  UINT8,
    beamGAP BoolType,
    aoA-Estimation  BoolType,
    aoD-Estimation  BoolType,
    rxTimeEstimation    BoolType,
    txTimeEstimation    BoolType,
    rttTwoSideTwoSignals    BoolType,
    rttTwoSideThreeSignals  BoolType,
    rttCyclicTwoSideThreeSignals    BoolType,
    csiBasedEstimation  BoolType,
    intraBandFrequencyHopping   SEQUENCE (SIZE(3)) OF UINT16,
    interBandFrequencyHopping   SEQUENCE (SIZE(3)) OF UINT16,
    posAnchor   BoolType,
    posCalculator   BoolType,
    nodePositioningCoordinates  NodePositioningCoordinates  OPTIONAL, -- Need OR
    ...
}
-- ASN1STOP
```

:::

:::{div}
:class: standard-paragraph

<p>TNodePositioningCapabilityFeedback由 T节点发送给 G 节点,用于进行 T 节点定位能力上报。</p>

:::

:::{div}
:class: standard-paragraph

<p>其中ofdmwaveRTTPositioning指示是否支持基于 RTT 的测量模式;ofdmwaveM2MFlagPositioning指示是否支持基于多锚点和多标签(M2M-FLAG)的测量模式;ofdmwaveDlFlagPositioning指示是否支持基于下行测量组快速定位的测量模式;ofdmwaveSullFlagPositioning指示是否支持自上行测量组快速定位(SUL-FLAG)的测量模式;ofdmwaveAulFlagPositioning指示是否支持辅助上行测量组快速定位(AUL-FLAG)的测量模式;ofdmwaveStitchingPositioning指示是否支持频率拼接双向复合信道的测量模式;txPosSignalBandwidthimitation用于指示发送位置测量信号支持的带宽,以20MHz带宽为单位;txPosSignalCSI用于指示是否支持发送基于 CSI的位置测量信号;txPosSignalSRS用于指示是否支持发送基于SRS的位置测量信号;txPosSignalPMS用于指示是否支持发送基于 PMS的位置测量信号;rxPosSignalBandwidthimitation用于指示接收位置测量信号支持的带宽,以20MHz带宽为单位;rxPosSignalCSI用于指示是否支持接收基于 CSI的位置测量信号;rxPosSignalSRS用于指示是否支持接收基于SRS的位置测量信号;rxPosSignalPMS用于指示是否支持接收基于 PMS的位置测量信号;portBasedTxSignal用于指示是否支持发送基于端口的位置测量信号;portNumber用于指示支持的最大端口数量;beamBasedTxSignal用于指示是否支持发送基于波束的位置测量信号;beamNumber用于指示支持的最大波束数量;beamGAP用于指示是否需要切换时间;aoA-Estimation用于指示是否支持位置测量信号到达角度测量;aoD-Estimation用于指示是否支持位置测量信号离开角度测量;rxTimeEstimation用于指示是否支持位置测量信号到达时间的测量;txTimeEstimation用于指示是否支持位置测量信号 离 开 时间的测量;rttTwoSideTwoSignals 用 于 指示是 否 支持 双向 两 信号测距;</p>

:::

:::{div}
:class: standard-paragraph

<p>rttTwoSideThreeSignals用于指示是否支持双向三信号测距;rttCyclicTwoSideThreeSignals用于指示是否支持循环双向三信号测距;csiBasedEstimation用于指示是否支持双向复合信道测距;intraBandFrequencyHopping用于指示节点在2.4GHz多信道间,5GHz多信道间以及6GHz多信道间进行跳频时的切换间隔,以微秒为单位,当该值为0时不支持跳频;interBandFrequencyHopping用于指示节点在2.4GHz和5GHz多信道间,2.4GHz和6GHz多信道间,以及5GHz和6GHz多信道间进行跳频时的切换间隔,以 微 秒 为 单位,当 该 值 为 0 时 不支持跳 频;posAnchor用 于 指示是 否 为 定位 锚 点;</p>

:::

:::{div}
:class: standard-paragraph

<p>posCalculator用于指示是否为位置解算节点;nodePositioningCoordinates用于指示节点的位置坐标。</p>

:::
