# 附录 J（资料性）TBPEKE

:::{div}
:class: standard-paragraph

<p>本文件规定的基于 TBPEKE(Two-BasisPasswordExponentialKeyExchange)的密钥协商算法使用的椭圆曲线为:SM2定义的椭圆曲线或者 Curve25519。TBPEKE的公共参数包括:阶数为素数p的椭圆曲线循环群,及群中的两个独立的基点 U 和 V。</p>

:::

<p>以上 V 点采用公开可验证的方式由各自的固定字符串gen_string生成(伪代码如下,具体的函数实现请见 参 考 代 码),保证 U 和 V 的 离 散 对 数关系计算 不 可知。其 中,SM2 的 gen_string 是”SparkLink-TBPEKE-SM2”,而 Curve25519的gen_string是”SparkLink-TBPEKE-25519”。</p>

:::

```text
found=FALSE,
counter=0,
while ! found
    counter++;
    x=hash256(counter,gen_string) mod p; //counter is treated as string
    if is_valid_for_curve(x,curve_equation) //x satisfies the curve equation
        found=True;
        y=sqrt(curve_equation(x)); //use the positive square root
return P(x,y)
```

:::{div}
:class: standard-paragraph

<p>TBPEKE的工作流程描述如下:T节点基于口令pw 计算$b=U+pw*V$,此处+表示椭圆曲线上的点加运算,*表示椭圆曲线上的点乘运算。T节点生成一个随机数作为私钥SKt,其中$1\leq \mathrm{SKt}\lt p$,并计算公钥$\mathrm{PKt}=\mathrm{SKt}*b$,公钥PKt作为密钥协商参数 KEt。T节点向 G节点发送关联请求信息。</p>

:::

:::{div}
:class: standard-paragraph

<p>G节点计算$b=U+pw*V$。G节点生成一个随机数作为私钥SKg,其中$1\leq \mathrm{SK}g\lt p$,并计算公钥$\mathrm{PK}g=\mathrm{SK}g*b$,公钥PKg作为密钥协商参数 KEg。</p>

:::

:::{div}
:class: standard-paragraph

<p>G节点根据 KEt计算密钥 K<sub>KE</sub>,$K_{\mathrm{KE}}=\mathrm{SK}g*\mathrm{KEt}$。G节点向 T节点发送安全上下文请求消息。</p>

:::

:::{div}
:class: standard-paragraph

<p>T节点计算密钥 KK′E,$K'_{\mathrm{K}\mathrm{E}}=\mathrm{SKt}*\mathrm{KE}g$。</p>

:::

:::{div}
:class: standard-paragraph

<p>$K_{\mathrm{KE}}=\mathrm{SK}g*\mathrm{KEt}=\mathrm{SK}g*(\mathrm{SKt}*b)=\mathrm{SKt}*(\mathrm{SK}g*b)=\mathrm{SKt}*\mathrm{KE}g=K'_{\mathrm{K}\mathrm{E}}$。G 节点和 T 节点得到共享密钥 K<sub>KE</sub>。</p>

:::
