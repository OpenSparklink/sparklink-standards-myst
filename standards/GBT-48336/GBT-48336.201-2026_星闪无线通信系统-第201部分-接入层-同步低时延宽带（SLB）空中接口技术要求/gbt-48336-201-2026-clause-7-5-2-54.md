# 7.5.2.54 超宽带脉冲感知流程请求消息

:::{div}
:class: figure-code

```asn1
-- ASN1START
SLPSensingProcedureRequest ::= SEQUENCE {
    xrc-Identifier  XRC-Identifier,
    slpsensingProcedureRequest  SEQUENCE (SIZE(1..256)) OF SlpSensingRequestItem
OPTIONAL,   -- Need OR
    lateNonCriticalExtension    OCTET STRING    OPTIONAL,
    nonCriticalExtension    SEQUENCE {} OPTIONAL
}
SlpSensingRequestItem ::= SEQUENCE {
    slpsensingProcedureRequestIndex UINT8,
    slpsensingRequestReport BIT32,
    slpsensingRequestReportTimeUnit UINT2,
    slpsensingRequestReportPeriod   UINT16,
    slpsensingRequestBandwidth  UINT8,
    slpsensingRequestChannel    UINT8,
    ...
}
-- ASN1STOP
```

:::

:::{div}
:class: standard-paragraph

<p>SLPSensingProcedureRequest由 T 节点发送给 G 节点,用于请求 G 节点进行超宽带脉冲感知。</p>

:::

:::{div}
:class: standard-paragraph

<p>其中,slpsensingProcedureRequestIndex用于指示请求超宽带脉冲感知流程索引;slpsensingRequestReport用于指示请求超宽带脉冲感知测量量;slpsensingRequestReportTimeUnit用于指示超宽带脉冲感知测量量上报周期的时间单位,0代表以超帧为单位,1代表以秒为单位,2代表以分为单位,3代表以小时为单位;slpsensingRequestReportPeriod用于指示超宽带脉冲感知测量量上报周期的时间单位个数,超宽带脉冲感知测量量上报周期为上报周期的时间单位*时间单位个数;slpsensingRequestBandwidth用于指示请求超宽带脉冲感知带宽;slpsensingRequestChannel用于指示请求超宽带脉冲感知信道。</p>

:::
