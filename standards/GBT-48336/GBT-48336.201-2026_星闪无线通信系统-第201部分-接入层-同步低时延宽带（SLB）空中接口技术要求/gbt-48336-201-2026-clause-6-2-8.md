# 6.2.8 多域同步流程

:::{div}
:class: standard-paragraph

<p>多域同步用来实现多个通信域之间的时间和频率同步。待同步通信域的 G 节点向同一频段内接收信号强度超过门限$Th_{\mathrm{sync}}$的、且同步信息块(SAB)中同步标识字段(SyncID)取值最大的同步域的G节点同步,该提供参考时间和频率的被同步 G节点称为同步源。这里同步至少是符号级同步。</p>

:::

:::{div}
:class: standard-paragraph

<p>多域同步主要包括同步源选择/更新、本域同步调整、域间同步跟踪等操作。</p>

:::

:::{div}
:class: standard-paragraph

<p>其中,同步源选择/更新包括如下步骤,如图3所示。</p>

:::{div}
:class: standard-paragraph

<p>步骤1:本域 G节点同步标识确定。</p>

:::

:::{div}
:class: standard-paragraph

<p>在每次开机时确定,或发生 G节点多域同步能力属性改变时进行。本域 G节点同步标识字段的取值共32比特,其中,低位24个比特为 G节点物理层标识,由 G节点随机产生;高位8个比特为 G节点多域同步能力属性,从最低位比特到最高位比特如下。</p>

:::

:::{div}
:class: standard-list-block

<ul class="standard-list">
<li><p>——— 1比特:预留,当前版本为0。</p>
</li>
<li><p>——— 1比特:设备优先级。1:高级域,0:低级域。</p>
</li>
<li><p>——— 2比特:定时来源。3:GNSS/GPS等外部授时源,2:蜂窝网等外部授时源,1:没有其他外部授时源,0:其他情况。</p>
</li>
<li><p>——— 1比特:工作状态。0:省电状态,1:非省电状态。</p>
</li>
<li><p>——— 2比特:多域同步版本。当前版本为1。</p>
</li>
<li><p>——— 1比特:发射功率。0:额定功率$P\lt 20\mathrm{dBm}$,1:额定功率$P\geq 20\mathrm{dBm}$。</p>
</li></ul>

:::

:::{div}
:class: standard-paragraph

<p>步骤2:对邻域同步信息块SAB的同步和解析。</p>

:::

:::{div}
:class: standard-paragraph

<p>每次开机时执行,或周期性执行。本域 G节点扫描同一频段内的其他 G 节点的同步信息块,捕获其同步信号,对邻域FTS信号强度超过门限$Th_{\mathrm{sync}}$的邻域 G 节点进行同步并解析获取其同步信息块(SAB)中同步标识字段(SyncID)的取值。</p>

:::

:::{div}
:class: standard-paragraph

<p>步骤3:确定同步源。</p>

:::

:::{div}
:class: standard-paragraph

<p>比较本域 G节点和捕获的各邻域 G节点同步信息块中同步标识字段(SyncID)的大小,该字段数值最大的 G节点为同步源。</p>

:::

:::{div}
:class: standard-paragraph

<p>确定同步源后,执行本域同步调整操作。如果同步源是本域 G 节点,则不用执行额外动作;如果同步源不是本域 G节点,则本域 G节点向同步源 G节点执行时间和频率同步操作。</p>

:::

:::{div}
:class: standard-paragraph

<p>对本域 G节点向邻域 G节点同步的情况,进一步地,本域 G节点通过如下两种方式使得本域 T 节点也进行相应的同步调整。</p>

:::

:::{div}
:class: standard-list-block

<ul class="standard-list">
<li><p>——— 方式1:G节点逐步微调定时和频偏。调整幅度不超过 T 节点的定时跟踪幅度,典型地,每次定时调整幅度$\leq 4\mathrm{Ts}$,相对频偏调整幅度$\leq 0.1\times 10^{-6}$。</p>
</li>
<li><p>——— 方式2:G节点和 T节点约定在统一时间进行定时/频偏改变。当本域 G 节点和同步源 G 节点同步偏差较大时,可通过下发 XRCreconfiguration消息进行同步偏差的调整和频率偏差的调整,也可通过 DomainSysInfo携带同步偏差的调整和频率偏差的调整。</p>
</li></ul>

:::

:::{div}
:class: standard-paragraph

<p>多域同步还包括域间同步跟踪操作,即本域 G 节点对同步源的同步跟踪。具体地,本域 G 节点在如下时刻检测同步源的同步信号,检测成功则调整相应时频同步。</p>

:::

:::{div}
:class: standard-list-block

<ul class="standard-list">
<li><p>——— 时刻1:本域 G节点空闲状态期间以250 s为周期检测同步源。</p>
</li></ul>

:::

:::{div}
:class: standard-paragraph

<p>$\mu$</p>

:::

:::{div}
:class: standard-list-block

<ul class="standard-list">
<li><p>——— 时刻2:本域 G节点每次占用信道结束后连续4个250 s检测同步源。</p>
</li></ul>

:::

:::{div}
:class: standard-paragraph

<p>$\mu$</p>
