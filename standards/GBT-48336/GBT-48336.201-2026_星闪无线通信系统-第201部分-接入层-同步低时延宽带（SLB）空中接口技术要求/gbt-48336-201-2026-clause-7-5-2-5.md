# 7.5.2.5 T节点能力查询请求消息

:::{div}
:class: figure-code

```asn1
-- ASN1START
TNodeCapabilityRequest ::= SEQUENCE {
    xrc-Identifier  XRC-Identifier,
    nodeCapabilityRequestObject BIT48,
    lateNonCriticalExtension    OCTET STRING    OPTIONAL,
    nonCriticalExtension    SEQUENCE {} OPTIONAL
}
-- ASN1STOP
```

:::

:::{div}
:class: standard-paragraph

<p>TNodeCapabilityRequest由 G节点发送给 T节点,用于查询 T节点的能力(通信能力见附录L,定位和感知能力见附录 M)。其中 nodeCapabilityRequestObject通过比特表的形式指示要查询的能力,其中1标识查询,0标识不查询。比特表从高位到低依次对应g-MaxLayer、t-MaxLayer、txPowerLimitation、rohcIndication、modulationCap、supportingSegmentation、cbg-Feedback、sub-cbg-Feeedback、two-Stage-Scheduling、ackDelay、frequency-Interleaving、ntp128bit、ntp64bit、ntp32bit、multiBandCap、codingModulationTable3、macTxBufferSize、macRxBufferSize、peakDataRate、pagingCap、PassthroughLinkCap、AuxiliaryLinkCap、ofdmwavePositioning、ofdmwaveSensing、ultraWideBandPositioning、ultraWideBandSensing、minDataDelay、cqiDelay、srsDelay、csi-rs2cqiDelay、sinrFeedbackGranularityCap、angleFeedbackGranularityCap、testModeCap、addressTypeCap、contentionAccessResourceCap、groupcastCap、lowEnergyCap、drxCap、spsCap、timeDomainSyncCap、freqDomainSyncCap、syncDomainGroupMeasCap、dataType1Cap和 measureCap等能力项。</p>

:::
