# 7.5.2.51 超宽带脉冲测量配置反馈消息

:::{div}
:class: figure-code

```asn1
-- ASN1START
SLPConfigurationFeedback ::= SEQUENCE {
    xrc-Identifier XRC-Identifier,
    sLPConfigIndex  UINT8,
    sLPConfigState  UINT8,
    lateNonCriticalExtension    OCTET STRING    OPTIONAL,
    nonCriticalExtension    SEQUENCE {} OPTIONAL
}
-- ASN1STOP
```

:::

:::{div}
:class: standard-paragraph

<p>SLPConfigurationFeedback由 T节点发送给 G 节点,用于向 G 节点进行超宽带脉冲测量配置反馈。sLPConfigIndex用于指示位置测量信号配置索引;sLPConfigState用于指示位置测量信号配置状态,标识节点是否接受该请求,0:接受位置测量信号配置;1:拒绝位置测量信号配置;其他数值预留。</p>

:::
