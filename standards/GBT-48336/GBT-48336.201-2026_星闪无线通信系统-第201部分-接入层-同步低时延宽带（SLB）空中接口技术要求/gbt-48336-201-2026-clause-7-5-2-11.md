# 7.5.2.11 XRC重配置完成消息

:::{div}
:class: figure-code

```asn1
-- ASN1START
XRCReconfigurationComplete ::= SEQUENCE {
    xrc-Identifier  XRC-Identifier,
    securityConfigComplete  NULL    OPTIONAL,
    result  XRCCommonFailureReason  OPTIONAL,
    lateNonCriticalExtension    OCTET STRING    OPTIONAL,
    nonCriticalExtension    SEQUENCE {} OPTIONAL
}
-- ASN1STOP
```

:::

:::{div}
:class: standard-paragraph

<p>xrcReconfigurationComplete由 T节点发送给 G节点,用于对xrcReconfiguration进行响应。具体的可包括对安全配置securityConfig的响应securityConfigComplete。result用于指示整个 XRC重配置结果,如果失败,指示具体失败原因。</p>

:::
