# 7.5.3.83 深度节能配置信息

:::{div}
:class: figure-code

```asn1
-- ASN1START
LowEnergyConfig ::= SEQUENCE {
    lowEnergyCfgAdd LowEnergyInfo   OPTIONAL,
    lowEnergyCfgDel NULL    OPTIONAL,
    lateNonCriticalExtension    OCTET STRING    OPTIONAL,
    nonCriticalExtension    SEQUENCE {} OPTIONAL
}
LowEnergyInfo ::= SEQUENCE {
    lowEnergyStarting   SEQUENCE {
    dhfn    BIT STRING (SIZE (13)),
    frameIndex  FrameIndex
    } OPTIONAL,
    lowEnergyPeriod INTEGER (1..65535),
    lowEnergyDuration INTEGER (1..65535),
    ...
}
-- ASN1STOP
```

:::

:::{div}
:class: standard-paragraph

<p>LowEnergyConfig深度节能配置信元,可增加或者删除相关配置。G 节点和 T 节点在深度节能的活跃期内进行 XRC连接和安全数据传输;在非活跃期,双方释放 XRC连接,并进入深度睡眠甚至关闭电源。LowEnergyInfo指示深度节能的时间信息。</p>

:::

:::{div}
:class: standard-list-block

<ul class="standard-list">
<li><p>——— lowEnergyStarting:以 DGFN 指示深度节能的活跃期起始时刻,可选参数,当 T 节点向 G 节点申请深度节能配置时可不配。</p>
</li>
<li><p>——— lowEnergyPeriod:深度节能活跃期的周期信息,单位为15s。</p>
</li>
<li><p>——— lowEnergyDuration:深度节能活跃期的持续时间,单位为秒。</p>
</li></ul>

:::
