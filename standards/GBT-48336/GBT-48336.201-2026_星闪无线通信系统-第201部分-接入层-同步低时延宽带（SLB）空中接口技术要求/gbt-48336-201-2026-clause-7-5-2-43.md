# 7.5.2.43 感知配置消息

:::{div}
:class: figure-code

```asn1
-- ASN1START
SensingConfiguration ::= SEQUENCE {
    xrc-Identifier  XRC-Identifier,
    sensingConfiguration    SEQUENCE (SIZE(1..256)) OF SensingResourceConfigItem    OPTIONAL,
-- Need OR
    lateNonCriticalExtension    OCTET STRING    OPTIONAL,
    nonCriticalExtension    SEQUENCE {} OPTIONAL
}
SensingResourceConfigItem ::= SEQUENCE {
    sensingConfigIndex  UINT8,
    sensFrequencyBandIndication ChannelNumber,
    sensFrequencyBandwidthIndication    INTEGER (1..255),
    sensResourcePeriod  UINT16,
    sensResourceOnduration  INTEGER (1..65535),
    sensResourceOffset  UINT16,
    measureMode ENUMERATED {m1, m2},
    sensingEventReport  UINT16,
    sensingReportTimeUnit   UINT2,
    sensingReportPeriod UINT16,
    positioningResourceIndicationMASK   BIT24   OPTIONAL,
    sensCpConfig    CPConfig    OPTIONAL,
    sensResouceMeasurementIndication    SensingResourceMeasurementIndication    OPTIONAL,
    ...
}
SensingResourceMeasurementIndication ::= SEQUENCE {
    symboleResouceIndication    BIT STRING (SIZE (480)),
    signalGenMethod ENUMERATED {csi, srs, pms },
    signalGenPMSParam   INTEGER (2..20),
    portNumber  UINT6,
    portRepNumber   UINT6,
    beamNumber  UINT9,
    beamRepNumber   UINT6,
    beamGAP BoolType,
    tx-rx-Indication    ENUMERATED {tx, rx},
    rxTimingMeasure BoolType,
    rxAoAMeasure    BoolType,
    txAoDMeasure    BoolType,
    rxPortCSIMeasure    BoolType,
    rxPortCSIMeasMode   UINT6,
    rxPortCSIMeasFrequencyComb  CombInfo-2,
    rxBeamCSIMeasure    BoolType,
    rxBeamCSIMeasMode   UINT6,
    rxBeamCSIMeasFrequencyComb  CombInfo-2,
    rxCIRMeasure-FirstPath  BoolType,
    rxCIRMeasure-StrongestPath  BoolType,
    rxAntennaPhaseDiffReport    BoolType,
    txAntennaPhaseDiffReport    BoolType,
    rangeDopplerMeasure-FirstPath   BoolType,
    rangeDopplerMeasure-StrongestPath   BoolType,
    sensingTargetReport BoolType,
    sensingDeviceStateReport    BoolType,
    posMeasIndication   BoolType,
    posReportPeriod UINT32,
    secureSensingParam-Type1    SecureSensingParam-Type1 OPTIONAL, -- Need OR
    secureSensingParam-Type2    SecureSensingParam-Type2 OPTIONAL, -- Need OR
    ...
}
SecureSensingParam-Type1 ::= SEQUENCE {
    obfuscationFunctionNumber   UINT8,
    obfuscationRandomLength UINT8,
    obfuscationRandomNumber SEQUENCE (SIZE(1.. 65535)) OF UINT16,
    obfuscationSamplingStartPointGroup  UINT8
}
SecureSensingParam-Type2 ::= SEQUENCE {
    obfuscationNumber   UINT8,
    obfuscationEventNumber  UINT8,
    obfuscationSeq  SEQUENCE (SIZE(1.. 65535)) OF UINT16
}
-- ASN1STOP
```

:::{div}
:class: standard-paragraph

<p>SensingConfiguration由 G节点发送给 T节点,用于进行感知配置。sensingConfigIndex用于指示感知信号配置索引;sensFrequencyBandIndication指示感知信号所在频带的信道号;sensFrequencyBandwidthIndication指示从sensFrequencyBandIndication指示的信道开始,向频率增大的方向覆盖的信道的个数;sensResourcePeriod指示感知信号的测量周期(以 TTI为单位),为感知事件的周期;sensResourceOnduration指示每个 TTI块内感知信号的持续时间(以无线帧为单位);sensResourceOffset指示感知信号发送的时刻,为每个 TTI块起始感知测量资源的时间偏移量(以符号为单位);measureMode取值1时指示单向测量信号,取值2时指示双向两信号测量模式;sensingEventReport指示一个测量信息上报对应的感知事件的个数;sensingReportTimeUnit用于指示感知测量量上报周期的时间单位,0代表以超帧为单位,1代表以秒为单位,2代表以分为单位,3代表以小时为单位;sensingReportPeriod用于指示感知测量量上报周期的时间单位个数,感知测量量上报周期为上报周期的时间单位$\times$时间单位个数;sensCpConfig指示感知信号所在 TTI的测量符号的循环前缀信息;sensResouceMeasurementIndication指示基于感知信号的测量配置信息;在sensResouceMeasurementIndication中,rxTimingMeasure指示需要 进行到 达 时间的测量,以本 地 CP-OFDM 符号的 初始 时间 为 基准;rxAoAMeasure指示需要进行到达角的测量;txAoDMeasure指示需要进行出发角的测量;rxPortCSIMeasure指示需要对端口感知信号进行信道状态信息测量;rxBeamCSIMeasure指示需要对波束感知信号进行信道状态信息测量;rxPortCSIMeasMode指示端口感知信号进行信道状态信息测量的模式,当该值为0时指示测量模式1,当该值不为0时指示测量模式2的信号索引;rxBeamCSIMeasMode指示波束感知信号进行信道状态信息测量的模式,当该值为0时指示测量模式1,当该值不为0时指示测量模式2的信号索引;rxCIRMeasure-FirstPath指示进行信道状态信息测量上报(CIR上报)-以第一径为初始参考;rxCIRMeasure-StrongestPath指示进行信道状态信息测量上报(CIR上报)-以最强径为初始参考;rxAntennaPhaseDiffReport指示进行接收天线相位差信息上报;txAntennaPhaseDiffReport指示进行发送天线相位差信息上报;rangeDopplerMeasure-FirstPath指示进行距离多普勒信息上报-以第一径为初始参考;rangeDopplerMeasure-StrongestPath指示进行距离多普勒信息上报-以最强径为初始参考;sensingTargetReport指示进行感知目标信息上报。sensingDeviceStateReport指示是否允许节点进行感知设备上报,0:优先级低,不允许进行感知设备状态上报;1:优先级高,允许进行感知设备状态上报。posMeasIndication指示在感知测量中是否进行位置测量。posReportPeriod指示位置测量量上报周期,以微秒为单位;当取值为0时,位置测量量为非周期上报;当值为0xFFFFFFFF时,该值无效,在感知测量中不进行位置测量量上报。SecureSensingParam-Type1指示安全感知方式一,obfuscationFunctionNumber指示发射矩阵使用的置乱函数数量,其取值与天线端口数和子载波数有关;obfuscationRandomLength指示配置给每个置乱函数的均匀分布随机数数量;obfuscationRandomNumber指示配置的随机数,用于给所有子载波上的感知信号生成置乱数;obfuscationSamplingStartPointGroup指示置乱函数采样初始时刻。SecureSensingParam-Type2指示安全感知方式二,obfuscationNumber指示给每个感知测量事件配置的置乱数数量,其取值与天线端口数和子载波数有关;obfuscationEventNumber指示配置的置乱数所支持的感知测量事件数量;obfuscationSeq指示配置的置乱数。</p>
