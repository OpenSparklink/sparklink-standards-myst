# 7.5.2.3 G 链路信道反馈消息

:::{div}
:class: figure-code

```asn1
-- ASN1START
GlinkChannelStatusFeedback ::= SEQUENCE {
    xrc-Identifier  XRC-Identifier,
    csi-rs-PortInfo PortInfo-2  OPTIONAL,
    glinkCommonChnStatusFeedback    CommonChannelStatusFeedback,
    lateNonCriticalExtension    OCTET STRING    OPTIONAL,
    nonCriticalExtension    SEQUENCE {} OPTIONAL
}
-- ASN1STOP
```

:::

:::{div}
:class: standard-paragraph

<p>GlinkChannelStatusFeedback由 T节点发送给 G节点,用于向 G节点上报 G链路信道状态信息。</p>

:::

:::{div}
:class: standard-paragraph

<p>该消息包括csi-rs端口信息csi-rs-PortInfo,通用链路状态信息glinkCommonChnStatusFeedback。</p>

:::
