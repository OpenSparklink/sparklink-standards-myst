# 6.1 一般描述

:::{div}
:class: standard-paragraph

<p>同步低时延宽带通信系统物理层向数据链路层提供数据传输服务,具体包括以下功能:</p>

:::

:::{div}
:class: standard-list-block

<ul class="standard-list">
<li><p>——— 传输信息的正确性校验并指示给数据链路层;</p>
</li>
<li><p>——— 传输信息的前向纠错(FEC)编码/解码;</p>
</li>
<li><p>——— 混合自动重传请求(HARQ)软合并;</p>
</li>
<li><p>——— 传输信息到对应的物理资源的速率匹配;</p>
</li>
<li><p>——— 编码后的传输信息到对应的物理资源的映射;</p>
</li>
<li><p>——— 物理层控制信息和物理层数据信息的调制和解调;</p>
</li>
<li><p>——— 频率和时间的同步;</p>
</li>
<li><p>——— 无线特性测量并指示给数据链路层;</p>
</li>
<li><p>——— 多输入多输出天线处理;</p>
</li>
<li><p>——— 波束赋形;</p>
</li>
<li><p>——— 射频处理。</p>
</li></ul>

:::

:::{div}
:class: standard-paragraph

<p>为了实现上述功能,物理层规定了一种基于循环前缀正交频分复用(CP-OFDM)波形和时分双工(TDD)的物理资源和帧结构,并在此基础上规定了物理层链路中传输的物理层信号、物理层控制信息和物理层数据信息的生成和使用物理资源的方法,用于传输物理层信号、物理层控制信息和物理层数据信息的物理层信息块,以及无线特性测量方法。</p>

:::

:::{div}
:class: standard-paragraph

<p>物理层信号使用一系列资源元素的集合传输,这些资源元素不用于承载源于高层的信息。物理层信号包括 G链路物理层信号、T链路物理层信号、附链路物理层信号、直通链路物理层信号。一些类型的物理层信号的规定适用于多种链路类型,对于强调这类物理层信号用于特定类型链路的情况,本文件在该物理层信号的名称前增加“G链路”“T链路”“附链路”“直通链路”等对应链路类型的前缀;对于不产生混淆或无需区分传输链路类型的情况,本文件不加前缀的使用该物理层信号的名称。</p>

:::

:::{div}
:class: standard-paragraph

<p>物理层控制信息使用一系列资源元素的集合传输,用于承载源于高层的控制信息。物理层控制信息包括 G链路物理层控制信息、T链路物理层控制信息、附链路物理层控制信息、直通链路物理层控制信息。</p>

:::

:::{div}
:class: standard-paragraph

<p>物理层数据信息使用一系列资源元素的集合传输,用于承载源于高层的数据信息。其中,源于高层的数据信息包含高层信令。所有类型的物理层数据信息的规定均既适用于 G 链路、T 链路、附链路、直通链路,对于强调这类物理层数据信息用于 G链路或 T 链路的情况,本文件在该物理层数据信息的名称前增加“G链路”或“T链路”“附链路”“直通链路”等对应链路类型的前缀;对于不产生混淆的情况,本文件不加前缀的使用该物理层数据信息的名称。</p>

:::

:::{div}
:class: standard-paragraph

<p>用于实现特定功能,传输多种物理层信号、物理层控制信息、物理层数据信息组合的一系列资源元素的集合称为物理层信息块。</p>

:::

:::{div}
:class: standard-paragraph

<p>除非特别说明,物理层各种时间长度均为基本时间单位 Ts的倍数。基本时间单位$\mathrm{Ts}=1/\mathrm{fs}$,其中物理层基准频率fs为30.72MHz。</p>

:::

:::{div}
:class: standard-paragraph

<p>在本文件中,下标为0的比特,比如$b_{0}$,是比特序列的最低位。一组比特序列按照比特位置从小到大的顺序在空口中传输,最低位最先在空口中传输。在本文件中,如果没有明确指定,描述一组比特序列时最低位在前,最高位在后,比如一个3比特的字段取值为“3”时,从低位到高位依次为110。在本文件中,8个比特组成一个字节。对于多个字节组成的字节序列,按照字节位置从小到大的顺序在空口中传输,最低位置字节最先在空口中传输。</p>

:::
