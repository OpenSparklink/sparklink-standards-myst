# 7.5.3.31 ACK 资源池信息

:::{div}
:class: figure-code

```asn1
-- ASN1START
ACK-Resource ::= SEQUENCE {
    ackTimeResource DedicatedTimeResource,
    freqResourceType2   FreqResourceType2   OPTIONAL,
    channelNumber   ChannelNumber   OPTIONAL,
    ackCombInfo CombInfo-1,
    ackCombOffset   CombOffset-1,
    dmrsSymbolNumber    INTEGER (1..16) OPTIONAL,
    firstStageSymbolNumber  UINT8   OPTIONAL,
    firstStageBits  INTEGER (1..255)    OPTIONAL,
    secondStageBits INTEGER (1..255)    OPTIONAL,
    mcsOffsetFeedbackBits   ENUMERATED {n0,n2,n3,n4,n5,spare3,spare2,spare1} OPTIONAL,
    mcsOffsetAdjustGranularity  ENUMERATED {m1,m2,m4,m8}    OPTIONAL,
    phyIDforRSsequence  PhyIDforRSsequence  OPTIONAL,
    phyIDforScrambling  PhyIDforScrambling  OPTIONAL,
    powerOffset PowerOffset OPTIONAL,
    ...
}
-- ASN1STOP
```

:::

:::{div}
:class: standard-paragraph

<p>ACK 资源池信息指示在1个 TTI内的1组用来反馈 ACK 信息的资源,其中,ackTimeResource确定时间域资源,freqResourceType2确定频率域资源,channelNumber确定所在的信道,ackCombInfo和ackCombOffset确定梳齿相关信息。mcsOffsetFeedbackBits用于指示反馈 T 节点 mcs偏移量的比特数。mcsOffsetAdjustGranularity用于指示 MCS偏移量调整的步进值。</p>

:::

:::{div}
:class: standard-paragraph

<p>DedicatedTimeResource确定的符号中,前dmrsSymbolNumber个符号用来传输参考信号,本文件取值为1。当采用两级 HARQ 反馈时,参考信号后的firstStageSymbolNumber个符号用来传输两级HARQ 反馈中第一级反馈的比特信息,剩余的符号用来传输两级 HARQ 反馈中第二级反馈的比特信息,firstStageBits指示第一级反馈的比特数,secondStageBits指示第二级反馈的比特数,如 mcsOffsetFeedbackBits为非零 时,secondStageBits则包 含 mcsOffsetFeedbackBits。当 采用单级 HARQ 反馈时,参考信号后的firstStageSymbolNumber个符号用来传输该单级 HARQ 反馈的比特信息,firstStageSymbolNumber需考虑 mcsOffsetFeedbackBits指示所需占的资源。</p>

:::

:::{div}
:class: standard-paragraph

<p>phyIDforRSsequence用于配置 HARQ 反馈信息的 T-DMRS-C 参考信号序列生成的物理层标识,可选信元。</p>

:::

:::{div}
:class: standard-paragraph

<p>phyIDforScrambling用于配置 HARQ 反馈信息比特加扰的物理层标识,可选信元。</p>

:::

:::{div}
:class: standard-paragraph

<p>powerOffset用于配置 HARQ 反馈信息的功率偏置值,默认值为0。</p>

:::
