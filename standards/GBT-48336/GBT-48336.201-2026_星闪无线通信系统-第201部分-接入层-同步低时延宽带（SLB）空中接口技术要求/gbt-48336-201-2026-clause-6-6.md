# 6.6 位置测量流程

(gbt-48336-201-2026-clause-6-6-1)=
## 6.6.1 概述

:::{div}
:class: standard-paragraph

<p>G节点配置位置锚点、位置标签和位置信息解算节点。G 节点可配置、读取位置锚点的位置信息,位置信息支持绝对位置信息和相对位置信息,其中绝对位置信息指地球经度信息、维度信息和海平面高度信息,相对位置信息指相对于地球某一点的经度偏移信息、维度偏移信息和海平面高度偏移信息。</p>

:::

:::{div}
:class: standard-paragraph

<p>对于位置锚点内容如下。</p>

:::

:::{div}
:class: standard-paragraph

<p>G节点通过 XRC消息配置位置锚点发送位置测量信号的时间资源、端口数量、波束数量、载波、信号带宽和信号序列,其中时间资源具体包括 TTI资源,无线帧资源,无线帧内的符号资源。位置锚点使用 XRC配置的资源发送位置测量信号。</p>

:::

:::{div}
:class: standard-paragraph

<p>G节点通过 XRC消息配置位置锚点发送位置测量信号的资源时,还可通过 XRC消息配置位置锚点测量位置测量信号离开时间,位置锚点根据配置将测量到的位置测量信号离开时间上报给 G节点。</p>

:::

:::{div}
:class: standard-paragraph

<p>G节点通过 XRC消息配置位置锚点接收位置测量信号的时间资源、端口数量、波束数量、载波、信号带宽和信号序列,其中时间资源具体包括 TTI资源,无线帧资源,无线帧内的符号资源。位置锚点使用 XRC配置的资源接收位置测量信号。</p>

:::

:::{div}
:class: standard-paragraph

<p>G节点通过 XRC消息配置位置锚点接收位置测量信号的资源时,还可通过 XRC消息配置位置锚点测量位置测量信号的测量信息,其中测量信息包括到达时间、到达角、出发角、信道状态信息等。位置锚点根据配置将测量到的测量信息上报给 G节点。</p>

:::

:::{div}
:class: standard-paragraph

<p>G节点通过 XRC消息配置位置锚点发送位置测量信号的载波、信号带宽和信号序列,G 节点通过位置测量信号资源指示信息动态指示无线帧资源和无线帧内的符号资源、端口数量和波束数量。位置锚点使用 XRC消息和动态信令指示的资源发送位置测量信号。</p>

:::

:::{div}
:class: standard-paragraph

<p>G节点通过 XRC消息和动态信令指示位置锚点发送位置测量信号的资源时,还可通过 XRC消息配置位置锚点测量位置测量信号的离开时间,位置锚点根据配置将测量到的离开时间上报给 G节点。</p>

:::

:::{div}

(gbt-48336-201-2026-clause-6-6-2)=
## 6.6.2 距离/位置信息测量

(gbt-48336-201-2026-clause-6-6-2-1)=
### 6.6.2.1 通则

:::{div}
:class: standard-paragraph

<p>当 T 节点能力基反馈消息指示 T 节点支持基于 OFDM 的测量/定位时,应支持 RTT 的测距(6.6.2.2),可支持测量组快速定位(6.6.2.3)和基于双向复合信道的测距(6.6.2.4)。</p>

:::

(gbt-48336-201-2026-clause-6-6-2-2)=
### 6.6.2.2 基于 RTT 的测距

:::{div}
:class: standard-paragraph

<p>G节点配置位置锚点和位置标签。</p>

:::

:::{div}
:class: standard-paragraph

<p>对于双向两信号测量,第一位置节点向第二位置节点发送第一测量信号,并根据第一位置测量信号的离开时间 T1和第二位置测量信号的到达时间 T4,计算第一时间差$T_{\mathrm{a}}$,第二位置节点向第一位置节点发送第二测量信号,并根据第一位置测量信号的到达时间 T2 和第二位置测量信号的离开时间T3,计算第二时间差$T_{\mathrm{b}}$,其中 T1、T2、T3和 T4是位置测量信号测量时间与位置测量信号本地参考时间的差。当位置测量信号包括多个基于端口的位置测量信号或多个基于波束的位置测量信号时,T1、T2、T3和 T4应基于多个位置测量信号进行测量。</p>

:::

:::{div}
:class: standard-paragraph

<p>第一位置节点可为 G节点或 T节点。当第一位置节点为 G节点、第二位置节点为 T 节点时,第一测量信号承载于同一个无线帧或不同无线帧的位置测量符号,第二测量信号包含承载于同一个无线帧或不同无线帧的位置测量符号。</p>

:::

:::{div}
:class: standard-paragraph

<p>当第一位置节点和第二位置节点支持发送安全位置测量信号时,第一位置测量信号和第二位置测量信号可以是安全位置测量信号,生成方式见6.2.3.9.2。</p>

:::

:::{div}
:class: standard-paragraph

<p>第一时间差$T_{\mathrm{a}}$ 为第一位置节点发送的第一位置测量信号的第一个测量符号的开端时刻,与第一位置节点接收到第二位置测量信号的第一个测量符号的开端时刻之间的时间间隔;第二时间差$T_{\mathrm{b}}$ 为第二位置节点发送的第二位置测量信号的第一个测量符号的开端时刻,与第二位置节点接收到第一位置测量信号的第一个测量符号的开端时刻之间的时间间隔。第一设备将$T_{\mathrm{a}}$ 发送给位置解算节点,第二设备将$T_{\mathrm{b}}$ 发送给位置解算节点。</p>

:::

:::{div}
:class: standard-paragraph

<p>位置解算节点根据$T_{\mathrm{a}}$ 和$T_{\mathrm{b}}$ 计算第一设备和第二设备的距离,如公式(44)所示。。</p>

:::

(gbt-48336-201-2026-equation-44)=
```{math}
D=\frac{T_a-T_b}{2}C=\frac{(t_4-t_1)-(t_3-t_2)}2C\tag{44}
```

:::{div}
:class: standard-paragraph

<p>式中:</p>

:::

:::{div}
:class: standard-definitions

$C$
: 光速。

:::

:::{div}
:class: standard-paragraph

<p>对于双向三信号测量,第一位置节点根据第一信号的离开时间 T1和第二信号的到达时间 T4,计算第一时间差$T_{\mathrm{a}}$,第二位置节点根据第一信号的到达时间 T2和第二信号的离开时间 T3,计算第二时间差$T_{\mathrm{b}}$;第一位置节点根据第二信号的到达时间 T1和第三信号的离开时间 T5,计算第三时间差$T_{\mathrm{c}}$,第二位置节点根据第二信号的离开时间 T3和第三信号的到达时间 T6,计算第四时间差$T_{\mathrm{d}}$,四个时间差测量量$T_{\mathrm{a}}$、$T_{\mathrm{b}}$、$T_{\mathrm{c}}$ 和$T_{\mathrm{d}}$ 的示意图如图11所示,其中 T1、T2、T3、T4、T5和 T6是位置测量信号测量时间与位置测量信号本地参考时间的差。当位置测量信号包括多个基于端口的位置测量信号或多个基于波束的位置测量信号时,T1、T2、T3、T4、T5和 T6应基于多个位置测量信号进行测量。</p>

:::

```{image} ../../../assets/structured/GBT-48336.201-2026/regions/p0095-figure-01-169.png
:class: source-figure

```

(gbt-48336-201-2026-figure-11)=
:::{div}
:class: standard-caption

<p>图 11　双向三信号的时间差测量量</p>

:::

:::{div}
:class: standard-paragraph

<p>第一设备将$T_{\mathrm{a}}$ 和$T_{\mathrm{c}}$ 发送给位置解算节点,第二设备将$T_{\mathrm{b}}$ 和$T_{\mathrm{d}}$ 发送给位置解算节点。位置解算节点根据$T_{\mathrm{a}}$、$T_{\mathrm{b}}$、$T_{\mathrm{c}}$ 和$T_{\mathrm{d}}$ 计算第一设备和第二设备的距离$D$,如公式(45)所示。</p>

:::

(gbt-48336-201-2026-equation-45)=
```{math}
D=\frac{T_a\times T_d-T_b\times T_c}{T_a+T_d+T_b+T_c}C\tag{45}
```

:::{div}
:class: standard-paragraph

<p>式中:</p>

:::

:::{div}

$C$
: 光速。

:::

:::{div}
:class: standard-paragraph

<p>G节点使用 G链路位置测量信号资源指示信息(第一格式至第三格式)或 XRC消息(位置测量信号配置消息或测量组参数配置消息)为第一测量信号、第二测量信号和/或第三测量信号配置时频资源。</p>

:::

:::{div}
:class: standard-paragraph

<p>G节点与 T节点利用同步信息块的训练信号(STS和FTS)作为第一信号,分别测量第一信号的第一个符号STS的离开时间 T1和到达时间 T2,以及利用接入信息块的训练信号(STS和 FTS)作为第二信号,分别测量第二信号的第一个符号STS的离开时间 T3和到达时间 T4。对于非连续传输下的无连接测量,当 G 节点发送的同步信息块中的 COT 剩余长度字段应设置为0,指示本同步信息块周期为COT的最后一个同步信息块周期,并且本同步信息块周期的最后一个无线帧为 T 节点发送接入信息块的资源。T节点可通过接入信息块的接入信息的接入目的字段,向 G 节点发送无连接测量的请求。</p>

:::

:::{div}
:class: standard-paragraph

<p>G节点将第一时间差$T_{\mathrm{a}}$ 通过 XRC建立消息发送给 T 节点,或者,T 节点将第二时间差$T_{\mathrm{b}}$ 通过 XRC建立完成消息发送给 G节点。G节点或 T节点根据第一时间差$T_{\mathrm{a}}$ 和第二时间差$T_{\mathrm{b}}$ 完成测量距离。</p>

:::

:::{div}
:class: standard-paragraph

<p>T节点接收到 G节点的通信域系统消息 DomainSysInfo-Group2时,根据指示 G 节点通信域的时间信息的domainWallClockTime和 G节点与 T节点之间的飞行时间,确定与 G节点的时间偏移量,向G节点的时间进行时间同步。</p>

:::

(gbt-48336-201-2026-clause-6-6-2-3)=
### 6.6.2.3 测量组快速定位(FLAG)

:::{div}
:class: standard-paragraph

<p>测量组辅助的快速定位(FLAG),使多个位置锚点与多个位置标签建立测量组,通过组播测量方式实现快速定位。按照锚点与标签是否交互测量信号,可分为快速单向定位和快速双向定位。快速单向定位包括下行FLAG(DL-FLAG)和辅助上行的 AUL(AssistantUplink)-FLAG。快速双向定位包括自上行SUL-FLAG(SUL-FLAG)和多锚点对多标签(多对多)的 RTT测距。</p>

:::

(gbt-48336-201-2026-clause-6-6-2-3-1)=
#### 6.6.2.3.1 测量组建立

:::{div}
:class: standard-paragraph

<p>G节点发送测量组建立消息,指示至少一个锚点和/或至少一个标签建立测量组。一个测量组包括测量组ID,多个测量组成员。测量组建立消息中多个测量组成员 PhyID 的排列顺序,指示了多个测量组成员发送测量信号的顺序和发送测量时间差报告的顺序。测量组建立消息中的被测节点位图字段指示测量组中测量成员的锚点或者标签身份,且通过连续的多个比特指示对应的多个测量成员是锚点或标签。在测量组的双向两信号或双向三信号或循环双向三信号的测量信号模式中,测量组内的多个锚点根据测量组建立消息指示的PhyID的排列顺序和测量信号模式,按顺序依次发送测量信号。</p>

:::

:::{div}
:class: standard-paragraph

<p>G节点向已建立连接的标签,发送 XRC重配置消息完成测量组的组播地址(groupcastConfig)的配置。</p>

:::

:::{div}
:class: standard-paragraph

<p>与 G节点未建立连接的标签,可通过初始接入的接入信息的接入目的字段设置为2,向 G 节点发送无连接测量的请求。G节点向标签回复 XRC建立消息,通过 NonConnectMeasConfig字段向发起无连接测量请求的节点发送组播地址(PhyID)和后续发送测量组建立消息和测量组参数配置消息所对应GCI的资源指示(measGroupSetupGCIOffset)。G 节点发送的组播地址对应于一个或多个测量组,且通过测量组建立消息将请求无连接测量的标签包含在组播地址对应的新测量组内。</p>

:::

(gbt-48336-201-2026-clause-6-6-2-3-2)=
#### 6.6.2.3.2 多锚点和多标签的成组辅助快速定位(M2M-FLAG)

:::{div}
:class: standard-paragraph

<p>多个位置锚点和多个位置标签进行位置测量时,G 节点可为锚点或标签,T 节点也可为锚点或标签。多锚点与多标签的 RTT测距流程见图12。</p>

:::

:::{div}
:class: standard-paragraph

<p>G节点发送测量组建立消息,指示至少一个锚点和至少一个标签建立测量组。一个测量组包括测量组ID,多个测量组成员。测量组建立消息中多个测量组成员 PhyID 的排列顺序,指示了多个测量组成员发送测量信号的顺序和发送测量时间差报告的顺序。测量组建立消息中的被测节点位图字段指示测量组中测量成员的锚点或者标签身份,且通过连续的多个比特指示对应的多个测量成员是锚点或标签。在测量组的双向两信号或双向三信号测量模式中,测量组内的多个锚点根据测量组建立消息指示的PhyID 的排列顺序,按顺序依次发送第一位置测量信号;在最后一个锚点发完第一位置测量信号后,测量组内的多个标签再按照PhyID的排列顺序,按顺序依次发送第二位置测量信号;在最后一个标签发完第二位置测量信号后,测量组内的多个锚点再按照顺序,依次发送第三位置测量信号。</p>

:::

:::{div}
:class: standard-paragraph

:class: standard-paragraph

:::

:::{div}
:class: standard-paragraph

:class: standard-paragraph

#### 6.6.2.3.4 自上行-成组辅助快速定位(SUL-FLAG)

:::{div}
:class: standard-paragraph

<p>G节点确定将测量组参数配置消息中的测量模式字段配置为 SUL-FLAG 模式,指示测量组对应的测量模式为SUL-FLAG 模式。SUL-TDOA 测量模式下,测量组的多个测量成员的类型为锚点和标签。</p>

:::

:::{div}
:class: standard-paragraph

<p>在SUL-FLAG中,测量组的多个锚点实现了时频同步,标签发送测量信号,多个锚点分别接收各个标签的测量信号,并按照到达时间差(TimeDifferenceofArrival,TDOA)方式,对标签进行定位。</p>

:::

:::{div}
:class: standard-paragraph

<p>SUL-FLAG的主要步骤如下。</p>

:::

:::{div}
:class: standard-list-block

<ol class="alpha-list" start="1">
<li><p>a) 多锚点执行双向测量(DL-FLAG)。在DL-FLAG 步骤中,G节点发送G链路位置测量信号资源指示信息(GCI第四格式),激活测量组的所有锚点执行双向两信号、双向三信号或者循环双向三信号测量信号模式。测量组的各个标签,基于 DL-FLAG计算得到各自的位置。</p>
</li>
<li><p>b) 针对步骤1的双向三信号或者循环双向三信号,G 节点分别配置和触发先发锚点或全部锚点组播时间差,后发锚点基于接收的时间差计算飞行时间,并向先发锚点定时同步。</p>
</li>
<li><p>c) G节点发送 G链路位置测量信号资源指示信息(GCI第四格式),触发测量组的所有标签,按顺序依次发送测量信号。</p>
</li></ol>

:::

:::{div}
:class: standard-list-block

<ol class="alpha-list" start="4">
<li><p>d) 各个锚点通过测量时间差报告消息,按顺序向解算节点发送各个标签测量信号的 TOA,解算节点基于各锚点报告的 TOA,计算得到各个标签的位置。</p>
</li></ol>

:::

:::{div}
:class: standard-paragraph

<p>步骤a)中,SUL-FLAG宜使用 DL-FLAG进行锚点间同步。G节点在发送测量组建立消息给多个锚点和多个标签后,再发送测量组参数配置消息,配置测量模式为SUL-FLAG,且使能 DL-FLAG 步骤以进行锚点间同步。测量组的多个锚点在通过 DL-FLAG 的双向测量获取到先发锚点的飞行时间后,向测量组的先发锚点进行时频同步。G节点或 T节点可以是测量组的先发锚点。</p>

:::

:::{div}
:class: standard-paragraph

<p>G节点可配置步骤1(DL-FLAG)的先发锚点/全部锚点针对测量组组播发送测量时间差报告消息,用于测量组的标签进行 DL-FLAG位置解算。当测量信号模式字段指示双向三信号时,应配置先发锚点发送测量时间差报告消息;当测量信号模式字段指示循环双向三信号时,则应配置全部锚点发送测量时间差报告消息。</p>

:::

:::{div}
:class: standard-paragraph

<p>在执行完 SUL-FLAG 的 DL-FLAG 的双向测量并在锚点发送测量时间差报告后,G 节点发送G链路位置测量信号资源指示信息 GCI,配置为第四格式,用于触发各标签按照测量组建立消息指示的顺序,依次向测量组的多个锚点发送 T链路测量信号。测量组的各个锚点收到各个标签发送的测量信号之后,按顺序通过测量时间差报告消息向解算节点发送 TOA。</p>

:::

:::{div}
:class: standard-paragraph

<p>当测量模式为SUL-FLAG测量模式,步骤1的锚点之间间隔符号的数量大于或等于1,步骤3的标签之间间隔符号的数量大于或等于0。</p>

:::

(gbt-48336-201-2026-clause-6-6-2-3-5)=
#### 6.6.2.3.5 辅助上行-成组辅助快速定位(AUL-FLAG)

:::{div}
:class: standard-paragraph

<p>G 节点 将 测量 组 参数配置 消 息中的测量 模式 字 段配置 为 辅助 上 行 FLAG(AssistantUplink FLAG,AUL-FLAG)模式,指示测量组对应的测量模式为 AUL-FLAG 模式。测量组内多个测量成员的类型为锚点和标签。</p>

:::

:::{div}
:class: standard-paragraph

<p>在 AUL-FLAG中,测量组包含多个锚点和多个标签。G节点发送测量组参数配置消息,配置测量组的多个标签按顺序发送测量信号,多个锚点不发送测量信号。多个锚点分别接收各个标签的测量信号,并将多个标签的到达时间(TOA),依次通过测量时间差报告消息,发送至测量组内的位置解算节点,由位置解算节点按照到时间差 TDOA 方式对标签进行定位。</p>

:::

:::{div}
:class: standard-paragraph

<p>按照 G节点的 G链路位置测量信号资源指示信息 GCI指示(配置为第四格式),激活测量组的各个标签按照测量组建立消息指示的发送顺序,依次向测量组的多个锚点发送上行测量信号。各个锚点收到各个标签发送的测量信号之后,依次通过测量时间差报告消息向测量组的解算节点,发送测量得到的到达时间 TOA。</p>

### 6.6.2.4 基于双向复合信道的测距

(gbt-48336-201-2026-clause-6-6-2-4-1)=
#### 6.6.2.4.1 跳频测量方法

:::{div}
:class: standard-paragraph

<p>位置标签和位置锚点采用跳频的方式,在多个载波上进行信道估计并生成双向复合信道(计算方法见附录 K),将多个载波的双向复合信道拼接成等效大带宽信道的信道状态信息。</p>

:::

:::{div}
:class: standard-paragraph

<p>G节点配置位置锚点和位置标签。</p>

:::

:::{div}
:class: standard-paragraph

<p>对于基于天线端口的测距:</p>

:::

:::{div}
:class: standard-list-block

<ol class="alpha-list" start="1">
<li><p>a) 第一设备在时间点 T1发送基于其天线端口数$(N_{\mathrm{port}})$的测距信号;</p>
</li>
<li><p>b) 第二设备在相应的时间点 T2接收第一设备发送的基于天线端口的测距信号,并测量每个测距信号对应的$M_{\mathrm{port}}$组信道状态信息(IQ 信息);</p>
</li>
<li><p>c) 第二设备在与 T2间隔一确定时间 T3发送基于其天线端口数$(M_{\mathrm{port}})$的测距信号;</p>
</li>
<li><p>d) 第一设备在与 T1间隔一确定时间 T4接收第二设备发送的基于天线端口的测距信号,并测量每个测距信号对应的$N_{\mathrm{port}}$组信道状态信息(IQ 信息),T3与 T4的数值相等;</p>
</li></ol>

:::

:::{div}
:class: standard-list-block

<ol class="alpha-list" start="5">
<li><p>e) 解算节点根据第二设备测量的$M_{\mathrm{port}}$组信道状态信息(IQ 信息)和第一设备测量的$N_{\mathrm{port}}$组信道状态信息(IQ 信息),对第一设备$N_{\mathrm{port}}$个端口和第二设备$M_{\mathrm{port}}$个端口间的共$N_{\mathrm{port}}\cdot M_{\mathrm{port}}$个双向信道进行复合;</p>
</li>
<li><p>f) 解算节点根据复合信道状态信息解算位置锚点和位置标签的距离信息。</p>
</li></ol>

:::

:::{div}
:class: standard-paragraph

<p>对于基于波束的测距:</p>

:::

:::{div}
:class: standard-list-block

<ol class="alpha-list" start="1">
<li><p>a) 第一设备从时间点 T1开始发送$N_{\mathrm{beam}}$个基于波束的测距信号;</p>
</li>
<li><p>b) 第二设备在相应的时间点 T2接收第一设备发送的基于波束的测距信号,并测量每个测距信号对应的1组信道状态信息(IQ 信息);</p>
</li>
<li><p>c) 第二设备在与 T2间隔一确定时间 T3后发送$N_{\mathrm{beam}}$个基于波束的测距信号,其中每个测距信号需按照第一设备发送的$N_{\mathrm{beam}}$个基于波束的测距信号的时间顺序,与每一个第一设备发送的基于波束的测距信号相匹配,也即,第二设备发送波束测距信号时的多天线处理,与第二设备接收第一设备发送的波束测距信号时的多天线处理相同;</p>
</li>
<li><p>d) 第一设备在与 T1间隔一确定时间 T4后接收第二设备发送的基于波束的测距信号,并测量每个测距信号对应的1组信道状态信息(IQ 信息),T3与 T4的数值相等;</p>
</li>
<li><p>e) 解算节点根据第二设备测量的$N_{\mathrm{beam}}$组信道状态信息(IQ 信息)和第一设备测量的$N_{\mathrm{beam}}$组信道状态信息(IQ 信息),对第一设备和第二设备间匹配的$N_{\mathrm{beam}}$个双向波束信道进行复合;</p>
</li>
<li><p>f) 解算节点根据复合信道状态信息解算位置锚点和位置标签的距离信息;</p>
</li>
<li><p>g) G节点使用位置测量信号资源指示信息或 XRC消息为第一测量信号和第二测量信号配置时频资源。</p>
</li></ol>

(gbt-48336-201-2026-clause-6-6-2-4-2)=
#### 6.6.2.4.2 跳频测量配置

:::{div}
:class: standard-paragraph

<p>G节点配置位置锚点和位置标签。</p>

:::

:::{div}
:class: standard-paragraph

<p>G节点和 T节点在初始工作信道上进行测量配置。G 节点和 T 节点分别发送定位能力查询消息和 T节点定位能力反馈消息进行定位能力交互,再由 G节点根据自身和 T 节点的跳频能力信息,发送位置测量信号配置消息配置跳频测量。</p>

:::

:::{div}
:class: standard-paragraph

<p>G节点配置位置锚点和位置标签跳频测距的参数,包括如下内容。</p>

:::

:::{div}
:class: standard-list-block

<ul class="standard-list">
<li><p>——— 跳频的载波信道号:多基础载波时,指示最低频率的基础载波的信道号。</p>
</li>
<li><p>——— 位置测量信号带宽:各跳的基础载波信道(组)可重叠。</p>
</li>
<li><p>——— 跳频图案:指示第一位置节点和第二位置节点的跳频顺序,包括初始工作信道号和至少一个跳频信道的载波信道号。多基础载波信道时,跳频信道的载波信道号指示最低频率的基础载波的信道号。</p>
</li>
<li><p>——— 位置测量信号的参数,包括端口数量、波束数量、重复次数等。</p>
</li>
<li><p>——— 无线帧结构:无线帧的帧结构(配比)信息、起始时刻、长度。</p>
</li>
<li><p>——— 位置测量符号资源:跳频测量下,跳频信道的测距帧支持全 G测量符号或全 T测量符号,初始工作信道上,测距帧可采用全 G测距符号或全 T 测距符号或当前 TTI/超帧正采用的无线帧结构。</p>
</li>
<li><p>——— 跳频稳定时长$T_{\mathrm{RF}}$:针对跳频,设备从一个基础载波信道(组)切换至另一个基础载波信道(组)且做好发送或接收的准确时,所需要的稳定时长。G节点配置跳频稳定时长时,对于交互位置测量信号的 两 个 设备的 跳 频 稳 定时 长$T_{\mathrm{RF},1}$,$T_{\mathrm{RF},2}$,跳 频 稳 定时 长 应设置 为$\mathbf{T}_{\mathbf{RF}}=\mathrm{max}$$\{T_{\mathrm{RF},1},T_{\mathrm{RF},2}\}\text{。}$</p>
</li>
<li><p>——— 信号发送模式:连续发送或非连续发送。</p>
</li>
<li><p>——— LBT最大窗口期:LBT时长达到 LBT最大窗口期时,G 节点和 T 节点均向下一跳的信道切换,用于避免 G/T节点过长时间在一个信道上 LBT。对 G 节点,如果 LBT 最大窗口期内没有占用信道,则向下一跳的信道切换,对于 T 节点,如果 LBT 最大窗口期内没有检测到 G 节点发送的信号,则向下一跳的信道切换。</p>
</li></ul>

:::

:::{div}
:class: standard-list-block

<ul class="standard-list">
<li><p>——— 位置测量信号生成方式:指示基于 CSI-RS,SRS或PMS中的一种。</p>
</li>
<li><p>——— 子载波分组参数P:G节点根据最大测距范围/反馈量确定的 CSI反馈分组参数。</p>
</li>
<li><p>——— CSI测量:取平均测量模式,测距帧内所有的测距符号的 CSI取平均;或者第$k$ 个符号测量模式,反馈测距帧内第$k$ 个测距符号的 CSI。</p>
</li></ul>

:::

(gbt-48336-201-2026-clause-6-6-2-4-3)=
#### 6.6.2.4.3 跳频测量流程

:::{div}
:class: standard-paragraph

<p>跳频流程包括以下步骤。</p>

:::

:::{div}
:class: standard-list-block

<ol class="alpha-list" start="1">
<li><p>a) 步骤1:位置标签和位置锚点在初始工作信道获取跳频配置。当 G 节点在初始工作信道上发送前导信息时,应将版本信息域设置为00。</p>
</li>
<li><p>b) 步骤2:位置标签和位置锚点在初始工作信道执行测量交互。位置标签和位置锚点测量交互结束后,位置标签和位置锚点按照预先确定的跳频图样跳至第二个信道(组)。</p>
</li>
<li><p>c) 步骤3:位置标签和位置锚点按照跳频参数,切换至第二个信道并再次执行测量交互,并在测量交互之后按照跳频图样跳至下一个信道。跳频过程中,位置标签和位置锚点应按照配置的跳频稳定时长在下一个信道上做好发送/接收准备。如果在该信道中需要进行非连续发送,则在第二个信道上持续执行空闲信道评估,直到接入信道发送前导(即同步信息块SAB和同步信息),或者直到空闲信道评估的时长达到了 G 节点配置的 LBT 最大窗口期时,按跳频图样跳往第三个信道。当 G 节点在跳频工作信道上发送前导信息时,应将版本信息域设置为01,用于指示跳频信道上发送位置测量帧。</p>
</li>
<li><p>d) 步骤4:位置标签和位置锚点按照跳频图样,在最后一个信道上完成测距交互后,切换至初始信道。位置标签和位置锚点将每个信道上测量的 CSI信息反馈至 G节点。</p>
</li></ol>

:::

:::{div}
:class: standard-paragraph

<p>在b)和c)中,测量交互中所有 T节点以 G节点发送的同步信号或位置测量帧作为同步基准信号。</p>

:::

:::{div}
:class: standard-paragraph

<p>每次测量交互中,第一位置节点发送一个或多个连续的位置测量帧,第二位置节点发送一个或多个连续的位置测量帧,连续位置测量帧的个数由XRC消息或前导信息指示。对于初始工作信道上的测量交互,位置测量帧可采用初始工作信道上超帧或 TTI正在采用的无线帧结构,G 节点的位置测量帧为全部由 G节点测量符号构成的无线帧,T节点的位置测量帧为全部由 T 节点测量符号构成的无线帧;</p>

:::

:::{div}
:class: standard-paragraph

<p>对于跳频信道上的测量交互,位置测量帧支持采用一般循环前缀配置和边界循环前缀配置的所有无线帧结构。当基于双向复合信道进行测距时,第一位置节点或第二位置节点发送的位置测量帧内的每个测量符号承载测量信息,用于对侧节点计算相应基础载波对应的信道(组)的信道状态信息。</p>

:::

:::{div}
:class: standard-paragraph

<p>按照跳频图案完成所有信道的跳频测量后,第一位置节点和第二位置节点跳频返回初始工作信道,并使用位置测量信号测量反馈消息反馈测量的 CSI。位置解算节点根据第一位置节点确定的第一信道状态信息和第二位置节点确定的第二信道状态信息,确定对应信道的双向复合信道的信道状态信息。</p>

:::

:::{div}
:class: standard-paragraph

<p>CSI反馈支持全反馈和部分反馈两种方式,其中部分反馈分为均匀反馈和非均匀反馈。</p>

:::

:::{div}
:class: standard-paragraph

<p>对于全反馈模式,每个基础载波的全部有效子载波(160个)的每个子载波反馈一个 CSI复数值(IQ值),其中 DC子载波不反馈。</p>

:::

:::{div}
:class: standard-paragraph

<p>跳频测量过的每个基础载波的信道,都反馈160个有效子载波的CSI及其对应的载波信道号,且基础载波与基础载波之间的间隔子载波不反馈 CSI。其中,载波信道号为每个20MHz基础载波对应的信道号。</p>

:::

:::{div}
:class: standard-paragraph

<p>对于部分反馈,每个基础载波的160个子载波进行分组反馈。G 节点应在测距协商阶段指示CSI反馈的分组参数$P$。对于均匀分组反馈,每个子载波组(160个有效子载波)内的子载波个数$P=$2、4、8,每个子载波组仅反馈一个 CSI复数值(IQ 值),如表16所示。</p>

:::

:::{div}
:class: standard-list-block

<ul class="standard-list">

</li>

</li>
