# 7.5.3.53 T链路信道探测信号配置信息

:::{div}
:class: figure-code

```asn1
-- ASN1START
SRS-Conf ::= SEQUENCE {
    srs-Identity    UINT16,
    newphy-IDforPreConfig   PreConfigPhysID OPTIONAL,
    srs-PortInfo    PortInfo-1  OPTIONAL,
    srs-CombInfo    CombInfo-1  OPTIONAL,
    srs-CombOffset  CombOffset-1    OPTIONAL,
    srs-TimeResource    DedicatedTimeResource   OPTIONAL,
    ttiPeriod   TTiPeriod   OPTIONAL,
    ttiOffset   TTiOffset   OPTIONAL,
    phyIDforRSsequence  PhyIDforRSsequence  OPTIONAL,
    ...
}
-- ASN1STOP
```

:::

:::{div}
:class: standard-paragraph

<p>当 GCI指示“T链路信道探测信号配置信息SRS”时,该SRS信息所在 TTI计算如下。</p>

:::

:::{div}
:class: standard-paragraph

<p>当前 TTI满足 mod((当前 TTI顺序号-GCI所在 TTI顺序号$),\mathrm{TTiPeriod})=\mathrm{TTiOffset}$时,或当TTiPeriod等于0且当前 TTI满足(当前 TTI顺序号-GCI所在 TTI顺序号$)=\mathrm{TTiOffset}$时,T节点使用SRS-Conf配置的资源发送 T链路信道探测信息参考信号,当ttiPeriod不配置时,默认取值为0;当ttiOffset不配置时,默认取值为0。DedicatedTimeResource指示 TTI中的符号资源。srs-Identity为当前SRS配置标识,可被物理层预配置调度激活去激活信息指示和调度。</p>

:::

:::{div}
:class: standard-paragraph

<p>当删除SRS相关配置时,只需要提供SRC配置标识信息srs-Identity即可。</p>

:::

:::{div}
:class: standard-paragraph

<p>针对 T链路信道探测信号梳齿集合信息srs-CombInfo和 T链路信道探测信号梳齿偏移序号信息srs-CombOffset,当子载波编号满足$\mathrm{mod}(\#\mathrm{subcarrier},\mathrm{srs}-\mathrm{CombInfo})=\mathrm{mod}(\mathrm{srs}-\mathrm{CombOffset},\mathrm{srs}-$CombInfo)时,该子载波发送 T链路信道探测信息参考信号。</p>

:::

:::{div}
:class: standard-paragraph

<p>若未配置newphy-IDforPreConfig,则需要配置。</p>

:::

:::{div}
:class: standard-paragraph

<p>phyIDforRSsequence用于配置SRS参考信号序列生成的物理层标识,可选信元。若未配置时,则可配置。</p>

:::
