# 7.5.2.34 测量组建立消息

:::{div}
:class: figure-code

```asn1
-- ASN1START
MeasurementGroupEstablishment ::= SEQUENCE {
    xrc-Identifier  XRC-Identifier,
    groupcastPhyID  UINT24,
    measGroupID UINT8,
    measMemberPhyID SEQUENCE (SIZE(0..4095)) OF UINT24,
    measuredMemberBitmap    BIT STRING (SIZE (0..4095)),
    nodePositioningCoordinates  SEQUENCE (SIZE(0..255)) OF NodePositioningCoordinates
OPTIONAL,   -- Need OR
    lateNonCriticalExtension    OCTET STRING    OPTIONAL,
    nonCriticalExtension    SEQUENCE {} OPTIONAL
}
-- ASN1STOP
```

:::

:::{div}
:class: standard-paragraph

<p>MeasurementGroupEstablishment由 G 节点 组播 发 送 给 多 个 T 节点,用 于进行 测量 组 建立。</p>

:::

:::{div}
:class: standard-paragraph

<p>groupcastPhyID指示测量组所有成员节点对应的组播地址 PhyId;measGroupID 为测量组的标识,用于区分不同位置锚点/位置标签构成的测量组;MeasMemberPhyID用于指示每个测量组成员的物理层标识PhyID;measuredMemberBitmap用于指示每个测量组成员的身份是位置锚点或位置标签的位图,当比特设置为1时指示 MeasMemberID中对应顺序索引的测量成员为执行测量的成员锚点,当比特设置为0时指示 MeasMemberID中对应顺序索引的测量成员为被测量的标签,且 measuredMemberBitmap应使用连续的比特指示锚点或者标签;nodePositioningCoordinates用于将各个锚点的位置坐标发送给标签。</p>

:::
