# 7.5.3.111 逻辑信道配置信息

:::{div}
:class: figure-code

```asn1
-- ASN1START
DomainLogicalChannelConfig ::= SEQUENCE {
    logicalchannelToAddModList-Tlink    LogicalChannelConfigList OPTIONAL,
    logicalchannelToAddModList-Glink    LogicalChannelConfigList OPTIONAL,
    logicalchannelToReleaseList-Tlink LogicalChannelConfigList  OPTIONAL,
    logicalchannelToReleaseList-Glink LogicalChannelConfigList  OPTIONAL,
    ...
}
LogicalChannelConfigList ::= SEQUENCE (SIZE(1..32)) OF LogicalChannelConfig
LogicalChannelConfig ::= SEQUENCE {
    logicalchannelidentity  LogicalChannelIdentity,
    sps-XRC-Identity    SPS-Identity    OPTIONAL,   --Need OR
    qosInfoList XQIList OPTIONAL,
    applicationInfoList SEQUENCE (SIZE(1..8)) OF AID    OPTIONAL,   --Need OR
    lc-Config   LC-Config   OPTIONAL,
    mac-Config  MAC-Config  OPTIONAL,
    mic-length  BIT16   OPTIONAL,
    ...
}
LogicalChannelIdentity ::= UINT5
-- ASN1STOP
```

:::

:::{div}
:class: standard-paragraph

<p>DomainLogicalchannelConfig用于逻辑信道配置的配置,包括添加、修改、释放等。当同时包含添加和删除操作时,T节点宜先进行删除操作,再进行添加操作。其中 LogicalChannelConfig中包含逻辑信道标识logicalchannelidentity,逻辑信道中数据的 QoS信息 qosInfoList和应用信息applicationInfoList,逻辑链路层相关配置lc-Config。逻辑信道配置中还包含sps-XRC-Identity用于指示与逻辑信道对应的SPS资源的标识。mic-length用于配置当前逻辑信道所使用的 MIC长度,为可选配置,默认使用securityContextRequest中配置的参数。</p>

:::

:::{div}
:class: standard-paragraph

<p>MAC层配置信息 mac-Config包括逻辑信道优先级priority,其中1为优先级最高。prioritisedBitSize指示逻辑信道首次数据封装的最大数据量,单位为字节,默认值为invalid。当配置为invalid时,数据封装量无限制。</p>

:::
