# 7.5.3.55 T链路调度请求配置信息

:::{div}
:class: figure-code

```asn1
-- ASN1START
SR-Config ::= SEQUENCE {
    sr-CombInfo CombInfo-1,
    sr-CombOffset   CombOffset-1,
    sr-TimeResource DedicatedTimeResource,
    ttiPeriod   TTiPeriod   OPTIONAL,
    ttiOffset   TTiOffset   OPTIONAL,
    trafficParamList    SEQUENCE (SIZE (1..32)) OF TrafficParamConf OPTIONAL, --
NEED OR
    phyIDforRSsequence  PhyIDforRSsequence  OPTIONAL,
    phyIDforScrambling  PhyIDforScrambling  OPTIONAL,
    powerOffset PowerOffset OPTIONAL,
    ...
}
TrafficParamConf ::= SEQUENCE {
    remainLatency   ENUMERATED {n0, n1, n2, n4, n6, n8, n10, n12,
    n14, n16, n18, n20, n22, n24, n26, n28},
    tlinkDataSizeIndex  BIT4,
    highReliabilityFlag BoolType    OPTIONAL,
    ...
}
-- ASN1STOP
```

:::

:::{div}
:class: standard-paragraph

<p>T链路调度请求资源(SR资源)所在 TTI计算如下。</p>

:::

:::{div}
:class: standard-paragraph

<p>对于无 RAB 的 TTI,其满足 mod((当前 TTI顺序号-SAB 所在 TTI顺序号$),\mathrm{TTiPeriod})=$TTiOffset时,T节点使用SR-Config配置的资源发送 T 链路调度请求(参考6.2.4.10.4),当ttiPeriod不配置时,默认取值为1;当ttiOffset不配置时,默认取值为0。DedicatedTimeResource指示 TTI中的符号资源。</p>

:::

:::{div}
:class: standard-paragraph

<p>针对 T链路调度请求梳齿集合信息sr-CombInfo和 T 链路调度请求梳齿偏移序号信息sr-CombOffset,当子载波编号满足$\mathrm{mod}(\#\mathrm{subcarrier},\mathrm{sr}-\mathrm{CombInfo})=\mathrm{mod}(\mathrm{sr}-\mathrm{CombOffset},\mathrm{sr}-\mathrm{CombInfo})$时,该子载波发送 T链路调度请求信息。</p>

:::

:::{div}
:class: standard-paragraph

<p>trafficParamList用于配置 T节点发送SR请求时携带关于 T链路数据的更多指示信息,为可选配置。当不配置时,6.2.4.10.4调度指示信息中的5比特无意义。当配置时,最多可配置32个 TrafficParamConf表项,T节点使用6.2.4.10.4调度指示信息中的5比特指示配置项索引号,取值范围为$0\sim 31$,0指示第一个 TrafficParamConf表项,1指示第二个 TrafficParamConf表项,以此类推。TrafficParamConf信元包含 T链路数据的时延余量信息remainLatency,单位为毫秒,n0指示对应 T 链路数据不紧急,n1指示对应 T 链路数据时延余量为1ms,n2指示对应 T 链路数据时延余量为2ms,n4指示对应 T链路数据时延余量为4ms,以此类推。tlinkDataSizeIndex指示待调度 T 链路数据的数据量范围索引,取值范围为$0\sim 15$,通过$(2\times \mathrm{tlinkDataSizeIndex}+1)$计算结果并用于指示表17中对应索引号。比如当tlinkDataSizeIndex等于3时,指示表17中对应数据量索引为7。highReliabilityFlag指示当前索引号对应的待发数据是否为高可靠数据,默认为false。</p>

:::

:::{div}
:class: standard-paragraph

<p>phyIDforRSsequence用于配置调度请求信息的 T-DMRS-C 信号序列生成的物理层标识,可选信元。</p>

:::

:::{div}
:class: standard-paragraph

<p>phyIDforScrambling用于配置调度请求信息比特加扰的物理层标识,可选信元。</p>

:::

:::{div}
:class: standard-paragraph

<p>powerOffset用于配置SR调度请求信息的功率偏置值,默认值为0。</p>

:::
