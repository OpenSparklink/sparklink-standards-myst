# 7.5.3.79 目标接收功率配置信息

:::{div}
:class: figure-code

```asn1
-- ASN1START
P0-NominalConfig ::= SEQUENCE {
    rach-P0-NominalConfig   P0-NominalValue OPTIONAL,
    srs-P0-NominalConfig    P0-NominalValue OPTIONAL,
    ack-P0-NominalConfig    P0-NominalValue OPTIONAL,
    sr-P0-NominalConfig P0-NominalValue OPTIONAL,
    cqi-P0-NominalConfig    P0-NominalValue OPTIONAL,
    data-Class1-P0-NominalConfig    P0-NominalValue OPTIONAL,
    data-Class2-P0-NominalConfig    P0-NominalValue OPTIONAL,
    gLinkReferenceSignalPower   INTEGER (-126..127) OPTIONAL,
    rxP0NominalConfig   P0-NominalValue OPTIONAL,
    ...
}
-- ASN1STOP
```

:::

:::{div}
:class: standard-paragraph

<p>rxP0NominalConfig用于统一指示 T 链路信号 或 数据的 目 标接收功率 值,包 括 RACH/SRS/ACK/SR/CQI信号,以及 T链路第一类或第二类数据。当配置特定的 T 链路信号或数据的目标接收功率值时(比如配置rach-P0-NominalConfig),在发送该信号或数据时,参考对应的目标接收功率值;当不配置特定的 T 链路信号或数据的目标接收功率值时,参考rxP0NominalConfig指示的目标接收功率值。</p>

:::

:::{div}
:class: standard-paragraph

<p>gLinkReferenceSignalPower为 G链路参考信号发射功率,单位为dBm/基础载波。发送功率具体取值范围应符合当地法规要求。</p>

:::
