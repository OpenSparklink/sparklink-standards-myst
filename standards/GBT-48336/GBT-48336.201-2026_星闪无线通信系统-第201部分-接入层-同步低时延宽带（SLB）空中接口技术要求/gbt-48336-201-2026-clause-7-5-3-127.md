# 7.5.3.127 TTI周期、TTI偏移值

:::{div}
:class: figure-code

```asn1
-- ASN1START
TTiPeriod ::= UINT8
TTiOffset ::= INTEGER (0..254)
-- ASN1STOP
```

:::

:::{div}
:class: standard-paragraph

<p>在一个通信域内,TTiPeriod表示整数个 TTI时长的时间周期,当其等于0时表示非周期,即单次。</p>

:::

:::{div}
:class: standard-paragraph

<p>TTiOffset表示在 一 个 TTiPeriod 内 的 偏 移 量,以 TTI时 长为 颗 粒 度,当 TTiPeriod 取 值 非 零 时,TTiOffset取值小于 TTiPeriod。</p>

:::
