# 7.5.3.86 G 链路状态反馈资源配置信息

:::{div}
:class: figure-code

```asn1
-- ASN1START
GlinkChannelStatusFeedbackResource ::= SEQUENCE {
    dedicatedTimeResource   DedicatedTimeResource,
    freqResourceType2   FreqResourceType2   OPTIONAL,
    channelNumber   ChannelNumber   OPTIONAL,
    superframePeriod    SuperframePeriod,
    superframeOffset    SuperframeOffset,
    modulation  SR-Modulation,
    lateNonCriticalExtension    OCTET STRING    OPTIONAL,
    nonCriticalExtension    SEQUENCE {} OPTIONAL
}
-- ASN1STOP
```

:::

:::{div}
:class: standard-paragraph

<p>当前超帧号满足 mod(超帧号$,\mathrm{Su}p\mathrm{erframePeriod})=\mathrm{Su}p\mathrm{erframeOffset}$时,T 节点使用 GlinkChannelStatusFeedbackResource配置的资源发送 GlinkChannelStatusFeedback消息,DedicatedTimeResource指示超帧中的符号资源,modulation表示反馈时采用的调制方式。</p>

:::
