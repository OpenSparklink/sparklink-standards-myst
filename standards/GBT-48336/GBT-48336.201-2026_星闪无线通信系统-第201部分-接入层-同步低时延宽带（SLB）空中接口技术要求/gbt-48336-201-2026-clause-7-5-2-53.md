# 7.5.2.53 超宽带脉冲测量行为指示消息

:::{div}
:class: figure-code

```asn1
-- ASN1START
SLPMeasBehavioralIndicator ::= SEQUENCE {
    xrc-Identifier  XRC-Identifier,
    sLPMeasConfigIndex  UINT8,
    activeSignalingFrameNumber UINT30,
    sLPMeasBehavioralConfiguration  UINT8,
    lateNonCriticalExtension    OCTET STRING    OPTIONAL,
    nonCriticalExtension    SEQUENCE {} OPTIONAL
}
-- ASN1STOP
```

:::

:::{div}
:class: standard-paragraph

<p>SLPMeasBehavioralIndicator由 G 节点发 送 给 T 节点,用 于 指示超宽带脉冲测量 行 为。</p>

:::

:::{div}
:class: standard-paragraph

<p>sLPMeasConfigIndex用于指示测量信号配置索引;activeSignalingFrameNumber指示启动测量生效时间,以无线帧表达;sLPMeasBehavioralConfiguration用于指示超宽带脉冲测量行为指示配置,其中,0:从启动测量生效时间重新开始执行超宽带脉冲测量,原有时间资源配置失效。当该启动测量生效时间指示的时间是过去时间时,被配置节点应根据该组信令计算后续的测量事件组的起始时间,并执行后续测量事件组的测量;1:超宽带脉冲测量终止,释放超宽带脉冲测量信号配置;2:超宽带脉冲测量停止,不释放超宽带脉冲测量信号配置。</p>

:::
