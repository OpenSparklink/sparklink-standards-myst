# 7.5.3.97 T节点信道测量配置信息

:::{div}
:class: figure-code

```asn1
-- ASN1START
Meas-ReportConfig ::= SEQUENCE {
    measreportConfigToRemoveList    SEQUENCE (SIZE(1..255)) OF MeasReportId OPTIONAL,
    measreportConfigToAddList   SEQUENCE (SIZE(1..255)) OF MeasReportConfig-IEs OPTIONAL,
    ...
}
MeasReportConfig-IEs ::= SEQUENCE {
    measReportId    MeasReportId,
    measConfig-TSpecific    MeasConfig-TSpecific,
    reportConfig    CHOICE {
    periodical  PeriodicalReportConfig,
    eventTriggered  EventTriggerConfig
    }
}
MeasReportId ::= INTEGER (1..255)
-- ASN1STOP
```

:::

:::{div}
:class: standard-paragraph

<p>Meas-ReportConfig由 G节点发送给 T节点,用于 T节点进行信道测量与上报相关配置。Meas-ReportConfig-IEs包含测量报告标识 measReportId、测量配置 measConfig-TSpecific和上报配置re-portConfig。</p>

:::

:::{div}
:class: standard-paragraph

<p>reportConfig主要配置上报类型,包括周期性上报periodical或事件触发类上报eventTriggered。</p>

:::
