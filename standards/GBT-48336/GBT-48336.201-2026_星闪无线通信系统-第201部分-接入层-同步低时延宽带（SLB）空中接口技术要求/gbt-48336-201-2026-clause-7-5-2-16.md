# 7.5.2.16 组密钥请求消息

:::{div}
:class: figure-code

```asn1
-- ASN1START
SecurityConfigGroupRequest ::= SEQUENCE {
    xrc-Identifier  XRC-Identifier,
    newSecurityContextID    SecurityContextID,
    lateNonCriticalExtension    OCTET STRING    OPTIONAL,
    nonCriticalExtension    SEQUENCE {} OPTIONAL
}
-- ASN1STOP
```

:::

:::{div}
:class: standard-paragraph

<p>由 T节点发送给 G节点,用于请求组播密钥。其中newSecurityContextID是由 AssociationSetup-NonSec消息所配置的安全上下文的临时标识。</p>

:::
