# 7.5.3.21 时间同步指示信息

:::{div}
:class: figure-code

```asn1
-- ASN1START
TimeDomainSyncIndication ::= SEQUENCE {
    timeDomainSync-Value    TimeDomainSync-Value,
    timeDomainSyncEnable    SuperframeIndex,
    ...
}
-- ASN1STOP
```

:::

:::{div}
:class: standard-paragraph

<p>timeDomainSync-Value指示G节点Ts为单位进行时间调整的调整量;timeDomainSyncEnable指示 G节点发送该 XRC消息所在的超帧之后进行时间调整的超帧的编号,在该超帧之前,G 节点仍旧使用未进行调整的时间信息进行数据传输。</p>

:::
