# 9.3.5 机密性和完整性保护

(gbt-48336-201-2026-clause-9-3-5-1)=
## 9.3.5.1 通则

:::{div}
:class: standard-paragraph

<p>信令面的完整性保护应开启。信令面的加密保护应开启。用户面的加密保护应开启,用户面的完整性保护是否开启和业务类型相关。状态报告PDU 的完整性保护应开启,头压缩反馈 PDU 的加密保护和完整性保护应开启。信令面处理 XRC消息;控制面处理链路控制层控制类型PDU;用户面处理上层数据,例如业务数据。</p>

:::

:::{div}
:class: standard-paragraph

<p>当选择加密算法和完整性保护算法时,加密流程和完整性保护流程顺序为:先执行加密流程,然后对加密后的密文执行完整性保护。</p>

:::

### 9.3.5.4.2 GIA2(ZUC)

:::{div}

<p>GIA2是基于128比特的ZUC(按 GB/T33133.3—2021)。</p>

:::

:class: standard-paragraph

<p>ZUC所需要的128比特的$\mathrm{IV}(\mathrm{IV}[0]||\mathrm{IV}[1]||\ldots ||\mathrm{IV}[15],$其中$\mathrm{IV}[i](0\leq i\leq 15)$为字节)构建如下:</p>

:::

```text
IV[0]=GFN[0], IV[1]=GFN[1],
IV[2]=GFN[2], IV[3]=GFN[3],
IV[4]=逻辑信道标识[低5位]预留字段[高3位],
IV[5]=预留字段[低7位]0,
IV[6]=0x00, IV[7]=0x00,
IV[8]=IV[0]⊕(链路方向标识<<7), IV[9]=IV[1],
IV[10]=IV[2], IV[11]=IV[3],
IV[12]=IV[4], IV[13]=IV[5],
```
```text
IV[14]=IV[6]⊕(链路方向标识<<7), IV[15]=IV[7]。
```

:::{admonition} 注
:class: note

<p>&lt;&lt;表示左移位操作。</p>

:::

:::{div}
:class: standard-paragraph

<p>截取输出的高位32比特作为 MIC。</p>

## 9.3.5.5 GFN 维护机制

(gbt-48336-201-2026-clause-9-3-5-5-1)=
### 9.3.5.5.1 单播 GFN 维护机制

:::{div}
:class: standard-paragraph

<p>GFN 是单播时密码算法输入中的新鲜性参数中的一部分。HFN 不需要传输,由 G 节点和 T 节点各自在本地维护。</p>

:::

:::{div}
:class: standard-paragraph

<p>根据 GFN 的用途和链路方向,G节点和 T节点需要维护六类 GFN,分别是用于信令面 T 链路的GFN.su、用于信令面 G链路的 GFN.sd、用于用户面 T链路的 GFN.uu、用于用户面 G 链路的 GFN.ud、用于控制面 T链路的 GFN.cu、用于控制面 G链路的 GFN.cd。</p>

:::

:::{div}
:class: standard-paragraph

<p>生成安全上下文后,GFN 初始化为0。连接断开后,G节点和 T节点应将 GFN 作为安全上下文的一部分保存。</p>

:::

:::{admonition} 注
:class: note

<p>连接建立时,GFN 可能不是从0开始。</p>

:::

(gbt-48336-201-2026-clause-9-3-5-5-2)=
### 9.3.5.5.2 组播 GGFN 维护机制

:::{div}
:class: standard-paragraph

<p>GGFN 是组播时密码算法输入中的新鲜性参数中的一部分。GHFN 不需要传输,由 G 节点和T节点各自在本地维护。</p>

:::

:::{div}
:class: standard-paragraph

<p>GGFN 只有 G链路方向。根据 GGFN 的用途,G节点和 T节点需要维护两个 GGFN,分别是用于信令面 G链路的 GGFN.sd和用于用户面 G链路的 GGFN.ud。</p>

:::

:::{div}
:class: standard-paragraph

<p>生成组密钥 GK 后,GGFN 初始化为0。连接断开后,G 节点和 T 节点应将 GGFN 作为安全上下文的一部分保存。</p>

:::

:::{admonition} 注
:class: note

<p>连接建立时,GGFN 可能不是从0开始。</p>

:::
