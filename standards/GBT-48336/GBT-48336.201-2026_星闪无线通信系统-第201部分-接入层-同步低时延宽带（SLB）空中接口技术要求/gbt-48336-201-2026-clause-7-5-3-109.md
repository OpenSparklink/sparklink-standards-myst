# 7.5.3.109 上层地址类型信息

:::{div}
:class: figure-code

```asn1
-- ASN1START
AddressTypeInfo ::= SEQUENCE {
    addressTypeBitmap   BIT8,
    macAddress  MACAddress  OPTIONAL,
    ...
}
-- ASN1STOP
```

:::

:::{div}
:class: standard-paragraph

<p>addressTypeBitmap为1字节比特位图,比特0指示 MAC地址,其他比特位预留。</p>

:::

:::{div}
:class: standard-paragraph

<p>macAddress指示6字节 MAC地址。</p>

:::
