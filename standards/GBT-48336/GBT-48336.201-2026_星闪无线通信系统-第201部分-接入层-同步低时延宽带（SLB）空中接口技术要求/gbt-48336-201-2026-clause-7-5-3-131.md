# 7.5.3.131 无连接测量配置信息

:::{div}
:class: figure-code

```asn1
-- ASN1START
NonConnectMeasConfig ::= SEQUENCE {
    groupcastPhyID  UINT24,
    measGroupSetupGCIOffset UINT8,
    ...
}
-- ASN1STOP
```

:::

:::{div}
:class: standard-paragraph

<p>measGroupPhyId指示由 G节点为测量组的测量成员节点(位置锚点和位置标签)配置的组播地址PhyId,用于对 G节点调度测量组建立消息和测量组参数配置消息的 GCI进行接收;measGroupSetupGCIOffset指示 G节点为请求无连接测量的节点发送调度测量组建立消息和测量参数配置消息的GCI的时间偏移量,以 TTI为单位,在非连续传输时只计算实际占用信道的有效时间,不包含竞争信道的时间。</p>

:::
