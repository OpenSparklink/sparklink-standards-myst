# 7.5.2.57 超宽带脉冲代理感知反馈消息

:::{div}
:class: figure-code

```asn1
-- ASN1START
SLPSensingByProxyFeedback ::= SEQUENCE {
    xrc-Identifier  XRC-Identifier,
    slpsensingByProxyIndex  UINT8,
    slpsensingProcedureIndex    UINT16,
    slpsensingByProxyState  UINT8,
    slpsensingReport1   BIT32,
    slpsensingReport2   BIT32,
    slpsensingBandwidth1    UINT8,
    slpsensingBandwidth2    UINT8,
    lateNonCriticalExtension    OCTET STRING    OPTIONAL,
    nonCriticalExtension    SEQUENCE {} OPTIONAL
}
-- ASN1STOP
```

:::

:::{div}
:class: standard-paragraph

<p>SLPSensingByProxyFeedback由 G 节点发送给 T 节点,用于向 T 节点进行超宽带脉冲代理感知反馈。slpsensingByProxyIndex用于指示超宽带脉冲代理感知流程索引。slpsensingByProxyState用于指示超宽带脉冲代理感知流程状态,标识节点是否接受该超宽带脉冲代理感知请求。0:接受代理感知请求;1:拒绝代理感知请求;2:拒绝,并发送正在进行的感知流程索引及配置;其他数值预留。slp-sensingProcedureIndex用于指示正在进行的超宽带脉冲感知流程,每8比特取值对应一个超宽带脉冲感知流程索引,当取值为0xFF时,指示对应的超宽带脉冲感知流程索引无效。slpsensingReport1使用位图的方式指示超宽带脉冲代理感知测量量1,当比特位为0时,不反馈相应的超宽带脉冲感知测量量,当比特位为1时,反馈相应的超宽带脉冲感知测量量。当超宽带脉冲代理感知状态指示字段取值为1时,超宽带脉冲代理感知测量量1为发送超宽带脉冲代理感知反馈的节点建议提供的超宽带脉冲代理感知测量量;当超宽带脉冲代理感知状态指示字段取值为2时,超宽带脉冲代理感知测量量1为超宽带脉冲感知流程索引字段高8比特指示的感知流程索引对应的超宽带脉冲代理感知测量量。比特0:AoA 测量上报;比特1:AoD测量上报;比特2:信道状态信息测量上报(载波IQ 信息上报);比特3:信道状态信息测量上报(CIR上报)-以第一径为初始参考;比特4:信道状态信息测量上报 (CIR 上报)-以最强径为初始参考;比特5:预留;比特6:预留;比特7:接收天线相位差信息上报;比特8:发送天线相位差信息上报;比特9:距离多普勒信息上报-以第一径为初始参考;比特10:距离多普勒信息上报-以最强径为初始参考;比特11:预留;比特12:目标信息上报;比特13:预留;比特14:预留;比特15:预留;比特16:不进行测量上报;其他比特预留。slpsensingReport2使用位图的方式指示超宽带脉冲代理感知测量量,当比特位为0时,不反馈相应的超宽带脉冲感知测量量,当比特位为1时,反馈相应的超宽带脉冲感知测量量。当超宽带脉冲代理感知状态指示字段取值为1时,超宽带脉冲代理感知测量量2字段无效;当超宽带脉冲代理感知状态指示字段取值为2时,超宽带脉冲代理感知测量量2为感知流程索引字段低8比特指示的超宽带脉冲感知流程索引对应的超宽带脉冲代理感知测量量。slpsensingBandwidth1用于指示超宽带脉冲代理感知中,建议的超宽带脉冲感知带宽。字段数值+1。当超宽带脉冲代理感知状态指示字段取值为1时,超宽带脉冲代理感知带宽1为发送超宽带脉冲代理感知反馈的节点建议提供的超宽带脉冲代理感知带宽;当超宽带脉冲代理感知状态指示字段取值为2时,超宽带脉冲代理感知带宽1为超宽带脉冲感知流程索引字段高8比特指示的感知流程索引对应的超宽带脉冲代理感知带宽。slpsensingBandwidth2用于指示超宽带脉冲代理感知中,建议的超宽带脉冲感知带宽。字段数值+1。当超宽带脉冲代理感知状态指示字段取值为1时,超宽带脉冲代理感知带宽2字段无效;当超宽带脉冲代理感知状态指示字段取值为2时,超宽带脉冲代理感知带宽2为超宽带脉冲感知流程索引字段低8比特指示的感知流程索引对应的超宽带脉冲代理感知带宽。</p>

:::
