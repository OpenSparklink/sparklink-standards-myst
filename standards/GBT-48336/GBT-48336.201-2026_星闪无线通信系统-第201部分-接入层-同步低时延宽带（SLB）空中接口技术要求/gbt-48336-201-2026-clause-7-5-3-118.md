# 7.5.3.118 多频段能力指示信息

:::{div}
:class: figure-code

```asn1
-- ASN1START
MultiBandCap ::= SEQUENCE {
    oneBandCapList  SEQUENCE (SIZE (1..16)) OF OneBandCap,
    ...
}
OneBandCap ::= SEQUENCE {
    bandIdx BandIndex,
    maxBccNum   MaxBccNumCap,
    maxMeasureBandwidthCap  MaxBandwidthCap OPTIONAL,
    nonContinousDual80MCap  BoolType    OPTIONAL,
    ...
}
-- ASN1STOP
```

:::

:::{div}
:class: standard-paragraph

<p>MultiBandCap指示多频段能力。oneBandCapList指示节点支持的一到多个频段能力信息。ban-dIdx指示频段索引号;maxBccNum 指示bandIdx所指频段内用于数据通信的最大基础载波数量;max-MeasureBandwidthCap用于指示 bandIdx所指频段上的最大测量带宽能力。若当前频段带宽大于160M,可通过nonContinousDual80MCap指示在该频段内是否支持两个非连续80M 带宽的多载波工作模式。</p>

:::
