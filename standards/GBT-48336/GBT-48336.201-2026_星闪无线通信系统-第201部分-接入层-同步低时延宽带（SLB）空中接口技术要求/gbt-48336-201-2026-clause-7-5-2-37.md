# 7.5.2.37 感知流程请求消息

:::{div}
:class: figure-code

```asn1
-- ASN1START
SensingProcedureRequest ::= SEQUENCE {
    xrc-Identifier  XRC-Identifier,
    sensingProcedureRequest SEQUENCE (SIZE(1..256)) OF SensingRequestItem   OPTIONAL, -- Need OR
    lateNonCriticalExtension OCTET STRING   OPTIONAL,
    nonCriticalExtension    SEQUENCE {} OPTIONAL
}
SensingRequestItem ::= SEQUENCE {
    sensingProcedureRequestIndex    UINT8,
    sensingRequestReport    BIT32,
    sensingRequestReportTimeUnit    UINT2,
    sensingRequestReportPeriod  UINT16,
    sensingRequestBandwidth UINT8,
    sensingRequestChannel   UINT8,
    ...
}
-- ASN1STOP
```

:::

:::{div}
:class: standard-paragraph

<p>SensingProcedureRequest由 T节点发送给 G节点,用于请求 G节点进行感知。其中,sensingProcedureRequestIndex用于指示请求感知流程索引;sensingRequestReport用于使用位图的方式指示请求感知测量量,当比特位为0时,不请求相应的感知测量量,当比特位为1时,请求相应的感知测量量。</p>

:::

:::{div}
:class: standard-paragraph

<p>sensingRequestReportTimeUnit用于指示感知测量量上报周期的时间单位,0代表以超帧为单位,1代表以秒为单位,2代表以分为单位,3代表以小时为单位;sensingRequestReportPeriod用于指示感知测量量上报周期的时间单位个数,感知测量量上报周期为上报周期的时间单位*时间单位个数;sensingRequestBandwidth用于指示请求感知带宽;sensingRequestChannel用于指示请求感知信道。</p>

:::
