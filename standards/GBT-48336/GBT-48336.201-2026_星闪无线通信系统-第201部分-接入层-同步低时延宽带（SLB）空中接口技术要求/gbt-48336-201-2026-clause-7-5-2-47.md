# 7.5.2.47 感知行为指示消息

:::{div}
:class: figure-code

```asn1
-- ASN1START
SensingBehavioralIndicator ::= SEQUENCE {
    xrc-Identifier  XRC-Identifier,
    sensingConfigIndex  UINT8,
    activeSignalingFrameNumber  UINT30,
    sensingBehavioralConfiguration  UINT8,
    lateNonCriticalExtension    OCTET STRING    OPTIONAL,
    nonCriticalExtension    SEQUENCE {} OPTIONAL
}
-- ASN1STOP
```

:::

:::{div}
:class: standard-paragraph

<p>SensingBehavioralIndicator由G节点发送给T节点,用于指示感知测量行为。sensingConfigIndex用于指示感知信号配置索引;activeSignalingFrameNumber指示启动测量生效时间,以无线帧表达;sens-ingBehavioralConfiguration用于指示感知行为指示配置,其中,0:从启动测量生效时间重新开始执行感知测量,原有时间资源配置失效。当该启动测量生效时间指示的时间是过去时间时,被配置节点应根据该组信令计算后续的测量事件组的起始时间,并执行后续测量事件组的测量;1:感知测量终止,释放感知信号配置;2:感知测量停止,不释放感知测量信号配置。</p>

:::
