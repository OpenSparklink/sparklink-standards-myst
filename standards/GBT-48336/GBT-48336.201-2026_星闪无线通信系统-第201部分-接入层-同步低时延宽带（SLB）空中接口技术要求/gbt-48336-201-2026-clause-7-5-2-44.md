# 7.5.2.44 感知配置反馈消息

:::{div}
:class: figure-code

```asn1
-- ASN1START
SensingConfigurationFeedback ::= SEQUENCE {
    xrc-Identifier  XRC-Identifier,
    sensingConfigIndex  UINT8,
    sensingConfigState  UINT8,
    lateNonCriticalExtension    OCTET STRING    OPTIONAL,
    nonCriticalExtension    SEQUENCE {} OPTIONAL
}
-- ASN1STOP
```

:::

:::{div}
:class: standard-paragraph

<p>SensingConfigurationFeedback由 T节点发送给 G节点,用于向 G 节点进行感知配置反馈。sens-ingConfigIndex用于指示感知信号配置索引;sensingConfigState用于指示感知信号配置状态,标识节点是否接受该请求。0:接受感知信号配置;1:拒绝感知信号配置;其他数值预留。</p>

:::
