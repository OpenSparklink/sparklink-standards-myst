# 7.5.2.55 超宽带脉冲感知流程反馈消息

:::{div}
:class: figure-code

```asn1
-- ASN1START
SlpsensingProcedureFeedback ::= SEQUENCE {
    xrc-Identifier  XRC-Identifier,
    slpsensingProcedureRequestIndex UINT8,
    slpsensingProcedureState    UINT8,
    lateNonCriticalExtension    OCTET STRING    OPTIONAL,
    nonCriticalExtension    SEQUENCE {} OPTIONAL
}
-- ASN1STOP
```

:::

:::{div}
:class: standard-paragraph

<p>SlpsensingProcedureFeedback由 G 节点发送给 T 节点,用于向 T 节点进行超宽带脉冲感知流程反馈。slpsensingProcedureRequestIndex用于指示请求超宽带脉冲感知流程索引;slpsensingProcedureState用于指示超宽带脉冲感知流程状态,标识节点是否接受该请求。0:接受感知测量流程;1:拒绝感知测量流程;其他数值预留。</p>

:::
