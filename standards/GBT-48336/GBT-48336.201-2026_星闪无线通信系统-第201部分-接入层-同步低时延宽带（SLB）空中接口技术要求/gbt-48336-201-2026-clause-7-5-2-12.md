# 7.5.2.12 XRC重配置请求消息

:::{div}
:class: figure-code

```asn1
-- ASN1START
XRCReconfigurationRequest ::= SEQUENCE {
    xrc-Identifier  XRC-Identifier,
    domainlogicalchannelRequest DomainLogicalChannelRequest OPTIONAL,
    drx-config  DRX-Config  OPTIONAL,
    lowEnergyConfig LowEnergyConfig OPTIONAL,
    lateNonCriticalExtension    OCTET STRING    OPTIONAL,
    nonCriticalExtension    SEQUENCE {} OPTIONAL
}
DomainLogicalChannelRequest ::= SEQUENCE {
    logicalchannelRequestToAddModList-Tlink LogicalChannelRequestList   OPTIONAL,
    logicalchannelRequestToReleaseList-Tlink LogicalChannelRequestList  OPTIONAL,
    ...
}
LogicalChannelRequestList ::= SEQUENCE (SIZE(1..32)) OF LogicalChannelRequest
LogicalChannelRequest ::= SEQUENCE {
    logicalchannelidentity  LogicalChannelIdentity  OPTIONAL,   --Need OR
    qosInfoList XQIList OPTIONAL,   --Need OR
    lc-RequestConfig    LC-RequestConfig    OPTIONAL,   --Need OR
    ...
}
LC-RequestConfig ::= SEQUENCE {
    lc-direction    ENUMERATED {tlinkOnly, both, spare2, spare1},
    lc-mode ENUMERATED {m11, m12, m21, m22, m3, spare3, spare2, spare1},
    lc-exclusive    ENUMERATED {share, exclusive, spare2, spare1},
    ...
}
-- ASN1STOP
```

:::

:::{div}
:class: standard-paragraph

<p>xrcReconfigurationRequest由 T节点发送给 G 节点,用于 T 节点主动请求 G 节点重新配置指定参数,可携带各项参数的期望取值。domainlogicalchannelRequest用于 T 节点根据自身新的 QoS要求向 G节点发起逻辑链路相关参数重配置;drx-config用于 T 节点根据自身 DRX 需求向 G 节点发起DRX重配置。lowEnergyConfig用于 T节点向 G节点发起深度睡眠配置请求。</p>

:::

:::{div}
:class: standard-paragraph

<p>当 G节点拒绝 T节点的重配置请求时,可发送不包含任何信元的xrcReconfiguration消息。</p>

:::
