# 6.2.3 物理层信号

(gbt-48336-201-2026-clause-6-2-3-1)=
## 6.2.3.1 同步信号

:::{div}
:class: standard-paragraph

<p>同步信号包括第一训练信号FTS、第二训练信号STS。</p>

:::

(gbt-48336-201-2026-clause-6-2-3-1-1)=
### 6.2.3.1.1 第一训练信号FTS

(gbt-48336-201-2026-clause-6-2-3-1-1-1)=
#### 6.2.3.1.1.1 信号序列

:::{div}
:class: standard-paragraph

<p>用于第一训练信号的序列$d_{\mathrm{FTS}}(n)$生成方法如公式(1)所示。</p>

:::

(gbt-48336-201-2026-equation-1)=
```{math}
d_{\mathrm{FTS}}(n)=\begin{cases}\exp\left(-j\frac{\pi u n(n+1)}{161}\right),&n=0,1,\cdots,160\text{ 且 }n\ne80\\0,&n=80\end{cases}\tag{1}
```

:::{div}
:class: standard-paragraph

<p>式中:</p>

:::

:::{div}
:class: standard-definitions

$n$
: 序列元素序号;

:::

:::{div}
:class: standard-definitions

$u$
: 第一训练信号标识。

:::

:::{div}
:class: standard-paragraph

<p>其中$,u=1$,160为通信域同步信息块第一训练信号标识,与符号类型对应$,u=1$对应类型一 A、类型一B或类型四$,u=160$对应类型二或类型三$;u=2$为通信域接入信息块第一训练信号标识$;u=159$为直通链路同步信息块第一训练信号标识。</p>

:::

(gbt-48336-201-2026-clause-6-2-3-1-1-2)=
#### 6.2.3.1.1.2 资源映射

:::{div}
:class: standard-paragraph

<p>序列$d_{\mathrm{FTS}}(n)$映射到资源元素的方法如公式(2)所示。</p>

:::

(gbt-48336-201-2026-equation-2)=
```{math}
a_{k,l}=d_{\mathrm{FTS}}(k)\times\exp\left(j\pi\frac{N0^2}{10}\right),\quad k=0,1,\cdots,160\tag{2}
```

:::{div}
:class: standard-paragraph

<p>式中:</p>

:::

:::{div}
:class: standard-definitions

$k$
: 资源网格的频域索引;

:::

:::{div}
:class: standard-definitions

$N0$
: 工作频段内基础信道序号。

:::

:::{div}
:class: standard-paragraph

<p>其中$,N0$取值见8.3。在一个基础载波上,当传输第一训练信号时,在连续两个符号上分别映射两个相同的第一训练信号序列,其中第一个符号的循环前缀长度是一般循环前缀长度的两倍,第二个符号无循环前缀。</p>

:::

## 6.2.3.2 信道探测信号SRS

:::{div}
:class: standard-paragraph

<p>信道探测信号传输使用 T链路符号,具体资源由高层srs-Set-Conf配置,并由预配置调度激活去激活信息激活。</p>

:::

:::{div}
:class: standard-paragraph

<p>通信域的 G节点在该通信域接收其他节点发送的信道探测信号,用于该 G节点测量其他节点到该G节点的传输信道特性。</p>

:::

:::{div}
:class: standard-paragraph

<p>对于单天线端口的情况,若 G节点配置的传输信道探测信号的资源包含一个超帧中$\#n$ 无线帧中资源元素$(k,l),$则被配置的节点在该超帧中$\#n$ 无线帧中资源元素$(k,l)$映射的复数值如公式(5)所示。</p>

:::

(gbt-48336-201-2026-equation-5)=
```{math}
a_{k,l}=\begin{cases}r_{n,l}(k+161\times N0),&k=0,1,\cdots,78,79,81,82,\cdots,160\\0,&k=80\end{cases}\tag{5}
```

:::{div}
:class: standard-paragraph

<p>式中:</p>

:::

:::{div}
:class: standard-definitions

$k$
: 资源网格的频域索引;

:::

:::{div}
:class: standard-definitions

$N0$
: 工作频段内基础信道序号。

:::

:::{div}
:class: standard-paragraph

<p>对于多天线端口的情况,若 G节点配置的传输天线端口$p_{0}$的信道探测信号的资源包含一个超帧中$\#n$ 无线帧中资源元素$(k,l),$则被配置的节点在天线端口$p$ 该超帧中$\#n$ 无线帧中资源元素$(k,l)_{p}$映射的复数值如公式(6)所示。</p>

<p>在映射SRS的 TTI中,映射SRS的工作子载波组由对应的预配置调度激活去激活信息中频域资源指示字段指示,在SRS的工作子载波组上,映射SRS的梳齿子载波由高层srs-Set-Conf配置。</p>

:::{div}
:class: standard-paragraph

<p>在包含同步信息块且对应同步信息“指示本基础载波包含哪些 T 节点组的 GCI”字段不等于0的基础载波上,每个包含同步信息块的 TTI内,G链路公共解调参考信号映射在该 TTI第一个无线帧的$\#6$符号;每个不包含同步信息块的 TTI内,G 链路公共解调参考信号映射在该 TTI第一个无线帧的$\#0$符号。在包含同步信息块且对应同步信息“指示本基础载波包含哪些 T 节点组的 GCI”字段等于0的基础载波上,每个包含同步信息块的 TTI内,G链路公共解调参考信号映射在该 TTI第一个无线帧的$\#6$符号;每个不包含同步信息块的 TTI内,不映射 G 链路公共解调参考信号。在不包含同步信息块的基础载波上不映射 G链路公共解调参考信号。</p>

## 6.2.3.6 数据信息解调参考信号 DMRS-D

:::{div}
:class: standard-paragraph

<p>通信域的 G节点在该通信域发送 G 链路数据信息解调参考信号,用于其他节点估计该 G 节点在相同天线端口发送的 G链路数据信息的传输信道;通信域的 G 节点在该通信域接收其他节点发送的T链路数据信息解调参考信号,用于该 G节点估计该其他节点在相同天线端口发送的 T链路数据信息的传输信道。</p>

:::

:::{div}
:class: standard-paragraph

<p>数据信息传输解调参考信号支持连续子载波发送,或者梳齿状子载波发送。当采用连续子载波发送时,子载波平均发送功率与数据信息符号的子载波平均发送功率相同;当采用梳齿状子载波发送时,偶数端口使用偶数子载波发送,奇数端口使用奇数子载波发送,每个端口占用的子载波平均发送功率与数据信息符号的子载波平均发送功率相同。</p>

:::

:::{div}
:class: standard-paragraph

<p>每个被调度传输数据信息的工作子载波组中,映射一组包含所有天线端口的数据信息解调参考信号 DMRS-D的符号由连续$N$ 个符号组成,其中$N=N_{\mathrm{port}}/N_{\mathrm{comb}}$,$N_{\mathrm{port}}$是端口总数量$,N_{\mathrm{comb}}$取1或者2,当采用连续子载波发送方式时$,N_{\mathrm{comb}}$为1,当采用梳齿方式发送时$,N_{\mathrm{comb}}$为2。$N$ 个符号中,第$M$ 个符号传输的端口号包括$[M\cdot N_{\mathrm{comb}},M\cdot N_{\mathrm{comb}}+N_{\mathrm{comb}}),$其中$M\in [0,N-1)$。$N_{\mathrm{comb}}$由高层dmrs-D-SetConf配置,未配置时$N_{\mathrm{comb}}=1$。</p>

:::

:::{div}
:class: standard-paragraph

<p>对于单天线端口的情况,若 G节点调度的数据信息解调参考信号的资源包含一个超帧中$\#n$ 无线帧中资源元素$(k,l),$则发送对应第二类数据信息的节点在该超帧中$\#n$ 无线帧中资源元素$(k,l)$映射的复数值。映射的复数值如公式(11)所示。</p>

:::

(gbt-48336-201-2026-equation-11)=
```{math}
a_{k,l}=\begin{cases}r_{n,l}(k+161\times N0),&k=0,1,\cdots,78,79,81,82,\cdots,160\\0,&k=80\end{cases}\tag{11}
```

:::{div}
:class: standard-paragraph

<p>式中:</p>

:::

:::{div}
:class: standard-definitions

### 6.2.3.10.2 安全感知测量信号

:::{div}
:class: standard-paragraph

<p>为保证感知测量过程的安全,T节点需至少配置两根天线,一根天线的感知测量信号为感知参考信号,另一根天线的感知测量信号为加扰信号。加扰信号为感知参考信号乘上恒模随机信号,这一随机信号只能被授权参与合法感知过程的 G节点和 T节点获得,非授权设备无法获得。</p>

:::

:::{div}
:class: standard-paragraph

<p>一个感知测量过程包括$S$ 个感知测量事件。在每次感知测量过程或事件开始前,G 节点需要配置保密参数,保密参数中的置乱数,或利用保密参数生成的置乱数用于生成加扰信号。配置$N_{t}(N_{t}\geq 2)$根天线的 T节点将第$n$ 个感知测量事件分为$P(P\geq N_{t})$个连续时间段,第$p$ 个时间段内天线$i$在子载波$k$ 上发送信号$X_{i}^{p}(k,n)($频域表示)。在时间段$p$,天线$i(i=p)$的信号$X_{p}^{p}(k,n)$为感知参考信号;在天线$i(i\ne p)$上的发送信号$X_{i}^{p}(k,n)$用于给信号$X_{p}^{p}(k,n)$加扰。天线$i(i\ne 0)$上的信号和天线0上信号之间的关系可表示为$:X_{i}^{p}(k,n)=X^{p}_{0}(k,n)\times e^{\mathrm{j}(\rho _{i}(k,n)+\phi _{i}^{p})}$,其中$\rho _{i}(k,n)$为保护感知隐私的置乱</p>

:::

:::{div}
:class: standard-paragraph

<p>数,$\phi_i^p=\frac{2\pi pi}{N_t(N_t-1)}$$,(i,p=0,1,2,\ldots ,N_{t}-1)\text{。}$发射机在第$n$ 个感知测量事件、第$k$ 个子载波上$,N_{t}$</p>

:::

:::{div}
:class: standard-paragraph

<p>个天线和$N_{t}$个时间段上的发射信号组成的矩阵如公式(17)所示。</p>

:::

(gbt-48336-201-2026-equation-17)=
```{math}
\boldsymbol X(k,n)=\begin{bmatrix}X_0^0(k,n)&X_1^1(k,n)e^{j(-\rho_1(k,n)-\phi_1^1)}&\cdots&X_{N_t-1}^{N_t-1}(k,n)e^{j(-\rho_{N_t-1}(k,n)-\phi_{N_t-1}^{N_t-1})}\\X_0^0(k,n)e^{j(\rho_1(k,n)+\phi_1^0)}&X_1^1(k,n)&\cdots&X_{N_t-1}^{N_t-1}(k,n)e^{j(\rho_1(k,n)-\rho_{N_t-1}(k,n)+\phi_1^{N_t-1}-\phi_{N_t-1}^{N_t-1})}\\X_0^0(k,n)e^{j(\rho_2(k,n)+\phi_2^0)}&X_1^1(k,n)e^{j(\rho_2(k,n)-\rho_1(k,n)+\phi_2^1-\phi_1^1)}&\cdots&X_{N_t-1}^{N_t-1}(k,n)e^{j(\rho_2(k,n)-\rho_{N_t-1}(k,n)+\phi_2^{N_t-1}-\phi_{N_t-1}^{N_t-1})}\\\vdots&\vdots&\vdots&\vdots\\X_0^0(k,n)e^{j(\rho_{N_t-1}(k,n)+\phi_{N_t-1}^0)}&X_1^1(k,n)e^{j(\rho_{N_t-1}(k,n)-\rho_1(k,n)+\phi_{N_t-1}^1-\phi_1^1)}&\cdots&X_{N_t-1}^{N_t-1}(k,n)\end{bmatrix}\tag{17}
```

:::{div}
:class: standard-paragraph

<p>式中:矩阵的第$i$行,第$p$ 列———发射机第$i$个天线第$p$ 个时间段发射的信号。当每个感知测量事件的时间段数量$P\gt N_{t}$时,后$P-N_{t}$时间段上的发射信号是前面时间段的按顺序重复。</p>

:::

:::{div}
:class: standard-paragraph

<p>感知测量过程的置乱数由 G节点与 T节点加密交互完成同步,置乱数同步方式由 G 节点配置,共包括由表6规定的两种。</p>

:::

:::{div}
:class: standard-list-block

<ul class="standard-list">
<li><p>——— 在方式一中,G节点配置保密参数,G/T节点利用保密参数各自生成置乱函数$\theta _{i,k}^{p}(t),$并基于置乱函数采样得到置乱数$\rho _{i}^{p}(k,n);$置乱数的生成步骤包括:</p>
<ul class="standard-list">
<li><p>· $\cdot$步骤1:整个感知过程包含$S$ 个感知测量事件,且前一个感知测量事件的起始时刻与相邻的后一个感知测量事件的起始时刻间隔为$T$,则感知测量过程的总持续时长为 ST,ST就是置乱函数$\theta _{p,i,k}(t)$的时间持续期;</p>
</li>
<li><p>· $\cdot$步骤2:对于任一子载波k,配置$M$ 个范围为$0\sim 2\pi$的均匀分布随机数,相邻随机数对应的时间间隔 为$\mathrm{ST}/M$,这 样,上述配置的$M$ 个随 机数 就 是$\theta _{i,k}^{p}(t)$在 0,$\mathrm{ST}/M,\ldots ,$$(M-1)*\mathrm{ST}/M$ 等时刻的采样;</p>
</li>
<li><p>· $\cdot$步骤3:对于上述样本,使用三次 Hermite插值算法进行插值得到置乱函数$\theta _{i,k}^{p}(t),$若$\theta _{i,k}^{p}(t)\gt 2\pi$,则令$\theta _{i,k}^{p}(t)=2\pi$;若$\theta _{i,k}^{p}(t)\lt 0$,则令$\theta _{i,k}^{p}(t)=0$;</p>
</li>
<li><p>· $\cdot$ 步 骤 4:置 乱函 数$\theta _{i,k}^{p}(t)$以$t_{0}$ 为 初始 时 刻$,T$ 为 间隔采样,得到 一 组 置 乱 数$\theta _{i,k}^{p}(t_{0}+nT)$,其中$n=0$,$1,\ldots S-1$,$t_{0}$为配置的保密参数$,T$ 是两次感知测量事件的时间间隔,这 样,第$n$ 个 感知测量 事 件 在 子载波 k 上 所 使用的置 乱 数$\rho _{i}^{p}(k,n)$等于$\theta _{i,k}^{p}(t_{0}+nT)$。</p>
</li></ul>
</li>
<li><p>——— 在方式二中,G节点直接配置置乱数。</p>
</li></ul>
