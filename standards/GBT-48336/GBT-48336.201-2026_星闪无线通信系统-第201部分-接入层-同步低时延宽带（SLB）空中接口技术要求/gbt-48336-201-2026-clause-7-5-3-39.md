# 7.5.3.39 第一类数据采样率信息

:::{div}
:class: figure-code

```asn1
-- ASN1START
SamplingRate ::= ENUMERATED {
    sr16, sr24, sr32, sr48,
    sr96, sr128, spare2, spare1
}
-- ASN1STOP
```

:::

:::{div}
:class: standard-paragraph

<p>用于指示第一类业务的采样速率,简称“采样率”。单位为 kHz。采样速率与工作带宽的关系见 H。</p>
