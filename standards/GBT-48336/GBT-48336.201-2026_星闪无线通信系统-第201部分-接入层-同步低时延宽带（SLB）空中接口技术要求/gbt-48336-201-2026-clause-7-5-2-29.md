# 7.5.2.29 测试模式参数响应消息

:::{div}
:class: figure-code

```asn1
-- ASN1START
TestModeParameterResponse ::= SEQUENCE {
    xrc-Identifier  XRC-Identifier,
    testModeParameterResponseVar    TestModeParameterResponse-IEs,
    lateNonCriticalExtension    OCTET STRING    OPTIONAL,
    nonCriticalExtension    SEQUENCE {} OPTIONAL
}
TestModeParameterResponse-IEs ::= SEQUENCE {
    sr-CPConfig CPConfig    OPTIONAL, -- Need OR
    commonDCISymbol ENUMERATED {n4, n8, n12, spare1}    OPTIONAL, -- Need OR
    accessControl   BIT4    OPTIONAL, -- Need OR
    keyAlgNegotiation   BIT32   OPTIONAL, -- Need OR
    domainName  DomainName  OPTIONAL, -- Need OR
    contentionAccessResource    ContentionAccessResource    OPTIONAL, -- Need OR
    p0-NominalValue P0-NominalValue OPTIONAL, -- Need OR
    ack-ResourceSetConf ACK-ResourceSetConf OPTIONAL, -- Need OR
    dataResourceConfType2   DataResourceConfType2   OPTIONAL, -- Need OR
    payLoadType INTEGER (0..4)  OPTIONAL, -- Need OR
    ...
}
-- ASN1STOP
```

:::

:::{div}
:class: standard-paragraph

<p>指示在数据信道中发送的比特序列的图样,当该值为0时,比特序列为全0,当该值为1时,比特序列为全1,当该值为2时,比特序列为‘0101’循环,当该值为3时,比特序列为‘1010’循环,当该值为4时,比特序列为随机序列。</p>
