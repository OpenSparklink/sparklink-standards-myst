# 7.5.3.19 时间同步量信息

:::{div}
:class: figure-code

```asn1
-- ASN1START
TimeDomainSync-Value ::= SEQUENCE {
    timeAdjustmentFramePart INTEGER (-8..8),
    timeAdjustmentIntegerPart   INTEGER (-3840.. 3840),
    timeAdjustmentResiduePart   ENUMERATED {m875, m750, m625, m500, m375, m250, m125,
p0, p125, p250, p375, p500, p625, p750, p875, spare1},
    ...
}
-- ASN1STOP
```

:::

:::{div}
:class: standard-paragraph

<p>timeAdjustmentFramePart指示以无线帧长度为单位进行时间调整的部分。timeAdjustmentIntegerPart指示以Ts为单位进行时间调整的整数部分,timeAdjustmentResiduePart指示以Ts为单位进行时间调整的小数部分,其中 m指示为负值,p指示为正值,875代表0.875,625代表0.625,以此类推。当调整量为负值时,G节点提前发送信息,当调整量为正值时,G节点推迟发送信息。G节点通过实现方法解决提前发送信息造成的时间资源冲突问题。</p>

:::
