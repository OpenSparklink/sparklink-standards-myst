# 7.5.3.7 第一类频率资源指示信息

:::{div}
:class: figure-code

```asn1
-- ASN1START
FreqResourceType1 ::= BIT STRING (SIZE (161))
-- ASN1STOP
```

:::

:::{div}
:class: standard-paragraph

<p>161比特中从低位比特开始到高位比特结束,与从最低频率开始到最高频率的161个子载波一一对应。161比特中,取值为1的比特代表使用该比特对应的子载波,取值为0的比特代表不使用该比特对应的子载波。第81个比特不指示任何信息,取值为0。</p>

:::
