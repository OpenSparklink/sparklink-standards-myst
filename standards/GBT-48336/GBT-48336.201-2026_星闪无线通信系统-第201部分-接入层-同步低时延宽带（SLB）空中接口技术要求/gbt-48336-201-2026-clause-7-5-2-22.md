# 7.5.2.22 没有安全上下文的关联建立消息

:::{div}
:class: figure-code

```asn1
-- ASN1START
AssociationSetupNonSec ::= SEQUENCE {
    xrc-Identifier  XRC-Identifier,
    gLayer2ID   Layer2ID    OPTIONAL,
    identityConfig  IDConfig    OPTIONAL,
    kgt-expiration  UINT16  OPTIONAL,
    gkc BIT256  OPTIONAL,
    gk  BIT256  OPTIONAL,
    gkID    UINT8   OPTIONAL,
    galgorithm  BIT24   OPTIONAL,
    gk-expiration   UINT16  OPTIONAL,
    sigk    BIT256  OPTIONAL,
    sgk BIT256  OPTIONAL,
    derivedKey-expiration   UINT16  OPTIONAL,
    dalgorithm  BIT8    OPTIONAL,
    causeReject SecurityFailureReason   OPTIONAL,
    lateNonCriticalExtension    OCTET STRING    OPTIONAL,
    nonCriticalExtension    SEQUENCE {} OPTIONAL
}
-- ASN1STOP
```

:::

:::{div}
:class: standard-paragraph

<p>associationSetupNonSec用于在没有安全上下文的条件下由 G节点发送给 T节点的关联(认证)消息,具体包含的信息元素见9.3。identityConfig包含下次接入时使用的ID,其安全性规则应符合第9章要求。kgt-expiration和gk-expiration的单位为分钟。密钥SIGK 和SGK 为256比特,如果需要的密钥长度为128比特,则截取SIGK 和SGK 的高128比特作为最终的密钥SIGK 和SGK。dalgorithm低4位表示认证加密算法或加密算法,高4位表示认证加密算法或完整性保护算法。</p>

:::

:::{div}
:class: standard-paragraph

<p>当拒绝接入时,causeReject中包含拒绝的具体原因,取值为2,即 G节点校验消息失败。</p>

:::

:::{div}
:class: standard-paragraph

<p>当允许接入时,identityConfig包含下次接入时在安全上下文消息中使用的安全上下文关联标识newSecurityContextID、用于下次接入使用的newphy-IdforNextAccess和用于本次接入后续消息交互的newphy-IDforUnicast,ID分配的安全性规则应符合第9章相关要求。</p>

:::
