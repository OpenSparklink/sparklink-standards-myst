# 7.5.2.17 安全机制更新消息

:::{div}
:class: figure-code

```asn1
-- ASN1START
SecurityConfig ::= SEQUENCE {
    xrc-Identifier  XRC-Identifier,
    securityConfigVar   SecurityConfig-IEs,
    lateNonCriticalExtension    OCTET STRING    OPTIONAL,
    nonCriticalExtension    SEQUENCE{}  OPTIONAL
}
SecurityConfig-IEs ::= SEQUENCE {
    counter UINT16  OPTIONAL,
    activationList  SEQUENCE (SIZE(1..32)) OF LCIDActivation    OPTIONAL,
    securityconfiggroupList SEQUENCE(SIZE (1..8)) OF CommonSecurityConfigGroup OPTIONAL,
    mibVerification MibVerification OPTIONAL,
    ...
}
CommonSecurityConfigGroup ::= SEQUENCE {
    phy-IDforGroupcast  PhyID,
    gkc BIT256,
    gk  BIT256,
    counterg    UINT16,
    gactivation UINT32,
    ...
}
MibVerification ::= SEQUENCE {
    mibVerificationKeyVar   CHOICE {
    mibVerificationKey  BIT256,
    nextMibVerificationKey  BIT256
    },
    sgkVar  CHOICE {
    sgk BIT256,
    nextSGK BIT256
    }   OPTIONAL,
    dhfn    INTEGER (0..8191)   OPTIONAL,
    domainKDF   BIT4    OPTIONAL,
    ...
}
LCIDActivation ::= SEQUENCE {
    logicalchannelID    LogicalChannelIdentity,
    activationg UINT32,
    activationt UINT32,
    ...
}
-- ASN1STOP
```

:::

:::{div}
:class: standard-paragraph

<p>SecurityConfig用于进行密钥更新,具体包括单播连接密钥更新counter与activationList,和组播密钥更新securityconfiggroup。具体包含的信元描述见9.3。</p>

:::

:::{div}
:class: standard-paragraph

<p>针对 mibVerificationKeyVar信元,当使用xrcReconfiguration消息携带securityConfig信元对 mi-bVerificationKeyVar进行初始配置时,使用 mibVerificationKey;当使用securityConfig消息对 mib-VerificationKeyVar进行更新配置时,使用nextMibVerificationKey。</p>

:::
