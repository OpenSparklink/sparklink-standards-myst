# 7.5.2.9 XRC建立完成消息

```asn1
-- ASN1START
```

:::{div}
:class: figure-code

```asn1
XRCSetupComplete ::= SEQUENCE {
    xrc-Identifier  XRC-Identifier,
    associationRequestWithSec   AssociationRequestWithSec   OPTIONAL,
    associationRequestNonSec    AssociationRequestNonSec    OPTIONAL,
    doubleSideTwoMessageRTTMeasure  NTP32   OPTIONAL, -- Need OR
    lateNonCriticalExtension    OCTET STRING    OPTIONAL,
    nonCriticalExtension    SEQUENCE{}  OPTIONAL
}
-- ASN1STOP
```

:::

:::{div}
:class: standard-paragraph

<p>XRCSetupComplete由 T 节点发送给 G 节点,并携带associationRequestWithSec或association-RequestNonSec信元,分别用于有安全上下文和没有安全上下文的关联请求。doubleSideTwoMes-sageRTTMeasure用于指示 T节点在 RACH 中向 G节点发送的 RAB的第一个符号STS到达天线连接器的时间t3,与在 RAB之前最近接收的SAB块的第一个符号STS到达天线连接器的时间t2之间的时间差$T_{\mathrm{b}}$,其中$T_{\mathrm{b}}=t3-t2$。</p>

:::
