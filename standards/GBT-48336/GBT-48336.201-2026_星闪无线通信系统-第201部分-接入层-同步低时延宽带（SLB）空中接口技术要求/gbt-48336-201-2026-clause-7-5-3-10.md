# 7.5.3.10 特定符号资源信息

:::{div}
:class: figure-code

```asn1
-- ASN1START
DedicatedTimeResource ::= SEQUENCE {
    symbolStarting  UINT10,
    symbolNumber    UINT10  OPTIONAL
}
-- ASN1STOP
```

:::

:::{div}
:class: standard-paragraph

<p>特定符号资源信息用于指示特定功能的系统开销使用的符号在无线帧、超帧或者 TTI中的位置,通过起始符号的编号和符号个数表达。其中,symbolNumber为可选,当配置 SRS、DMRS、CSI-RS资源时,默认值为1,即符号个数为1;当配置SR、ACK 资源时,默认值为2,即符号个数为2;当配置CQI资源时,默认值为3,即符号个数为3。</p>

:::
