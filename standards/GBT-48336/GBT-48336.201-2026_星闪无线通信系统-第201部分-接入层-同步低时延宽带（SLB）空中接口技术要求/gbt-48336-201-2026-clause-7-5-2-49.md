# 7.5.2.49 超宽带脉冲测量能力响应消息

:::{div}
:class: figure-code

```asn1
-- ASN1START
SLPCapabilityResponse ::= SEQUENCE {
    xrc-Identifier  XRC-Identifier,
    sLPCapabilityResponseVar    SLPCapabilityResponse-IEs,
    lateNonCriticalExtension    OCTET STRING    OPTIONAL,
    nonCriticalExtension    SEQUENCE{}  OPTIONAL
}
-- ASN1STOP
```

:::

:::{div}
:class: figure-code

```asn1
-- ASN1START
SLPCapabilityResponse-IEs ::= SEQUENCE {
    measSessionSupport UINT8,
    measSignalCapability    BIT64,
    measReportCapability    BIT32,
    txMultipleAntenna   UINT8,
    txMultipleAntenna-Gap   UINT8,
    rxMultipleAntenna   UINT8,
    rxMultipleAntenna-Gap   UINT8,
    txMultipleAntenna-SwitchingOrder    BIT4,
    rxMultipleAntenna-SwitchingOrder    BIT4,
    sLPMeasEvent-Gap    UINT24,
    sLPMeasInnerEvent-Gap   UINT24,
    sLPMeasEventGroup-Gap   UINT24,
    sLPChannelCapability    BIT128,
    ...
}
-- ASN1STOP
```

:::

:::{div}
:class: standard-paragraph

<p>SLPCapabilityResponse由 T节点发送给 G节点,用于进行 T 节点超宽带脉冲测量能力响应。其中 measSessionSupport用于指示支持的测量数量;measSignalCapability使用位图的方式指示测量信号的能力,当比特位为0时,不支持对应的能力,当比特位为1时,支持对应的能力,其中比特0到比特28预留,比特29:安全测量序列;比特30:长度31的测量码字,占空比16;比特31:长度63的测量码字,占空比8;比特32:长度91的测量码字,占空比4;比特33:长度91的测量码字,占空比8;比特34:长度127的测量码字,占空比4;比特35:长度133的测量码字,占空比4;比特36:长度133的测量码字,占空比8;比特37:非等长测量码字集合;比特38:测量子片段符号的可选数量;比特39:测量子片段的可选数量;比特40:测量符号循环前缀的可选长度;比特41:测量符号补零的可选长度;比特42:测量码字循环移位;比特43:-10dB带宽大于或等于500MHz;比特44:-10dB带宽大于1GHz;其他比特预留。measReportCapability使用位图的方式指示测量上报的能力,当比特位为0时,不支持对应的能力,当比特位为1时,支持对应的能力,其中比特0:AoA 测量;比特1:AoD测量;比特2:信道状态信息测量上报(载波IQ 信息上报);比特3:信道状态信息测量上报 (CIR 上报)-以第一径为初始参考;比特4:信道状态信息测量上报 (CIR 上报)-以最强径为初始参考;比特5:信道状态信息测量上报 (CIR上报)-以信号发送时间为初始参考;比特6:双边两消息/双边三消息时间信息上报;比特7:接收天线相位差信息上报;比特8:发送天线相位差信息上报;比特9:距离多普勒信息上报-以第一径为初始参考;</p>

:::

:::{div}
:class: standard-paragraph

<p>比特10:距离多普勒信息上报-以最强径为初始参考;比特11:距离多普勒信息上报-以信号发送时间为初始参考;比特12:目标信息上报;比特13:重叠方式信道拼接;比特14:连续方式信道拼接;比特15:不连续方式信道拼接;比特16:不支持测量上报;其他比特预留。txMultipleAntenna用于指示发送多天线能力;txMultipleAntenna-Gap用于指示发送多天线切换间隔,单位为微秒;rxMultipleAntenna用于指示接收多天线能力;rxMultipleAntenna-Gap用于指示接收多天线切换间隔,单位为微秒。txMulti-pleAntenna-SwitchingOrder使用位图的方式指示发送多天线切换次序的能力,当比特位为0时,不支持对应的能力,当比特位为1时,支持对应的能力,其中比特0:顺序切换;比特1:随机切换;其他比特预留,当发送多天线的数量为1时,该字段所有比特置为0。rxMultipleAntenna-SwitchingOrder使用位图的方式指示接收多天线切换次序的能力,当比特位为0时,不支持对应的能力,当比特位为1时,支持对应的能力,其中比特0:顺序切换;比特1:随机切换;其他比特预留,当接收多天线的数量为1时,该字段所有比特置为0。sLPMeasEvent-Gap用于指示超宽带脉冲测量事件间间隔,两个相邻的超宽带脉冲测量事件中,前面事件的传输结束时刻与后面事件传输开始时刻间的时间是指超宽带脉冲测量事件间间隔,该字段为该间隔的最小值,以纳秒为单位。sLPMeasInnerEvent-Gap用于指示超宽带脉冲测量事件内间隔,在一次超宽带脉冲测量事件中,前一个节点的传输结束时刻与后一个节点传输开始时刻间的时间是指超宽带脉冲测量 事 件 内 间隔,该 字 段 为 该 间隔的 最 小值,以 纳 秒 为 单位。</p>

:::

:::{div}
:class: standard-paragraph

<p>sLPMeasEventGroup-Gap用于指示超宽带脉冲测量事件组间间隔,对于相邻的两个超宽带脉冲测量事件组,前面事件组最后一个事件的传输结束时刻与后面事件组第一个传输的传输开始时刻间的时间是指超宽带脉冲测量事件组间间隔,字段数值为该间隔的最小值,以纳秒为单位。sLPChannelCapability使用位图的方式指示超宽带脉冲信道能力,128个比特中,最低位比特(第0位比特)对应物理信道号0,次低位比特(第1位比特)对应物理信道号1,按照此顺序,第79位比特对应物理信道号79;第125位比特对应物理信道号125,中心频点为7542.6;第126位比特对应物理信道号126,中心频点为8041.8;</p>

:::

:::{div}
:class: standard-paragraph

<p>第127位比特对应物理信道号127,中心频点为8541.0;第80位比特到第124位比特预留。</p>

:::
