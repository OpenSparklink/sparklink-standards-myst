# 7.5.2.38 感知流程反馈消息

:::{div}
:class: figure-code

```asn1
-- ASN1START
SensingProcedureFeedback ::= SEQUENCE {
    xrc-Identifier  XRC-Identifier,
    sensingProcedureRequestIndex    UINT8,
    sensingProcedureState   UINT8,
    lateNonCriticalExtension    OCTET STRING    OPTIONAL,
    nonCriticalExtension    SEQUENCE {} OPTIONAL
```

:::

```asn1
-- ASN1STOP
```

:::{div}
:class: standard-paragraph

<p>SensingProcedureFeedback由 G 节点发送给 T 节点,用于向 T 节点进行感知流程反馈。sensing-ProcedureRequestIndex用 于 指示 请 求感知流程 索 引;sensingProcedureState用 于 指示感知流程 状态,标识节点是否接受该请求。0:接受感知测量流程;1:拒绝感知测量流程;其他数值预留。</p>

:::
