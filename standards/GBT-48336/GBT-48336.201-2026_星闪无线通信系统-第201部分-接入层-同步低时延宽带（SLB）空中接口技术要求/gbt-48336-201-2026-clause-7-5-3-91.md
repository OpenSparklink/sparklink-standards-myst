# 7.5.3.91 T链路半静态调度配置信息

:::{div}
:class: figure-code

```asn1
-- ASN1START
SPS-ConfigTlink ::= SEQUENCE {
    sps-XRC-Identity    SPS-Identity,
    newphy-IDforPreConfig   PreConfigPhysID OPTIONAL,
    sps-ResourceIndicator   CHOICE {
    type1ResourcePackage-Tlink  DataResourceConfPackage,
    type2Resource-Tlink DataResourceConfType2
    },
    gciDedicatedACK ACK-Resource    OPTIONAL,
    logicalchannelID    LogicalChannelIdentity  OPTIONAL,
    harqProcessList SEQUENCE (SIZE (1..4)) OF HarqProcessIndex OPTIONAL,
    redundancyVersion   RedundancyVersion   OPTIONAL,
    dmrs-D-TlinkConf    Dmrs-D-TlinkConf    OPTIONAL,
    carrierChannelList  SEQUENCE (SIZE (1..16)) OF ChannelNumber    OPTIONAL,
    phyIDforRSsequence  PhyIDforRSsequence  OPTIONAL,
    ...
}
Dmrs-D-TlinkConf ::= SEQUENCE {
    ttiPeriod   TTiPeriod,
    ttiOffset   TTiOffset,
    dmrs-D-TlinkSetConf SEQUENCE (SIZE(1..64)) OF Dmrs-D-TlinkResrcConf,
    ...
}
Dmrs-D-TlinkResrcConf ::= SEQUENCE {
    dmrs-D-TimeResource DedicatedTimeResource,
    dmrs-D-PortInfo PortInfo-1,
    dmrs-D-CombInfo CombInfo-1,
    dmrs-D-CombOffset   CombOffset-1,
    ...
}
-- ASN1STOP
```

:::

:::{div}
:class: standard-paragraph

<p>SPS-ConfigTlink用于进行 T 链路 半静态 调度配置信息,具 体包 括 高 层 SPS 标识 sps-XRC-Identity,与高层SPS标识对应的SPS传输资源 sps-ResourceIndicator,SPS对应的 HARQ 进程号列表harqProcessList,可包含一到多个 HARQ 进程号,不配置时默认为 HARQ 进程0。redundancyVersion指示对应的冗余版本,不配置时,默认为冗余版本0。T链路半静态调度配置信息还可包含逻辑信道标识logicalchannelID。gciDedicatedACK 用于配置对物理层预配置调度激活去激活信息进行反馈的 ACK 资源。carrierChannelList用于指示当前半静态配置可调度的一到多个载波所在信道号列表,即支持跨载波的半静态调度,该信元为可选项,默认为发送该预配置调度信息所在的信道号。</p>

:::

:::{div}
:class: standard-paragraph

<p>若未配置newphy-IDforPreConfig,则需要配置。</p>

:::

:::{div}
:class: standard-paragraph

<p>可为 T链路半静态调度配置专用 DMRS-D资源 Dmrs-D-TlinkConf。该 DMRS-D资源的工作子载波组与对应半静态数据时频资源的工作子载波组相同。ttiPeriod和ttiOffset共同指示该 DMRS-D资源的周期信息。针对该周期,可配置多个不同位置的 DMRS-D符号,每个符号配置信息由 Dmrs-D-TlinkResrcConf指示。其中,dmrs-D-TimeResource指示了该符号相对于所在 TTI起始时刻的偏移位置;dmrs-D-PortInfo、dmrs-D-CombInfo、dmrs-D-CombOffset指示该符号对应的端口和梳齿信息。</p>

:::

:::{div}
:class: standard-paragraph

<p>phyIDforRSsequence用于配置 T链路 DMRS-D参考信号序列生成的物理层标识,可选信元。配置 T链路 DMRS-D时,若该信元未配置时,则可配置。</p>

:::
