# 3 术语和定义

:::{div}
:class: standard-reference

<p>GB/T48336.101界定的以及下列术语和定义适用于本文件。</p>

:::

(gbt-48336-202-2026-clause-3-1)=
## 3.1 无线帧 radio frame

:::{div}
:class: standard-paragraph

<p>同步低时延宽带通信系统中每3840个基础时间单位组成的资源。</p>

:::

(gbt-48336-202-2026-clause-3-2)=
## 3.2 第一训练信号 first training signal

:::{div}
:class: standard-paragraph

<p>同步低时延宽带通信系统中用作时间和频率同步的主要信号。</p>

:::

(gbt-48336-202-2026-clause-3-3)=
## 3.3 第二训练信号 secondary training signal

:::{div}
:class: standard-paragraph

<p>同步低时延宽带通信系统中用作时间和频率同步的辅助信号。</p>

:::

(gbt-48336-202-2026-clause-3-4)=
## 3.4 相位调整信号 phase adjustment signal

:::{div}
:class: standard-paragraph

<p>同步低时延宽带通信系统中用作相位调整的信号。</p>

:::

(gbt-48336-202-2026-clause-3-5)=
## 3.5 物理层标识 physical layer identity

:::{div}
:class: standard-paragraph

<p>用于物理层寻址的标识。</p>

:::
