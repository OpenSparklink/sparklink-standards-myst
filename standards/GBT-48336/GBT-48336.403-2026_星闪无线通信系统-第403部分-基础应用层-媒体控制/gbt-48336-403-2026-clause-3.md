(gbt-48336-403-2026-clause-3)=
# 3 术语和定义

:::{div}
:class: standard-reference

<p>GB/T 48336.101 界定的以及下列术语和定义适用于本文件。</p>

:::

(gbt-48336-403-2026-clause-3-1)=
## 3.1 媒体 media

:::{div}
:class: standard-paragraph

<p>承载音频、视频或音视频信息的载体。</p>

:::

(gbt-48336-403-2026-clause-3-2)=
## 3.2 媒体播放实例 media play instance

:::{div}
:class: standard-paragraph

<p>在低功耗无线通信系统中，接收管理节点发送的接入层资源管理信息，根据接入层资源管理信息进行数据的发送或者接收的节点。</p>

:::

(gbt-48336-403-2026-clause-3-3)=
## 3.3 当前媒体 current media

:::{div}
:class: standard-paragraph

<p>媒体播放实例操作作用的媒体。</p>

:::

(gbt-48336-403-2026-clause-3-4)=
## 3.4 媒体组 media group

:::{div}
:class: standard-paragraph

<p>由多个有某种共同特征或逻辑关联的媒体对象形成的组。</p>

:::

:::{admonition} 注
:class: note

<p>一个媒体组内的媒体对象为媒体或媒体组。</p>

:::

(gbt-48336-403-2026-clause-3-5)=
## 3.5 当前媒体组 current media group

:::{div}
:class: standard-paragraph

<p>媒体播放实例操作作用的媒体组。</p>

:::

(gbt-48336-403-2026-clause-3-6)=
## 3.6 父媒体组 parent media group

:::{div}
:class: standard-paragraph

<p>当前媒体组的上一级媒体组。</p>

:::

(gbt-48336-403-2026-clause-3-7)=
## 3.7 子媒体组 child media group

:::{div}
:class: standard-paragraph

<p>当前媒体组的下一级媒体组。</p>

:::

(gbt-48336-403-2026-clause-3-8)=
## 3.8 媒体段 media segment

:::{div}
:class: standard-paragraph

<p>对单个媒体从时间维度上进行的切片。</p>

:::

:::{admonition} 注
:class: note

<p>将节目、故事情节封装为媒体段的形式方便选择和检索。</p>

:::

(gbt-48336-403-2026-clause-3-9)=
## 3.9 媒体段标识 media segment identifier

:::{div}
:class: standard-paragraph

<p>在单个媒体范围内，用于唯一标识一个媒体段。</p>

:::

(gbt-48336-403-2026-clause-3-10)=
## 3.10 媒体对象 media object

:::{div}
:class: standard-paragraph

<p>一个媒体组或一个媒体。</p>

:::

(gbt-48336-403-2026-clause-3-11)=
## 3.11 媒体对象标识 media object identifier

:::{div}
:class: standard-paragraph

<p>在设备范围内，用于唯一标识一个媒体对象。</p>

:::

(gbt-48336-403-2026-clause-3-12)=
## 3.12 寻道 seeking

:::{div}
:class: standard-paragraph

<p>媒体播放位置进行快速移动的过程。</p>

:::

:::{admonition} 注
:class: note

<p>本文件中特指快进或快退的过程。</p>

:::

(gbt-48336-403-2026-clause-3-13)=
## 3.13 主音量 master volume

:::{div}
:class: standard-paragraph

<p>影响所有音频通道音量的属性。</p>

:::

(gbt-48336-403-2026-clause-3-14)=
## 3.14 通道音量 channel volume

:::{div}
:class: standard-paragraph

<p>影响单一音频通道音量的属性。</p>

:::

(gbt-48336-403-2026-clause-3-15)=
## 3.15 服务端 server

:::{div}
:class: standard-paragraph

<p>提供至少一种具体服务的星闪设备。</p>

:::

:::{div}
:class: standard-paragraph

<p>[来源：GB/T 48336.301—2026，3.2]</p>

:::

(gbt-48336-403-2026-clause-3-16)=
## 3.16 客户端 client

:::{div}
:class: standard-paragraph

<p>访问服务端并接受至少一种具体服务的星闪设备。</p>

:::

:::{div}
:class: standard-paragraph

<p>[来源：GB/T 48336.301—2026，3.3]</p>

:::

(gbt-48336-403-2026-clause-3-17)=
## 3.17 媒体播放控制服务端 media control server

:::{div}
:class: standard-paragraph

<p>提供媒体播放控制服务的服务端。</p>

:::

(gbt-48336-403-2026-clause-3-18)=
## 3.18 媒体播放控制客户端 media control client

:::{div}
:class: standard-paragraph

<p>访问媒体播放控制服务的客户端。</p>

:::

(gbt-48336-403-2026-clause-3-19)=
## 3.19 音量控制服务端 volume control server

:::{div}
:class: standard-paragraph

<p>提供音量控制服务的服务端。</p>

:::

(gbt-48336-403-2026-clause-3-20)=
## 3.20 音量控制客户端 volume control client

:::{div}
:class: standard-paragraph

<p>访问音量控制服务的客户端。</p>

:::
