# 6 角色与功能

(gbt-48336-403-2026-clause-6-1)=
## 6.1 媒体播放控制角色和功能

:::{div}
:class: standard-paragraph

<p>媒体播放控制角色分为媒体播放控制端和媒体播放端。媒体播放控制端通过与媒体播放端交互，实现特定功能。</p>

:::

:::{div}
:class: standard-paragraph

<p>媒体播放端应承载媒体播放控制服务，作为媒体播放控制服务端。媒体播放控制端作为媒体播放控制客户端。</p>

:::

:::{div}
:class: standard-paragraph

<p>媒体播放端提供媒体播放控制和媒体浏览两类功能，其中：</p>

:::

:::{div}
:class: standard-list-block

<ul class="standard-list">
<li><p>—— 媒体播放控制端通过媒体播放请求控制媒体播放端的播放；</p>
</li>
<li><p>—— 媒体播放控制端通过媒体浏览请求浏览媒体播放端上的媒体内容。</p>
</li></ul>

:::

:::{div}
:class: standard-paragraph

<p>此外，媒体播放控制端可通过读取属性和接收通知来获取或同步媒体播放端上的信息。媒体播放端开放的功能和调用这些功能的方法见第 7 章。</p>

:::

(gbt-48336-403-2026-clause-6-2)=
## 6.2 媒体对象结构

:::{div}
:class: standard-paragraph

<p>媒体对象结构是媒体对象之间的关系，用于对媒体进行分类、管理和浏览。媒体对象结构有如下定义，详见图 1。</p>

:::

:::{div}
:class: standard-list-block

<ul class="standard-list">
<li><p>—— 媒体可归属于一个或多个媒体组。</p>
</li>
<li><p>—— 媒体组 X 可包含媒体组 A，此时称媒体组 X 为媒体组 A 的上一级媒体组（父媒体组），媒体组</p>
</li></ul>

:::

:::{div}
:class: standard-paragraph

<p>A 为媒体组 X 的下一级媒体组（子媒体组）。</p>

:::

:::{div}
:class: standard-list-block

<ul class="standard-list">
<li><p>—— 媒体组可包含媒体或媒体组两类媒体对象，这两种媒体对象不应同时存在。</p>
</li></ul>

## 6.3 音量控制角色

:::{div}
:class: standard-paragraph

<p>音量控制角色分为音量控制端和音频输出端。音量控制端通过与音频输出端交互，实现对音频输出端实际输出音频音量的调整。</p>

:::

:::{div}
:class: standard-paragraph

<p>音频输出端应承载音量控制服务，作为音量控制服务端。音量控制端作为音量控制客户端。</p>

:::

:::{div}
:class: standard-paragraph

<p>音频输出端提供的功能是对音频输出音量的控制，音量控制端可通过音量控制请求调整音频输出端的主音量和通道音量，以及是否静音。此外，音量控制端可通过读取属性或接收通知来获取或同步音频输出端的主音量状态以及通道音量状态信息。音频输出端开放的功能和使用方法见第 9 章。</p>

:::

(gbt-48336-403-2026-clause-6-4)=
## 6.4 音量控制框架

:::{div}
:class: standard-paragraph

<p>音频输出端的音量控制分为主音量控制和通道音量控制两层，其中：</p>

:::

:::{div}
:class: standard-list-block

<ul class="standard-list">
<li><p>—— 主音量：调整影响所有通道的音量；</p>
</li>
<li><p>—— 通道音量：为主音量基础上的偏移。</p>
</li></ul>

:::

:::{div}
:class: standard-paragraph

<p>最终音频输出端特定通道的音量是主音量和对应通道音量共同作用的结果。不同音频通道的音量可不同。音量控制结构见图 2。</p>

:::

:::{div}
:class: standard-paragraph

<p>若音频输出端只有单个音频通道或者音频通道的音量是相同的，仅需控制主音量。</p>

:::

:::{div}
:class: standard-paragraph

<p>主音量对应音量控制服务的音量状态属性，通道音量对应音量控制服务的通道音量状态属性。通道音量状态属性是可选的，当出现前述情况时，音量控制服务可不设置通道音量状态属性。</p>

:::
