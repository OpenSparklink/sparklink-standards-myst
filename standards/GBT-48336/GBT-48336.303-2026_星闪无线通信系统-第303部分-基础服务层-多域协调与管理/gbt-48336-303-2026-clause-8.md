## 8.3 多域协调与管理消息

(gbt-48336-303-2026-clause-8-3-1)=
### 8.3.1 邻区扫描指示消息

:::{div}
:class: standard-paragraph

<p>邻区扫描指示消息用于一个 G 节点向另一个 G 节点发送周围潜在的邻区目标 G 节点信息,用于指示上述另一个 G 节点扫描发现邻区目标 G 节点。</p>

:::

:::{div}
:class: standard-paragraph

<p>非管理模式时,接收端 G 节点不要求应反馈 NeighborScanResponse消息。</p>

:::

:::{div}
:class: standard-paragraph

<p>对于管理模式,接收端 G 节点应反馈 NeighborScanResponse消息。</p>

:::

```asn1
NeighborScanIndication ::= SEQUENCE {
    transactionID INTEGER (1..16),
    sourceLayer2ID Layer2ID,
    neighborInfoList SEQUENCE (SIZE (1..8)) OF NeighborInfo,
    ...
}
NeighborInfo ::= SEQUENCE {
    target-g-Layer2ID Layer2ID,
    targetDomainSysInforPeriod ENUMERATED {sf64, sf128, sf256, sf512} OPTIONAL,
    scanType ENUMERATED {slb, sle, spare2, spare1},
    timeout INTEGER (0..65535),
    carrierChannelToScanList SEQUENCE (SIZE (1..80)) OF  ChannelNumber OPTIONAL,  -- Need ON
    scanStartTimeOffset INTEGER (1..512) OPTIONAL,
    scanDuration INTEGER (1..128) OPTIONAL,
    resultIndication ENUMERATED {true} OPTIONAL,
    ...
}
```

:::{div}
:class: standard-paragraph

<p>各个字段含义为:</p>

:::

:::{div}
:class: standard-list-block

<ul class="standard-list">
<li><p>——— transactionID:用于标识一条具体的邻区扫描指示消息;</p>
</li>
<li><p>——— sourceLayer2ID:发送方 G 节点的媒体接入层标识;</p>
</li>
<li><p>——— target-g-Layer2ID:待扫描或待发现的 G 节点的媒体接入层标识;</p>
</li>
<li><p>——— scanType:本次扫描类型为 SLB 扫描或者 SLE 扫描。targetDomainSysInforPeriod:待扫描G 节点/目标 G 节点的通信域系统消息发送周期,取值范围为 SF64,SF128,SF256,SF512,SF64指示可能发送系统消息的超帧的起始编号为64的倍数,SF128,SF256,SF512含义类推;</p>
</li>
<li><p>——— timeout:从收到该信令的时刻算起,该信令内容的有效期。单位为100ms;</p>
</li>
<li><p>——— carrierChannelToScanList:待扫描G 节点/目标G 节点的工作载波的标识清单,即待扫描的载波/信道清单;</p>
</li></ul>

:::

:::{div}
:class: standard-list-block

<ul class="standard-list">
<li><p>——— scanStartTimeOffset:从接收到该信令时刻算起,启动扫描的时间偏移量,单位为1ms;</p>
</li>
<li><p>——— scanDuration:在单个载波信道上的扫描持续时间,单位为1ms;</p>
</li>
<li><p>——— resultIndication:仅可能出现在管理模式。如果携带,应在邻区扫描响应消息中反馈扫描结果。如果不出现,扫描结果是否反馈由具体技术实现方案决定。</p>
</li></ul>

:::

(gbt-48336-303-2026-clause-8-3-2)=
### 8.3.2 邻区扫描响应消息

:::{div}
:class: standard-paragraph

<p>管理模式时,邻区扫描响应消息用于一个 G 节点向另一个 G 节点响应之前发送的邻区扫描指示消息。非管理模式时,不发送邻区扫描响应信息。</p>

:::

```asn1
NeighborScanResponse ::= SEQUENCE {
    transactionID INTEGER (1..16),
    sourceLayer2ID Layer2ID,
    cause INTEGER (1..8) OPTIONAL,
    scanResultList SEQUENCE (SIZE (1..8)) OF ScanResult OPTIONAL,
    ...
}
ScanResult ::= SEQUENCE {
    target-g-Layer2ID Layer2ID,
    targetCarrierChannelList SEQUENCE (SIZE (1..80)) OF ChannelNumber OPTIONAL,  -- Need ON
    cause INTEGER (1..8) OPTIONAL
}
```

:::{div}
:class: standard-paragraph

<p>各个字段含义如下。</p>

:::

:::{div}
:class: standard-list-block

<ul class="standard-list">
<li><p>——— transactionID:设置为对应的邻区扫描指示消息的transactionID。</p>
</li>
<li><p>——— sourceLayer2ID:发送方 G 节点的媒体接入层标识。</p>
</li>
<li><p>——— cause:仅在无法反馈完整扫描结果时携带,指明具体的失败原因。1代表信息当前获取;2代表不兼容的参数;3代表超出上限;4代表无效参数;5代表无法接纳请求;6代表扫描状态不对其可见,7和8保留。</p>
</li>
<li><p>——— target-g-Layer2ID:扫描到的 G 节点的媒体接入层标识。</p>
</li>
<li><p>——— targetCarrierChannelList:扫描到的 G 节点所在的载波信道。</p>
</li></ul>

:::

(gbt-48336-303-2026-clause-8-3-3)=
### 8.3.3 通信域资源报告消息

:::{div}
:class: standard-paragraph

<p>管理模式时,多域成员节点向多域管理节点上报当前通信域资源报告信息,包括资源占用情况、待承载的新业务信息。非管理模式时,不发送邻区扫描响应信息。</p>

:::

```asn1
DomainResourceReport ::= SEQUENCE {
    slbDedicatedReport SLBDedicatedReport OPTIONAL,
    sleDedicatedReport SLEDedicatedReport OPTIONAL,
    ...
}
SLBDedicatedReport ::= SEQUENCE {
    slbLayer2ID Layer2ID,
    sps-TrafficInformationToAddModList SPS-TrafficInformationToAddModList OPTIONAL,
    currentSLBCarrierChannelList SEQUENCE (SIZE (1..32)) OF ChannelNumber OPTIONAL,
    currentSlbSPSConfigList SLB-SPS-ConfigList OPTIONAL,
    ...
}

SLEDedicatedReport ::= SEQUENCE {
    sleLayer2ID Layer2ID,
    sle-TrafficInformationToAddModList SLESlotPatternInfoList OPTIONAL,
    currentSLECarrierChannelList SEQUENCE (SIZE (1..80)) OF ChannelNumber OPTIONAL,
    currentSLESlotPatternInfoList SLESlotPatternInfoList OPTIONAL,
    ...
}
SPS-TrafficInformationToAddModList ::= SEQUENCE (SIZE(1..32)) OF SPS-TrafficInformation
SPS-TrafficInformation ::= SEQUENCE {
    sps-TrafficpatternInformation SPSTrafficPatternInfo OPTIONAL,
    serviceCharcteristic SEQUENCE {
        samplinglength ENUMERATED {sl16, sl24, sl32},
        samplingrate ENUMERATED {sr16, sr24, sr32, sr48, sr96, sr128}
    } OPTIONAL,
    application-Info AID OPTIONAL,
    qos-Info XQI OPTIONAL,
    vendor-specific BIT STRING (SIZE (128)) OPTIONAL
}
```

:::{div}
:class: standard-paragraph

<p>各个字段含义为:</p>

:::

:::{div}
:class: standard-list-block

<ul class="standard-list">
<li><p>——— sps-TrafficInformationToAddModList:多域成员节点覆盖下准备进行的SPS业务信息;多域管理节点可基于该类业务信息,为多域成员节点分配资源;</p>
</li>
<li><p>——— currentSLBCarrierChannelList:当前SLB使用的载波信道列表;</p>
</li>
<li><p>——— currentSLECarrierChannelList:当前SLE使用的载波信道列表;</p>
</li>
<li><p>——— currentSlbSPSConfigList:多域成员节点当前SLB周期性资源的分配情况;</p>
</li>
<li><p>——— currentSLESlotPatternInfoList:多域成员节点当前SLE周期性资源的分配情况;</p>
</li>
<li><p>——— sps-TrafficpatternInformation:多域成员节点期望增加的SPS业务特征信息;</p>
</li>
<li><p>——— serviceCharcteristic:多域成员节点期望增加的第一类业务,包括采样率samplingrate和量化位宽samplinglength;</p>
</li>
<li><p>——— application-Info:多域成员节点期望增加的业务类型信息;</p>
</li>
<li><p>——— qos-Info:多域成员节点期望增加的业务服务质量索引信息。</p>
</li></ul>

:::

(gbt-48336-303-2026-clause-8-3-4)=
### 8.3.4 通信域资源配置消息

:::{div}
:class: standard-paragraph

<p>管理模式时,多域管理节点向多域成员节点发送通信域资源配置消息,包括可用的载波信道、资源等信息。非管理模式时,不发送通信资源配置消息。</p>

:::

```asn1
DomainResourceConfiguration ::= SEQUENCE {
    transactionID INTEGER (1..16),
    sourceLayer2ID Layer2ID,
    slbDedicatedConfig SLBDedicatedConfig OPTIONAL,
    sleDedicatedConfig SLEDedicatedConfig OPTIONAL,
    ...
}

SLBDedicatedConfig ::= SEQUENCE {
    allowedCarrierChannelList SEQUENCE (SIZE (1..32)) OF  ChannelNumber OPTIONAL,  -- Need ON
    dedicatedSpsResourceConfig SLB-SPS-ConfigList OPTIONAL,  -- Need OR
    ...
}
SLEDedicatedConfig ::= SEQUENCE {
    allowedCarrierChannelList SEQUENCE (SIZE (1..80)) OF  ChannelNumber OPTIONAL,  -- Need ON
    dedicatedSleResourceConfig SLESlotPatternInfoList OPTIONAL,  -- Need OR
    ...
}
```

:::{div}
:class: standard-paragraph

<p>各个字段含义如下。</p>

:::

:::{div}
:class: standard-list-block

<ul class="standard-list">
<li><p>——— transactionID:用于标识一条具体的通信域资源配置消息。</p>
</li>
<li><p>——— sourceLayer2ID:多域管理节点的媒体接入层标识。</p>
</li>
<li><p>——— slbDedicatedConfig:SLB的资源专属配置信息。</p>
</li>
<li><p>——— sleDedicatedConfig:SLE的资源专属配置信息。</p>
</li>
<li><p>——— allowedCarrierChannelList:允许使用的载波信道列表。如果一个载波信道配置同时配置了dedicatedSpsResourceConfig或 dedicatedSleResourceConfig,则只允许使用 dedicatedSpsRe-sourceConfig或dedicatedSleResourceConfig指定的资源;否则,该载波信道上的资源如何使用可由多域成员节点自主决定。</p>
</li>
<li><p>——— dedicatedSpsResourceConfig:指示了一个载波信道上的可用的半静态资源信息。</p>
</li></ul>

:::

(gbt-48336-303-2026-clause-8-3-7)=
### 8.3.7 测距请求消息

:::{div}
:class: standard-paragraph

<p>管理模式时,用一个 G 节点向另一个 G 节点发送测距请求消息,请求对被测目标执行测距并反馈结果。非管理模式时,不发送测距请求消息。</p>

:::

```asn1
RangingRequest ::= SEQUENCE {
    transactionID INTEGER (1..32),
    sourceLayer2ID Layer2ID,
    rangingID INTEGER (1..32),
    rangingObject SEQUENCE {
        slbLayer2ID Layer2ID OPTIONAL,
        sleLayer2ID Layer2ID OPTIONAL
    },
    rangingMode INTEGER (1..32),
    reportingPeriod INTEGER (0..100),
    duration INTEGER (0..65535),
    rangeAccuracy ENUMERATED {l1, l2, l3, spare5, spare4, spare3, spare2, spare1} OPTIONAL,
    ...
}
```

:::{div}
:class: standard-paragraph

<p>各个字段含义如下。</p>

:::

:::{div}
:class: standard-list-block

<ul class="standard-list">
<li><p>——— sourceLayer2ID:发送方 G 节点的媒体接入层标识。</p>
</li>
<li><p>——— rangingID:测距项标识。</p>
</li>
<li><p>——— rangingObject:被测距方的媒体接入层标识。</p>
</li>
<li><p>——— rangingMode:测距模式。1代表基于SLB和SLE的 RSSI测量模式,2代表基于SLB的飞行时间测量模式,其他保留。</p>
</li>
<li><p>——— reportingPeriod:测距报告周期,单位为100ms。</p>
</li>
<li><p>——— duration:从收到消息时刻算起,执行测距的总时长,单位为秒(s)。</p>
</li>
<li><p>——— rangeAccuracy:测距精度要求。11为厘米级,12为亚米级,13为米级,其他预留。</p>
</li></ul>

:::

(gbt-48336-303-2026-clause-8-3-8)=
### 8.3.8 测距响应消息

:::{div}
:class: standard-paragraph

<p>管理模式时,一个 G 节点向另一个 G 节点发送测距响应消息,反馈被测目标的测距结果。非管理模式时不发送测距响应消息。</p>

:::

```asn1
RangingResponse ::= SEQUENCE {
    transactionID INTEGER (1..32),
    sourceLayer2ID Layer2ID,
    rangingID INTEGER (1..32),
    cause INTEGER (1..8) OPTIONAL,
    gPosition Position3D OPTIONAL,  -- Need OR
    referenceTime SEQUENCE {
        dSecond DSecond,
        minuteOfTheDay MinuteOfTheDay OPTIONAL
    },
    rangingResultList SEQUENCE (SIZE (1..64)) OF RangingResult OPTIONAL,
    rangingUnit ENUMERATED {milimeter, centimeter, decimeter, meter} OPTIONAL,  -- Need ON
    timeUnit ENUMERATED {t1ms, t10ms, t1s, spare1} OPTIONAL,  -- Need ON
    ...
}
Position3D ::= SEQUENCE {
    lat Latitude,
    long Longitude,
    elevation Elevation OPTIONAL
}
RangingResult ::= SEQUENCE {
    timeOffset INTEGER (-255..255),
    distance INTEGER (0..4095),
    rangingconfidence Confidence
}
```

:::{div}
:class: standard-paragraph

<p>各个字段含义为:</p>

:::

:::{div}
:class: standard-list-block

<ul class="standard-list">
<li><p>——— sourceLayer2ID:发送方 G 节点的媒体接入层标识;</p>
</li></ul>

:::

:::{div}
:class: standard-list-block

<ul class="standard-list">
<li><p>——— rangingID:测距项标识;</p>
</li>
<li><p>——— cause:仅在测距无法继续执行时携带,1代表精度无法满足要求,2代表无法找到被测距方,3代表测距失败,4代表最后一次反馈测距结果,其他取值预留;</p>
</li>
<li><p>——— gPosition:当前 G 节点的3D 位置;</p>
</li>
<li><p>——— referenceTime:测量结果列表中记录信息的参照时刻;</p>
</li>
<li><p>——— rangingUnit:测距结果列表中的测距单位;</p>
</li>
<li><p>——— timeUnit:测距结果列表中的时间偏移量单位;</p>
</li>
<li><p>——— rangingconfidence:测距置信度。</p>
</li></ul>

:::

### 8.4.14 第二类数据信息传输物理资源配置信息

:::{div}
:class: standard-paragraph

<p>第二类数据信息传输物理资源配置信息信元格式如下所示:</p>

:::

```asn1
DataResourceConfType2 ::= SEQUENCE {
    dmrs-PortInfo ENUMERATED {port1, port2, port4, port8},
    dmrs-CombInfo ENUMERATED {off, on, even, odd},
    codingModulationInfo ENUMERATED {mcs0, mcs1, mcs2, mcs3, mcs4, mcs5, mcs6, mcs7,
        mcs8, mcs9, mcs10, mcs11, mcs12, mcs13, mcs14, mcs15, mcs16, mcs17, mcs18, mcs19,
        mcs20, mcs21, mcs22, mcs23, mcs24, mcs25, mcs26, mcs27, mcs28, mcs29, mcs30, mcs31} OPTIONAL,
    freqResourceType2 BIT STRING (SIZE (10)),
    frameScheduleStarting INTEGER (0..7),
    frameScheduleLength INTEGER (0..7),
    superframePeriod INTEGER (0..127),
    superframeOffset INTEGER (0..127)
}
```

:::{div}
:class: standard-paragraph

<p>各个字段含义如下。</p>

:::

:::{div}
:class: standard-list-block

<ul class="standard-list">
<li><p>——— freqResourceType2:第二类频率资源指示信息,10 比特中从低位比特开始到高位比特结束,与从最低频率开始到最高频率的10个子载波组一一对应。10比特中,取值为1的比特代表使用该比特对应的子载波组,取值为0的比特代表不使用该比特对应的子载波组。</p>
</li></ul>

:::

:::{div}
:class: standard-list-block

<ul class="standard-list">
<li><p>——— frameScheduleStarting:指示超帧内的起始无线帧编号,起始无线帧为#(frameScheduleStarting*6)的无线帧。</p>
</li>
<li><p>——— frameScheduleLength:指示超帧内连续传输的无线帧数量,即第二类数据信息传输在一个超帧内连续传输的无线帧数量为(frameScheduleLength*6+6)。</p>
</li>
<li><p>——— superframePeriod:DataResourceConfType2配置的资源有效的超帧个数。</p>
</li>
<li><p>——— superframeOffset:当超帧号满足 mod(超帧号$,\mathrm{superframePeriod}+1)=\mathrm{superframeOffset}$时,使用 DataResourceConfType2配置的资源传输数据信号。</p>
</li></ul>

:::

:::{div}
:class: standard-paragraph

<p>第二类数据信息传输半静态调度数据在无线帧中使用的资源是控制信息指示的资源中刨除系统开销符号以及用于第一类业务传输资源池资源后的时频资源。</p>

:::

:::{div}
:class: standard-paragraph

<p>第二类数据信息传输解调参考信号支持连续子载波发送,或者梳齿状子载波发送。当采用梳齿状子载波发送时,偶数端口使用偶数子载波发送,奇数端口使用奇数子载波发送。</p>

:::

:::{div}
:class: standard-paragraph

<p>第二类数据信息传输解调参考信号所用的符号是被调度资源中相应子载波可用的前 N 个符号,其中$N=N\_\mathrm{port}/N\_\mathrm{comb},N\_\mathrm{port}$是端口总数量,N_comb取1或者2,当采用连续子载波发送方式时,N_comb为1,当采用梳齿方式发送时,N_comb为2。N 个符号中,第 M 个符号传输的端口号包括[M*N_comb,M*N_comb +N_comb),其中$M=[0,N-1]\text{。}$</p>

:::
