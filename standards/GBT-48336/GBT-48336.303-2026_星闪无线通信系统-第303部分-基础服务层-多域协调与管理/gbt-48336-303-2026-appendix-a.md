# 附录 A (资料性) 多域协调与管理需求场景举例

(gbt-48336-303-2026-clause-a-1)=
## A.1 概述

:::{div}
:class: standard-paragraph

<p>当两个正在工作的 G 节点相互靠近,或者两者的覆盖范围相互重叠时,两者之间使用多域资源协调。</p>

:::

:::{div}
:class: standard-paragraph

<p>当支持多域资源协调的 G 节点存在严格优先级,或者业务存在固定的连接关系时,使用管理模式的多域资源协调。</p>

:::

:::{div}
:class: standard-paragraph

<p>当支持多域资源协调的 G 节点不存在严格优先级,业务上也不存在固定的连接关系,使用非管理模式的多域资源协调。</p>

:::

(gbt-48336-303-2026-clause-a-2)=
## A.2 智能汽车

:::{div}
:class: standard-paragraph

<p>座舱域控制器(CDC)与车载配件(例如,智能车钥匙控制器)之间,使用多域资源协调。</p>

:::

:::{div}
:class: standard-paragraph

<p>车内移动终端与座舱域控制器之间,使用多域资源协调。</p>

:::

:::{div}
:class: standard-paragraph

<p>车内移动终端与车载终端,例如,手机/平板与车载显示屏相互间使用多域资源协调。</p>

:::

:::{div}
:class: standard-paragraph

<p>车内移动终端与另一个车内移动终端之间,例如两个车内手机之间,使用多域资源协调。两者之间不存在严格优先级,根据手机担任管理节点的意愿来协调资源;如果其中一个手机不能担任管理节点,则双方采用多域非管理模式进行资源协调。</p>

:::

:::{div}
:class: standard-paragraph

<p>智能车钥匙控制器与车钥匙定位站之间,使用测距交互。</p>

:::

(gbt-48336-303-2026-clause-a-3)=
## A.3 智能终端

:::{div}
:class: standard-paragraph

<p>邻近的智能终端之间,例如两个智能手机、智能手机与智能音箱、智能音箱与智能电视、智能平板与智能平板之间,使用多域资源协调。</p>

:::

:::{div}
:class: standard-paragraph

<p>密集的办公室内,多个智能笔记本电脑之间,使用多域资源协调。</p>

:::

(gbt-48336-303-2026-clause-a-4)=
## A.4 智能家居

:::{div}
:class: standard-paragraph

<p>智能家居控制器与另一个智能终端之间,例如智能家居网关与突然靠近的智能终端之间,使用多域资源协调。</p>

:::

:::{div}
:class: standard-paragraph

<p>智能家居中相邻的成员设备之间,例如两个智能音箱、智能电视与智能手机之间,使用多域资源协调。</p>

:::

(gbt-48336-303-2026-clause-a-5)=
## A.5 智能制造

:::{div}
:class: standard-paragraph

<p>一个智能制造控制器与相关的一个智能制造子控制器之间,使用管理模式的多域资源协调。</p>

:::
