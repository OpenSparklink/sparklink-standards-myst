(gbt-48336-102-2026-clause-3)=
# 3 术语和定义

:::{div}
:class: standard-paragraph

<p>下列术语和定义适用于本文件。</p>

:::

(gbt-48336-102-2026-clause-3-1)=
## 3.1 媒体接入层标识 media access layer identifier

:::{div}
:class: standard-paragraph

<p>分配给星闪设备的唯一标识，可用于通信的鉴权和寻址。</p>

:::

:::{admonition} 注
:class: note

<p>也称“层二标识”（L2ID）。</p>

:::

(gbt-48336-102-2026-clause-3-2)=
## 3.2 全球唯一机构标识 globally unique organizational identifier

:::{div}
:class: standard-paragraph

<p>与某一公司、组织、制造商、经销商、实体等唯一对应的 24 比特标识或 32 比特标识。</p>

:::

(gbt-48336-102-2026-clause-3-3)=
## 3.3 随机媒体接入层标识 random media access layer identifier

:::{div}
:class: standard-paragraph

<p>星闪设备随机生成并使用的媒体接入层标识（3.1）。</p>

:::

(gbt-48336-102-2026-clause-3-4)=
## 3.4 机构本地媒体接入层标识 organizational local media access layer identifier

:::{div}
:class: standard-paragraph

<p>用于与外部网络隔离的本地星闪网络的媒体接入层标识（3.1）。</p>

:::

(gbt-48336-102-2026-clause-3-5)=
## 3.5 预留媒体接入层标识 reserved media access layer identifier

:::{div}
:class: standard-paragraph

<p>标识管理组织预留的媒体接入层标识（3.1）。</p>

:::

(gbt-48336-102-2026-clause-3-6)=
## 3.6 单播标识 unicast identifier

:::{div}
:class: standard-paragraph

<p>在星闪网络中，用于星闪设备单播的媒体接入层标识（3.1）。</p>

:::

(gbt-48336-102-2026-clause-3-7)=
## 3.7 组播标识 multicast identifier

:::{div}
:class: standard-paragraph

<p>在星闪网络中，用于星闪设备组播的媒体接入层标识（3.1）。</p>

:::
