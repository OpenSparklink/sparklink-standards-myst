# 7.5.5.8 方法调用

(gbt-48336-301-2026-clause-7-5-5-8-1)=
## 7.5.5.8.1 SSAP\_CALL\_METHOD\_CMD消息

:::{div}
:class: standard-paragraph

<p>SSAP_CALL_METHOD_CMD 消息为方法调用命令消息,用于客户端向服务端发送无需响应的方法调用,支持分包发送。</p>

:::

:::{div}
:class: standard-paragraph

<p>SSAP_CALL_METHOD_CMD 消息由消息码、消息控制码、句柄和参数等参数组成(见表83)。</p>

:::

::::{div}
:class: table-scroll

(gbt-48336-301-2026-table-83)=
:::{div}
:class: standard-table-caption

<p>表 83　SSAP_CALL_METHOD_CMD消息格式</p>

:::

<table class="standard-table ">
<tr>
<th>消息参数</th>
<th>长度/字节</th>
<th>消息参数描述</th>
</tr>
<tr>
<td>消息码 (0x12)</td>
<td>1</td>
<td>消息码</td>
</tr>
<tr>
<td>消息控制码</td>
<td>1</td>
<td>bit1~bit0:起 始 包 (0b00)/接 续 包 (0b01)/结 束 包<br/>(0b10)/单个数据包(0b11)<br/>bit7~bit2:预留</td>
</tr>
<tr>
<td>句柄</td>
<td>2</td>
<td>方法的句柄</td>
</tr>

</tr>

::::

:::{div}
:class: standard-paragraph

<p>消息码参数值设置为0x12。</p>

:::

:::{div}
:class: standard-paragraph

<p>消息控制码参数值使用bit1~bit0指示本条消息的分包信息,其他比特位为预留。</p>

:::

:::{div}
:class: standard-paragraph

<p>句柄参数值设置为调用方法的句柄值。</p>

:::

:::{div}
:class: standard-paragraph

<p>参数的长度可变,其值设置为调用方法的参数值,具体格式由基础应用层或基础服务层相关功能单元定义。</p>

:::

:::{div}
:class: standard-paragraph

<p>SSAP_CALL_METHOD_CMD 消息中的句柄应为有效句柄,其参数值在成功设置后应根据基础应用层或基础服务层相关功能单元决定其输出结果。</p>

:::

:::{div}
:class: standard-paragraph

<p>SSAP_CALL_METHOD_CMD 消息收到后,服务端不应产生任何响应。</p>

:::

(gbt-48336-301-2026-clause-7-5-5-8-3)=
## 7.5.5.8.3 SSAP\_CALL\_METHOD\_RSP消息

:::{div}
:class: standard-paragraph

<p>SSAP_CALL_METHOD_RSP消息为方法调用响应消息,用于服务端收到SSAP_CALL_METH-OD_REQ 消息后,向客户端发送方法调用响应,支持分包发送。</p>

:::

:::{div}
:class: standard-paragraph

<p>SSAP_CALL_METHOD_RSP消息由消息码、消息控制码和结果等参数组成(见表85)。</p>

:::

::::{div}
:class: table-scroll

(gbt-48336-301-2026-table-85)=
:::{div}
:class: standard-table-caption

<p>表 85　SSAP_CALL_METHOD_RSP消息格式</p>

:::

<table class="standard-table ">
<tr>
<th>消息参数</th>
<th>长度/字节</th>
<th>消息参数描述</th>
</tr>
<tr>
<td>消息码(0x14)</td>
<td>1</td>
<td>消息码</td>
</tr>
<tr>
<td>消息控制码</td>
<td>1</td>
<td>bit1~bit0:起始包(0b00)/接续包(0b01)/结束包(0b10)/单个数据包(0b11)<br/>bit7~bit2:预留</td>
</tr>
<tr>
<td>结果</td>
<td>可变</td>
<td>方法调用结果返回。服务方法调用后返回的结果,具体格式由基础应用层或基础服务层其他功能单元定义</td>
</tr>
</table>

::::

:::{div}
:class: standard-paragraph

<p>消息码参数值设置为0x14。</p>

:::

:::{div}
:class: standard-paragraph

<p>消息控制码参数值使用bit1~bit0指示本条消息的分包信息,其他比特位为预留。</p>

:::

:::{div}
:class: standard-paragraph

<p>结果参数长度可变,值设置为方法调用返回的结果,该结果具体格式由基础应用层或基础服务层相关功能单元定义。</p>

:::

:::{div}
:class: standard-paragraph

<p>SSAP_CALL_METHOD_REQ 消息中的句柄应为有效句柄,其参数值在成功设置后应根据上层应用服务决定其输出结果。</p>

:::

:::{div}
:class: standard-paragraph

<p>如SSAP_CALL_METHOD_REQ 消息中的句柄在服务端不存在,服务端应发送包含“无效句柄”错误码的SSAP_ERROR_RSP消息,并将错误句柄值设置为对应的请求句柄值。</p>

:::

:::{div}
:class: standard-paragraph

<p>如SSAP_CALL_METHOD_REQ 消息中的句柄对应的条目不可使用方法进行访问,服务端应发送包含“方法访问错误”错误码的 SSAP_ERROR_RSP 消息,并将错误句柄值设置为对应的请求句柄值。</p>

:::
