(gbt-48336-301-2026-clause-3)=
# 3 术语和定义

:::{div}
:class: standard-reference

<p>GB/T48336.101—2026和 GB/T48336.102—2026界定的以及下列术语和定义适用于本文件。</p>

:::

(gbt-48336-301-2026-clause-3-1)=
## 3.1 发现等级 discovery level

:::{div}
:class: standard-paragraph

<p>指示发现方如何处理所接收信息的被发现方公开信息。</p>

:::

(gbt-48336-301-2026-clause-3-2)=
## 3.2 服务端 server

:::{div}
:class: standard-paragraph

<p>提供至少一种具体服务的设备。</p>

:::

(gbt-48336-301-2026-clause-3-3)=
## 3.3 客户端 client

:::{div}
:class: standard-paragraph

<p>访问服务端并接受至少一种具体服务的设备。</p>

:::

(gbt-48336-301-2026-clause-3-4)=
## 3.4 服务结构 service structure

:::{div}
:class: standard-paragraph

<p>描述服务的统一表达格式和框架。</p>

:::

(gbt-48336-301-2026-clause-3-5)=
## 3.5 服务结构缓存 service structure cache

:::{div}
:class: standard-paragraph

<p>服务端服务结构信息保存在客户端本地的副本。</p>

:::

(gbt-48336-301-2026-clause-3-6)=
## 3.6 属性值 attribute value

:::{div}
:class: standard-paragraph

<p>属性条目中的数据值。</p>

:::

(gbt-48336-301-2026-clause-3-7)=
## 3.7 标准服务 standard service

:::{div}
:class: standard-paragraph

<p>由相关机构定义的服务。</p>

:::

(gbt-48336-301-2026-clause-3-8)=
## 3.8 自定义服务 custom service

:::{div}
:class: standard-paragraph

<p>由厂商根据实际需求在符合本文件基础上自行定义的服务。</p>

:::

(gbt-48336-301-2026-clause-3-9)=
## 3.9 端口 port

:::{div}
:class: standard-paragraph

<p>基础应用层与基础服务层进行业务数据交互的基本通路。</p>

:::

(gbt-48336-301-2026-clause-3-10)=
## 3.10 传输模式 transport mode

:::{div}
:class: standard-paragraph

<p>传输通道处理数据的方式。</p>

:::

(gbt-48336-301-2026-clause-3-11)=
## 3.11 缺省传输通道 default transport channel

:::{div}
:class: standard-paragraph

<p>具有固定 TCID 与默认参数、随接入层逻辑信道建立或删除而自动建立或删除的传输通道。</p>

:::

(gbt-48336-301-2026-clause-3-12)=
## 3.12 业务传输通道 service transport channel

:::{div}
:class: standard-paragraph

<p>承载数据业务的传输通道。</p>

:::

(gbt-48336-301-2026-clause-3-13)=
## 3.13 融合传输 multiple access services of data transfer

:::{div}
:class: standard-paragraph

<p>同一业务流数据可承载在不同接入层的传输方式。</p>

:::

(gbt-48336-301-2026-clause-3-14)=
## 3.14 业务流 traffic flow

:::{div}
:class: standard-paragraph

<p>映射到一个端口的应用层数据流。</p>

:::

(gbt-48336-301-2026-clause-3-15)=
## 3.15 SLB设备 SLB device

:::{div}
:class: standard-paragraph

<p>接入层使用SLB技术的设备。</p>

:::

(gbt-48336-301-2026-clause-3-16)=
## 3.16 SLE设备 SLE device

:::{div}
:class: standard-paragraph

<p>接入层使用SLE技术的设备。</p>

:::

(gbt-48336-301-2026-clause-3-17)=
## 3.17 句柄 handler

:::{div}
:class: standard-paragraph

<p>服务端本地用于唯一指示一个条目的索引。</p>

:::
