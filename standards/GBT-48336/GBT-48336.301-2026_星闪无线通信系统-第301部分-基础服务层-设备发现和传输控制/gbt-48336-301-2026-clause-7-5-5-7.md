# 7.5.5.7 通知或指示

(gbt-48336-301-2026-clause-7-5-5-7-1)=
## 7.5.5.7.1 SSAP\_VALUE\_NTF消息

:::{div}
:class: standard-paragraph

<p>SSAP_VALUE_NTF消息为服务数据变化通知消息,用于服务端向客户端发送无需确认的服务数据属性或事件变化通知,支持一次性发送多条通知,支持分包发送。</p>

:::

::::{div}
:class: table-scroll

(gbt-48336-301-2026-table-80)=
:::{div}
:class: standard-table-caption

<p>表 80　SSAP_VALUE_NTF消息格式</p>

:::

<table class="standard-table ">
<tr>
<th>消息参数</th>
<th>长度/字节</th>
<th>消息参数描述</th>
</tr>
<tr>
<td>消息码(0x0F)</td>
<td>1</td>
<td>消息码</td>
</tr>
<tr>
<td>消息控制码</td>
<td>1</td>
<td>bit1~bit0:起始包(0b00)/接续包(0b01)/结束包(0b10)/单个数据包(0b11)<br/>bit2:$0=$属性值的通知$;1=$事件的通知<br/>bit7~bit3:预留</td>
</tr>
<tr>
<td>数据列表</td>
<td>可变</td>
<td>结构:{{句柄1,数据值1长度,数据值1},{句柄2,数据值2长度,数据值2}…...},….}句柄:2字节,通知属性或事件对应的句柄数据值<br/>长度:2字节,指示后续数据值长度数据值:属性值或事件的状态值等</td>
</tr>
</table>

::::

:::{div}
:class: standard-paragraph

<p>SSAP_VALUE_NTF消息由消息码、消息控制码和数据列表等参数组成(见表80)。</p>

:::

:::{div}
:class: standard-paragraph

<p>消息码参数值设置为0x0F。</p>

:::

:::{div}
:class: standard-paragraph

<p>消息控制码参数值以位图方式表示,其中bit7~bit3为预留值。</p>

:::

:::{div}
:class: standard-paragraph

<p>数据列表参数值的长度可变,其结构为{{句柄1,数据值1长度,数据值1},{句柄2,数据值2长度,数据值2}…...},….}。其中,句柄为2字节,指示通知属性或事件对应的句柄;数据值长度为2字节,指示数据值长度;数据值设置为属性值或事件的状态值。</p>

:::

:::{div}
:class: standard-paragraph

<p>数据列表中的句柄值应为有效的句柄。其数据值在成功设置后应成为该属性的新属性值。</p>

:::

:::{div}
:class: standard-paragraph

<p>如客户端在执行服务发现前接收到其不能识别的通知消息时,该客户端可不作处理。后续的处理可由基础应用层或基础服务层功能单元决定。</p>

:::

:::{div}
:class: standard-paragraph

<p>当客户端收到SSAP_VALUE_NTF消息后,不应产生任何响应。</p>

:::

## 7.5.5.7.2 SSAP\_VALUE\_IND消息

:::{div}
:class: standard-paragraph

:::

:class: standard-paragraph

(gbt-48336-301-2026-clause-7-5-5-7-3)=
## 7.5.5.7.3 SSAP\_VALUE\_ACK 消息

:::{div}
:class: standard-paragraph

<p>SSAP_VALUE_ACK 消息为服务数据变更确认消息,用于客户端收到SSAP_VALUE_IND 消息后,向服务端发送服务数据属性或事件变更确认,支持分包发送。</p>

:::

:::{div}
:class: standard-paragraph

<p>SSAP_VALUE_ACK 消息由消息码、消息控制码和数据列表等参数组成(见表82)。</p>

:::

::::{div}
:class: table-scroll

(gbt-48336-301-2026-table-82)=
:::{div}
:class: standard-table-caption

<p>表 82　SSAP_VALUE_ACK 消息格式</p>

:::

<table class="standard-table ">
<tr>
<th>消息参数</th>
<th>长度/字节</th>
<th>消息参数描述</th>
</tr>
<tr>
<td>消息码(0x11)</td>
<td>1</td>
<td>消息码</td>
</tr>
<tr>
<td>消息控制码</td>
<td>1</td>
<td>bit1~bit0:起 始 包 (0b00)/接 续 包 (0b01)/结 束 包<br/>(0b10)/单个数据包(0b11)<br/>bit2:$0=$属性值的指示确认$;1=$事件的指示确认<br/>bit7~bit3:预留</td>
</tr>
<tr>
<td>数据列表</td>
<td>可变</td>
<td>数据列表结构:{确认标志1,确认标志2,……}确认标志:1字节,表示客户端的接收确认$;0=$接收失败$;1=$接收成功</td>
</tr>
</table>

::::

:::{div}
:class: standard-paragraph

<p>消息码参数值设置为0x11。</p>

:::

:::{div}
:class: standard-paragraph

<p>消息控制码参数值以位图方式表示,其中bit7~bit3为预留值。</p>

:::

:::{div}
:class: standard-paragraph

<p>数据列表参数值的长度可变,其结构为{确认标志1,确认标志2,……}。其中,确认标志为1字节,表示客户端的接收确认状态:值为0时表示接收失败,值为1时表示接收成功。</p>

:::

:::{div}
:class: standard-paragraph

<p>如数据列表中的句柄值或属性值为无效值或不能识别,客户端应向服务端发送 SSAP_VALUE_ACK 消息,可忽略已接收到的句柄与属性值信息。</p>

:::
