# 8.9 传输通道性能测量

(gbt-48336-301-2026-clause-8-9-1)=
## 8.9.1 概述

:::{div}
:class: standard-paragraph

<p>传输通道性能测量由测量管理功能单元触发,并由数据传输与适配功能单元执行。测量结果由测量管理功能单元进行收集和记录。记录后的测量结果可用于其他功能单元或授权应用。</p>

:::

:::{div}
:class: standard-paragraph

<p>当本端数据传输与适配功能单元接收到测量管理功能单元触发的传输通道性能测量指示后,通过与对端交互测量帧的方式获取测量帧在两端的收发时间,用于计算传输通道端到端时延和抖动性能。</p>

:::

:::{div}
:class: standard-paragraph

<p>本文件仅支持流模式和可靠模式传输通道的性能测量,相关的测量流程见8.9.2和8.9.3。</p>

:::

:::{div}
:class: standard-paragraph

<p>为满足测量精度,本文件建议两端宜支持一定的时钟同步精度要求。可参考表172提供的时钟同步源类型。</p>

:::

(gbt-48336-301-2026-clause-8-9-2)=
## 8.9.2 流模式下传输通道性能测量

:::{div}
:class: standard-paragraph

<p>流模式下传输通道性能测量为单向测量,主要用于测量传输通道单向时延和抖动。具体执行步骤如下。</p>

:::

:::{div}
:class: standard-list-block

<ol class="alpha-list" start="1">
<li><p>a) 步骤1:当本端数据传输与适配功能单元接收到测量管理功能单元针对特定传输通道的测量配置指示信息后,根据该测量实例配置的总测量时长duration字段值和总测量帧数量probeMaxNum 字段值的要求,按照定义的测量帧格式生成第$k$测量周期的测量请求帧,并在相应传输通道内发送。测量帧 Rep_mode字段设置为0b0000。当测量请求帧生成后,数据传输与适配功能单元应立刻将该测量帧放入对应传输通道的缓存区。其中,同步时钟源类型应设置为对端在测量实例建立回复消息中反馈的selectedSyncClock字段值。</p>
</li>
<li><p>b) 步骤2:当对端在传输通道接收到第$k$测量周期的测量请求帧后,记录接收到测量请求帧的时戳$\mathrm{Timestamp}\_R(k),$并按照如下公式可计算得到该传输通道在第$k$ 测量周期的单向时延和</p>
</li></ol>

:::

:::{div}
:class: standard-paragraph

<p>抖动。</p>

:::

:::{div}
:class: standard-list-block

<ul class="standard-list">
<li><p>——— 单向时延$:\mathrm{Delay}(k)=\mathrm{Timestamp}\_R(k)-\mathrm{Sender}\_\mathrm{Timstamp}(k)$</p>
</li>
<li><p>——— 抖动$:\mathrm{Jitter}(k)=|\mathrm{Delay}(k)-\mathrm{Delay}(k-1)|$其中:</p>
</li>
<li><p>• $k$小于或等于总测量帧数量probeMaxNum 字段值;</p>
</li>
<li><p>• $\mathrm{Sender}\_\mathrm{Timstamp}(k)$为第$k$测量周期本端数据传输与适配功能单元发送测量请求帧的时刻;</p>
</li>
<li><p>• $\mathrm{Timestamp}\_R(k)$为第$k$测量周期对端数据传输与适配功能单元接收到测量请求帧的时刻。</p>
</li></ul>

:::

(gbt-48336-301-2026-clause-8-9-3)=
## 8.9.3 可靠模式下传输通道性能测量

:::{div}
:class: standard-paragraph

<p>在设置测量请求帧内Rep_Mode字段为0b0001时,可靠模式下传输通道性能测量可支持双向测量和单向测量,具体执行步骤如下。</p>

:::

:::{div}
:class: standard-list-block

<ol class="alpha-list" start="1">
<li><p>a) 步骤1:根据测量建立配置的总测量时长和总测量帧数量,本端数据传输与适配功能单元按照测量帧格式生成第$k$ 测量周期的测量请求帧,并在相应传输通道内发送。当测量请求帧生成后,本端数据传输与适配功能单元应立刻将该测量帧放入对应传输通道的缓存区,并记录本端发送测量请求帧时戳为$\mathrm{Sender}\_\mathrm{Timstamp}(k)\text{。}$</p>
</li>
<li><p>b) 步骤2:当对端在传输通道接收到第$k$测量周期的测量请求帧后,解析测量请求帧 Rep_Mode字段为0b0001,则立即生成相应第$k$ 测量周期的测量应答帧,在测量应答帧内记录接收到测量请求帧的时戳$\mathrm{Timestamp}\_R(k)\text{。}$并复制测量请求帧记录的测量请求帧发送时戳Sender_$\mathrm{Timstamp}(k)$到测量应答帧$\mathrm{Timstamp}\_S(k)$字段。对端数据传输与适配功能单元应将测量应答帧放入对应传输通道的缓存区,并记录对端发送测量应答帧时戳为$\mathrm{Sender}\_\mathrm{Timstamp}(k)\text{。}$</p>
</li>
<li><p>c) 步骤3:当本端收到对端发送的第$k$测量周期的测量应答帧后,本端数据传输与适配功能单元应本地记录当前时刻为测量应答帧接收时戳$\mathrm{Timestamp}\_R'(k),$并且读取测量应答帧内包含的$\mathrm{Sender}\_\mathrm{Timstamp}(k)\text{、}\mathrm{Timestamp}\_R(k)$和$\mathrm{Timestamp}\_S(k)$时戳。</p>
</li>
<li><p>d) 步骤4:可分别按照如下公式计算得到两端时钟同步和两端时钟非同步情况下,第$k$测量周期的双向时延和抖动以及单向时延和抖动:</p>
<ul class="standard-list">
<li><p>——— 两端时钟同步情况:</p>
</li>
<li><p>• 双向时延:$\mathrm{Delay}(k)=(\mathrm{Timestamp}\_R(k)-\mathrm{Sender}\_\mathrm{Timstamp}(k))+(\mathrm{Timestamp}\_R'(k)-\mathrm{Timestamp}\_S(k))$</p>
</li>
<li><p>• 双向时延抖动:$\mathrm{Jitter}=|\mathrm{Delay}(k)-\mathrm{Delay}(k-1)|$</p>
</li>
<li><p>• 去程单向时延:$\mathrm{Delay}(k)=\mathrm{Timestamp}\_R(k)-\mathrm{Sender}\_\mathrm{Timstamp}(k)$</p>
</li>
<li><p>• 去程单向时延抖动:$\mathrm{Jitter}=|\mathrm{Delay}(k)-\mathrm{Delay}(k-1)|$</p>
</li>
<li><p>• 回程单向时延:$\mathrm{Delay}'(k)=\mathrm{Timestamp}\_R'(k)-\mathrm{Timestamp}\_S(k)$</p>
</li>
<li><p>• 回程单向时延抖动:$\mathrm{Jitter}=|\mathrm{Delay}'(k)-\mathrm{Delay}'(k-1)|$</p>
</li>
<li><p>——— 两端时钟非同步情况:</p>
</li>
<li><p>• 环回时延:$\mathrm{RTT}(k)=\mathrm{Timestamp}\_R'(k)-\mathrm{Sender}\_\mathrm{Timstamp}(k)$</p>
</li>
<li><p>• 环回时延抖动:</p>
</li></ul>
</li></ol>

:::

```{math}
\mathrm{Jitter}=|\mathrm{RTT}(k)-\mathrm{RTT}(k-1)|
```

:::{div}
:class: standard-list-block

<ul class="standard-list">
<li><p>• 去程/回程单向时延:$\mathrm{Delay}(k)=\mathrm{RTT}(k)/2$</p>
</li>
<li><p>• 去程/回程单向时延抖动:$\mathrm{Jitter}=|\mathrm{Delay}(k)-\mathrm{Delay}(k-1)|$</p>
</li></ul>

:::

:::{div}
:class: standard-paragraph

<p>其中,假设往返空口传输链路时延相同,发送端可基于环回时延(RTT)取平均值的方式近似计算得到去程或回程单向时延。</p>

:::

:::{div}
:class: standard-paragraph

<p>可靠模式传输通道在进行单向测量时,设置测量请求帧内 Rep_Mode字段为0b0000,并通过本端向对端或对端向本端仅发送测量请求帧进行单向时延和抖动测量。具体执行步骤与流模式传输通道单向时延测量流程相同。</p>

:::
