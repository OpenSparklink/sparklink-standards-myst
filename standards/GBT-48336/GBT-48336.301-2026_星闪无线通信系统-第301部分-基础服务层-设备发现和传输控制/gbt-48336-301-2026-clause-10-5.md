# 10.5 测量管理流程

(gbt-48336-301-2026-clause-10-5-1)=
## 10.5.1 传输通道测量实例建立与触发

:::{div}
:class: standard-diagram

```{mermaid}
sequenceDiagram
  participant A as 星闪设备1（本端）
  participant B as 星闪设备2（对端）
  A->>B: 测量实例建立请求
  B->>A: 测量实例建立回复
  A-->>B: 测量实例建立回复确认
```

:::

(gbt-48336-301-2026-figure-90)=
:::{div}
:class: standard-caption

<p>图 90　传输通道测量实例建立流程</p>

:::

:::{div}
:class: standard-paragraph

<p>应先通过连接管理能力查询以确认对端是否支持测量管理功能。应在对端支持测量管理功能时才能发起传输通道测量实例建立。测量实例建立流程如下(见图90)。</p>

:::

:::{div}
:class: standard-paragraph

<p>测量实例建立回复确认信令为可选信令。当测量请求帧由本端发送时无需发送该信令;当测量请求帧由对端发送时应发送以触发对端开始测量。</p>

:::

:::{div}
:class: standard-paragraph

<p>步骤1:本端测量管理功能单元向对端测量管理功能单元发送测量实例建立请求信令 Measure_St-artUp_Req。</p>

:::

:::{div}
:class: standard-list-block

<ul class="standard-list">
<li><p>——— 如果新建一个测量实例,则 measureID 字段应设置为一个未被配置过的新值;如果对一个已建立的测量实例进行重配置,则 measureID 字段应设置为待重配置的测量实例标识。</p>
</li>
<li><p>——— srcTCID 字段和dstTCID 字段分别设置为待测量传输通道在本端和对端的 TCID。</p>
</li>
<li><p>——— 仅支持流模式或可靠模式传输通道的测量。当流模式时,则 measureMode字段只允许配置为0x00(即仅支持单向测量模式)。</p>
</li>
<li><p>——— 如果本端期望对端发送测量请求帧,MT 字段应设置为1。</p>
</li></ul>

:::

:::{div}
:class: standard-paragraph

<p>步骤2:对端测量管理功能单元向本端测量管理功能单元发送测量实例建立回复信令 Measure_St-artUp_Rsp,其中:</p>

:::

:::{div}
:class: standard-list-block

<ul class="standard-list">
<li><p>——— 如果能成功建立该测量实例,则result字段设置为0x00;</p>
</li>
<li><p>——— 如果无法建立该测量实例,则result字段应设置具体失败原因。</p>
</li></ul>

:::

:::{div}
:class: standard-paragraph

<p>步骤3:本端测量管理功能单元接收到测量实例建立回复信令后,流程如下。</p>

:::

:::{div}
:class: standard-list-block

<ul class="standard-list">
<li><p>——— 如果在测量实例建立请求信令中未设置 MT 字段为1,即测量请求帧由本端发送,则本端测量管理功能单元将通知数据传输与适配功能单元触发测量任务,具体流程见8.9。</p>
</li>
<li><p>——— 如果在测量实例建立请求信令中设置 MT 字段为1,即测量请求帧由对端发送,则本端测量管理功能单元向对端测量管理功能单元发送测量实例建立回复确认信令。对端测量管理功能单元接收到测量实例建立回复确认信令后,将通知数据传输与适配功能单元触发测量任务,具体流程见8.9。</p>
</li></ul>

:::

(gbt-48336-301-2026-clause-10-5-2)=
## 10.5.2 传输通道测量实例释放

:::{div}
:class: standard-diagram

```{mermaid}
sequenceDiagram
  participant A as 星闪设备1（本端）
  participant B as 星闪设备2（对端）
  A->>B: 测量实例释放请求
  B->>A: 测量实例释放回复
```

:::

(gbt-48336-301-2026-figure-91)=
:::{div}
:class: standard-caption

<p>图 91　传输通道测量实例释放流程</p>

:::

:::{div}
:class: standard-paragraph

<p>对于每一个正在执行中的测量实例,本端测量管理功能单元可向对端发起测量实例释放流程(见图91)。测量实例释放流程如下。</p>

:::

:::{div}
:class: standard-paragraph

<p>步骤1:本端测量管理功能单元向对端测量管理功能单元发送测量实例释放请求信令 Measure_Release_Req,其中:</p>

:::

:::{div}
:class: standard-list-block

<ul class="standard-list">
<li><p>——— measureID 字段应填写为一个已成功建立且待被释放的测量实例标识;</p>
</li>
<li><p>——— 如果测量请求帧由对端发送,则应设置 MT 字段为1。</p>
</li></ul>

:::

:::{div}
:class: standard-paragraph

<p>步骤2:对端测量管理功能单元接收到释放请求信令后,向本端测量管理功能单元发送测量实例释放回复信令 Measure_Release_Rsp。如果 Measure_Release_Req信令中 MT 字段取值为1,则应通知数据传输与适配功能单元停止发送测量请求帧。</p>

:::

:::{div}
:class: standard-paragraph

<p>步骤3:本端测量管理功能单元接收到测量实例释放回复信令后,如果成功释放且测量请求帧由本端发送,则本端测量管理功能单元应通知数据传输与适配功能单元停止发送测量请求帧。</p>

:::

(gbt-48336-301-2026-clause-10-5-3)=
## 10.5.3 传输通道测量结果反馈

:::{div}
:class: standard-diagram

```{mermaid}
sequenceDiagram
  participant A as 星闪设备1（本端）
  participant B as 星闪设备2（对端）
  B->>A: 测量结果反馈
  A->>B: 测量结果反馈应答
```

:::

(gbt-48336-301-2026-figure-92)=
:::{div}
:class: standard-caption

<p>图 92　传输通道测量结果反馈流程</p>

:::

:::{div}
:class: standard-paragraph

<p>在 Measure_StartUp_Req信令 measureMode字段配置为0x00或0x02进行单向测量,且由本端发送测量请求帧时,对端测量管理功能单元可在完成一个或多个测量实例的测量后触发测量结果反馈流程(见图92)。测量结果反馈流程如下。</p>

:::

:::{div}
:class: standard-paragraph

<p>步骤1:对端测量管理功能单元向本端测量管理功能单元发送测量结果反馈信令 Measure_Notice,包含由 measureID 字段值对应测量实例的测量结果。</p>

:::

:::{div}
:class: standard-paragraph

<p>步骤2:本端测量管理功能单元在接收到测量结果反馈信令后,向对端测量管理功能单元发送测量结果反馈应答信令 Measure_Notice_Confirm。</p>

:::
