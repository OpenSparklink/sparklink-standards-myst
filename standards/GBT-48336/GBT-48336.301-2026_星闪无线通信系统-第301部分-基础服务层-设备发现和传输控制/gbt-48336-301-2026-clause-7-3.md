# 7.3 层间交互

:::{div}
:class: standard-paragraph

<p>如图7所示,服务管理功能单元为基础应用层和基础服务层其他功能单元提供服务注册、维护、删除等功能。各功能单元交互接口属于设备内部接口。</p>

:::

:::{admonition} 注
:class: note

<p>本文件不规定相关接口细节,由实现决定。</p>

:::

```{image} ../../../assets/structured/GBT-48336.301-2026/regions/p0032-figure-01-323.png
:alt: 图 7　服务管理层间交互示例
:class: source-figure

```

(gbt-48336-301-2026-figure-7)=
:::{div}
:class: standard-caption

<p>图 7　服务管理层间交互示例</p>

:::

:::{div}
:class: standard-paragraph

<p>服务端应提供服务注册、服务删除功能。当服务注册完成后,服务端应生成注册服务的服务结构。</p>

:::

:::{div}
:class: standard-paragraph

<p>当接收到服务删除请求后,服务端应释放对应服务的服务结构。</p>

:::

:::{div}
:class: standard-paragraph

<p>服务端应上报服务访问结果(如属性值被修改、接收到方法调用等),并由基础应用层或基础服务层其他功能单元进行后续处理。</p>

:::

:::{div}
:class: standard-paragraph

<p>如被访问到需授权的服务结构,服务端应上报授权请求,由基础应用层或基础服务层其他功能单元决定是否进行授权,并进行授权反馈。</p>

:::

:::{div}
:class: standard-paragraph

<p>客户端应接收来自基础应用层或基础服务层其他功能单元的服务发现和服务访问请求,返回相应的服务结构或服务访问结果,上报来自服务端的事件、通知或指示信息。</p>

:::

:::{div}
:class: standard-paragraph

<p>服务管理功能单元使用服务管理信令(即SSAP消息)并通过数据传输与适配功能单元提供的传输通道实现服务端与客户端之间的服务交互,可使用三种基础模式传输通道:</p>

:::

:::{div}
:class: standard-list-block

<ul class="standard-list">
<li><p>——— SLB服务管理传输通道;</p>
</li>
<li><p>——— SLE服务管理传输通道;</p>
</li>
<li><p>——— SLB中继服务管理传输通道。</p>
</li></ul>

:::

:::{div}
:class: standard-paragraph

<p>当接入层同时支持SLB和SLE时,所使用的传输通道类型可由基础应用层或基础服务层其他特定功能单元指定。在满足一定条件下,也可使用可靠模式传输通道进行更可靠的服务交互。</p>

:::
