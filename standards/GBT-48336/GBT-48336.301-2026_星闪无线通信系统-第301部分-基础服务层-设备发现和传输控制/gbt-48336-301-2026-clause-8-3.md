# 8.3 传输通道类型和作用

(gbt-48336-301-2026-clause-8-3-1)=
## 8.3.1 通则

:::{div}
:class: standard-paragraph

<p>应支持缺省传输通道和非缺省传输通道。</p>

:::

:::{div}
:class: standard-paragraph

<p>缺省传输通道使用固定 TCID,具备默认配置参数。数据传输与适配功能单元可在接入层逻辑信道建立完成后自动建立并激活一条或多条缺省传输通道,也可在接入层逻辑信道释放后自动释放一条或多条缺省传输通道,设备间无需进行信令协商。</p>

:::

:::{div}
:class: standard-paragraph

<p>非缺省传输通道使用动态 TCID,应通过连接管理功能单元相关信令交互进行建立或释放。</p>

:::

(gbt-48336-301-2026-clause-8-3-2)=
## 8.3.2 SLB通用管理传输通道

:::{div}
:class: standard-paragraph

<p>SLB通用管理传输通道仅工作在使用SLB作为接入层技术的场景,用于承载连接管理、测量管理和 QoS管理等功能单元相关信令。</p>

:::

(gbt-48336-301-2026-clause-8-3-3)=
## 8.3.3 SLE通用管理传输通道

:::{div}
:class: standard-paragraph

<p>SLE通用管理传输通道仅工作在使用SLE作为接入层技术的场景,用于承载连接管理、测量管理和 QoS管理等功能单元相关信令。</p>

:::

(gbt-48336-301-2026-clause-8-3-4)=
## 8.3.4 SLB服务管理传输通道

:::{div}
:class: standard-paragraph

<p>SLB服务管理传输通道仅工作在使用SLB作为接入层技术的场景,用于承载服务管理功能单元相关信令。</p>

:::

(gbt-48336-301-2026-clause-8-3-5)=
## 8.3.5 SLE服务管理传输通道

:::{div}
:class: standard-paragraph

<p>SLE服务管理传输通道仅工作在使用SLE作为接入层技术的场景,用于承载服务管理功能单元相关信令。</p>

:::

(gbt-48336-301-2026-clause-8-3-6)=
## 8.3.6 SLB中继服务管理传输通道

:::{div}
:class: standard-paragraph

<p>SLB中继服务管理传输通道仅工作在使用SLB作为接入层技术且支持中继传输功能的场景,承载服务管理功能单元相关信令,用于不同 T 节点之间通过同一 G 节点进行服务发现。</p>

:::

(gbt-48336-301-2026-clause-8-3-7)=
## 8.3.7 多域协调与管理传输通道

:::{div}
:class: standard-paragraph

<p>多域协调与管理传输通道仅适用于支持 G 节点身份且支持多域协调与管理功能的设备,用于承载不同 G 节点之间多域协调与管理功能单元相关信令。</p>

:::

(gbt-48336-301-2026-clause-8-3-8)=
## 8.3.8 5G 融合传输通道

:::{div}
:class: standard-paragraph

<p>5G 融合传输通道仅适用于支持5G 融合功能的设备,用于承载与5G 融合功能单元相关信令。</p>

:::

(gbt-48336-301-2026-clause-8-3-9)=
## 8.3.9 SLB默认单播数据传输通道

:::{div}
:class: standard-paragraph

<p>SLB默认单播数据传输通道仅工作在使用SLB 作为接入层技术的场景,并使用基础模式,用于承载对 QoS没有特定要求的业务数据。</p>

:::

(gbt-48336-301-2026-clause-8-3-10)=
## 8.3.10 SLE默认单播数据传输通道

:::{div}
:class: standard-paragraph

<p>SLE默认单播数据传输通道仅工作在使用SLE作为接入层技术的场景,并使用基础模式,用于承载对 QoS没有特定要求的业务数据。</p>

:::

(gbt-48336-301-2026-clause-8-3-11)=
## 8.3.11 通用控制广播传输通道

:::{div}
:class: standard-paragraph

<p>通用控制广播传输通道仅适用于接入层支持发送上层通用控制广播信息的设备。</p>

:::

:::{div}
:class: standard-list-block

<ul class="standard-list">
<li><p>——— 对于SLE设备,通用控制广播传输通道中的数据可通过SLE基础广播帧、SLE 扩展广播帧或SLE发现响应帧进行发送。</p>
</li>
<li><p>——— 对于SLB设备,通用控制广播传输通道中的数据可通过SLB系统消息进行发送。</p>
</li></ul>

:::

:::{div}
:class: standard-paragraph

<p>典型地,通用控制广播传输通道可用于承载设备发现功能单元生成的设备公开信息。</p>

:::

:::{admonition} 注
:class: note

<p>数据传输与适配功能单元对通用控制广播数据不进行任何封装和调度,直接将其承载在接入层相关广播帧中发送,本文件不对通用控制广播传输通道分配 TCID。</p>

:::

(gbt-48336-301-2026-clause-8-3-12)=
## 8.3.12 非缺省方式下的传输通道

:::{div}
:class: standard-paragraph

<p>非缺省传输通道可用于承载对 QoS有要求的控制信令或业务数据。应通过连接管理功能单元相关信令交互以动态建立或释放非缺省传输通道,包括动态 TCID、传输通道参数等。</p>

:::
