# 8.6 融合传输

(gbt-48336-301-2026-clause-8-6-1)=
## 8.6.1 概述

:::{div}
:class: standard-paragraph

<p>融合传输包含冗余传输、分流传输、SLB2SLE切换传输和SLE2SLB切换传输等四种使用方式。</p>

:::

:::{div}
:class: standard-paragraph

<p>对于采用融合传输的设备,相应业务传输通道支持映射到一个或多个逻辑信道。数据传输与适配功能单元可根据连接管理功能单元的信令协商结果调整传输通道与接入层逻辑信道的映射关系,包括增加、更新和删除业务传输通道对应的逻辑信道。</p>

:::

(gbt-48336-301-2026-clause-8-6-3)=
## 8.6.3 传输通道数据传输

(gbt-48336-301-2026-clause-8-6-3-1)=
### 8.6.3.1 冗余传输

:::{div}
:class: standard-paragraph

<p>当使用冗余传输方式进行融合传输时,一个传输通道应同时映射到一个SLB逻辑信道和一个SLE逻辑信道。相关的连接及映射关系建立流程见9.4.4.2。</p>

:::

:::{div}
:class: standard-paragraph

<p>当建立传输通道后,数据传输与适配功能单元可对该传输通道内的数据执行冗余传输。其中执行冗余传输的数据和总体传输数据的比例,可依赖测量管理和本传输通道的传输能力,留待具体实现。</p>

:::

:::{div}
:class: standard-paragraph

<p>冗余传输开始时刻不应早于为 SLB 和 SLE 相关逻辑信道全被配置完成的时刻。当 SLB 和 SLE相关逻辑信道的任何一个释放或删除映射关系后,冗余传输应停止执行。</p>

:::

:::{div}
:class: standard-paragraph

<p>当使用冗余传输的传输通道采用流模式或可靠模式时,重排序流程应分别遵循相关模式的规定。</p>

:::

(gbt-48336-301-2026-clause-8-6-3-2)=
### 8.6.3.2 分流传输

:::{div}
:class: standard-paragraph

<p>当使用分流传输方式进行融合传输时,一个传输通道应同时映射到一个SLB逻辑信道和一个SLE逻辑信道。相关的连接及映射关系建立流程见9.4.4.2。</p>

:::

:::{div}
:class: standard-paragraph

<p>当建立传输通道后,数据传输与适配功能单元可对该传输通道内的数据执行分流传输。其中各逻辑信道上的分流比例依赖于测量管理和本传输通道的传输能力,留待具体实现。</p>

:::

:::{div}
:class: standard-paragraph

<p>分流传输开始时刻不应早于为 SLB 和 SLE 相关逻辑信道全被配置完成的时刻。当 SLB 和 SLE相关逻辑信道中的任何一个释放或删除映射关系后,分流传输应停止执行。</p>

:::

:::{div}
:class: standard-paragraph

<p>当使用分流传输的传输通道采用流模式或可靠模式时,重排序流程应分别遵循相关模式的规定。</p>

:::

(gbt-48336-301-2026-clause-8-6-3-3)=
### 8.6.3.3 SLB2SLE切换传输

:::{div}
:class: standard-paragraph

<p>针对一个传输通道中的数据,从SLB切换到SLE的控制面流程见9.4.4.3。</p>

:::

:::{div}
:class: standard-paragraph

<p>本文件不对切换条件及切换时机进行规定,具体机制依赖测量管理和本传输通道的传输能力,留待具体实现。</p>

:::

:::{div}
:class: standard-paragraph

<p>在可靠模式下,在切换过程,设备针对该传输通道应先建立并映射到新的SLE 逻辑信道。在映射建立完成后,发送端应将该传输通道中的 PDU 在新的 SLE 逻辑信道上传输并且取消传输通道与SLB逻辑信道的映射。</p>

:::

:::{div}
:class: standard-paragraph

<p>切换过程中,相同 TxSeq包的丢弃和超时丢包操作见8.4.3和8.4.4。</p>

:::
