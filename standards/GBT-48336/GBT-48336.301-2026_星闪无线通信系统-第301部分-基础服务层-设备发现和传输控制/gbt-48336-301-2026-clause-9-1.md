# 9.1 概述

:::{div}
:class: standard-paragraph

<p>连接管理功能单元定义了传输通道相关的连接管理功能、信令及交互流程,包括传输通道的建立、更新和删除流程,以及传输通道与接入层逻辑信道的映射关系维护等。</p>

:::

:::{div}
:class: standard-paragraph

<p>更具体的,连接管理功能单元主要负责以下功能:</p>

:::

:::{div}
:class: standard-list-block

<ul class="standard-list">
<li><p>——— 传输通道的建立、更新和删除;</p>
</li>
<li><p>——— 端口与传输通道 TCID 的映射关系维护;</p>
</li>
<li><p>——— 传输通道与接入层逻辑信道的映射关系维护;</p>
</li>
<li><p>——— 触发接入层建立、更新或删除逻辑信道;</p>
</li>
<li><p>——— 向 QoS管理功能单元反馈当前传输通道的建立状态;</p>
</li>
<li><p>——— 向接入层指示已建立的传输通道 TCID;</p>
</li>
<li><p>——— 接入层传输路径的选择;</p>
</li>
<li><p>——— 与接入层接口信息交互的维护;</p>
</li>
<li><p>——— 向接入层提供业务的模式以及周期。</p>
</li>
<li><p>——— 连接管理功能单元与接入层、基础服务层其他功能单元的关系见图31。</p>
</li></ul>

:::
