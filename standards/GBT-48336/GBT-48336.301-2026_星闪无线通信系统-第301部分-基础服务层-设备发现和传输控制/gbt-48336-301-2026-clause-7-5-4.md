# 7.5.4 SSAP基础要求指令集

:::{div}
:class: standard-paragraph

<p>本文件规定SSAP基础要求指令集,包含客户端和服务端应正确实现的最小指令集合,完成最基础的SSAP交互功能,减少双方服务交互次数,降低获取所需服务时延。</p>

:::

:::{div}
:class: standard-paragraph

<p>基础要求指令集包括客户端针对服务端所提供服务结构条目进行快速发现和读取的消息。客户端应能正确发送该类请求消息并处理对应的响应消息;服务端应能正确接收处理该类消息并发出相应的响应消息:</p>

:::

:::{div}
:class: standard-list-block

<ul class="standard-list">
<li><p>——— SSAP_FIND_STRUCTURE_REQ 消息;</p>
</li>
<li><p>——— SSAP_FIND_BY_UUID_REQ 消息;</p>
</li>
<li><p>——— SSAP_READ_REQ 消息;</p>
</li>
<li><p>——— SSAP_READ_BY_UUID_REQ 消息。</p>
</li></ul>

:::

:::{div}
:class: standard-paragraph

<p>基础要求指令集还应包含以下通知或指示消息。服务端应能正确发送该类消息;客户端应能正确处理该类消息:</p>

:::

:::{div}
:class: standard-list-block

<ul class="standard-list">
<li><p>——— SSAP_VALUE_NTF消息。</p>
</li></ul>

:::

:::{div}
:class: standard-paragraph

<p>基础要求指令集还应包含具有错误处理能力的消息。当错误发生时,服务端应能正确识别错误类型并发送该类消息;客户端应能正确接收和处理该类消息,识别错误类型并做出后续响应。</p>

:::

:::{div}
:class: standard-list-block

<ul class="standard-list">
<li><p>——— SSAP_ERROR_RSP消息。</p>
</li></ul>

:::
