# 10.4 测量管理信令

:::{div}
:class: standard-paragraph

<p>测量管理信令使用SLE通用管理传输通道或SLB通用管理传输通道进行传输,包括测量实例建立、测量实例释放和测量结果反馈等。</p>

:::

:::{div}
:class: standard-paragraph

<p>测量管理信令使用基础服务层通用控制信令格式,各测量管理信令见表167。</p>

:::

<p>信令各字段定义如下。</p>

:::

:::{div}
:class: standard-list-block

<ul class="standard-list">
<li><p>——— measureID:1字节,测量实例标识,取值范围为1~measureInstanceNum 参数值。measureInstanceNum 表示两端设备支持的最大测量实例数,按附录 D 中默认参数配置。</p>
</li>
<li><p>——— srcTCID:1字节,待测量传输通道的本端 TCID。</p>
</li>
<li><p>——— dstTCID:1字节,待测量传输通道的对端 TCID。</p>
</li>
<li><p>——— measureMode:1字节,表示测量模式(见表168)。</p>
</li>
<li><p>——— duration:2字节,表示测量持续时间,单位为秒。</p>
</li>
<li><p>——— probeMaxNum:2字节,表示可发送的最大测量帧数量,范围0~65535。</p>
</li>
<li><p>——— syncClockBitmap:2字节,指示本端支持的一个或多个同步时钟源类型(见表172):</p>
</li>
<li><p>• bit0:预留;</p>
</li>
<li><p>• bit1:GNSS,全球导航卫星系统(GlobalNavigationSatelliteSystem);</p>
</li>
<li><p>• bit2:PTP;</p>
</li>
<li><p>• bit3:基站授时;</p>
</li>
<li><p>• bit4~bit15:预留。</p>
</li>
<li><p>——— MT:1比特,取值为1时,用于指示 MT1事件触发;取值为0时,MT1事件未触发。</p>
</li></ul>

:::

:::{admonition} 注
:class: note

<p>MT1事件:本端期望由对端发送测量请求帧。</p>

:::

:::{div}
:class: standard-list-block

<ul class="standard-list">
<li><p>——— MI:1比特,取值为1时,用于指示有扩展字段;取值为0时,指示无扩展字段。</p>
</li>
<li><p>——— 扩展字段:前2字节是 metricsIndicationBitmap字段,指示对端应在测量结果反馈信令中包含的对端设备性能参数(见图82)。</p>
</li></ul>

:::

<p>信令各字段定义如下。</p>

:::

:::{div}
:class: standard-list-block

<ul class="standard-list">
<li><p>——— measureID:1字节,测量实例标识,应与测量实例建立请求中对应字段取值相同。</p>
</li>
<li><p>——— result:1字节,表示测量实例建立结果。如果取值为0x00,表示测量实例建立成功;如果取值为非0,表示测量实例建立失败,具体设置见表169。</p>
</li>

</li></ul>

:::

:::{admonition} 注
:class: note

<p>MT2事件:当测量实例建立请求信令中 measureMode字段取值为0x02,但是对端仅能支持其中一种测量模式。</p>

:::

:::{div}
:class: standard-list-block

<ul class="standard-list">
<li><p>——— SDC:1比特,取值为0,表示无扩展字段selectedsyncClock;取值为1,表示有扩展字段selectedsyncClock。</p>
</li>
<li><p>——— RFU:6比特,预留。</p>
</li>
<li><p>——— selectedMeasureMode:1字节,扩展字段,仅在触发 MT2事件时包含,取值见表168。</p>
</li></ul>

:::

:::{div}
:class: standard-list-block

<ul class="standard-list">
<li><p>——— selectedsyncClock:2字节,扩展字段,在测量实例建立请求syncClockBitmap字段中选择一种双方均支持的同步时钟源类型。</p>
</li></ul>

<p>信令帧结构各字段定义如下。</p>

:::{div}

<ul class="standard-list">
<li><p>——— measureID:1字节,表示当前测量结果所关联的测量实例标识,取值范围为1~measureInstanceNum 参数值。</p>
</li>
<li><p>——— B:1比特,取值为0,表示无扩展字段buffer;取值为1,表示有扩展字段buffer。</p>
</li>
<li><p>——— AD:1比特,取值为0,表示无扩展字段avgDelay;取值为1,表示有扩展字段avgDelay。</p>
</li>
<li><p>——— AJ:1比特,取值为0,表示无扩展字段avgJitter;取值为1,表示有扩展字段avgJitter。</p>
</li>
<li><p>——— R:1比特,取值为0,表示无扩展字段resultInfo;取值为1,表示有扩展字段resultInfo。</p>
</li>
<li><p>——— buffer:可选字段,1字节,表示设备收发帧缓存区的空闲率,取值范围为0~100。</p>
</li>
<li><p>——— avgDelay:可选字段,2字节,表示在全测量周期内的时延平均值,单位为毫秒,取值范围为0~65535。</p>
</li>
<li><p>——— avgJitter:可选字段,2字节,表示在全测量周期内的时延抖动平均值,单位为毫秒,取值范围为0~65535。</p>
</li></ul>

</li>
<li><p>• length:2字节,指示resultInfo字段总长度;</p>
</li>
<li><p>• delay:2字节,表示一个测量帧的端到端时延,单位为毫秒;</p>
</li>
<li><p>• jitter:2字节,表示一个测量帧的端到端时延抖动,单位为毫秒。</p>
</li></ul>
