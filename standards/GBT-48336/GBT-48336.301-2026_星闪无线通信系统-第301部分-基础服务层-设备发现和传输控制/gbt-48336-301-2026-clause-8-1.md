# 8.1 概述

:::{div}
:class: standard-paragraph

<p>基础服务层的数据传输基于传输通道进行,数据传输与适配功能单元定义了传输通道在数据传输过程中的各种功能,包括:</p>

:::

:::{div}
:class: standard-list-block

<ul class="standard-list">
<li><p>——— 对SDU 进行分片与聚合、生成PDU;</p>
</li>
<li><p>——— 在传输通道上传输PDU,实现流控、分流、中继等功能;</p>
</li>
<li><p>——— 基于测量帧的测量功能。</p>
</li></ul>

:::

:::{admonition} 注
:class: note

<p>从传输通道角度,SDU 是指来自基础服务层其他功能单元或基础应用层的数据报文;PDU 是指在传输通道中传输的、符合传输通道四种帧格式之一的数据报文。</p>

:::

:::{div}
:class: standard-paragraph

<p>在设备内部,SDU 被映射到基础服务层匹配的传输通道,并进一步映射到一个或多个接入层逻辑信道。</p>

:::

:::{div}
:class: standard-paragraph

<p>每个传输通道通过参数 MTU 和 MPS等对传输中的数据大小进行限制。其中 MTU 表示该传输通道可接收的最大SDU 长度,超过该长度的SDU 无法被传输通道处理而被丢弃;MPS表示该传输通道可传递给接入层的最大 PDU 长度,超过该长度的 PDU 会因接入层无法处理而丢弃。设备在建立SLB或SLE通用管理传输通道之后应进行能力协商,查询对方的 MTU 和 MPS。在建立传输通道时,传输通道的 MTU、MPS不能超过设备支持的最大 MTU、MPS,否则传输通道会创建失败。</p>

:::
