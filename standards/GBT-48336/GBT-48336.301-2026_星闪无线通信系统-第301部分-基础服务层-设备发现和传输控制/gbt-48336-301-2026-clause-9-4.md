# 9.4 连接管理流程

(gbt-48336-301-2026-clause-9-4-1)=
## 9.4.1 通用管理传输通道的管理流程

(gbt-48336-301-2026-clause-9-4-1-1)=
### 9.4.1.1 概述

:::{div}
:class: standard-paragraph

<p>通用管理传输通道用于承载基础服务层通用控制信令,包括传输控制信令、中继控制信令、测量管理信令和 QoS管理信令等。根据使用的接入层技术不同,可分为SLB通用管理传输通道和SLE 通用管理传输通道。</p>

:::

(gbt-48336-301-2026-clause-9-4-1-2)=
### 9.4.1.2 通用管理传输通道建立

:::{div}
:class: standard-paragraph

<p>通用管理传输通道默认映射到接入层默认承载。当SLB默认承载建立时,SLB通用管理传输通道自动建立;当SLE默认承载建立时,SLE通用管理传输通道自动建立(见图61)。</p>

:::

:::{div}
:class: standard-diagram

</li>
<li><p>b) 步骤2:连接管理功能单元向接入层实体发送逻辑信道建立请求,其中srcTCID 字段设置为SLB通用管理传输通道或SLE通用管理传输通道。</p>
</li>
<li><p>c) 步骤3:双方接入层共同完成默认承载建立,分别向各自连接管理功能单元反馈逻辑信道建立响应或逻辑信道建立指示。</p>
</li>
<li><p>d) 步骤4:双方各自连接管理功能单元激活各自通用管理传输通道。</p>
</li>
<li><p>e) 步骤5:设备1连接管理功能单元通过原语通知基础应用层初始连接建立情况,设备2向基础应用层通过原语通知通用管理传输通道的连接状态指示。</p>
</li></ol>

:::

(gbt-48336-301-2026-clause-9-4-1-3)=
### 9.4.1.3 通用管理传输通道释放

:::{div}
:class: standard-paragraph

<p>当接入层逻辑信道释放后,通用管理传输通道自动释放。根据释放方式,可分为主动式释放和被动式释放。</p>

:::

:::{div}
:class: standard-paragraph

<p>主动式释放由连接管理功能单元主动发起,本文件不规定其触发条件。典型地,可通过用户界面人工点击触发或由基础应用层触发。以基础应用层触发为例,通用管理传输通道主动式释放过程见图62。</p>

(gbt-48336-301-2026-clause-9-4-2)=
## 9.4.2 其他缺省传输通道的管理流程

(gbt-48336-301-2026-clause-9-4-2-1)=
### 9.4.2.1 其他缺省传输通道的建立

:::{div}
:class: standard-paragraph

<p>对于SLB中继服务管理传输通道,当接入层默认承载建立且支持中继能力时,该传输通道自动建立。</p>

:::

:::{div}
:class: standard-paragraph

<p>对于多域协调与管理传输通道,当 G 节点接入层默认承载建立且支持多域协调与管理功能时,该传输通道自动建立。</p>

:::

:::{div}
:class: standard-paragraph

<p>对于5G 融合功能传输通道,当接入层默认承载建立且支持5G 融合功能时,该传输通道自动建立。</p>

:::

:::{div}
:class: standard-paragraph

<p>对于其他缺省传输通道,当连接管理功能单元在接入层默认承载建立时自动建立并激活。</p>

:::

(gbt-48336-301-2026-clause-9-4-2-2)=
### 9.4.2.2 其他缺省传输通道的释放

:::{div}
:class: standard-paragraph

<p>对于SLB 中继服务管理传输通道,当 SLB 默认承载释放或关闭中继功能时,该传输通道自动释放。</p>

:::

:::{div}
:class: standard-paragraph

<p>对于多域协调与管理传输通道,当 G 节点接入层默认承载释放或关闭多域协调与管理功能时,该传输通道自动释放。</p>

:::

:::{div}
:class: standard-paragraph

<p>对于5G 融合功能传输通道,当接入层默认承载释放或关闭5G 融合功能时,该传输通道自动释放。</p>

:::

:::{div}
:class: standard-paragraph

<p>对于其他缺省传输通道,连接管理功能单元在接入层默认承载释放时自动释放。</p>

:::

(gbt-48336-301-2026-clause-9-4-3)=
## 9.4.3 非缺省传输通道的管理流程

(gbt-48336-301-2026-clause-9-4-3-1)=
### 9.4.3.1 概述

:::{div}
:class: standard-paragraph

<p>非缺省传输通道主要用于业务控制命令以及业务数据的传输。特殊情况下,非缺省传输通道也可用于承载基础服务层各功能单元的控制信令传输。</p>

:::

:::{div}
:class: standard-paragraph

<p>非缺省传输通道需要根据业务传输需求动态建立,使用传输控制信令确定包括传输模式在内的传输通道参数,采用动态 TCID。</p>

:::

<p>传输通道与业务流的关系可以是一对一映射或一对多映射。当传输通道与业务流映射关系发生变化时,可通过增加或删除业务流对传输通道进行重配置。图66为相关典型流程。</p>

(gbt-48336-301-2026-clause-9-4-3-5)=
### 9.4.3.5 广播业务传输通道的建立

(gbt-48336-301-2026-clause-9-4-3-5-1)=
#### 9.4.3.5.1 通则

:::{div}
:class: standard-paragraph

<p>广播业务传输通道是用于传输广播业务数据,使用动态 TCID。</p>

:::

:::{div}
:class: standard-paragraph

<p>广播业务传输通道依赖接入层广播能力,需要其提供支持业务广播的逻辑信道。广播业务传输通道不依赖于连接,其控制信息需要借助通用控制广播传输通道进行传输。</p>

:::

:::{div}
:class: standard-paragraph

<p>需要进行广播业务的设备,分为发送方与接收方。</p>

:::

:::{div}
:class: standard-paragraph

<p>发送方应执行三个操作:</p>

:::

:::{div}
:class: standard-list-block

<ul class="standard-list">
<li><p>——— 建立发送方的广播业务传输通道;</p>
</li>
<li><p>——— 基于该广播业务传输通道,发布广播业务数据;</p>
</li>
<li><p>——— 基于通用控制广播传输通道,发布该广播业务传输通道控制信息,用于通知一到多个接收方存在广播业务以及相关参数,其参数用于建立接收方的广播业务传输通道。</p>
</li></ul>

:::

:::{div}
:class: standard-paragraph

<p>接收方应执行三个操作:</p>

:::

:::{div}
:class: standard-list-block

<ul class="standard-list">
<li><p>——— 监听通用控制广播传输通道,接收一个或多个广播业务传输通道控制信息;</p>
</li>
<li><p>——— 选择一个广播业务传输通道控制信息,并正确建立接收方的广播业务传输通道;</p>
</li>
<li><p>——— 在该广播业务传输通道上接收广播业务。</p>
</li></ul>

:::

## 9.4.4 融合传输连接管理流程

(gbt-48336-301-2026-clause-9-4-4-1)=
### 9.4.4.1 通则

:::{div}
:class: standard-paragraph

<p>融合传输连接管理是指连接管理功能单元根据业务流的 QoS需求对传输通道进行参数配置,使其能执行冗余传输、分流传输、SLB2SLE 切换传输或 SLE2SLB 切换传输等四种融合传输方式之一。具体包括:</p>

:::

:::{div}
:class: standard-list-block

<ul class="standard-list">
<li><p>——— 配置将一条传输通道与多条SLB逻辑信道和SLE逻辑信道建立映射关系,用于冗余传输;</p>
</li>
<li><p>——— 配置将一条传输通道与多条SLB逻辑信道和SLE逻辑信道建立映射关系,用于分流传输;</p>
</li>
<li><p>——— 配置将一条传输通道对应的SLB逻辑信道切换至SLE逻辑信道;</p>
</li>
<li><p>——— 配置将一条传输通道对应的SLE逻辑信道切换至SLB逻辑信道。</p>
</li></ul>

:::

:::{div}
:class: standard-paragraph

<p>在执行融合传输连接管理之前,本端连接管理功能单元应确认对端也同时支持SLB 和SLE 接入技术。</p>

:::
