# 8.5 传输通道帧格式

(gbt-48336-301-2026-clause-8-5-1)=
## 8.5.1 概述

:::{div}
:class: standard-paragraph

<p>传输通道支持基础帧、增强帧、透传帧和测量帧等PDU 帧格式。</p>

:::

:::{div}
:class: standard-paragraph

<p>基础帧和增强帧均包含PI字段,长度为1字节,指示支持的SDU 类型。本文件定义 PI字段的取值如下:</p>

:::

:::{div}
:class: standard-list-block

<ul class="standard-list">
<li><p>——— 0:预留;</p>
</li>
<li><p>——— 1:IPv4;</p>
</li>
<li><p>——— 2:IPv6;</p>
</li>
<li><p>——— 3:CLTP,无连接传输协议(Connectionless-modeTransportProtocol);</p>
</li>
<li><p>——— 4:LWCTP,基于连接传输协议(LightWeightConnection-modeTransportProtocol);</p>
</li>
<li><p>——— 5:WNP,无线网络协议(WirelessNetworkProtocol);</p>
</li>
<li><p>——— 6:WAP,无线邻居协议(WirelessAdjacencyprotocol);</p>
</li>
<li><p>——— 7:GMP,通用消息PDU(GeneralMessagePDU);</p>
</li>
<li><p>——— 8:NSMP,网络安全消息(NetworkSecurityMessagePDU);</p>
</li>
<li><p>——— 9:SSAP;</p>
</li>
<li><p>——— 10:WNCP,无线网络控制协议(WirelessNetworkControlProtocol);</p>
</li>
<li><p>——— 241~250:用户自定义使用;</p>
</li></ul>

:::

:::{div}
:class: standard-list-block

<ul class="standard-list">
<li><p>——— 251~255:试验测试临时使用;</p>
</li>
<li><p>——— 其他:预留。</p>
</li></ul>

:::

(gbt-48336-301-2026-clause-8-5-2)=
## 8.5.2 基础帧

:::{div}
:class: standard-paragraph

<p>基础帧应用于基础模式传输通道。</p>

:::

:::{div}
:class: standard-paragraph

<p>基础帧对SDU 增加包含 TCID、帧类型指示、PI和数据长度指示等字段的帧头。基础帧不对SDU进行分包处理。</p>

:::

:::{div}
:class: standard-paragraph

<p>基础帧格式见图16,各字段定义如下。</p>

:::

:::{div}
:class: standard-list-block

<ul class="standard-list">
<li><p>——— TCID:1字节,在单播传输通道中包含为对端 TCID,在广播传输通道中包含为本端 TCID。</p>
</li>
<li><p>——— 帧类型指示:4比特,指示帧的类型。取值为0b0000表示为基础帧。</p>
</li>
<li><p>——— O:1比特,取值应为0,表示无扩展字段。</p>
</li>
<li><p>——— C:1比特,取值应为0,表示无 CRC校验值。</p>
</li>
<li><p>——— RFU:2比特,预留字段,取值应为0。</p>
</li>
<li><p>——— 长度指示:2字节,指示该字段后剩余部分的字节长度。</p>
</li>
<li><p>——— PI:1字节,指示SDU 类型。</p>
</li>
<li><p>——— 扩展字段:变长,结构同图22中扩展字段结构。</p>
</li>
<li><p>——— 数据信息:变长,0字节~65535 字节,SDU 应用数据。</p>
</li>
<li><p>——— CRC:2字节,可选字段,CRC校验值。</p>
</li></ul>

:::

:::{div}
:class: standard-paragraph

<p>其中,当 TCID 取值为0x01~0x1D 时,基础帧格式中应省略PI字段。</p>

## 8.5.3 增强帧

:::{div}
:class: standard-paragraph

<p>增强帧应用于流模式或可靠模式传输通道。</p>

<p>增强帧从功能角度分为双向帧、单向帧和应答帧;从数据内容角度分为聚合帧和分片帧。</p>

:::

:class: standard-paragraph

<p>不同类型的增强帧可有不同的帧格式,通过帧类型指示字段识别对应类型。</p>

<p>增强帧不同类型帧格式中的各个字段定义如下。</p>

:::

:::{div}
:class: standard-list-block

<ul class="standard-list">
<li><p>——— TCID:1字节,传输通道标识。具体的在单播业务通道中包含为对端标识,在广播传输通道中包含为本端标识。</p>
</li>
<li><p>——— 帧类型指示:4比特,0b0001 标识单向聚合帧,0b0010 标识单向分片帧,0b0011 标识是双向聚合帧,0b0100标识双向分片帧,0b0101标识为应答帧。</p>
</li>
<li><p>——— O:1比特,取值为1表示帧结构中包含扩展字段;取值为0表示无扩展字段。</p>
</li>
<li><p>——— C:1比特,取值应为1,表示帧结构末尾包含2字节 CRC校验值。</p>
</li>
<li><p>——— P:1比特,当P比特为1,则需要对端立即对该数据帧回复,否则为0。</p>
</li>
<li><p>——— F:1 比特,单向帧和双向帧的P比特设置为1时,则接收方下一个双向帧/应答帧中 F比特设置为1,标识对相应单向帧/双向帧的立即回复,其他应答包含$F==0\text{。}$</p>
</li>
<li><p>——— 长度指示:2字节,指示该字段后剩余部分的字节长度。</p>
</li>
<li><p>——— ReqSeq:14比特,期待接收下一个PDU 的 TxSeq。</p>
</li>
<li><p>——— S:1比特,应答帧含义$\text{。}S==0$为正常应答$,S==1$为异常应答。</p>
</li>
<li><p>——— RFU:1比特,预留。</p>
</li>
<li><p>——— TxSeq:14比特,发送PDU 的序列号。</p>
</li>
<li><p>——— SAR:2比特,在分片帧中指示分片状态,0b00:未分片,包含一个完整 SDU;0b01:包含 SDU第一个分片;0b10:包含SDU 中间分片;0b11:包含SDU 最后一个分片。</p>
</li>
<li><p>——— SDU 长度指示:0字节~2字节,指示整个SDU 数据包的长度。在聚合帧中,每一个数据信息包含一个完整的SDU,每个数据信息前都有一个SDU 长度指示。</p>
</li>
<li><p>——— 数据信息:0字节~65535 字节,应用数据。</p>
</li>
<li><p>——— CRC:2字节,CRC校验值。</p>
</li>
<li><p>——— 扩展字段:前1字节指示扩展字段的数量,后续包含扩展字段数量的扩展字段,扩展字段定义为 TLV 格式。针对扩展字段内容长度固定的扩展字段类型,扩展字段长度字段可省略,如图22 所示。</p>
</li></ul>

:::

<p>其中,扩展字段数量:8比特,指示扩展字段的数量;扩展字段类型:8比特,指示扩展字段内容类型;</p>

:::

<p>扩展字段长度:8比特,指示扩展字段内容字节数;扩展字段内容:变长。长度和内容由扩展字段类型值和扩展字段长度值决定。扩展字段类型取值定义如下。</p>

</li>
<li><p>——— 0x01:QoS流标识扩展字段类型,扩展字段内容取值为16比特 QFI。</p>
</li></ul>

:::

<li><p>——— 0x02:QoS流传输性能测量扩展字段类型。扩展字段帧格式应遵循 GB/T48336.302—2026中8.3.2的规定。</p>
</li>
<li><p>——— 0x03~0xFF:预留。</p>
</li></ul>

## 8.5.5 测量帧

:::{div}
:class: standard-paragraph

:::{div}
:class: standard-paragraph

<p>测量帧分为测量请求帧和测量应答帧,帧格式定义分别见图24和图25。当测量帧用于流模式传输通道时,仅支持与数据流传输方向相同的单向测量,此时测量请求帧的 Rep_mode字段应设置为0b0000。当测量帧应用于可靠模式传输通道时,支持单向测量和双向测量,测量请求帧 Rep_mode字段由实际测量需求确定。</p>

:::

:::{div}
:class: standard-paragraph

<p>测量帧不同类型帧格式中各字段定义如下。</p>

:::

:::{div}
:class: standard-list-block

<ul class="standard-list">
<li><p>——— TCID:1字节,指示被测量的传输通道。在单播传输通道中为对端 TCID,在广播传输通道中为本端 TCID。</p>
</li>
<li><p>——— 帧类型:4比特,0b0110标识当前帧为测量请求帧,0b0111标识当前帧为测量应答帧。</p>
</li>
<li><p>——— O:1比特,置1表示帧结构中包含扩展字段;置0表示无扩展字段。</p>
</li>
<li><p>——— C:1比特,置1表示帧结构末尾包含2字节 CRC校验值;置0表示无 CRC校验值。</p>
</li>
<li><p>——— RFU:2比特,预留。</p>
</li>
<li><p>——— 长度指示:2字节,指示该字段后剩余部分的字节长度。</p>
</li>
<li><p>——— 应答模式:4比特,仅出现在测量请求帧。其中,0b0000指示对端接收到该测量请求帧后不需要发送测量应答帧进行回复;0b0001指示对端接收搭配测量请求帧后应立即生成并发送测量应答帧。</p>
</li>
<li><p>——— 标志位:1 字节比特位图。bit0 指示该 TLV 不识别,bit1 指示 TLV 中length 字段定义的value长度与实际参数值长度不匹配,bit2指示测量帧的完整性。其余比特位为预留。</p>
</li>
<li><p>——— 请求帧序列号:14比特,当发送测量请求帧时,指示当前测量请求帧的序列号;当发送测量应答帧时,指示当前测量应答帧对应的测量请求帧的序列号。</p>
</li>
<li><p>——— 请求帧发送时戳:8字节,仅出现在测量应答帧,用于记录测量请求帧的生成时刻,其值应与对应测量请求帧的Sender_Timestamp取值相同。</p>
</li></ul>

:::

:::{div}
:class: standard-list-block

<ul class="standard-list">
<li><p>——— 请求帧接收时戳:8字节,仅出现在测量应答帧,用于记录对应测量请求帧的接收时刻。</p>
</li>
<li><p>——— 帧发送时戳:8字节,用于记录本端数据传输与适配单元发送当前测量帧的时刻。当数据传输</p>
</li></ul>

:::

:::{div}
:class: standard-paragraph

<p>与适配功能单元生成测量帧后,应立刻将该测量帧放入对应传输通道的缓存区。</p>

:::

:::{div}
:class: standard-list-block

<ul class="standard-list">
<li><p>——— 扩展字段:变长,结构同图22中扩展字段结构。</p>
</li>
<li><p>——— CRC:2字节,CRC校验值。</p>
</li></ul>
