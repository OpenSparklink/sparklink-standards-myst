# 6 角色设计

(gbt-48336-402-2026-clause-6-1)=
## 6.1 集合配置器

:::{div}
:class: standard-paragraph

<p>集合配置器应仅作为合作设备集合管理客户端，而不应承载合作设备集合管理服务。</p>

:::

:::{div}
:class: standard-paragraph

<p>集合配置器可接收合作设备集合管理服务端广播发送的设备公开信息，通过设备发现流程发现合作设备集合管理服务端；也可广播发送集合组建邀请，合作设备集合管理服务端通过设备发现流程，接收广播信息并发现集合配置器。</p>

:::

:::{div}
:class: standard-paragraph

<p>集合配置器与合作设备集合管理服务端设备建立连接后，可根据服务管理流程以客户端身份访问合作设备集合管理服务，配置合作设备集合管理服务的属性。</p>

:::

:::{div}
:class: standard-paragraph

<p>集合配置器是一个逻辑功能，可存在以下三种状态：</p>

:::

:::{div}
:class: standard-list-block

<ul class="standard-list">
<li><p>—— 集合配置器；</p>
</li>
<li><p>—— 既为集合配置器又为集合使用者；</p>
</li>
<li><p>—— 既为集合配置器又为集合成员。</p>
</li></ul>

:::

(gbt-48336-402-2026-clause-6-2)=
## 6.2 集合使用者

:::{div}
:class: standard-paragraph

<p>集合使用者分为可配置集合使用者和独立集合使用者。可配置集合使用者由集合配置器配置设备后产生；独立集合使用者不依赖集合配置器、可独立工作。独立集合使用者可仅作为合作设备集合管理的客户端，而不承载合作设备集合管理服务。</p>

:::

:::{div}
:class: standard-paragraph

<p>集合使用者可接收集合成员广播发送的设备公开信息，通过设备发现流程发现集合成员；也可广播发送开放连接合作设备集合邀请或定向连接合作设备集合邀请，集合成员通过设备发现流程，接收广播信息并发现集合使用者。</p>

:::

:::{div}
:class: standard-paragraph

<p>集合使用者与集合成员建立连接后，集合使用者可根据服务管理流程以客户端身份访问集合成员的合作设备集合管理服务，并获取合作设备集合管理服务属性的信息。</p>

:::

:::{div}
:class: standard-paragraph

<p>集合使用者可接收集合配置器通过广播发送的设备公开信息，通过设备发现流程发现集合配置器；</p>

:::

:::{div}
:class: standard-paragraph

<p>也可广播发送开放连接合作设备集合邀请或定向连接合作设备集合邀请，集合配置器通过设备发现流程，接收广播并发现集合使用者。</p>

:::

:::{div}
:class: standard-paragraph

<p>可配置集合使用者与集合配置器建立连接后，集合配置器可根据服务管理流程以客户端身份访问可配置集合使用者的合作设备集合管理服务，配置合作设备集合管理服务的属性。</p>

:::

:::{div}
:class: standard-paragraph

<p>集合使用者是一个逻辑功能，可存在以下两种状态：</p>

:::

:::{div}
:class: standard-list-block

<ul class="standard-list">
<li><p>—— 集合使用者；</p>
</li>
<li><p>—— 既为集合配置器又为集合使用者。</p>
</li></ul>

:::

(gbt-48336-402-2026-clause-6-3)=
## 6.3 集合成员

:::{div}
:class: standard-paragraph

<p>集合成员组成合作设备集合，应承载合作设备集合管理服务，作为合作设备集合管理服务端。集合成员分为固定集合成员和动态集合成员，固定合作设备集合由固定集合成员组成，动态合作设备集合由动态合作设备集合成员组成。动态合作集合成员由集合配置器配置产生。动态合作设备集合可脱离于集合配置器独立工作。</p>

:::

:::{div}
:class: standard-paragraph

<p>集合成员可接收集合使用者通过广播发送的设备公开信息，通过设备发现流程发现集合使用者；也可广播发送合作设备集合和定向连接使用者邀请，集合使用者通过设备发现流程，接收广播信息并发现集合成员。</p>

:::

:::{div}
:class: standard-paragraph

<p>集合使用者与集合成员建立连接后，集合使用者根据服务管理流程以客户端身份访问集合成员的合作设备集合管理服务，并获取合作设备集合管理服务属性的信息。</p>

:::

:::{div}
:class: standard-paragraph

<p>集合成员可接收集合配置器通过广播发送的设备公开信息，通过设备发现流程发现集合配置器；也可广播发送合作设备集合类型服务数据，集合配置器通过设备发现流程，接收广播信息并发现集合成员。</p>

:::

:::{div}
:class: standard-paragraph

<p>动态集合成员与集合配置器建立连接后，集合配置器可根据服务管理流程以客户端身份访问动态集合成员的合作设备集合管理服务，配置合作设备集合管理服务的属性。</p>

:::

:::{div}
:class: standard-paragraph

<p>集合成员是一个逻辑功能，可存在以下两种状态：</p>

:::

:::{div}
:class: standard-list-block

<ul class="standard-list">
<li><p>—— 集合成员；</p>
</li>
<li><p>—— 既为集合配置器又为集合成员。</p>
</li></ul>

:::

(gbt-48336-402-2026-clause-6-4)=
## 6.4 待配置设备

:::{div}
:class: standard-paragraph

<p>待配置设备应承载合作设备集合管理服务，作为合作设备集合管理服务端。</p>

:::

:::{div}
:class: standard-paragraph

<p>待配置设备可接收集合配置器通过广播发送的设备公开信息，通过设备发现流程发现集合配置器；</p>

:::

:::{div}
:class: standard-paragraph

<p>也可广播发送待配置集合，集合配置器通过设备发现流程，接收广播信息并发现待配置设备。</p>

:::

:::{div}
:class: standard-paragraph

<p>待配置设备与集合配置器建立连接后，集合配置器应根据服务管理流程以客户端身份访问待配置设备的合作设备集合管理服务，配置合作设备集合管理服务的必选属性。</p>

:::

:::{div}
:class: standard-paragraph

<p>集合配置器可将待配置设备配置为可配置集合使用者或动态合作设备集合成员；也可将可配置集合使用者或动态合作设备集合成员移出集合，使其成为待配置设备。</p>

:::

:::{div}
:class: standard-paragraph

<p>待配置设备的合作设备集合密钥的属性值应为全零。</p>

:::
