(gbt-48336-402-2026-clause-3)=
# 3 术语和定义

:::{div}
:class: standard-reference

<p>GB/T 48336.101—2026 界定的以及下列术语和定义适用于本文件。</p>

:::

(gbt-48336-402-2026-clause-3-1)=
## 3.1 合作设备集合 cooperative devices set

:::{div}
:class: standard-paragraph

<p>由一组合作设备成员组成的、提供特定服务的统一整体。</p>

:::

(gbt-48336-402-2026-clause-3-2)=
## 3.2 合作设备集合配置器 cooperative devices set configurator

:::{div}
:class: standard-paragraph

<p>管理动态合作设备集合的设备。</p>

:::

:::{admonition} 注
:class: note

<p>包括组建集合、加入集合成员、移除集合成员等，简称“集合配置器”。</p>

:::

(gbt-48336-402-2026-clause-3-3)=
## 3.3 合作设备集合使用者 cooperative devices set user

:::{div}
:class: standard-paragraph

<p>使用合作设备集合提供服务的设备。</p>

:::

:::{admonition} 注
:class: note

<p>简称“集合使用者”。</p>

:::

(gbt-48336-402-2026-clause-3-4)=
## 3.4 合作设备集合成员 cooperative devices set member

:::{div}
:class: standard-paragraph

<p>组成合作设备集合、合作提供特定服务的设备。</p>

:::

:::{admonition} 注
:class: note

<p>简称“集合成员”。</p>

:::

(gbt-48336-402-2026-clause-3-5)=
## 3.5 合作设备集合密钥 cooperative devices set key

:::{div}
:class: standard-paragraph

<p>唯一标识一个合作设备集合的密钥。</p>

:::

(gbt-48336-402-2026-clause-3-6)=
## 3.6 合作设备集合标识 cooperative devices set identification

:::{div}
:class: standard-paragraph

<p>由合作设备集合密钥产生的、用于合作设备集合发现和连接的标识。</p>

:::

(gbt-48336-402-2026-clause-3-7)=
## 3.7 固定合作设备集合 fixed cooperative devices set

:::{div}
:class: standard-paragraph

<p>不可灵活配置的集合，集合成员不可变动、成员承载的合作设备集合管理服务的属性值不能更改。</p>

:::

(gbt-48336-402-2026-clause-3-8)=
## 3.8 动态合作设备集合 dynamic cooperative devices set

:::{div}
:class: standard-paragraph

<p>可灵活配置的集合，集合成员能够添加和删除、成员承载的合作设备集合管理服务的属性值允许更改。</p>

:::

(gbt-48336-402-2026-clause-3-9)=
## 3.9 合作设备集合服务 cooperative devices set service

:::{div}
:class: standard-paragraph

<p>集合成员合作提供的特定服务。</p>

:::

:::{admonition} 注
:class: note

<p>简称“集合服务”。</p>

:::
