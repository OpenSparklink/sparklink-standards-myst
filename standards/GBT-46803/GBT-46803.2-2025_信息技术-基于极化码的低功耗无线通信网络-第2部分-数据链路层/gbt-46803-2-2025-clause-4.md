# 4 缩略语

:::{div}
:class: standard-paragraph

<p>下列缩略语适用于本文件。</p>

:::

:class: standard-definitions

ACK
: 确认字符(AcknowledgeCharacter)

:::

:::{div}
:class: standard-definitions

CBG
: 编码块组(CodeBlockGroup)

:::

:::{div}
:class: standard-definitions

CRC

:::

:::{div}
:class: standard-definitions

ECDH

:::

:::{div}
:class: standard-definitions

:::

:::{div}
:class: standard-definitions

IRK
: 身份解析密钥(IdentityResolvingKey)

:::

:::{div}
:class: standard-definitions

NTP
: 网络时间协议(NetworkTimeProtocol)

:::

:::{div}
:class: standard-definitions

PIN
: 个人识别码(PersonalIdentificationNumber)

:::

:::{div}
:class: standard-definitions

PSK
: 预共享密钥(Pre-SharedKey)

:::

:::{div}
:class: standard-definitions

SDU
: 服务数据单元(ServiceDataUnit)

:::

:::{div}
:class: standard-definitions

TB

:::

:::{div}
:class: standard-definitions

UUID
