(gbt-46803-1-2025-clause-3)=
# 3 术语和定义

:::{div}
:class: standard-paragraph

<p>下列术语和定义适用于本文件。</p>

:::

(gbt-46803-1-2025-clause-3-1)=
## 3.1 管理节点 grant-node

:::{div}
:class: standard-paragraph

<p>G<strong> </strong><strong>节点</strong>在低功耗无线通信系统中,发送接入层资源管理信息的节点。</p>

:::

(gbt-46803-1-2025-clause-3-2)=
## 3.2 终端节点 terminal-node

:::{div}
:class: standard-paragraph

<p>T<strong>节点</strong>在低功耗无线通信系统中,接收管理节点发送的接入层资源管理信息,根据接入层资源管理信息进行数据的发送或者接收的节点。</p>

:::

(gbt-46803-1-2025-clause-3-3)=
## 3.3 无线帧 radio frame

:::{div}
:class: standard-paragraph

<p>发送节点在一个信道中发送的具有时间结构的信息。</p>

:::

:::{admonition} 注
:class: note

<p>包括前导信号部分、同步信号部分、物理层控制信息部分和可能存在的数据部分。</p>

:::

(gbt-46803-1-2025-clause-3-4)=
## 3.4 系统基础时隙长度 system basic slot length

:::{div}
:class: standard-paragraph

<p>基础广播帧、扩展广播帧、系统管理帧、查询请求帧、查询响应帧、接入请求帧、接入响应帧、无链接同步广播数据、无链接异步广播数据起始发送时刻的时间粒度。</p>

:::

(gbt-46803-1-2025-clause-3-5)=
## 3.5 系统调度时隙长度 system scheduling slot length

:::{div}
:class: standard-paragraph

<p>链接态异步数据传输和同步数据传输的起始发送时刻的可调度时间粒度。</p>

:::

(gbt-46803-1-2025-clause-3-6)=
## 3.6 事件 event

:::{div}
:class: standard-paragraph

<p>数据传输的最小基本过程,可以是两个设备先后收发的一次过程,或者广播设备发送一次数据的过程。</p>

:::

(gbt-46803-1-2025-clause-3-7)=
## 3.7 事件组 event group

:::{div}
:class: standard-paragraph

<p>多个事件构成的数据传输的过程。</p>

:::

(gbt-46803-1-2025-clause-3-8)=
## 3.8 事件组集合 event group set

:::{div}
:class: standard-paragraph

<p>多个事件组构成的数据组集合。</p>

:::

(gbt-46803-1-2025-clause-3-9)=
## 3.9 事件内间隔 intra event interval

:::{div}
:class: standard-paragraph

<p>在一次事件中,先发节点的传输结束时刻与后发节点传输开始时刻间的时间。</p>

:::

(gbt-46803-1-2025-clause-3-10)=
## 3.10 事件间间隔 inter event interval

:::{div}
:class: standard-paragraph

<p>在一个事件组内的相邻两个事件中,前面事件的传输结束时刻与后面事件的传输开始时刻间的时间。</p>

:::

(gbt-46803-1-2025-clause-3-11)=
## 3.11 事件组间间隔 inter event group interval

:::{div}
:class: standard-paragraph

<p>对于相邻的两个事件组,前面事件组最后一个事件的传输结束时刻与后面事件组第一个事件的传输开始时刻间的时间。</p>

:::

(gbt-46803-1-2025-clause-3-12)=
## 3.12 异步数据传输 asynchronous data transmission

:::{div}
:class: standard-paragraph

<p>G 节点与 T 节点,或者两个 T 节点间进行可靠数据传输。</p>

:::

(gbt-46803-1-2025-clause-3-13)=
## 3.13 同步数据传输 synchronous data transmission

:::{div}
:class: standard-paragraph

<p>G 节点与 T 节点,或者两个 T 节点间进行非可靠数据传输。</p>

:::

(gbt-46803-1-2025-clause-3-14)=
## 3.14 组长节点 group leader node

:::{div}
:class: standard-paragraph

<p>在一个节点对多个节点的传输中的该一个节点。</p>

:::

(gbt-46803-1-2025-clause-3-15)=
## 3.15 组员节点 group member node

:::{div}
:class: standard-paragraph

<p>在一个节点对多个节点的传输中的该多个节点中的某一个节点。</p>

:::

(gbt-46803-1-2025-clause-3-16)=
## 3.16 数据组播传输 groupcast with data transmission

:::{div}
:class: standard-paragraph

<p>组长节点向多个组员节点发送数据,所有组员节点仅向组长节点反馈数据的正确/错误信息的过程。</p>

:::

(gbt-46803-1-2025-clause-3-17)=
## 3.17 反馈组播传输 groupcast with group leader feekback

:::{div}
:class: standard-paragraph

<p>多个组员节点向组长节点发送数据,组长节点在一个无线帧中向所有组员节点反馈各组员节点数据的正确/错误信息的过程。</p>

:::

(gbt-46803-1-2025-clause-3-18)=
## 3.18 先发节点 former transmission node

:::{div}
:class: standard-paragraph

<p>在一次事件中,在事件开始时刻发送数据的节点。</p>

:::

(gbt-46803-1-2025-clause-3-19)=
## 3.19 后发节点 latter transmission node

:::{div}
:class: standard-paragraph

<p>在一次事件中,在先发节点传输数据后发送数据的节点。</p>

:::

(gbt-46803-1-2025-clause-3-20)=
## 3.20 事件组时间同步锚点 event group synchronization anchor

:::{div}
:class: standard-paragraph

<p>事件组进行时间同步的时刻。</p>

:::

(gbt-46803-1-2025-clause-3-21)=
## 3.21 事件组时间同步锚点时延 delay of event group synchronization anchor

:::{div}
:class: standard-paragraph

<p>事件组的起始时间与该事件组的时间同步锚点的时间间隔。</p>

:::

(gbt-46803-1-2025-clause-3-22)=
## 3.22 基于极化码的低功耗无线通信网络 lowpowerwirelesscommunicationnetworkbasedonpolar

:::{div}
:class: standard-paragraph

<p>coding</p>

:::

:::{div}
:class: standard-paragraph

<p>基于快速信道跳频的单载波通信技术的网络,支持 GFSK 调制和相位调制,支持极化码信道编码。</p>

:::

(gbt-46803-1-2025-clause-3-23)=
## 3.23 基础广播信道 basic broadcast channel

:::{div}
:class: standard-paragraph

<p>使用广播频率承载基础广播帧的信道。</p>

:::

(gbt-46803-1-2025-clause-3-24)=
## 3.24 扩展广播信道 extended broadcast channel

:::{div}
:class: standard-paragraph

<p>由基础广播帧指示的承载扩展广播帧的信道。</p>

:::

(gbt-46803-1-2025-clause-3-25)=
## 3.25 BCH 编码 bose-chaudhuri-hocquenghem code

:::{div}
:class: standard-paragraph

<p>由博斯(Bosc)、查德胡理(Chaudhure)和霍昆格姆(Hocquenghem)提出的能纠正多个随机错误的循环码。</p>

:::

(gbt-46803-1-2025-clause-3-26)=
## 3.26 极化码 polar code

:::{div}
:class: standard-paragraph

<p>基于信道极化理论的前向错误更正编码。</p>

:::
