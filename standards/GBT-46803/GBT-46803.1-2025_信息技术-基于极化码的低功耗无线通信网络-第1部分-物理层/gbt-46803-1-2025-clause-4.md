# 4 符号和缩略语

:::{div}
:class: standard-paragraph

<p>下列缩略语适用于本文件。</p>

:::

:::{div}
:class: standard-definitions

CBG
: 编码块组 (CodeBlockGroup)

:::

:::{div}
:class: standard-definitions

CRC
: 循环冗余校验 (CyclicRedundancyCheck)

:::

:::{div}
:class: standard-definitions

EIRP
: 等效全向辐射功率 (EquivalentIsotropicRadiatedPower)

:::

:::{div}
:class: standard-definitions

GFSK
: 高斯频移键控 (GaussianFrequencyShiftKeying)

:::

:::{div}
:class: standard-definitions

HARQ
: 混合自动重传请求 (HybridAutomaticRepeatreQuest)

:::

:::{div}
:class: standard-definitions

LSB
: 最低有效位 (LeastSignificantBit)

:::

:::{div}
:class: standard-definitions

MCS
: 调制编码方式 (ModulationCodingScheme)

:::

:::{div}
:class: standard-definitions

MSB
: 最高有效位 (MostSignificantBit)

:::

:::{div}
:class: standard-definitions

PSK
: 相移键控 (PhaseShiftKeying)

:::

:::{div}
:class: standard-definitions

RSSI
: 接收信号强度指示 (ReceivedSignalStrengthIndication)

:::
