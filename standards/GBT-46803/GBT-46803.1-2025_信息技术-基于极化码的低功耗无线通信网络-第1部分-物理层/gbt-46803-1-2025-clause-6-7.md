<p>对于基础广播帧、扩展广播帧、查询请求帧、查询响应帧、接入请求帧、接入响应帧,无线帧循环冗余校验字段采用 CRC24A,CRC生成种子为0x555555。</p>

:::

:::{div}
:class: standard-paragraph

<p>对于基础广播帧,采用无线帧类型4,信道编码进行码块分段时,每个码块的循环冗余校验采用CRC24B,CRC生成种子为0x555555。</p>

:::

:::{div}
:class: standard-paragraph

<p>对于扩展广播帧、查询请求帧、查询响应帧、接入请求帧、接入响应帧,采用无线帧类型3和无线帧类型4,信道编码进行码块分段时,每个码块的循环冗余校验采用CRC24B,CRC生成种子为0x555555。</p>

:::

:::{div}
:class: standard-paragraph

<p>系统管理帧,数据链路,在建立链路时通过控制帧信令指示无线帧循环冗余校验字段采用CRC24A或者 CRC32,CRC生成种子由控制帧信令指示。</p>

:::

:::{div}
:class: standard-paragraph

<p>系统管理帧,数据链路,采用无线帧类型3或无线帧类型4,信道编码进行码块分段时,每个码块的循环冗余校验采用 CRC24B进行校验,CRC生成种子由控制帧信令指示。</p>

:::

:::{div}
:class: standard-paragraph

<p>进行循环冗余校验运算的输入信息位序列记为$a_{0},a_{1},a_{2},a_{3},\ldots a_{\mathrm{A}-1}$,生成的校验位序列记为$p_{0},p_{1}$,p<sub>2</sub>,p<sub>3</sub>,…,p<sub>L-1</sub>,其中 A 是输入位的数量,L是校验位的数量。</p>

:::

:::{div}
:class: standard-paragraph

<p>循环冗余校验采用系统码的方式,也即在 GF(2)域中,多项式:$a_{0}D^{\mathrm{A}+\mathrm{L}-1}+a_{1}D^{\mathrm{A}+\mathrm{L}-2}+\ldots +a_{\mathrm{A}-1}D^{\mathrm{L}}+p_{0}D^{\mathrm{L}-1}+p_{1}D^{\mathrm{L}-2}+\ldots +p_{\mathrm{L}-2}D^{1}+p_{\mathrm{L}-1}$可被相应的循环冗余校验生成多项式整除。</p>

:::

:::{div}
:class: standard-paragraph

<p>经过循环冗余校验后的输出位序列表示为$b_{0},b_{1},b_{2},b_{3},\ldots ,b_{\mathrm{B}-1}$,其中$B=A+L\text{。}$输入信息位、校验位、输出位的关系为:</p>

:::

:::{div}
:class: standard-paragraph

<p>$b_{\mathrm{k}}=a_{\mathrm{k}}$,其中$k=0$,1,2…A-1;</p>

:::

:::{div}
:class: standard-paragraph

<p>$b_{\mathrm{k}}=p_{\mathrm{k}-\mathrm{A}}$,其中$k=A$,A+1,A+2…A+L-1。</p>

:::

:::{div}
:class: standard-paragraph

<p>当需要对循环冗余校验输出位序列增加掩码时,经过循环冗余校验后的输出位序列表示为$b_{0},b_{1}$,b<sub>2</sub>,b<sub>3</sub>,…,b<sub>B-1</sub>,其中$B=A+L$。输入信息位、校验位、输出位的关系为:</p>

:::

:::{div}
:class: standard-paragraph

<p>$b_{\mathrm{k}}=a_{\mathrm{k}}$,其中$k=0$,1,2…A-1;</p>

:::

:::{div}
:class: standard-paragraph

<p>$b_{\mathrm{k}}=(p_{\mathrm{k}-\mathrm{A}}+x_{\mathrm{MASK},\mathrm{k}-\mathrm{A}})\mathrm{mod}2$,其中$k=A$,A+1,A+2…A+L-1;</p>

:::

:::{div}
:class: standard-paragraph

<p>其中$L=24,x_{\mathrm{MASK},0},x_{\mathrm{MASK},1},x_{\mathrm{MASK},2},\ldots ,x_{\mathrm{MASK},23}$是掩码序列。</p>

:::

(gbt-46803-1-2025-clause-6-7-3-2)=
### 6.7.3.2 伪随机数生成器

:::{div}
:class: standard-paragraph

<p>伪随机数生成器有两个输入参数,跳频参数1根据时隙计数确定,跳频参数2根据同步序列或者先发链路逻辑链路标识确定。跳频参数的生成方法如下。</p>

:::

:::{div}
:class: standard-list-block

<ul class="standard-list">
<li><p>——— 跳频参数1:16位。截取当前 G 节点的调度时隙计数的低16位。</p>
</li>
<li><p>——— 跳频参数 2:16 位。支持同步序列为 32 位或者 64 位。如果是 64 位同步序列,则截取低32位。如果是24位先发逻辑链路标识,则高位补零为32位。低16和高16位进行异或运算后作为跳频参数2。</p>
</li></ul>

:::

:::{div}
:class: standard-paragraph

<p>伪随机数生成过程包括多个异或、反转和乘加求模过程。跳频参数1和跳频参数2进行异或之后,得到的16位的输出。将输出先进行反转,再将反转后的结果和跳频参数2进行乘加求模,得到的16位的输出。输出的结果进行前述同样的反转和乘加求模过程,并将此过程重复三遍。最后将16位的结果和跳频参数2进行异或,得到最终的16位随机数。</p>

:::

:::{div}
:class: standard-paragraph

<p>各子过程的具体含义如下。</p>

:::

:::{div}
:class: standard-paragraph

<p>异或:运算法则为$0\oplus 0=0,1\oplus 0=1,0\oplus 1=1,1\oplus 1=0($同为0,异为1)。</p>

:::

:::{div}
:class: standard-paragraph

<p>反转:对输入的16位的低8位和高8位分别进行位反转,如位0反转后为位7,位7反转后为位0,位8反转后为位15,位15反转后为位8。</p>

:::

:::{div}
:class: standard-paragraph

<p>乘加求模:相乘、相加、再求模后得到输出。将反转得到的16位结果乘以17,再将相乘后的结果与16位的跳频参数2相加,最后将相加后的结果模上2的16次方得到16位的输出。</p>

:::

(gbt-46803-1-2025-clause-6-7-3-3)=
### 6.7.3.3 数据链路跳频

(gbt-46803-1-2025-clause-6-7-3-3-1)=
#### 6.7.3.3.1 概述

:::{div}
:class: standard-paragraph

<p>数据链路的跳频流程主要分为三个部分,分别为伪随机数生成过程,初次频点映射过程和可用频点映射过程。</p>

:::

:::{div}
:class: standard-paragraph

<p>数据链路跳频的输入参数给伪随机数生成器之后,输出16位的随机数,作为初次频点映射过程的输入。初次频点映射过程将随机数取模并映射后输出对应的跳频频点。如初次频点映射过程的结果为有效频点,则直接输出,如判断为无效频点,则继续使用可用频点映射过程确定跳频频点。</p>

:::

:::{div}
:class: standard-paragraph

<p>数据传输按照事件进行跳频。</p>

:::

(gbt-46803-1-2025-clause-6-7-3-3-2)=
#### 6.7.3.3.2 初次频点映射过程

:::{div}
:class: standard-paragraph

<p>初次频点映射过程将伪随机数生成器输出的16位随机数进行求模,再将求模得到的频点索引在完整频点表上进行映射,并输出映射频点。对应的具体流程如下。</p>

:::

:::{div}
:class: standard-paragraph

<p>步骤一:随机数取模,得到频点索引。对于2.4GHz频段,频点索引(物理信道号)通过随机数模76后获得,对于5.1GHz频段,频点索引(物理信道号)通过随机数模194并增加79后获得,对于5.8GHz频段,频点索引(物理信道号)通过随机数模119并增加276后获得。</p>

:::

:::{div}
:class: standard-paragraph

<p>步骤二:将得到的频点索引映射到完整频点表,最终输出映射频点。其中完整频点表由6.8.1.2对应频段的除去广播信道所用频点的其他所有频点组成。</p>

:::

:::{div}
:class: standard-paragraph

<p>对于1M 带宽场景:直接映射到完整频点表并输出对应映射频点。如果映射的频点在信道质量估计的结果中不属于有效频点,则走可用频点映射过程。</p>

:::

:::{div}
:class: standard-paragraph

<p>对于2M 和4M 场景:如果初次频点映射过程输出的频点不属于2M/4M 跳频频点,则认为是无效频点,走可用频点映射过程。</p>

:::

(gbt-46803-1-2025-clause-6-7-3-3-3)=
#### 6.7.3.3.3 可用频点映射过程

:::{div}
:class: standard-paragraph

<p>将初次频点映射过程得到的频点进行判断,如判断为有效频点,则直接输出跳频频点,如判断为无效频点,则继续走可用频点映射过程。对应具体流程如下。</p>

:::

:::{div}
:class: standard-paragraph

<p>步骤一:可用频点映射过程将伪随机数生成器输出的16位随机数进行重映射,具体计算为随机数乘以可用频点个数再除以2的16次方,最后将结果向下取整,得到频点索引。</p>

:::

:::{div}
:class: standard-paragraph

<p>步骤二:将得到的频点索引映射到可用频点表,最终输出映射频点。其中可用频点表为经过信道质量估计之后得到的有效频点,频点表的频点按照从小到大顺序排列。</p>

:::

:::{div}
:class: standard-paragraph

<p>对于1M/2M/4M 的场景,分别使用对应带宽的频点表得到可用频点后进行索引。</p>

:::

(gbt-46803-1-2025-clause-6-7-3-4)=
### 6.7.3.4 系统管理帧链路跳频

(gbt-46803-1-2025-clause-6-7-3-4-1)=
#### 6.7.3.4.1 概述

:::{div}
:class: standard-paragraph

<p>系统管理帧链路的跳频流程主要分为三个部分,分别为伪随机数生成过程、可用频点映射过程和跳频表更新过程。</p>

:::

:::{div}
:class: standard-paragraph

<p>伪随机数生成过程是将系统管理帧链路跳频的输入参数给伪随机数生成器之后,伪随机数生成器按照6.2.3.2输出16位的随机数,作为可用频点映射过程的输入。</p>

:::

:::{div}
:class: standard-paragraph

<p>可用频点映射过程按照6.7.3.4.2的过程输出映射频点。</p>

:::

:::{div}
:class: standard-paragraph

<p>系统管理帧链路的跳频流程由于直接在可用频点表上进行映射,需要系统支持信道估计,并根据信道估计的结果更新跳频频点表,跳频表更新过程见6.7.3.4.3。</p>

:::

(gbt-46803-1-2025-clause-6-7-3-4-2)=
#### 6.7.3.4.2 可用频点映射过程

:::{div}
:class: standard-paragraph

<p>可用频点映射过程对应的具体流程如下。</p>

:::

:::{div}
:class: standard-paragraph

<p>步骤一:可用频点映射过程将伪随机数生成器输出的16位随机数进行重映射,具体计算为随机数乘以可用频点个数再除以2的16次方,最后将结果向下取整,得到频点索引。</p>

:::

:::{div}
:class: standard-paragraph

<p>步骤二:将得到的频点索引映射到可用频点表,最终输出映射频点。其中可用频点表为经过信道质量估计之后得到的有效频点,频点表的频点按照从小到大顺序排列。</p>

:::

:::{div}
:class: standard-paragraph

<p>对于1M/2M/4M 的场景,分别使用对应带宽的频点表得到可用频点后进行索引。</p>

:::

(gbt-46803-1-2025-clause-6-7-3-4-3)=
#### 6.7.3.4.3 跳频表更新过程

:::{div}
:class: standard-paragraph

<p>跳频表更新过程对应的具体流程如下。</p>

:::

:::{div}
:class: standard-paragraph

<p>步骤一:跳频频点个数固定,跳频表内的所有频点均为可用频点。允许收发双方通过信令交互更新跳频频点个数。</p>

:::

:::{div}
:class: standard-paragraph

<p>步骤二:将信道质量估计得到的可用频点作为输入,当信道质量变化,可用频点表中的频点变为不可用频点时,将其替换为最新信道质量估计的结果。具体更新过程为将最新的可用频点直接替换频点表中的不可用频点,最后频点表中的频点号顺序不一定按照从小到大排列。</p>

:::

:::{div}
:class: standard-paragraph

<p>直接替换频点表中的不可用频点可保证频点表更新时部分频点重复,提高防掉链功能。</p>

:::

<p>对于数据链路,对于每一个事件,将该事件起始时刻的调度时隙序号的低6位设置为0号~5号寄存器的值,并将6号寄存器设置为1作为初始值。</p>

:::

:::{div}
:class: standard-paragraph

<p>在无线帧中,将控制信息编码后的位序列,数据信息、完整性保护信息(可选)和循环冗余校验串联并编码后的位序列,串联后进行位加扰,进行信道位加扰时不复位初始值。</p>
