# 6.3 物理层控制信息

(gbt-46803-1-2025-clause-6-3-1)=
## 6.3.1 物理层控制信息 A组

(gbt-46803-1-2025-clause-6-3-1-1)=
### 6.3.1.1 概述

:::{div}
:class: standard-paragraph

<p>无线帧类型1和无线帧类型2使用物理层控制信息 A 组,物理层控制信息 A 组包括控制信息A1~A7。</p>

:::

(gbt-46803-1-2025-clause-6-3-1-2)=
### 6.3.1.2 控制信息 A1(0b00001)

(gbt-46803-1-2025-clause-6-3-1-2-1)=
#### 6.3.1.2.1 使用场景

:::{div}
:class: standard-paragraph

<p>使用在基础广播帧、扩展广播帧、查询请求帧、查询响应帧、接入请求帧和接入响应帧中。</p>

:::

:::{div}
:class: standard-list-block

<ul class="standard-list">
<li><p>——— 链路质量指示:长8位,包括前4位调制和编码速率指示字段和后4位预留;</p>
</li>
<li><p>——— 广播类型:长3位,0代表不可接入不可查询,1代表可接入不可查询,2代表不可接入,可查询,3代表可接入,可查询,其他取值预留;</p>
</li>
<li><p>——— 包类型:长3位,0代表基础广播,1代表扩展广播,2代表查询请求,3代表查询响应,4代表接入请求,5代表接入响应;</p>
</li>
<li><p>——— 预留:长6位;</p>
</li>
<li><p>——— 数据长度指示:长8位,以字节为单位,指示物理层数据信息部分和完整性保护字段(可选)的长度;</p>
</li>
<li><p>——— 循环冗余校验:长12位,根据6.7.1的处理方法,使用循环冗余校验生成多项式g<sub>CRC12</sub>(D)计算循环冗余校验序列,生成种子为同步序列的低12位。</p>
</li></ul>

:::

:::{div}
:class: standard-paragraph

<p>无线帧类型1不包含链路质量指示字段,控制信息共32位,无编码;无线帧类型2包含链路质量指示字段,控制信息共40位,经过Polar信道编码为64位。</p>

:::

</li>

</li>

</li>
<li><p>——— 系统管理帧接收指示:长1位,指示下一个系统管理帧是否需要接收,当系统管理帧长时间不发生变化时,发送端可指示接收端不接收系统管理帧,节约功耗,0表示需要接收,1表示不需要接收;</p>
</li>
<li><p>——— 预留:长2位;</p>
</li>
<li><p>——— 数据长度指示:长11位,以字节为单位,指示物理层数据信息部分和完整性保护字段(可选)的长度;</p>
</li>
<li><p>——— 循环冗余校验:长12位,根据6.7.1的处理方法,使用循环冗余校验生成多项式g<sub>CRC12</sub>(D)计算循环冗余校验序列,生成种子为同步序列的低12位。</p>
</li></ul>
