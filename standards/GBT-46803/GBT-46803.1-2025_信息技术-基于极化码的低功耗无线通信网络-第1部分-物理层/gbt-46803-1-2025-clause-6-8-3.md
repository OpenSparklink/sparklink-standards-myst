# 6.8.3 接收机

(gbt-46803-1-2025-clause-6-8-3-1)=
## 6.8.3.1 接收功率范围

(gbt-46803-1-2025-clause-6-8-3-1-1)=
### 6.8.3.1.1 参考灵敏度

:::{div}
:class: standard-paragraph

<p>在 GFSK 波形有效载荷字节长度为256字节,初传误包率(PER)不大于10%的情况下,接收机的最小输入电平即参考灵敏度应不大于表34的要求。</p>

:::

:::{div}
:class: standard-paragraph

<p>在PSK 波形有效载荷字节长度为256字节,信道编码为 Polar码,初传误包率(PER)不大于10%的情况下,接收机的最小输入电平即参考灵敏度应不大于表35的要求。</p>

:::

(gbt-46803-1-2025-clause-6-8-3-1-2)=
### 6.8.3.1.2 最大输入电平

:::{div}
:class: standard-paragraph

<p>在 GFSK 有效载荷字节长度为256字节时,初传误包率(PER)不大于10%的情况下,接收机的最大输入电平不低于-10dBm。</p>

:::

(gbt-46803-1-2025-clause-6-8-3-3)=
## 6.8.3.3 接收机杂散发射

:::{div}
:class: standard-paragraph

<p>接收机杂散发射应符合国家频谱法规规定的杂散要求。</p>

:::

(gbt-46803-1-2025-clause-6-8-3-4)=
## 6.8.3.4 接收机 RSSI测量精度

:::{div}
:class: standard-paragraph

<p>如果设备支持接收信号强度指示(RSSI)测量,则在参考灵敏度+6dB的接收信号强度测量误差应不大于$\pm 6\mathrm{dB}\text{。}$</p>

:::

(gbt-46803-1-2025-clause-6-8-3-5)=
## 6.8.3.5 参考信号

:::{div}
:class: standard-paragraph

<p>伪随机序列PRBS11的生成方式如下。</p>

:::

:::{div}
:class: standard-paragraph

<p>由11阶线性反馈移位寄存器产生的伪随机序列,作为有用信号的数据信息。PRBS11 序列以(2^11-1)2047位长度周期重复。见图34,PRBS11由11阶线性反馈移位寄存器产生,其输出端(第10阶)的位和第1阶的位模2相加,结果反馈给输入端(第0阶)。该寄存器的初始值设为全1(11阶都为1)。</p>

:::

```{image} ../../../assets/structured/GBT-46803.1-2025/diagrams/figure-34-register.svg
:alt: 图 34　11阶线性反馈移位寄存器,产生伪随机序列PRBS111。第 1 级和第 10 级输出反馈到加法节点连接至第 0 级。
:class: standard-vector-figure
```

:class: standard-caption

:::{div}
:class: standard-paragraph

:::

:::{div}
:class: standard-paragraph

<p>伪随机序列PRBS17的生成方式如下。</p>

:::

:::{div}
:class: standard-paragraph

<p>由17阶线性反馈移位寄存器产生的伪随机序列,作为干扰信号的数据信息。PRBS17 序列以(2^17-1)131071位长度周期重复。见图35,PRBS17 由17 阶线性反馈移位寄存器产生,其输出端(第16阶)的位和第2阶的输出位模2相加,结果反馈给输入端(第0阶)。该寄存器的初始值设为全1(17阶都为1)。</p>

:::{div}

<p>参考信号的生成方式如下。</p>

:::

:::{div}
:class: standard-paragraph

<p>有用信号使用PRBS11序列作为数据信息,每次发射重复使用相同的PRBS11序列,且采用协议要求的帧格式。</p>

:::

:::{div}
:class: standard-paragraph

<p>干扰信号使用PRBS17序列作为数据信息,每次发射重复使用相同的PRBS17序列。具体的,干扰信号没有帧格式,而是连续的 GFSK 调制信号,并保持和有用信号相同的带宽。此外,干扰信号连续发射不中断。在开始发射有用信号前,干扰信号需要提前至少1ms稳定。</p>

:::

:::{div}
:class: standard-paragraph

<p>测试信号幅度上升和稳定时间如下。</p>

:::

:::{div}
:class: standard-paragraph

<p>上升时间:信号幅度达到最终功率+/-3dB的范围所需要的时间。</p>

:::

:::{div}
:class: standard-paragraph

<p>稳定时间:信号幅度达到最终功率+/-1dB的范围所需要的时间。</p>

:::

:::{div}
:class: standard-paragraph
