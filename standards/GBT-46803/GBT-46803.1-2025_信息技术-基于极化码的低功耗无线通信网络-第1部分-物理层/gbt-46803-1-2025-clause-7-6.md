# 7.6 发射机测试

(gbt-46803-1-2025-clause-7-6-1)=
## 7.6.1 输出功率范围

:::{div}
:class: standard-paragraph

<p>测试目的:验证节点输出功率范围。</p>

:::

:::{div}
:class: standard-paragraph

<p>测试依据:6.8.2.1测试初始配置:支持功率控制的设备需要设置在最大输出功率状态。</p>

:::

:::{div}
:class: standard-paragraph

<p>测试流程。</p>

:::

:::{div}
:class: standard-list-block

<ol class="alpha-list" start="1">
<li><p>a) 设置被测设备调制方式。</p>
</li>
<li><p>b) 被测设备的发射频率设为支持频段内的最低工作频率。</p>
</li>
<li><p>c) 设置被测设备传输速率。</p>
</li>
<li><p>d) 设置被测设备发送的数据包类型。</p>
</li>
<li><p>e) 频谱分析仪应作以下设置:</p>
<ol class="decimal-list" start="1">
<li><p>1) 中心频率:被测设备工作频率;</p>
</li>
<li><p>2) 扫描宽度:0Hz;</p>
</li>
<li><p>3) 分辨率带宽:1M/2M 模式使用3MHz带宽,4 M 模式使用5MHz带宽;</p>
</li>
<li><p>4) 视频带宽$:\geq$分辨率带宽;</p>
</li>
<li><p>5) 检波方式:峰值检波;</p>
</li>
<li><p>6) 模式:Clear/Write;</p>
</li>
<li><p>7) 扫描时间:至少一个完整数据包。</p>
</li></ol>
</li>
<li><p>f) 测试仪记录轨迹中的功率最大值。</p>
</li>
<li><p>g) 将被测设备的输出功率降低一个功率控制精度(下一次测量应从被测设备已经达到新的功率步进时开始)。</p>
</li>
<li><p>h) 重复步骤c)~步骤g),直到被测设备达到它的最小输出功率,并记录每个功率控制精度调整前后功率的差值。</p>
</li>
<li><p>i) 将被测设备的输出功率提高一个功率控制精度(下一次测量应从被测设备已经达到新的功率步进时开始)。</p>
</li>
<li><p>j) 重复步骤c)~步骤f),直到被测设备达到它的最大输出功率,并记录每个功率控制精度调整前后功率的差值。</p>
</li>
<li><p>k) 被测设备的发射频率设为支持频段内的最高工作频率,重复步骤c)~步骤j)。</p>
</li>
<li><p>l) 被测设备的发射频率设为支持频段内的中间工作频率,重复步骤c)~步骤j)。</p>
</li>
<li><p>m) 被测设备如果支持多个频段,则在其他频段内重复步骤b)~步骤l)。</p>
</li>
<li><p>n) 被测设备如果支持多个调制方式,则设置其他调制方式重复步骤a)~步骤 m)。</p>
</li></ol>

:::

:::{div}
:class: standard-paragraph

<p>预期结果:低功耗通信系统设备的最大和最小输出功率应满足表28的定义,该功率为天线连接器处的传导功率,并假定天线增益为0dBi。另外,低功耗通信系统还应符合国家频谱法规规定的功率或者 EIRP的要求。</p>

:::

:::{div}
:class: standard-paragraph

<p>功率控制请求功能可用于根据接收设备的信号电平请求调整连接的发射设备的发射功率电平。当发射间隔较长时,接收设备可使用最近连接的 RSSI测量值来确定是否发送功率控制请求。当发射设备根据功率控制请求调整其发射功率电平时,任意两个相邻发射的功率电平之间的差值应不大于8dB。</p>

:::

(gbt-46803-1-2025-clause-7-6-2)=
## 7.6.2 调制精度

(gbt-46803-1-2025-clause-7-6-2-1)=
### 7.6.2.1 GFSK 频率偏差

:::{div}
:class: standard-paragraph

<p>测试目的:验证基于极化码的低功耗无线通信设备满足 GFSK 频率偏差。</p>

:::

:::{div}
:class: standard-paragraph

<p>测试依据:6.8.2.2.1</p>

:::

:::{div}
:class: standard-paragraph

<p>测试初始配置:支持功率控制的设备需要设置在最大输出功率状态。</p>

:::

:::{div}
:class: standard-paragraph

<p>测试流程。</p>

:::

:::{div}
:class: standard-list-block

<ol class="alpha-list" start="1">
<li><p>a) 设置被测设备的调制方式为 GFSK。</p>
</li>
<li><p>b) 被测设备的发射频率设为支持频段内的最低工作频率,关闭跳频。</p>
</li>
<li><p>c) 被测试设备工作频率记为f0。</p>
</li>
<li><p>d) 设置被测设备传输速率。</p>
</li>
<li><p>e) 设置被测设备发送的数据包类型,数据样式为11110000。</p>
</li>
<li><p>f) 频谱分析仪应作以下设置:</p>
<ol class="decimal-list" start="1">
<li><p>1) 中心频率:被测设备工作频率;</p>
</li>
<li><p>2) 扫描宽度:500kHz;</p>
</li>
<li><p>3) 分辨率带宽:100kHz;</p>
</li>
<li><p>4) 视频带宽:300kHz;</p>
</li>
<li><p>5) 检波方式:峰值检波;</p>
</li>
<li><p>6) 模式:最大保持。</p>
</li></ol>
</li>
<li><p>g) 测试仪记录轨迹中的最大功率点,并记录频率值f1。</p>
</li>
<li><p>h) 频率偏差为$\mathrm{fd}1=f1-f0$。</p>
</li>
<li><p>i) 连续统计10帧的频率偏差平均值。</p>
</li>
<li><p>j) 设置数据样式为10101010,重复步骤f)~步骤g)。</p>
</li>
<li><p>k) 频率偏差为$\mathrm{fd}2=f1-f0$。</p>
</li>
<li><p>l) 连续统计10帧的频率偏差平均值。</p>
</li>
<li><p>m) 被测设备的发射频率设为支持频段内的中间工作频率和最高工作频率,重复步骤c)~步骤l)。</p>
</li>
<li><p>n) 被测设备如果支持多个频段,则在其他频段内重复步骤a)~步骤 m)。</p>
</li></ol>

:::

:::{div}
:class: standard-paragraph

<p>预期结果:使用1Msym/sGFSK 调制的符号间隔是$1\mu s;$对任意序列,最小频率偏差应不小于185kHz;对11110000固定序列,频率偏差fd1应不小于225kHz且不大于275kHz;对10101010固定序列,频率偏差fd2应不小于185kHz;且fd2与fd1在至少10帧上的稳定时段内的平均值的比值应不小于0.8。</p>

:::

:::{div}
:class: standard-paragraph

<p>使用2Msym/sGFSK 调制的符号间隔是$0.5\mu s$;对任意序列,最小频率偏差应不小于370kHz;对11110000固定序列,频率偏差fd1应不小于450kHz且不大于550kHz;对10101010固定序列,频率偏差fd2应不小于370kHz;且fd2与fd1在至少10帧上的稳定时段内的平均值的比值应不小于0.8。</p>

:::

:::{div}
:class: standard-paragraph

<p>使用4Msym/sGFSK 调制的符号间隔是$0.25\mu s$;对任意序列,最小频率偏差应不小于740kHz;</p>

:::

:::{div}
:class: standard-paragraph

<p>对11110000固定序列,频率偏差fd1应不小于900kHz且不大于1100kHz;对10101010固定序列,频率偏差fd2应不小于740kHz;且fd2与fd1在至少10帧上的稳定时段内的平均值的比值应不小于0.8。</p>

:::

:::{div}
:class: standard-paragraph

<p>过零误差是理想符号边界和测量的过零时间之间的时间差,应小于符号周期的$\pm 1/8\text{。}$</p>

:::

(gbt-46803-1-2025-clause-7-6-2-2)=
### 7.6.2.2 PSK 误差矢量幅度

:::{div}
:class: standard-paragraph

<p>测试目的:验证基于极化码的低功耗无线通信设备满足PSK 误差矢量幅度。</p>

:::

:::{div}
:class: standard-paragraph

<p>测试依据:6.8.2.2.2测试初始配置:支持功率控制的设备需要设置在最大输出功率状态。取消跳频。</p>

:::

:::{div}
:class: standard-paragraph

<p>测试流程:</p>

:::

:::{div}
:class: standard-list-block

<ol class="alpha-list" start="1">
<li><p>a) 被测设备的发射频率设为支持频段内的最低工作频率,关闭跳频;</p>
</li></ol>

:::

:::{div}
:class: standard-list-block

<ol class="alpha-list" start="2">
<li><p>b) 设置被测设备调制方式,传输速(码)率;</p>
</li>
<li><p>c) 设置数据包类型;</p>
</li>
<li><p>d) 设置测试仪与被测设备参数一致;</p>
</li>
<li><p>e) 测试仪记录误差矢量结果;</p>
</li>
<li><p>f) 被测设备的发射频率设为支持频段内的最高工作频率,重复步骤a)~步骤e);</p>
</li>
<li><p>g) 被测设备如果支持多个调制方式,则每个调制方式重复步骤a)~步骤f);</p>
</li>
<li><p>h) 被测设备如果支持多个频段,则在其他频段内重复步骤a)~步骤g);</p>
</li></ol>

:::

:::{div}
:class: standard-paragraph

<p>预期结果:低功耗通信系统 PSK 调制采用$\pi /2-\mathrm{BPSK},\pi /4-\mathrm{QPSK}$ 和$\pi /8-8\mathrm{PSK}$ 调制方式。参考波形和被测波形之间的差值称作误差矢量,误差矢量幅度(EVM)用来评估 PSK 调制方式参考波形和被测波形之间的区别。PSK 调制的 EVM 应不大于表29的限值。</p>

:::

(gbt-46803-1-2025-clause-7-6-2-3)=
### 7.6.2.3 频率容限

:::{div}
:class: standard-paragraph

<p>测试目的:验证基于极化码的低功耗无线通信设备满足频率容限。</p>

:::

:::{div}
:class: standard-paragraph

<p>测试依据:见6.8.2.2.3测试初始配置:支持功率控制的设备需要设置在最大输出功率状态。</p>

:::

:::{div}
:class: standard-paragraph

<p>测试流程。</p>

:::

:::{div}
:class: standard-list-block

<ol class="alpha-list" start="1">
<li><p>a) 被测设备的发射频率设为支持频段内的最低工作频率;关闭跳频。</p>
</li>
<li><p>b) 设置被测设备调制方式,传输速(码)率。</p>
</li>
<li><p>c) 设置数据包类型。</p>
</li>
<li><p>d) 设置测试仪与被测设备参数一致。</p>
</li>
<li><p>e) 对于测试仪表设置:</p>
<ol class="decimal-list" start="1">
<li><p>1) 模式:FMdemodulation;</p>
</li>
<li><p>2) 解调滤波器带宽:2MHz;</p>
</li>
<li><p>3) 滤波器通带纹波:0.5dB;</p>
</li>
<li><p>4) 触发模式:RF。</p>
</li></ol>
</li>
<li><p>f) 使用上述设置对数据包进行FM 解调。在传输数据包中的前导字段开始进行测量。测试仪将FM 解调信号的频率从第一个前导码位的中心积分到第8个前导位之后的第一位,共8位。</p>
</li>
<li><p>g) 上述积分和为被测设备的初始载波频率,记为f0。</p>
</li>
<li><p>h) 在整个数据包的有效载荷中,测试仪从有效载荷的第二位开始以10位间隔积分FM 解调信号的频率。重复测量,直到有效载荷持续时间结束。最后一个10位序列不应与数据包末尾的CRC字段重叠。</p>
</li>
<li><p>i) 积分和记为fn,其中n是1~k的整数。fk表示数据包中 CRC 字段开始之前的最后一个积分和。</p>
</li>
<li><p>j) 测试至少包含10个数据包。</p>
</li>
<li><p>k) 测试仪记录频率偏移和频率漂移结果。</p>
</li>
<li><p>l) 被测设备的发射频率设为支持频段内的中间工作频率和最高工作频率,重复步骤a)~步骤k)。</p>
</li>
<li><p>m) 被测设备如果支持多个调制方式,则每个调制方式重复步骤a)~步骤l)。</p>
</li>
<li><p>n) 被测设备如果支持多个频段,则在其他频段内重复步骤a)~步骤 m)。</p>
</li></ol>

:::

:::{div}
:class: standard-paragraph

<p>预期结果:</p>

:::

:::{div}
:class: standard-paragraph

<p>低功耗通信系统在发送数据包期间信道中心频率容限应不大于表30和表31的限值,其中初始频率偏差包括初始频率偏移和漂移。PSK 调制方式包含$\pi /2-\mathrm{BPSK},\pi /4-\mathrm{QPSK}$ 和$\pi /8-8\mathrm{PSK}$ 三种调制方式。</p>

:::

## 7.6.3 无用发射

(gbt-46803-1-2025-clause-7-6-3-1)=
### 7.6.3.1 GFSK 频段内发射

:::{div}
:class: standard-paragraph

<p>测试目的:验证基于极化码的低功耗无线通信设备满足 GFSK 频段内发射。</p>

:::

:::{div}
:class: standard-paragraph

<p>测试依据:6.8.2.3.1测试初始配置:支持功率控制的设备需要设置在最大输出功率状态。</p>

:::

:::{div}
:class: standard-paragraph

<p>测试流程。</p>

:::

:::{div}
:class: standard-list-block

<ol class="alpha-list" start="1">
<li><p>a) 被测设备的发射频率设为支持频段内的最低工作频率,关闭跳频。</p>
</li>
<li><p>b) 设置被测设备传输速率。</p>
</li>
<li><p>c) 设置被测设备发送的数据包类型发射伪随机数据。</p>
</li>
<li><p>d) 频谱分析仪应作以下设置:</p>
