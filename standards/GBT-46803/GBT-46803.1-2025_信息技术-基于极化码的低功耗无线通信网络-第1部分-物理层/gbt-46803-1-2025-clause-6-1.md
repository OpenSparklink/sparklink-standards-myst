(gbt-46803-1-2025-clause-6-1-1)=
## 6.1.1 波形和调制符号

(gbt-46803-1-2025-clause-6-1-1-1)=
### 6.1.1.1 GFSK 调制

:::{div}
:class: standard-paragraph

<p>GFSK 采用带宽和位周期乘积为0.5,调制系数在0.45和0.55之间。位1表示为正频偏,位0表示为负频偏。过零误差应在理想过零点时间的$\pm 1/8$符号间隔内。GFSK 调制波形示意图见图1。</p>

:::

:::{div}
:class: standard-paragraph

<p>带宽1MHzGFSK 的符号间隔是$1\mu s,$频偏不小于185kHz。</p>

:::

:::{div}
:class: standard-paragraph

<p>带宽2MHzGFSK 的符号间隔是$0.5\mu s$,频偏不小于370kHz。</p>

:::

:::{div}
:class: standard-paragraph

<p>带宽4MHzGFSK 的符号间隔是$0.25\mu s$,频偏不小于740kHz。</p>

:::

(gbt-46803-1-2025-clause-6-1-1-2)=
### 6.1.1.2 PSK 调制和导频相位

:::{div}
:class: standard-paragraph

<p>调制方式PSK 采用BPSK、QPSK、8PSK 三种类型:</p>

:::

:::{div}
:class: standard-list-block

<ul class="standard-list">
<li><p>——— BPSK 调制:位0表示为90°相位,位1表示为-90°相位,导频符号使用90°相位,在偶数符号时,额外增加顺时针90°相位旋转;</p>
</li>
<li><p>——— QPSK 调制:位00表示为45°相位,位01表示为135°相位,位11表示为-135°相位,位10表示为-45°相位,导频符号使用45°相位,在偶数符号时,额外增加顺时针45°相位旋转;</p>
</li>
<li><p>——— 8PSK 调制:位000表示为22.5°相位,位001表示为67.5°相位,位011表示为112.5°相位,位010表示为157.5°相位,位110表示为-157.5°相位,位111表示为-112.5°相位,位101表示为-67.5°相位,位100表示为-22.5°相位,导频符号使用22.5°相位,在偶数符号时,额外增加顺时针22.5°相位旋转。</p>
</li></ul>

:::

:::{div}
:class: standard-paragraph

<p>当被调制位序列与调制符号位数不对齐时,在被调制位序列的末尾补充填充位,对齐调制符号位数。PSK 调制采用平方根升余弦脉冲整形生成低通基带信号,如公式(1)所示。</p>

:::

(gbt-46803-1-2025-equation-1)=
```{math}
|P(f)|=\begin{cases}1,&0\leq|f|\leq\frac{1-\beta}{2T}\\\sqrt{\frac12\left\{1-\sin\left[\frac{\pi(2|f|T-1)}{2\beta}\right]\right\}},&\frac{1-\beta}{2T}\leq|f|\leq\frac{1+\beta}{2T}\\0,&\text{其他}\end{cases}\tag{1}
```

:::{div}
:class: standard-paragraph

<p>式中:</p>

:::

:::{div}
:class: standard-definitions

$\beta$
: 滚降系数,为0.4;

:::

:::{div}
:class: standard-definitions

$T$
: 符号周期,带宽 1 MHzPSK 信号符号周期是$1\mu s$,带宽 2 MHzPSK 信号符号周期是$0.5\mu s$,带宽4MHz,PSK 信号符号周期是$0.25\mu s$。

:::

(gbt-46803-1-2025-clause-6-1-2)=
## 6.1.2 前导信号

:::{div}
:class: standard-paragraph

<p>当采用基于 GFSK 调制的无线帧类型1,前导信号采用 GFSK 调制的[0,1]交替变换的序列。前导码长度$10\mu s,$前导序列的第一个码元是0。</p>

:::

:::{div}
:class: standard-paragraph

<p>当采用基于PSK 调制的无线帧类型2、无线帧类型3、无线帧类型4时,前导信号采用相位$[\pi /4,0]$交替变换的序列。对于无线帧类型2,前导码长度$10\mu s\text{。}$对于无线帧类型3,前导码长度$12\mu s\text{。}$对于无线帧类型4,前导码长度$16\mu s\text{。}$</p>

:::

:::{div}
:class: standard-paragraph

<p>不同的信号带宽,前导码所占的绝对时间保持不变。</p>

:::

:::{div}
:class: standard-paragraph

<p>前导码的示例参考附录 A。</p>

:::

(gbt-46803-1-2025-clause-6-1-3)=
## 6.1.3 同步序列/同步信号

(gbt-46803-1-2025-clause-6-1-3-1)=
### 6.1.3.1 同步信号1

:::{div}
:class: standard-paragraph

<p>广播帧采用32 位的固定同步序列0x5A2BDA62,位序列从最低位到最高位为:<span class="standard-literal"><code>01000110010110111101010001011010</code></span>。其他类型帧按照下述方式产生相应的同步序列。</p>

:::

:::{div}
:class: standard-paragraph

<p>24位逻辑链路标识,经过 BCH 编码和 m 序列加扰后,产生32位,再经过 GFSK 调制后生成由32个符号构成的同步信号。32位同步序列生成流程见图2。</p>

:::

:::{div}
:class: table-scroll figure-table-scroll

<table class="standard-table figure-table">
<tr><th class="figure-table-scope-col">步骤</th><th class="figure-table-scope-col">字段顺序或运算</th></tr>
<tr><td>BCH 编码器输入</td><td>10｜逻辑链路标识 $a_0a_1\ldots a_{23}$</td></tr>
<tr><td>BCH 编码器输出</td><td>10｜$a_0a_1\ldots a_{23}$｜$c_0c_1\ldots c_4$</td></tr>
<tr><td>伪随机数</td><td>$p_0p_1$｜$p_2p_3\ldots p_{25}$｜$p_{26}\ldots p_{30}$</td></tr>
<tr><td>32 位参考信号</td><td>BCH 编码器输出与伪随机数模二相加，按 LSB → MSB 排列为 $b_0b_1\ldots b_{30}$｜0</td></tr>
</table>

:::

(gbt-46803-1-2025-figure-2)=
:::{div}
:class: standard-caption

<p>图 2　32位同步序列生成流程</p>

:::

:::{div}
:class: standard-paragraph

<p>24位的逻辑链路标识的多项式表示为$A(d)=a_{0}+a_{1}d+a_{2}d^{2}+\ldots +a_{23}d^{23}$,其中d表示一个位的时延$,a_{0}$是逻辑链路标识的 LSB,a<sub>23</sub>是逻辑链路标识 MSB。32位参考信号的生成流程如下。</p>

:::

:::{div}
:class: standard-list-block

<ul class="standard-list">
<li><p>——— 第一步,24位逻辑链路标识前面补两个位“10”,得到26位序列$\widetilde{,A}(d)=1+d^{2}A(d),$其中,d表示一个位的时延,A(d)为24位的逻辑链路标识$\widetilde{,A}(d)$表示生成的26位序列。</p>
</li>
<li><p>——— 第二步,第一步生成的26位序列输入(31,26)BCH 编码器进行编码,(31,26)BCH 编码器生成多项式的八进制$G(d)=0o45,\mathrm{BCH}$ 编码器产生的校验位序列$C(d)=d^{5}\widetilde{A}(d)\mathrm{modG}(d),$通过信息位和校验位合并得到31位的汉明距离为3的码字$\widetilde{S(d)=A}(d)+d^{26}C(d)\text{。}$</p>
</li>
<li><p>——— 第三步,31位码字和31位的伪随机序列P(d)异或操作$\widetilde{S}(d)=S(d)+P(d)\text{。}$</p>
</li>
<li><p>——— 第四步,末尾补一个位的“0”,得到32位的同步序列,经过 GFSK 调制产生32个同步符号。</p>
</li></ul>

:::

:::{div}
:class: standard-paragraph

<p>伪随机序列采用31位的 m 序列,通过下面的5阶线性反馈移位寄存器产生,初始值全1,其中第一个输出位是最低位,最后一个输出位是最高位。32位同步序列的 m 序列生成器见图3。</p>

:::

```{image} ../../../assets/structured/GBT-46803.1-2025/diagrams/figure-3-register.svg
:alt: 图 3　32位同步序列的 m 序列生成器。第 1 级和第 4 级输出反馈到加法节点连接至第 0 级。
:class: standard-vector-figure
```

(gbt-46803-1-2025-figure-3)=
:::{div}
:class: standard-caption

<p>图 3　32位同步序列的 m 序列生成器</p>

:::

:::{div}
:class: standard-paragraph

<p>生成的同步序列需满足如下3个条件:</p>

:::

:::{div}
:class: standard-list-block

<ul class="standard-list">
<li><p>——— 不能出现7个或7个以上的连续0或1;</p>
</li>
<li><p>——— 不能出现26次或26次以上的0和1之间的跳转;</p>
</li>
<li><p>——— 不能和广播帧的同步序列相同。</p>
</li></ul>

:::

### 6.1.3.2 同步信号2

:::{div}
:class: standard-paragraph

<p>广播帧采用64位的固定同步序列0x7DE7585C6D226540,位序列从最低位到最高位为:<span class="standard-literal"><code>0000001010100110010001001011011000111010000110101110011110111110</code></span>。其他类型帧按照下述方式产生相应的同步序列,但是不能和广播帧的固定同步序列相同。</p>

:::

:::{div}
:class: standard-paragraph

<p>24位逻辑链路标识,经过BCH 编码和 m 序列加扰后,产生64位,再 QPSK 调制后生成由32个符号构成的同步信号。64位同步序列生成流程见图4。</p>

</li></ul>
