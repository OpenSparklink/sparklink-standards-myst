# 7.7 接收机测试

(gbt-46803-1-2025-clause-7-7-1)=
## 7.7.1 接收功率范围

(gbt-46803-1-2025-clause-7-7-1-1)=
### 7.7.1.1 参考灵敏度

:::{div}
:class: standard-paragraph

<p>测试目的:验证基于极化码的低功耗无线通信设备满足参考灵敏度。</p>

:::

:::{div}
:class: standard-paragraph

<p>测试依据:6.8.3.1.1测试初始配置:无。</p>

:::

:::{div}
:class: standard-paragraph

<p>测试流程:</p>

:::

:::{div}
:class: standard-list-block

<ol class="alpha-list" start="1">
<li><p>a) 设置测试仪发射频率为被测设备支持频段的最低工作频率,关闭跳频;</p>
</li>
<li><p>b) 设置测试仪参数,调制方式和 MCS编号(码率),有效载荷字节长度为256字节,信道编码为Polar码,带宽为1MHz(仅针对PSK 调制);</p>
</li>
<li><p>c) 设置测试仪向被测设备连续发送数据块,发射电平为灵敏度值(GFSK 见表34,PSK 见表35);</p>
</li>
<li><p>d) 测试仪接收返回的数据块,并计算初传误包率(PER);</p>
</li>
<li><p>e) 设置测试仪发射频率为被测设备支持频段的中间工作频率和最高工作频率,重复步骤a)~步骤d);</p>
</li>
<li><p>f) 被测设备如果支持多个频段,则在其他频段内重复步骤a)~步骤e);</p>
</li>
<li><p>g) 被测试设备支持的调制方式、带宽和 MCS都需要重复步骤a)~步骤f)。</p>
</li></ol>

:::

:::{div}
:class: standard-paragraph

<p>预期结果:有效载荷字节长度为256字节,PSK 信道编码为 Polar码,初传误包率(PER)不大于10%的情况下,接收机的最小输入电平即参考灵敏度应不大于表34和表35。</p>

:::

(gbt-46803-1-2025-clause-7-7-1-2)=
### 7.7.1.2 最大输入电平

:::{div}
:class: standard-paragraph

<p>测试目的:验证基于极化码的低功耗无线通信设备满足最大输入电平要求。</p>

:::

:::{div}
:class: standard-paragraph

<p>测试依据:6.8.3.1.2测试初始配置:无。</p>

:::

:::{div}
:class: standard-paragraph

<p>测试流程:</p>

:::

:::{div}
:class: standard-list-block

<ol class="alpha-list" start="1">
<li><p>a) 设置测试仪发射频率为被测设备支持频段的最低工作频率,关闭跳频;</p>

</li>
<li><p>c) 设置测试仪向被测设备连续发送数据块,发射电平为-10dBm;</p>

:::

(gbt-46803-1-2025-clause-7-7-2)=
## 7.7.2 接收机选择性

(gbt-46803-1-2025-clause-7-7-2-1)=
### 7.7.2.1 频段内选择性

:::{div}
:class: standard-paragraph

<p>测试目的:验证基于极化码的低功耗无线通信设备满足接收机频段内选择性。</p>

:::

:::{div}
:class: standard-paragraph

<p>测试依据:6.8.3.2.1测试初始配置:取消跳频。</p>

:::

:::{div}
:class: standard-paragraph

<p>测试流程:</p>

:::

:::{div}
:class: standard-list-block

<ol class="alpha-list" start="1">
<li><p>a) 设置测试仪发射频率为被测设备支持频段的最低工作频率,关闭跳频;</p>
</li>
<li><p>b) 设置测试仪,同时向被测设备发送两个信号;</p>
</li>
<li><p>c) 有用信号:调制方式、信道带宽和 MCS编号(码率)见表34和表35,有效载荷字节长度为256字节,信道编码为Polar码,发射电平为灵敏度值+3dB;</p>
</li>
<li><p>d) 干扰信号:调制方式为 GFSK,带宽与有用信号相同,中心频率距离有用信号中心频率的偏移见表36和表37,发射电平见表36;</p>
</li>
<li><p>e) 测试仪测试初传误包率(PER);</p>
</li>
<li><p>f) 被测设备支持多个调制方式、MCS或者带宽,重复步骤a)~步骤c);</p>
</li>
<li><p>g) 设置测试仪发射频率为被测设备支持频段的中间工作频率和最高工作频率,重复步骤a)~步骤d);</p>
</li>
<li><p>h) 被测设备如果支持多个频段,则在其他频段内重复步骤a)~步骤e)。</p>
</li></ol>

:::

:::{div}
:class: standard-paragraph

<p>预期结果:低功耗通信系统在有效载荷字节长度为256字节,PSK 信道编码为Polar码,初传误包率(PER)不大于30%的情况下,接收机选择性应符合表36和表37。</p>

:::

:::{div}
:class: standard-paragraph

<p>当干扰信号中心频率距离有用信号中心频率偏移大于f2时,低功耗通信系统最多允许有5个杂散响应点,杂散响应点上的干扰信号位置不应是上述镜像频率和镜像频率的邻频。杂散响应点的干扰信号电平应满足-50dBm。</p>

:::

:::{div}
:class: standard-paragraph

<p>当表36和表37中的两个干扰信号对应同一个信道,则选择要求较松的那个干扰信号电平值。</p>

:::

:::{div}
:class: standard-paragraph

<p>假设有用信号带宽是$k\mathrm{MHz},$而镜像中心频率距离有用信号中心频率的偏移不等于$n\times k\mathrm{MHz},$则选择最接近镜像中心频率的$n\times k\mathrm{MHz}$作为镜像信道。</p>

:::

### 7.7.2.3 接收机干扰互调

:::{div}
:class: standard-paragraph

<p>测试目的:验证基于极化码的低功耗无线通信设备满足接收机干扰互调。</p>

:class: standard-paragraph

:::

:::{div}
:class: standard-list-block

<ol class="alpha-list" start="1">

</li>
<li><p>b) 设置信道带宽;</p>
</li>
<li><p>c) 设置测试仪,同时向被测设备发送三个信号;</p>
</li>
<li><p>d) 有用信号:调制方式 GFSK、有效载荷字节长度为256字节,发射电平为灵敏度值+6dB;</p>

</li>
<li><p>j) 按照表38或者表39调整支持的信道带宽,重复步骤b)~步骤e);</p>
</li>
<li><p>k) 设置测试仪发射频率为被测设备支持频段的中间工作频率和最高工作频率,重复步骤b)~步骤f);</p>
</li>
<li><p>l) 被测设备如果支持多个频段,则在其他频段内重复步骤a)~步骤g)。</p>
</li></ol>

:::

:::{div}
:class: standard-paragraph

<p>预期结果:在 GFSK 有效载荷字节长度为256字节时,初传误包率(PER)小于或等于30%的情况下,接收机干扰互调应符合表40。</p>
